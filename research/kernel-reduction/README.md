# kernel-reduction — EXPERIMENTAL research code

`[EXP]` This is a **research instrument**, not KnowledgeOS architecture. Nothing here is canonical.
Do not import it from production code.

Write-up: `docs/knowledgeos/research/kernel-reduction/` (start at `00-INDEX.md`).

```
python3 run_all.py        # regenerates results/*.json  (~30 s, no dependencies)
```

| Module | Role |
|---|---|
| `kr/atoms.py` | the 14-atom semantic vocabulary — the anti-smuggling device |
| `kr/carriers.py` | carrier kinds + derivation table (kinds derive from inputs+atoms, never from operator identity) |
| `kr/operators.py` | the 13 `C0` operator contracts + `Qualify` |
| `kr/reach.py` | `Reach(S)` least fixpoint over typed composition |
| `kr/capabilities.py` | C1–C25 and their requirements |
| `kr/scenarios.py` | the 16 deterministic scenarios |
| `kr/properties.py` | P1–P10 randomized property checks + the **vacuity audit** |
| `kr/variants.py` | 7 alternative models (V1–V7) for robustness |
| `kr/ablate.py` | LOO, pairwise, triples, atom-level, smuggling probes |
| `kr/infotheory.py` | data-processing-inequality and confounding experiments |

Deterministic given the seeds `[1, 7, 13, 101, 2718]`. The reach fixpoint is seed-independent.

**Note.** `results/variant_summary.json` and `results/smuggling_probes.json` are scratch outputs from
interactive runs; they are subsets of `variants.json` and `smuggling.json` and are not regenerated by
`run_all.py`.
