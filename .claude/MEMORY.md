- **Aggregate Protection Principle (APP — ARB, 2026-07-26, permanent governance):** *an aggregate exists to protect domain properties (finality, uniqueness, attribution, authenticity, integrity), not merely to encapsulate domain objects — objects are the vehicle; protected properties are the purpose.* Kills the anti-pattern "we have an entity, therefore we need an aggregate." - **Value Object Derivation Principle (VODP — ARB, 2026-07-26, permanent governance):** *a VO is justified only when it strengthens the expression, validation, or protection of accepted business invariants; convenience grouping/data packaging alone is insufficient.* Derivation: truth → invariant → concepts needed — never fields-that-travel-together. Event companion (artifact-№6 entry condition): *a Domain Event must trace to accepted invariants AND represent a business-significant occurrence* — litmus: would a domain expert describe it as something that happened in the business, regardless of implementation? Never method-executed→event.
- **Architectural Silence Principle (ASP — ARB, 2026-07-26, permanent governance):** *the absence of an architectural element is a decision, not a default — rejected candidates and deliberate non-events are recorded with rationale and reversal conditions.* "Why isn't there X?" must have an answer already on the record.
