## The findings that should survive into the next session

1. **Entitlement ≠ possession ≠ ability to cast.** Runtime-observed: a credential is **issued unarmed** (`codes.can_vote_now = false`) and armed **only** when the voter verifies the code. **Voter import does not grant the ability to vote; entitlement does not either.**
2. **Both voter-source modes converge at `ElectionMembership`.** `start()` reads only that — never `voter_source_strategy`, `uses_full_membership` or `Member`.
3. **The one-vote invariant lives on the credential, not the ballot** — `votes` has no `user_id` by anonymity design, so `codes UNIQUE(election_id,user_id)` + exhaustion carries it.
4. **`election_memberships.has_voted` is read by `start()` and written by nothing** — a legacy consumer, non-authoritative and inert.
5. **⚠️ `PBDIGIT-65` is NOT closed by the successful run.** The journey passed **only because the organisation page was visited first** to set tenant context. The correct statement is *"voting path verified under correctly established tenant context."*
