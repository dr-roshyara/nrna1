### Findings worth keeping
- **Opening voting:** `voting_locked = true` is set by `open_voting` (`transitionTo`, cache lock + transaction) or by the scheduled job (`enforceVotingLock`, no lock, no transaction). It is never reset. An election can go straight from SetupNomination to VotingActive.
- **Settings race:** the settings save can race with opening voting (no transaction, no row lock; the raw opening update doesn't bump `settings_version`).
- **Unused scaling table:** `NetworkThresholdInterpreter` has no runtime caller.
- **Partial audit:** System B refusals are recorded only in `election_security_events`, which no admin page shows.
- **Synchronous email:** `SendVoteSavingCode` imports `ShouldQueue` but doesn't implement it, so the email is sent synchronously inside the cast transaction while the network lock is held. **This is work outside PBDIGIT-286; I recommend a new backlog item (not yet created).**
