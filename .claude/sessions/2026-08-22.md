## §V — UM-23 · THREE ARCHITECTURAL GAPS — "NOT NEW LENSES, BUT THE MISSING ARCHITECTURAL CONSEQUENCES OF EXISTING DISCOVERIES" · NEW CANDIDATES H-KOS-CONTEXT-001 · H-KOS-NONINTERFERENCE-001 · H-KOS-CONTRADICTION-001 · RELATIONSHIP PRIMACY CONSTRAINT · FOUR-CATEGORY STRUCTURE · ANTI-PROLIFERATION DISCIPLINE

**V-2. Gap 1 — Semantic Context Boundary** (assessment: **strong candidate**; "the most important missing piece").
- The previous `Expression ≠ Meaning` is **incomplete**. The real relationship is **`Expression → Meaning → Context / Frame of Reference`** — *a representation cannot produce meaning by itself*.
- Example: "The system is secure" — same expression, different semantic frames (security / business / legal / operational contexts give different meanings).
- Collapse: `Representation → Meaning`; but the **deeper collapse is `Meaning → Universal Truth` without preserving context**. *(NEW forbidden collapse added to the vocabulary.)*
- **H-KOS-Context-001 — Semantic Frame Preservation** (Candidate, should-voice): *"KnowledgeOS should preserve the semantic frame in which a proposition is interpreted. A change of semantic frame should be represented as an explicit transformation, not as a silent reinterpretation."*
- Why "frame" not "domain": context can be business domain · temporal frame · legal jurisdiction · operational scenario · observer perspective.
- DDD connection: **Bounded Context → Semantic Boundary → Meaning Preservation**. Topology/sheaf analogy becomes useful here.

**V-3. Gap 2 — Non-Interference Between Dimensions** (assessment: **very strong**; "probably the operational expression of INV-KOS-001 Dimension Independence").
- Earlier "dimensions must not silently modify each other" was abstract; this makes it **testable**.
- Bad: `Evidence changed → Authority automatically lowered` — forbidden, because `Evidence state ≠ Authority state`.
- Correct: an **explicit governed relationship transition** — *"Authority changed because evidence X invalidated basis Y."* The relationship must be explicit.
- **H-KOS-NonInterference-001 — No Implicit Dimension Transitions** (Candidate, should-voice): *"KnowledgeOS should prevent implicit transitions between knowledge dimensions. A change in one dimension requires an explicit governed transformation before affecting another dimension."*
- Classification: **cross-dimensional invariant, NOT a new dimension.** May become part of **INV-KOS-001 during P5**.

**V-4. Gap 3 — Contradiction Tolerance** (assessment: **very important**; "where Zero contributes something unique").
- Most systems: `true / false`. Knowledge systems need: **`true / false / unknown / conflicted`**.
- The mistake: `Conflict → choose winner → store result` — **destroys epistemic history**.
- Correct: Evidence A + Evidence B → same Knowledge Identity → **state: `CONFLICTED`** — the system **preserves disagreement**.
- **H-KOS-Contradiction-001 — Conflict Preservation** (Candidate, should-voice): *"KnowledgeOS should preserve contradictory evidence and represent unresolved conflict explicitly rather than silently collapsing competing claims into a single asserted truth."*
- Key distinction: **Evidence conflict ≠ Knowledge failure.** *The system knows that it does not yet know.* Extends H-ZERO-001's state space: `UNKNOWN` → `CONFLICTED` (both preserved states, neither collapsed to FALSE).
