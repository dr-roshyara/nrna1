## Decisions (PO, this session)

- Policy OFF ≠ "cannot record evidence"; evidence operations independent of `admission.required`; only the status column is policy-conditional.
- "Identity verified" = evidence for one requirement, not final admission; no final-admission UI until a second requirement exists.
- `Code.has_voted` = authoritative process-completion fact, not authorization; consumed by atomic compare-and-set **before** the vote insert in one transaction; aggregate invariant (votes per election = consumed codes).
- Cast reason enum with `Allowed` the only success, forwarding the entitlement reasons; `AlreadyVotedPreCheck` is not authoritative.
- Constitutional invariant: participation knowledge without ballot knowledge.
- **A5 (computable `vote_hash`) = critical, priority #0**; characterize first (Phase 1, test K1–K9); no production change, no random-secret implementation, view-my-vote kept for now.
- No IP binding, no new persisted authorization field, no UUID change yet; no `git hash-object` / index manipulation for commits.
