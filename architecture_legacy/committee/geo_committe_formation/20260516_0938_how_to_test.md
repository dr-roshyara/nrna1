  If Something Doesn't Work

  Issue: Roles show as 'N/A' in table

  Check:
  1. Is the role column in database?
  psql production_db
  \d committee_member_projection
  1. Look for role column
  2. Did you run migrations?
  php artisan migrate

  Issue: API returns error "Missing tenant context"

  Check:
  1. Are you sending X-Tenant-Id header?
  2. Is the header value a valid UUID?

  Issue: "Invalid committee ID" error

  Check:
  1. Is the committee ID a ULID (26 chars), not UUID (36 chars)?
  2. Does the committee exist in database?

  Issue: Member doesn't appear after adding

  Check:
  1. Did you get 201 response?
  2. Check browser console for errors (F12)
  3. Refresh page to force reload
