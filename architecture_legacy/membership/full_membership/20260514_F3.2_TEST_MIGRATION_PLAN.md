### Pattern 4: Using Direct new Constructor Instead of Transition Methods (9 failures)

**Files affected:**
1. `tests/Unit/Constitutional/Membership/AcceptMemberTest.php` (3 failures)
2. `tests/Unit/Constitutional/Membership/MutationResistance/AggregateConsistency/MembershipLineageConsistencyTest.php` (5 failures)
3. Other aggregate tests

**Symptoms:**
- Tests create SUSPENDED/TERMINATED via `new CommitteeAssociation(..., status: SUSPENDED)` or direct constructor
- Constructor now validates: SUSPENDED/TERMINATED MUST have audit fields (actorId, transitionReason, transitionedAt)
- Direct construction violates invariants

**Root cause:**
Tests were written before constructor validation was added. Old pattern allowed any status in constructor; new pattern enforces strict rules.

**Fix (Deterministic):**

**For creating SUSPENDED episodes:**
```php
// WRONG (old pattern):
$suspended = new CommitteeAssociation(
    associationId: AssociationId::generate(),
    memberId: $member,
    committeeId: $committee,
    associationType: ApplicationReason::RESIDENCE,
    associatedAt: $now,
    status: MembershipStatus::SUSPENDED,
    // ← Missing actorId, transitionReason, transitionedAt
);

// RIGHT (new pattern):
$active = CommitteeAssociation::create($member, $committee, ApplicationReason::RESIDENCE, $now);
$suspended = $active->suspend('test-actor-uuid', 'Test suspension reason', $now);
```

**For creating TERMINATED episodes:**
```php
// WRONG (old pattern):
$terminated = new CommitteeAssociation(
    associationId: AssociationId::generate(),
    memberId: $member,
    committeeId: $committee,
    associationType: ApplicationReason::RESIDENCE,
    associatedAt: $now,
    status: MembershipStatus::TERMINATED,
    // ← Missing actorId, transitionReason, transitionedAt
);

// RIGHT (new pattern):
$active = CommitteeAssociation::create($member, $committee, ApplicationReason::RESIDENCE, $now);
$terminated = $active->terminate('test-actor-uuid', 'Test termination reason', $now);
```

**For using rehydrate() in tests:**
```php
// RIGHT (when simulating DB reconstruction):
$suspended = CommitteeAssociation::rehydrate(
    AssociationId::generate(),
    $memberId,
    $committeeId,
    ApplicationReason::RESIDENCE,
    $now,
    MembershipStatus::SUSPENDED,
    actorId: 'test-actor-uuid',
    transitionReason: 'Test reason',
    transitionedAt: $now,
);
```

**Tests affected:**
1. `AcceptMemberTest::committee_accepts_member_into_constitutional_relationship`
2. `AcceptMemberTest::each_constitutional_relationship_has_permanent_identity`
3. `AcceptMemberTest::constitutional_relationship_records_its_origin`
