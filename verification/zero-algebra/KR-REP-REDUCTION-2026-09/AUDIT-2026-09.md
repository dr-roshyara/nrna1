# ⚠️ FAIL 2.3 — the rank conventions are NOT invertible recodings

**Claim under audit** (`results.md` §5, in both my original and the review-supplied wording):
*the ascending and descending rank conventions are information-equivalent recodings.*

**The audit tested the assumed relation `desc = (n+1) − asc` instead of assuming it. It is false.**

```
minimal witness    R3 = [23000, 46000, 46000]
                   asc        = [1, 2, 3]
                   desc       = [3, 1, 2]
                   (n+1)−asc  = [3, 2, 1]      ← not equal
```

**Cause: the tie-break.** Ascending sorts by `(v, i)`, descending by `(−v, i)` — **both give the
earlier index the lower rank among equals.** So descending reverses the *values* but not the *tie
resolution*, and the two maps diverge whenever values tie.

**The decisive follow-up — do they at least induce the same partition?**

```
asc → desc well-defined ?   NO   21 369 violations
desc → asc well-defined ?   NO   20 873 violations
SAME PARTITION ?            NO
N_viol                      5 530 777 (asc)  vs  5 577 078 (desc)
|image|                     162  both
```

> ## `[NEG]` **They are NOT information-equivalent. The claim is withdrawn.**
>
> **What survives:** adequacy is **nearly** invariant (`Ĥ` 3.3937 vs 3.3965, `N_viol` within 0.8 %)
> while the fixed decoder's argmax accuracy swings **54 points**. **The adequacy/realization
> separation stands.**
>
> **What is withdrawn:** that the swing is *purely* a decoder effect. The partitions differ, so part
> of it is representational, and **this experiment cannot apportion it.**
>
> **And `DECISION-01` does NOT apply to this pair** — it governs invariance under *invertible*
> recodings, and invertibility is refuted.

### The finding that replaces it — sharper than the one it replaces

> **The tie-break rule — a choice adopted purely for determinism — is entangled with the ordering
> direction and thereby becomes EVIDENTIAL.**

**A presentational convention turned out to carry information.** This is a better instance of the
programme's own theme than the claim it replaces, and it was invisible until an audit tested an
assumption rather than restating it. **Design §0.2's rule — never assert equivalence without proving
it — is precisely what would have been breached.**

# ⚠️ FAIL 1.3 — the bootstrap CI does not bracket the point estimate

```
point estimate   Ĥ(Q|R4) = 0.42985
bootstrap CI     [0.36203 , 0.37621]        ← entirely BELOW the point
```

**Diagnosis.** Bootstrap resampling with replacement **duplicates cases**, which inflates fiber
occupancy and therefore *depresses* conditional entropy. On a sparse discrete support this shifts the
whole bootstrap distribution downward, so the interval is **not a valid coverage interval** for
`Ĥ(Q|R)`.

> `[DEFECT]` **The `H_hat_Q_given_R_ci95` values in `results/metrics.json` are NOT trustworthy as
> confidence intervals and must not be quoted as such.**
>
> **They were never used in `results.md`'s conclusions** — the reported evidence rests on `N_viol`
> (an exact combinatorial count, bias-free) and on the TRAIN/TEST agreement, neither of which depends
> on the bootstrap. **The defect is contained, but it is real.**
>
> **Remedy, not implemented here:** a bootstrap over *fibers* rather than cases, or an analytic
> variance for the plug-in estimator. **Recorded as required before any future report quotes an
> entropy CI.**
