### Audit 5: Semantic Regression Prevention (AST/Token Scanner)

To enforce the **Constitutional Vocabulary Doctrine**, we need a safeguard that breaks the CI pipeline if any developer inadvertently introduces authoritative terminology (`allow`, `deny`, `authorize`) inside purely evaluative classes (Policies, Overlays, or Coordinators).

This test tokenizes the codebase files and flags lexical leaks.

```php
<?php

namespace Tests\Unit\Models\Election;

use Tests\TestCase;

class SemanticVocabularyRegressionTest extends TestCase
{
    /**
     * @test
     * Covers Audit 5 (Semantic Regression)
     */
    public function it_enforces_semantic_discipline_by_banning_authoritative_lexemes_in_evaluative_domains()
    {
        // Target paths that must remain non-sovereign and purely descriptive
        $targetPaths = [
            app_path('Domain/Election/Policies'),
            app_path('Domain/Election/Overlays'),
        ];

        // Forbidden procedural/authoritative words that represent sovereignty leakage
        $forbiddenLexemes = ['allow', 'deny', 'authorize', 'grant', 'canVote', 'eligible'];
        $violations = [];

        foreach ($targetPaths as $path) {
            if (!is_dir($path)) continue;

            $directoryIterator = new \RecursiveDirectoryIterator($path);
            $iterator = new \RecursiveIteratorIterator($directoryIterator);
            $regex = new \RegexIterator($iterator, '/\.php$/i', \RecursiveRegexIterator::GET_MATCH);

            foreach ($regex as $file) {
                $filePath = $file[0];
                $content = file_get_contents($filePath);
                
                // Tokenize to scan method signatures, variables, and string literal contents safely
                $tokens = token_get_all($content);

                foreach ($tokens as $token) {
                    $tokenText = is_array($token) ? $token[1] : $token;
                    $normalizedText = strtolower($tokenText);

                    foreach ($forbiddenLexemes as $forbidden) {
                        if (str_contains($normalizedText, strtolower($forbidden))) {
                            // Check the token's lineage line number for the report
                            $line = is_array($token) ? $token[2] : 'Unknown';
                            $violations[] = "Sovereignty leak detected in [{$filePath}] on line {$line}: Found forbidden lexeme '{$tokenText}'";
                        }
                    }
                }
            }
        }

        // Output clean execution logs if violations exist
        if (!empty($violations)) {
            $report = implode("\n", $violations);
            $this->fail("CONSTITUTIONAL VOCABULARY DOCTRINE VIOLATED:\n" . $report);
        }

        $this->assertTrue(true);
    }
}
```
