# 8. CRITICAL DOMAIN RULE

The persistence layer must preserve the semantic distinction:

```text

decidedAt
recordedAt
seq
```

These are different clocks.

Do not collapse them into one timestamp.

In particular:

- `effectiveAt` = when the business fact is effective
- `decidedAt` = when the decision was made
- `recordedAt` = when the system learned/recorded it
- `seq` = aggregate recording order

The domain's temporal semantics must remain deterministic.

Facts are authoritative history.

# 10. CONCURRENCY — VERY IMPORTANT

Do not implement naïve optimistic locking such as:

```text
if version == expectedVersion:
    append
```

and assume this is sufficient.

The Principal Review already established that a stale accepted decision cannot simply be retried.

On a version conflict:

```text
reload current aggregate
        ↓
re-authorise
        ↓
re-run domain guards
        ↓
recompute G*
        ↓
accept/refuse against current state
        ↓
append only if still valid
```

Never reuse a stale `AcceptedDecision`.

Never reuse stale:

- consequences
- guards
- G*
- aggregate state

after a concurrency conflict.
