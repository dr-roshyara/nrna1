Plaintext verification codes are written to logs (VE-06). |
| **Decisions (PO, 2026-10-05)** | demo election on the real code routes → **refused, fail closed (403)** · logging cleanup = **plaintext code values only** · election types: only `real` / `demo` exist (blueprint §1) |
