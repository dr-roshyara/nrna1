## Gap taxonomy (per review-chair guidance)

- **THEORY gap** — possibly-missing/mis-bounded governance *theory* (families, recursion, legitimacy structure). Resolved by **discovery**.
- **SEMANTIC gap** — one term, several meanings. Resolved by **Inventory** (`Round40-06`) → later Ontology. *Recorded, not defined.*
- **COVERAGE gap** — a real entity/stage the model does not yet include. Resolved by **extending coverage** at discovery.

## Generic closure template (every RQ inherits, unless overridden)

A family hypothesis **closes as `Supported`** only if it shows, under hostile replication: **(i)** an independent capability, **(ii)** independent mechanisms, **(iii)** independent actors, **(iv)** independent failure modes, **(v)** it survives a refutation attempt. Fewer than all five → `Partially supported` / `Narrowed`; none → `Rejected`.
