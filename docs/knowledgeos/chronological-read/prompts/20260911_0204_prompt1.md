# 11. DUPLICATES

`NEAR DUPLICATE`

`PARTIAL OVERLAP`

`SAME-LINEAGE REPETITION`

`INDEPENDENT SOURCE`

A duplicated definition remains historical evidence of repetition, but it must not be counted as independent confirmation.
