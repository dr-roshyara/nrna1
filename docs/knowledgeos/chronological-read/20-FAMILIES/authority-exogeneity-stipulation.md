- **[ANALYSIS/CORRECTION]** [S1691]: Finding ON-1: the corpus does break the 7-node cycle via Step 187's stipulation that authority is exogenous (Authority subset Actor x Action x Context x Time, with no Assertion in it), but this is classified as a normative decision, not a mathematical result -- the theory is acyclic if and only if authority is exogenous, and that exogeneity is declared rather than derived, making every theorem about K conditional on an unspecified external authority oracle; moreover Step 187's own field B (the recorded normative/provenance basis of an authority state) is exactly the artefact that re-enters the cycle at the representational level, so semantic closure and governance closure are not both achieved.
- **[ARGUMENT/CORRECTION]** [S1707]: Finding GR-3: directly answers the mandate's four-way classification question -- the constitutional layer (authority as exogenous) is NOT mathematically necessary (a self-referential/fixed-point authority model is consistent, merely harder), IS architecturally necessary (without it the dependency graph is cyclic, per 03-FOUNDATIONAL-ONTOLOGY.md ON-1), is empirically only partially observed and the observation cuts against the stipulation (see GR-4/GR-5), and is fundamentally NORMATIVE -- Step 187 decides authority is exogenous and presents that decision as a finding rather than labelling it as a decision; every theorem about K is therefore conditional on an unspecified external authority oracle, consistent with Step 266 listing Authority as class C.
- **[ARGUMENT/RETRACTION]** [S1761]: The regress Policy -> Authorization -> Authority -> Constitutional authority terminates via a two-level model: a frozen constitutional layer inside the system (EKP constitution, ADR+ARB amendment), anchored by reference to human acts outside it (humanActRef). D-2 is declared derived and retired; the first-order register's G-38 (claimed theory/implementation contradiction) is withdrawn.
