## Rationale
The problem this hypothesis addresses is how to give "knowledge gap" a measurable form: S2309 introduces an Ideal Knowledge State S*_t(O) versus an Actual Measured Knowledge State ŝ_t(O), proposing their distance D(S*_t, ŝ_t) as knowledge/knowledge-gap, but immediately flags the unresolved problem that if the true ideal state is literally unknowable, the distance cannot actually be computed and needs a reference/expected-state proxy [S2309]. The same source connects this formulation to an earlier "2B-5 Lord/Omega investigation," arguing that Omega-a's ideal-reference responsibility was transformed into a bounded, Knower-owned Ideal State and then into the Epistemic Contract, and poses as an open research question whether Omega-b's unboundedness is actually mathematically required, introducing "Ideal State ≠ complete Knowledge Space" as the key idea that may make unboundedness unnecessary [S2309]. S2309 further proposes this as a "candidate unifying structure, not yet a completed theory" that could connect several previously separate corpus strands (Phase 1, Phase 2, KST, Pritchard, Zero, Knower, Evidence, Kernel) while explicitly warning against collapsing them prematurely [S2309]. Later rows repeatedly correct and refine the formula: S2310 restates the Ideal State as K_t*=I(G,C,S,t), explicitly "not absolute/complete truth," with sufficiency determined by the Knower who owns the epistemic frame, and separately distinguishes Z_t=0 (contract satisfied) from K_t being complete/all-possible-knowledge [S2310]. S2316 sharpens this further by distinguishing two previously-conflated gaps — epistemic uncertainty (how certain we are a measurement is correct) versus state discrepancy (how far the measured state is from the ideal) — illustrated with a worked example (high confidence + large discrepancy = highly certain the system is wrong, versus moderate confidence + unknown discrepancy = we don't know if it's wrong) [S2316]. S2317 decomposes "Zero" into three named gaps (Z_truth, Z_information, Z_contract) to preserve existing corpus distinctions [S2317]. S2321 argues the generic formula G_t=D(P_t,P*) is too generic and requires seven explicit specifications before it is meaningful [S2321]. S2323 splits the gap into an optional probabilistic-uncertainty gap and a primary requirement gap (the Ideal-State requirements K_t fails to sufficiently determine) [S2323]. S2325 uses the sufficient-statistic criterion to argue K_t need not preserve all information, only what is relevant to its declared purpose [S2325]. S2326 makes the Ideal State inquiry-relative (I_Q=IdealState(Q)) rather than free-floating [S2326]. Finally S2356 identifies a still-missing derivation — I_t is asserted to arise from the Knower's purpose/goal and Epistemic Contract but was never formally constructed as (A,G,EC,O)→I_t — and argues the whole research programme has been looking for the missing piece "one level too late," proposing the priority should shift from "what is D(K_t,I_t)?" to the earlier construction questions of how K_t itself is generated from observations [S2356].
