## Rationale
Walks 14 core primitives (Receive Intent, Structural Parse, Semantic Reconstruction, Dimension Discovery, Acquire Evidence, Create Observation, Create Assertion, Coherence Checking, Conflict Detection, Gap Detection, Discrepancy, Distance, Sārathi Navigation, Lord) through a computability check, each judged computable but with varying determinism. Notably SemanticParse->CandidateMeaning, not SemanticParse->Truth (semantic parsing is probabilistic, not a deterministic oracle), and Candidate ≠ Knowledge for Lord's outputs. Coherence/Conflict/Gap detection are judged deterministic PROVIDED the relevant rules/Ideal-State are made explicit (e.g. conflict example: two Nexus-version assertions on the same entity/dimension/context/validity interval trigger a deterministic 'potential contradiction' flag, without the system knowing which is true) [S0821].

Classifies theory maturity into three levels: L1 Conceptual definition (know what a thing means, mostly resolved), L2 Mathematical specification (can define inputs/outputs/invariants, mostly resolved), L3 Computable semantics (know an executable algorithm producing the result, NOT completely resolved) — the theory has reached L2 for most of the architecture but not L3 everywhere [S0839]. Names eight operators still requiring computational closure, each individually diagnosed: Observe(x,C) (what makes a database row / human statement / LLM output / sensor reading count as an observation, still unformalized); semantic reconstruction f_semantic:Text×Context->SemanticRepresentation (unspecified, needed to detect when a question is insufficiently specified and generate clarification); DiscoverDimensions (needs an acceptance criterion for when a candidate dimension is sufficiently justified to enter the Knowledge Model); AssessEvidence(E,A,C)->(Support,Uncertainty,Validity) (needs to account for source reliability, relevance, independence, corroboration, contradiction, temporal validity, provenance, having rejected Support=Probability); DetectConflict (ConflictDetection=RuleEvaluation, needing SameSubject∧SameDimension∧CompatibleScope∧TemporalOverlap∧IncompatibleValues, with the rule language/semantics unspecified); EvaluateCoherence (Coherent(K)=W∧L∧E∧T∧C is defined but each predicate like Logical(K) or Contextual(K) still needs an executable validator); ConstructIdeal (needs an Ideal-State authority model — who determines what is desired: Human/Constitution/Policy/Domain rules/Purpose/Manifesto/ADR/System configuration/LLM proposal/Negotiation — otherwise KnowledgeOS could manufacture an unauthorized 'ideal'); MeasureDiscrepancy (Δ≠necessarily one scalar is settled, but numeric d(x,y)=|x-y| vs categorical d(Confirmed,Observed) vs understanding-distance d(U_1,U_2) may not even be a metric, favoring 'Typed Discrepancy' over one universal distance function) [S0839].

Nine-row closure-status table: Input->Artifact (Closed), Artifact->SourceObservation (Closed), SourceObservation->Interpretation (architecturally closed, interpretation can be ambiguous), Interpretation->CandidateProposition (Closed), CandidateProposition->Assertion (closed conceptually, admission policy remains configurable), Assertion->KnowledgeState (Closed), Assertion<->Evidence (needs formal evidence model), Assertion<->Conflict (needs conflict-rule formalization), Assertion<->Gap (needs gap-detector formalization). Names 'Evidence' as the next major closure target: what counts as evidence, how it relates to an assertion, how it can be computationally evaluated without reducing epistemic reasoning to an arbitrary confidence score, to be tested against direct measurement/DB output/document statement/human testimony/expert opinion/LLM output/derived calculation/multiple independent sources/circular sources/stale sources/contradictory sources, aiming to make Assess(A,E,Π,C)->Σ_A 'computationally realizable rather than merely philosophical' [S0846].

Lists operations a normal modern PC can execute: GraphTraversal, SchemaValidation, TypeChecking, ProvenanceChecking, HashVerification, EventProcessing, RuleEvaluation, ModerateStatisticalAnalysis -- 'not inherently distributed'. Gives example complexity O(V+E) for graph traversal (e.g. V=1,000,000, E=5,000,000, manageable on a single machine with engineering optimization) and O(log n) or near-constant indexed lookups (e.g. find EvidenceByClaimId).
