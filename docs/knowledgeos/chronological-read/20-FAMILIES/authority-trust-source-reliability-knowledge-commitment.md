## Rationale
Frames the central problem this object addresses: when KnowledgeOS holds evidence for incompatible propositions, the answer must not be "pick the most trustworthy source" — authority, evidential support, reliability, applicability, independence, and epistemic commitment need to be kept as separate dimensions rather than collapsed into one trust score [S0876]. The object closes a gap left by naive single-scalar trust models: it rejects source-voting and rejects a linear weighted sum W=w1A+w2R+w3F as the *fundamental* model (usable only as a policy-level approximation) [S0876], rejects treating a numeric acceptance threshold as "mathematics of truth" rather than governance policy [S0876], and rejects treating a high Bayesian posterior as automatic operational permission to act (EpistemicProbability ≠ OperationalPermission) [S0876]. It explicitly positions LLM output as a zero-intrinsic-authority `Candidate` that must pass through evidence assessment before becoming governed knowledge, which the object's own closing restatement frames as a defining KnowledgeOS architectural property rather than mere caution [S0876]. The object hands off open uncertainty-representation work to Step 20 [S0876], and is later reused (S0898) to motivate a context-dependent partial order over authority sources, since precedence among legal/policy/architecture/ADR/runbook sources depends on what kind of proposition is being evaluated [S0898].
