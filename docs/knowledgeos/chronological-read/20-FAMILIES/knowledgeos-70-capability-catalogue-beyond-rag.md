## Rationale

Argues that an implemented KnowledgeOS would function as a controlled epistemic operating layer between raw information and operational decisions, not merely a better knowledge graph or RAG-with-metadata; a conventional information system approximates Data->Information->Application and conventional RAG approximates Documents->Retrieval->Generation, while KnowledgeOS aims at a 13-stage Reality->Observation->Information->Representation->Proposition->Evidence->Warrant->Knowledge->Determination->Decision->Authorization->Action->Outcome pipeline where each transition has explicit semantics [S2834].
