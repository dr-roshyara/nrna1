## Rationale
Names the Verification Gate as the architectural keystone: the only admission path into knowledge (claim + authentic evidence + acquisition method + inference rule + reasoning path), through which every engine, LLM, and source must pass, realizing Articles 1, 6, 7, 9, 10, and 11 simultaneously [S0243]. Places the LLM in the ENGINE layer as a governed generation mechanism at the mouth of the Verification Gate; it is architecturally incapable of the two things the Constitution reserves for the kernel — persistent epistemic identity (external Identity Service) and historical belief evolution (external History Service) — 'it may propose; it may never possess.' [S0243]. HPA ratification verdict on Constitution v1.0: the Kernel/Engine separation prevents four category confusions (graph database ≠ knowledge · vector embedding ≠ identity · LLM reasoning ≠ justification · workflow state ≠ truth · ontology ≠ reality); the eleven laws are anti-corruption constraints, not features [S0244].
