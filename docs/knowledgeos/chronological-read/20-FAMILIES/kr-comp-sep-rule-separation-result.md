## Rationale
Argues the majority-vs-intraframe-only choice is genuinely normative/semantic (aggregate across frames vs refuse cross-frame aggregation) -- an experiment can show the alternatives behave differently but cannot establish what the system ought to mean by cross-frame divergence, making [DECISION] the appropriate classification. [S2502] Explains precisely why the commissioned shape fails to separate: internal conflict is absorbing under both majority and intraframe-only (both short-circuit to (1,1) whenever any frame conflicts internally), so adding internal conflict to a witness destroys the separation rather than creating it -- the two rules differ only in behavior when NO frame conflicts internally, exactly the case the commissioned shape excludes by construction. [S2503] Works out concretely, for C7, that whether majority violates it is contingent on DECISION-02: if a frame is merely a representational partition (finer clock resolution on the same evidence), the C7 variation is non-evidential and majority violates it; if a frame is a semantic context (frame individuation is part of the evidence), the variation is evidential and majority does not violate it -- making deferral of majority-vs-intraframe-only necessary, not merely prudent. [S2505] Argues the C7 failure is not a fixable implementation defect but constitutive: since a frame is created by any difference in a frame feature, frame count is inherently an artefact of recording resolution, and any rule that counts frames inherits that artefact -- the majority cost is the price of the 'aggregate' option itself, not a flaw in one implementation of it; cross-frame aggregation cannot exist without frame individuation becoming an input. [S2507] Draws the crux-of-the-decision parallel: last-wins was eliminated for depending on something not part of the evidence (enumeration order via C6); C7 shows majority depends on something equally not part of the evidence (timestamp resolution) -- if C6 is accepted as a criterion, C7 is a criterion of the same kind, and accepting one while rejecting the other requires a stated reason; the majority-vs-intraframe-only decision is therefore coupled to whether the programme accepts 'invariance under non-evidential variation' as a class of criterion at all (both C6 and C7 unratified [PROP]). [S2507] Notes that if the programme judges determination-blocking unacceptable, majority becomes the coherent choice provided it openly accepts that verdicts then depend on timestamp resolution -- an honest cost-acceptance framing rather than a resolution. [S2507] Details Option A (frame is a representational partition): commits to evidence-chunking being a recording artefact, not a world-fact; under this option majority violates DECISION-01 by counting representational boundaries, making representation granularity semantically observable -- a stronger objection than 'majority assumes equal frame weights', since a quantity with no evidential status becomes visible in the verdict; leaves intraframe-only or a third operator as what remains. [S2508] Details Option B (frame is a semantic context): commits to frame individuation being part of evidential content; under this option majority does not violate C7 (the refinement test then compares genuinely different evidential situations), but Option B does not thereby license majority -- it only removes the C7 objection; majority still owes a stated basis for equal per-frame weighting w(fi)=1, since frame count ≠ evidential weight unless explicitly decided. [S2508] Warns explicitly against choosing intraframe-only merely because majority violates C7 -- that would convert 'aggregation is representation-sensitive' into 'aggregation is forbidden', an implication that does not follow; this is the same over-inference later formally withdrawn in Z-DECISION §8. [S2508]
