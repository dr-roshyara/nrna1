- (ANALYSIS) Transformation->K_{t+1} is classified NECESSARY for a dynamic theory of knowledge state, even though (per the Step 240 finding) the exact signature of delta_K remains unresolved -- the dependency's necessity and the function's canonicity are separable questions. [S1588]
- (ANALYSIS) Provenance/lineage (lambda) -> Knowledge is classified NECESSARY FOR TRACEABLE KNOWLEDGEOS KNOWLEDGE specifically, motivated by the historical finding that provenance is the only candidate invariant surviving all reconstructed phases -- but not mathematically necessary for all possible knowledge in general. [S1588]
- (ANALYSIS) The 5-component kernel is shown to be internally heterogeneous, not five objects of the same semantic category: G is representation, sigma is epistemic qualification, theta is temporal qualification, lambda is provenance/lineage, pi is governance constraint -- calling all five 'primitives' requires justification the corpus does not supply. [S1588]
- (ANALYSIS) Independent circularity test 1 (Validation<->Knowledge): not automatically circular -- classified BENIGN/WELL-FOUNDED provided V:K->{true,false} evaluates an already-defined state and does not use its own result as input. [S1588]
- (ANALYSIS) Independent circularity test 2 (Evidence<->Knowledge): Evidence->K and K->Evidence (via the knowledge state determining which evidence is relevant/requested) is resolved as K_t->Question->EvidenceRequest->Evidence->K_{t+1}, a TEMPORAL FEEDBACK loop across time, NOT a circular definition. [S1588]
- (ANALYSIS/CORRECTION) A significant result: the 5-component kernel's components appear to be CROSS-CUTTING DIMENSIONS characterizing knowledge from several directions (relational structure, epistemic status, temporal validity, provenance, governance constraint), not a complete causal chain or complete state-transition system -- Content, Observation/Input, Transformation and decision semantics are still needed elsewhere in the meta-model. [S1588]
