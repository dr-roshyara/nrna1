## Rationale
Applies the three-layer memory model to an AI agent session example: a later session's agent (Agent t+1) need not remember an earlier session's agent (Agent t) state, but KnowledgeOS can preserve History(Agent) outside the ephemeral per-session agent memory, so the agent does not have to carry its entire history itself. [S1067] Argues that a determination D1 must retain its actor, context, evidence, method, timestamp and provenance even after the originating session disappears, because without this it degrades from governed knowledge into a mere unattributed 'historical epistemic artifact' ('something the AI once said'); this is offered as the reason provenance must be external to transient agent state. [S1067] The Bhagavad Gita research track is classified as external research, not an architecture source. Correct method: Gita text -> philosophical principle -> abstract structural pattern -> KnowledgeOS question -> mathematical/architectural test -> possible hypothesis; forbidden shortcuts are 'Gita character -> KnowledgeOS object' and 'philosophical idea -> equation -> architecture'. Current research covers Chapters 1-4, with candidate hypotheses including Continuity != Memory != Observation and Knowledge != Wisdom != Action ('Wisdom is active discernment concerning what should be done and what should not be done'), explicitly framed as research hypotheses only. DeepSeek's Gita document is separately classified EXTERNAL RESEARCH / NON-AUTHORITATIVE / CONCEPTUAL LENSES / HYPOTHESES, and its unsupported quantitative equations are not accepted as KnowledgeOS derivations. [S1348]
