## Rationale
Derives the substrate each regime individually requires: Bayesian estimation needs S_Bayes=(state space, prior P(S), likelihood, Bayes update) and does not require a pre-defined KST structure K, working with any state space/likelihood; Dempster-Shafer needs S_DS=(frame of discernment Theta, mass function m, Dempster's combination) with no single correct structure; non-monotonic logic needs S_NML=(language, default rules, exceptions, preferential entailment); argumentation theory needs S_Arg=(arguments, attack relations, semantics), not a state space at all. [S0680] Across KST/Bayesian/Dempster-Shafer/non-monotonic/argumentation, five elements seem necessary in every regime: a domain, evidence, time, source, and uncertainty; the intersection yields S_min=(D,E_{<=t},Source,Time,Uncertainty) -- explicitly described as not a state, structure, or representation, but the substrate from which any of those can be reconstructed. [S0680] Brachman & Levesque supply the corpus's first technical argument for Kernel minimality: representation is finite while belief is unbounded/infinite, and reasoning is what bridges that gap; a Kernel attempting to hold the closure of belief would be attempting to represent the infinite, which is why the split (preserve finite structure / perform reasoning elsewhere) is necessary rather than merely tidy. [S0698] Places the current research maturity on a 12-stage diagram (Research -> Phenomenon -> Dimensions/State -> Observation/Evidence -> Extraction/Determination -> Knowledge -> Time-change/Uncertainty -> Knowledge trajectory -> What must be preserved -> Kernel admission -> Architecture), self-assessed as sitting around the Knowledge->trajectory->preservation boundary, not yet at architecture. Reduces everything to one biggest unresolved question: given the complete state may have potentially infinite dimensions, how can an observer construct, evaluate, and continuously revise a knowledge state without knowing the dimensions that remain undiscovered -- and commits to challenging the dialogue's own model with external research rather than assuming every prior conclusion is correct. [S0703]
