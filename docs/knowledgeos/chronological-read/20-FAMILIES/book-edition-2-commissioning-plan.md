The plan's executive recommendation: commission Edition 2 as a HYBRID full-depth technical book (form D -- monograph structure with mandatory research-status marking, rejecting pure-monograph form A, engineering-reference form B, and pure-research form C), built atop the frozen/accepted Edition 1 (its 25 essays become chapter abstracts); scope Option A -- commission Parts III/II/IV now (sources already deep) while kernel full-read research runs as a parallel commissioned track gating Part I.3's expansion. [S1239] Edition 1 is reassessed: it merely names six concept clusters without block-form definitions (M49, BC_Governance, 8 K_t primitives, 4 Zero arms, 7 EXP-01 properties, 6 DC components), derives nothing (five derivations are reproducible from sources but none is reproduced), and cites evidence only in evidence-maps rather than prose; explicitly 'Edition 1 is not reinterpreted as defective -- it is the correct artifact of its ratified specification, and it is the wrong artifact for the full-depth goal.' [S1239] The programme's authoritative gate chain, as of this handover, runs: historical corpus -> 3B falsification -> GN-19 -> v0.2 AUTHORIZED -> 3C conformance COMPLETE -> GN-24 -> Brainstorming Archaeology COMPLETE -> Final Architecture synthesis -> GN-31 -> FINAL ARCHITECTURE RATIFIED -> GN-34 -> BOOK ARCHITECTURE RATIFIED -> GN-35 -> BOOK PRODUCTION AUTHORIZED -> Edition 1 produced -> GN-41 -> EDITION 1 ACCEPTED/FROZEN -> GN-42 -> EDITION 2 commissioned. Frozen authorities recorded: canonical architecture model/canonical-architecture-v0.2.md (checksum e928af571f44707867034ae0b7a7ade9), Final Architecture (GN-31), Book Architecture (GN-34), Edition-2 amendment (GN-42), Edition 1 accepted and frozen. [S1348] Part III (10/10 chapters: III.1 The Five Layers through III.10 The Invariants, ~29,000+ words) is complete and the programme is now at a 'PART III METHOD & QUALITY GATE' -- a producer-side check plus an independent fresh-context review determining whether the Edition-2 method is adequate for the rest of the book, with expected gate verdicts PASSES / PASSES WITH CORRECTIONS REQUIRED / FAILS and method assessments UNCHANGED / ADJUSTED WITH NAMED ADJUSTMENTS / NOT ADEQUATE. 'Validated' is explicitly forbidden as a status word; prefer 'method adequate / method sound with qualifications / method requires adjustment'. Parts II, IV, and I must not start before this gate completes. [S1348] Edition-2 book-writing methodology for a mentor role: before writing a chapter, ask what the reader must learn, the chapter's boundary, its authoritative sources, existing mathematical/formal material, what is established vs open, which findings affect the chapter, and which interfaces with previous chapters must stay consistent. During writing, follow the chain CLAIM -> SOURCE -> GRADE -> FORMAL MEANING -> ARCHITECTURAL MEANING -> EXAMPLE -> LIMITATION. After writing, run provenance, terminology, mathematical-strength, architecture-boundary, open-question, running-example, relation-status, no-hindsight, and forbidden-status-vocabulary checks, rerun after any substantive edit. When a difficult concept is encountered, the only permitted choices are: EXPLAIN EXISTING MODEL, EXPOSE OPEN QUESTION, REPORT FINDING, or REQUEST GOVERNANCE -- never 'INVENT A BETTER ARCHITECTURE' without an explicit research/governance commission.
