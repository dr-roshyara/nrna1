## Sources (how this label entered the ledger)
- **OBJECT-INDEX** (batch B0033, scope THEORY-LEVEL): Redefines the Kernel mathematically as 'Invariant Enforcement Boundary': a transition is in AllowedTransitions only if Preconditions(Transition)=True -- stronger than 'the Kernel stores knowledge', and explicitly stronger than a database abstraction. Enumerates what the Kernel still does NOT do: compute P(H|E) and declare truth, determine moral/organizational authority, interpret domain meaning, or judge whether an inference is semantically reasonable -- it only verifies the declared transition contract is satisfied. Formalizes two distinct functions: a semantic evaluator f_sem(E,p)->Assessment (intelligent, domain-specific, can be AI) and a transition validator f_val(Assessment,r)->Allowed/Rejected (deterministic), giving the architecture pattern 'probabilistic reasoning -> deterministic admission gate' -- rated potentially one of the strongest foundations of the KnowledgeOS architecture.
