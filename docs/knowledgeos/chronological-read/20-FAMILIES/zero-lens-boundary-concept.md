## Rationale
Combining the existing Zero Lens formulation ZL(K_t,I_t,Gamma_t,L_t) -> B_t with the metaphor's Boundary->Tension->Inquiry->Interaction->Reconciliation->Closure->Knowledge chain shows the KnowledgeOS epistemic process is cyclic: K_t -Zero-> B_t -Inquiry-> Interaction -?-> K_{t+1} -> Zero(K_{t+1}), i.e. a new state does not permanently escape Zero but becomes the subject of another boundary examination. [S2435] Rejects importing arithmetic cancellation (+a+(-a)=0) into KnowledgeOS as epistemic closure, because numeric zero can correspond to radically different epistemic situations (genuinely reconciled evidence, contradiction, insufficient evidence, incomparable evidence, dependent evidence, different temporal contexts); therefore Zero = Boundary Lens is retained over Zero = Balance. [S2435] Claims ZeroLens(K_t)=P_Unknown(K_t) (projection onto an unknown subspace) formally 'solves' the Zero problem, and that evidence-independence via inner product 'solves' the circular-sources problem (G-09), the independence-factor problem (G-21), and the aggregation problem -- these solved-problem claims are subsequently contradicted by S2476's finding that the inner-product structure actually collapses Unknown/Absent/NotAssessed/Contradiction onto the same zero vector, and that orthogonality does not legitimately represent independence. [S2477] Adds an explicit R_req-to-subsystem integration-usage mapping not spelled out this concretely elsewhere in the batch: for Contr, D-1.1 triggers isolation detection, D-3.1 feeds the polarity graph, D-4.1 drives the contradiction-management state machine; for Zero, four specific conditions are required (no Contradictory/Underdetermined per D-1.1, all-Current per D-2.1, a Justification Mode present per D-1.2 for every proposition, no Dual evidence direction per D-3.1); for Evaluation adequacy, D-1.1/D-1.2/D-2.1/D-3.1/D-4.2 must all be preserved. [S2572]
