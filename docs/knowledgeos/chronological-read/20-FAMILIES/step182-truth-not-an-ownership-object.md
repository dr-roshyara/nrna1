## Sources (how this label entered the ledger)
- **OBJECT-INDEX** (batch B0033, scope THEORY-LEVEL): Step 182's foundational move: given a fact like 'the production server runs RHEL 9.8', no single actor (engineer, infrastructure team, server, CMDB, architecture repository) literally 'owns' the truth; instead actors possess responsibility for establishing it, authority to determine it, responsibility for maintaining it, or accountability for acting on it -- 'truth itself is not an organizational ownership object'; organizations own determinations, records, decisions, responsibilities, and governance processes, never truth itself. Also deconstructs 'single source of truth' into three incompatible meanings (one place stores the current value; one system is authoritative for a particular fact; one system contains all organizational knowledge), judging only the second generally defensible.
