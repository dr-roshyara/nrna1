## Rationale
Summarizes the classical justified-true-belief (JTB) analysis of knowledge, the Gettier problem (true+justified belief can be true merely by luck), and reliabilism's answer (the belief-forming process must be reliably truth-conducive), as external epistemological grounding for the framework that follows.
