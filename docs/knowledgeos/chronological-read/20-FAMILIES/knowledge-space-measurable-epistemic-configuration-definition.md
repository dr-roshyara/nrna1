## Rationale
Explains the kernel-reduction experiment's 13-vs-8 instability as a direct consequence of attempting to answer 'what is the smallest operator set' before fixing X (carrier), A (sigma-field), =_sem (semantic equivalence), K (Knowledge-State space), D (gap operator) and T (transition); prescribes a corrected nine-stage research order: Epistemic observables -> X -> A -> K_t -> semantic equivalence -> adequacy -> transition -> invariants -> kernel minimality [S2369].

Worked example connecting the regime architecture to the earlier measure-theoretic apparatus: a probabilistic regime may compute P(p|F_t)=0.93 as a projection over the core, but this NEVER changes the core relation Knows(a,p,c,t) into that number -- giving PosteriorAssessment != KnowledgeAttribution as one of the strongest architectural invariants reached so far [S2371].
