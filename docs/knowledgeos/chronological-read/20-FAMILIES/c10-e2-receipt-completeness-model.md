## Rationale
The four-part ownership model (semantic/data/invariant/authority owner) is justified by testing it against orthogonality (fields diverge and converge across the same dimension set), necessity (without the split 'C-10 stores it' collapses into 'C-10 owns it'), and sufficiency (no field required a fifth dimension; NONE is a legal, informative authority-owner value). [S0122] An actor_reference field is forbidden as C-10-owned because it would invite the identity-binding inference D1 disallows, would import C-5 (identity attestation, an open capability) into C-10, and because self-declared identity is only evidential (INV-ATTR-1/INV-ATTR-2); if the estate ever needs 'who acknowledged', it must arrive through C-5 attestation or as external_correlation_reference content, never as a C-10-owned field. [S0122] A semantic-inflation discovery over five at-risk fields (receipt_id, issuer, actor_reference, session_reference, external_correlation_reference) each tested against a five-way misreading test (AUTHORITY/IDENTITY/APPLICABILITY/COMPLIANCE/VERIFICATION) with a recorded prohibition per field, e.g. 'a receipt exists, therefore the act was warranted' is explicitly forbidden. [S0122] Four verified divergences between the delivered, AMD6-corrected E2 and a re-sent assignment: (1) field renamed to drop 'applicability' vs reverting to 'applicability_reference'; (2) field classification vocabulary present vs absent; (3) D1 asymmetry preserved vs restated symmetrically (a weaker delivery claim); (4) seven vs six anti-corruption rules. Restoring 'applicability' to a field name is flagged as reintroducing exactly the ownership implication the anti-corruption rule forbids. [S0123]
