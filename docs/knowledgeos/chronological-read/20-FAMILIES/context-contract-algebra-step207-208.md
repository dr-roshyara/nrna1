## Rationale
Answers Step 207's central open question definitively: if each contract in a chain C1:E->A, C2:A->G, C3:G->D is individually valid, the composed chain C3 compose C2 compose C1 is not automatically valid, because each context may deliberately or accidentally discard information the next context requires; names this non-compositionality as a key architectural result -- semantic transformations may be locally valid but globally invalid -- explaining why a distributed architecture can produce wrong decisions even when every individual service appears correct.
