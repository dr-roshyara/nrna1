## Rationale

Names the factivity finding the programme's first genuinely negative structural theorem about its own definitions: sharp in that it does not claim the theory is wrong overall, only that exactly two specific clauses (DEF-1 factivity and the v1.1 attribution equation) cannot both hold, with three named repairs available elsewhere in the artifact set. [S2383] Identifies P11 (factivity) as the ONLY fully oracle-independent property among all 20 tested: its evaluator reads World.truth, structurally inaccessible to any agent transition, whereas every other property merely compares the agent's own state against itself under a theory-supplied definition -- explaining why P11's failure carries far more evidentiary weight than any pass among the other 19. [S2384] Identifies Scenario D as the methodologically strongest of the ten scenarios: the only one holding reality, observation, evidence, AND inquiry all fixed while varying a single theory object (S^epi), cleanly isolating epistemic standards and showing them doing real work rather than merely decorating the model. [S2385] States the first of two design decisions making the v1.1 simulation's results meaningful: unlike the prior KR-2026-09-01 kernel-reduction lane (which reasoned only about reachability of carrier kinds, whose own THM-9 established Reachability != Adequacy), this simulator carries actual instance-level CONTENT (tokens, readings, weights, sources, provenance) -- only this design choice makes factivity, dependence, ambiguity and fabrication testable at all. [S2387] States the second design decision: oracle independence is enforced STRUCTURALLY, not by convention -- World.truth is read only by the evaluator, verified by a static audit greping every agent-side module for any access, with zero hits found -- this structural guarantee is precisely what makes P11 (factivity) an empirical test rather than a mere definitional restatement, and is also directly why factivity was found to fail (the agent genuinely has no path to truth).
