## Rationale
Buddhi reframed as an operator-selection mechanism B(K_t,O_t)->which transformation (from {E,R,C,X,Q,Z,...}) is appropriate, rather than another knowledge dimension -- 'the Kernel is not merely storing knowledge, it continuously discriminates what epistemic operation should happen next'. Yoga reframed as operator composition Y = O_n o ... o O_1, e.g. Y_purify = Q o C o R o E o Z (detect absence -> discover dimension -> refine/correct -> qualify -> new state) vs Y_conflict = Q o X o C. Proposes studying the resulting algebra's closure, associativity, and (expected) non-commutativity, e.g. E o Q != Q o E because discovering a dimension before qualification differs from qualifying before discovering it -- hypothesized as a non-commutative epistemic algebra [S2226].

Reframes the purification model: adding a new sentence's important effect is often D_1>D_0 (a new dimension is discovered) rather than |K_1|>|K_0| (more propositions), and further evidence can separately improve the value of an existing dimension v_0(d)->v_1(d); yields a small operator taxonomy that sentence addition maps to: new dimension, new value, new context, new relation, correction, or qualification -- described as exactly the operator algebra sought [S2228].

Refines purification: P:Sigma_t->Sigma_{t+1} must not assume P(Sigma_t)>Sigma_t (per Step 287's finding that axes lack fully declared orders); instead a desired property Q(Sigma_{t+1})>=Q(Sigma_t) is wanted where Q is a future epistemic-quality functional that does not yet exist (an important research gap). Illustrates via example that K_1={1000 unsupported claims} could contain more information than K_2={100 well-supported claims} yet K_2 may be epistemically superior -- so Knowledge quantity != Knowledge quality, and Purification != accumulation; the kernel should maximize epistemic adequacy, not raw knowledge [S2239].
