## Rationale

Operations must first be classified into (1) knowledge-state transformations, (2) epistemic assessments, (3) governance operations, (4) audit/history operations, (5) observation operations; not every legitimate KnowledgeOS operation is an endomorphism T:K->K — e.g. Assess:K x X -> Assessment and Authorize:Actor x Action x Policy -> Decision are non-state-closing operations, and only state-transforming operations enter the primary congruence test [S1636]. Central negative result of the step: a valid global congruence proof is impossible while the mandatory transformation family T is not itself closed, because the universal quantifier 'for all T in T' is not well-defined over an incomplete set; this reinforces the required sequencing Transformation Inventory -> Semantic Classification -> Congruence, rather than jumping to K -> Congruence in isolation [S1636]. DDD interpretation of the congruence criterion: a bounded-context state representation is legitimate only when its externally observable behavior under the context's published operations does not depend on information the context's state has discarded — i.e. the congruence test is a rigorous check for an accidentally omitted domain invariant, not mathematical decoration [S1636]. Statistical interpretation: two histories can produce the same estimated distribution P_theta under a distributional candidate state F_E, yet still be distinguishable by a future transformation dependent on information not identifiable from that distribution; statistical sufficiency must not be assumed to imply KnowledgeOS operational sufficiency without separate proof [S1636]. Structural (by-construction) explanation for why congruence held in every test: T's derived signature K x Op x Policy x Authority -harpoon-> K x Outcome does not include History in its domain, so T cannot depend on it — a function cannot depend on an argument it does not receive. This holds under exactly two assumptions: A1 (T reads only K, Policy, Authority — PROVEN by elimination of actor/time/evidence/context during signature derivation) and A2 (no operation consults order-of-arrival — HOLDS for the twelve derived operations because A and R are sets, making order structurally unobservable) [S1642]. ARC E (State vs History, called 'the deepest and most honest arc') is independently checked and found genuinely sound where claimed: semantic minimality is correctly distinguished from mere syntactic compactness; the requirement that the equivalence relation be a congruence (not merely an equivalence) for the transformation set is correctly derived; the reflexivity/symmetry/transitivity proofs are verified correct but trivial (holding for any observational equivalence, establishing nothing KnowledgeOS-specific) — and importantly, the corpus itself does not overclaim them; hash identity is correctly kept distinct from semantic identity [S1673]. Four second-order findings summarised: SO-1 the previously-UNRESOLVED 259.9 congruence matrix is computed (K=(A,R) congruent for all class-1 operations, both variants, 208-state domain); SO-2 congruence is necessary but not sufficient (Merge/sensitive passes vacuously); SO-3 the invariant audit finds 5/6 mandated invariants expressible with a corpus-supplied repair for the sixth; SO-4 after reclassification 17/57 gaps are genuine theoretical holes, and all five remaining CRITICAL ones converge on Sigma [S1767]. Indexes the seven programs in exec/: so_model.py (shared Obj/State model, six abstractions F1-F6, eight class-1 operations each with blind/sensitive variants) and so_exp01-06 (congruence matrix, invariant-expressibility, adversarial operation classification, mandated-invariant audit, Sigma-from-272 derivation, 29-node closure marking respectively) [S1770].
