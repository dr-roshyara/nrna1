## All rows (source_id order)

- [S2305] types=[DEFINITION, FORMALIZATION] scope=OBJECT — "The Brier score I_BR(cr,omega) = sum_i (tv_omega(X_i) - cr(X_i))^2 measures inaccuracy in a possible world omega. The Gradational Accuracy Theorem: every non-probabilistic credence function is accuracy-dominated (strictly worse in every world) by some probabilistic credence function, while no probabilistic credence function is ever accuracy-dominated. A scoring rule is 'proper' if a probabilistic agent expects her own distribution to score best under it (Brier and log scores are proper; the absolute-value score is not). The Accuracy Updating Theorem: for any proper scoring rule, Conditionalization minimizes expected inaccuracy. Mapped as 'a non-pragmatic justification for probabilism -- rationality requires maximizing accuracy.'" (anchor: "If cr is probabilistic, there does not exist cr' that accuracy-dominates cr.")
