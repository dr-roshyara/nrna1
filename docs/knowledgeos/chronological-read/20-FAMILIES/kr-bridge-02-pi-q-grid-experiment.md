## Rationale
Reports a second, subtler provenance error even after the first was corrected: Pi_arity, declared to read no field, actually reads the v field after transformation T_C_dedup because arity depends on which records survive deduplication and survival is decided by that field, a coupling found only by a perturbation test (changing one input field and observing which outputs move) and not by reading the implementation code. [S2666] An anti-circularity requirement (candidate FR-003) is proposed: read-disjointness of Pi and Q must be verified on the triple (Pi,Q,T) because T can derive an output field Pi reads from sources Pi never declared; two concrete KR-BRIDGE-02 failures (a rank field secretly shared with Q's tag field, and an arity observable secretly reading value via deduplication survivorship) show declaration is not verification.
