## Rationale

Programmatic check of the workflow record shows the architecture lane producing Amendment 1 held mutation ownership at HANDOFF but never received a START/CONTINUATION afterward, meaning Amendment 1 was produced by a lane not verifiably ACTIVE on the record -- distinguished from whether its claims are independently assessable (they are) [S0090]. Additionally, The discovery's core structural result: BC-7's invariants (I-1 single mutation owner, I-2 HANDOFF+human START, I-3 sticky STOPPED, G-1 closure is a governance act, G-2 single writer for the Authority State) are all mechanically enforced, while almost every invariant outside BC-7 (R-34 producer!=acceptor, INV-ATTR-2 separation, AIP-11 frozen-artifact supersession, AIP-14 Product Primacy) is declared only, with no enforcement mechanism [S0091]. Further, Finding X-2: this verification's own workflow lane has no recorded START, meaning the report is produced off-record -- the second occurrence of the same lifecycle-gap pattern at a 'Verification #3' slot across this estate, classified as a platform gap (bearing on C-10/knowledge-distribution and G-3) rather than a defect of Correction #2 [S0092]. Relatedly, A recurring delivery/record gap pattern is recorded: an artifact states it is delivered, but the lane that produced it never performed the corresponding HANDOFF transition, so the workflow record lags the actual work; Governance performs the handoff now rather than back-dating it [S0094]. In the same vein, A workflow lane that is HANDED_OFF to but never STARTed leaves mutationOwner as None, mechanically blocking every subsequent lane's handoff (Inv C requires the current mutation owner to hand off) -- a live, measured blocker rather than a theoretical one, confirmed by probing a scratch copy of the record [S0095]. Diagnosis: the entire workflow chain is blocked by exactly one missing human START act; once the PO/ARB affirms it occurred, Governance transcribes the START (preserving on the record's face that the artifact predates the transition) and the blocked handoff chain unblocks in one move [S0095]. Additionally, A cumulative pattern is named explicitly: the record and the governed acts on this work item have crossed (diverged and required reconciliation) four separate times, treated as a recurring structural pattern each disposed individually by Governance rather than absorbed silently [S0110]. Further, Governance declines to register a new workflow lane for D5, because the current mutation owner (S5, an outstanding/refused verification) would need to hand off, which would misrepresent that verification as concluded; instead D5 proceeds as a PO/ARB-directed act, deferring the lane-creation question until S5's disposition is settled [S0116]. Relatedly, A structural result from the KOS-AIP04-DISCOVERY-001 role-model discovery: the estate's assurance is strong exactly where it is executable (BC-7, the workflow engine) and weak exactly where it is prose (everywhere else); since separation itself is Declared, not attestable (INV-ATTR-2), naming more precise roles buys no additional assurance [S0164]. In the same vein, Partially confirms P3-F3: re-derives the 5/5 mechanically-enforced vs 6/6 declared-only invariant counts directly from the baseline's own inventory and finds the disputed phrasing already hedged, while agreeing the corpus sampling is incomplete given P3-F1's findings [S0199]. There are no domain types in EKS's governance subsystem (no WorkItem/Grant/Session/Transition class, no value object, no repository interface -- only a JSON schema-by-convention and functions over associative arrays), while the assurance subsystem (scripts/lib/EngineeringKnowledge/) is a real hexagonal tactical model with ~60 domain classes and 252 passing tests -- flagged as the single most consequential DDD finding: modelling investment is inversely proportional to invariant weight (the highest-stakes part is modelled least rigorously) [S0206]. Additionally, Authority is enforced nowhere against engineering work; in exactly four places against the record itself: (1) only governance may write a grant; (2) a grant must carry a humanActRef; (3) only the current mutation owner may hand off; (4) only governance/human may record COMPLETE or CONTINUATION. Each is a precondition on a write to the JSON file, evaluated by a CLI the actor chose to run, with the writer role supplied as a command-line flag. 'EKS enforces the well-formedness of its own record. It enforces nothing about engineering' -- no file edit, commit, push, merge, deploy, document creation, or architectural change is gated by any grant, ownership, or transition [S0206]. Further, Executable-vs-documented governance table: nine core workflow-record disciplines plus read-purity/one-interpreter rules plus the closed verdict vocabulary are executable and tested (29+17+252 tests respectively); knowledge-schema conformance/placement/identifier-collision/reference-integrity are executable but only advisory or non-blocking; but the registry-first workflow, ES-001..006 in full, the promotion ladder, the 14-phase Operating Loop, EP-01/02/03, the six-role operating model, and work-item acceptance/closure are ALL documented-only. EKS's own STANDARDS_INDEX.md states 'the smallest automation set justified by evidence: ZERO new hooks' -- recorded here as a deliberate decision, not a defect, while noting the enforcement-scope consequence follows from it inescapably [S0206]. Relatedly, Headline structural finding -- the invariant asymmetry: assurance is strong where it is executable (BC-7) and weak where it is prose (outside BC-7). 'The platform mechanically protects orchestration, and protects knowledge/verification/communication only by declaration.' Stated as the single most important structural property of AIP's current architecture [S0234]. In the same vein, Sharply distinguishes a mechanism's refusal-on-lane-existence (a re-appointment guard, correctly firing here) from a substantive finding about independence (which was never actually violated), locating the true defect as a provenance gap: real eligibility facts existed but were never recorded by the specific mechanism responsible for recording them [S0387].
