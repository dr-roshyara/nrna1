## Rationale
This object addresses what Chapter 1 of the Gita (Arjuna's crisis) contributes to a KnowledgeOS kernel model: not a new canonical primitive, but a rich model of a pathological/failure kernel state that motivates the later Chapter 2 reconstruction [S2261]. The central finding is that Arjuna possesses abundant information (battlefield, armies, teachers, relatives, consequences) yet his decision process collapses — giving the general principle "more information does not imply better decision" [S2261], formalized as Knowledge available AND Buddhi (discrimination) impaired ⇒ decision failure [S2261]. This closes a gap in a purely information-theoretic account of Zero (absence) by refining Zero into three distinct forms — Missing information, Missing interpretation, Blocked discrimination — with Arjuna's case classified as primarily an interpretive/discriminative deficiency rather than an information gap [S2260], described as "a major refinement" of prior Zero=missing-information formulations [S2260]. It also introduces a model-adequacy distinction: a valid inference can still arise from an inadequate model, so the kernel must evaluate not only InferenceValid? but also ModelAdequate?, with correction modeled as M_t --Buddhi--> M_{t+1} [S2260]. Throughout, the object is explicit that this is architectural/epistemic modelling, not theology: Krishna ≠ Kernel; the Krishna-lens is treated as a Guidance/Correction function distinct from the Kernel as a Mind-like processing unit [S2260].
