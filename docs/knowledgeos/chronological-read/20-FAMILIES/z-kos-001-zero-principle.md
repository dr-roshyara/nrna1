## Rationale
Eleven rows are classified rationale-bearing, spanning the whole B0007 origin episode. The purpose Zero addresses: preventing eight named "category collapses" that constitute KnowledgeOS's major failure modes (Representation→Identity, Authority→Truth, Probability→Truth, Similarity→Identity, Observation→Inference, Transformation→Replacement, Contradiction→Error, Agent→Reality) [S0254]. It was introduced as an eighth research lens extending the Vedic extraction, framed per-dimension (Identity, Context, Evidence, Contradiction, Transformation, Agent) as already resolving to existing kernel confirmations rather than requiring a new dimension or kernel object — hence classified "Foundational Meta-Principle" [S0251]. Architecturally, Zero was found to be already distributed across the frozen Reference Architecture's kernel services (Verification Gate=neutral admission, Contradiction Registry=neutral suspension, Dimension Registry=comparison baseline, Identity+History=continuity, Decision Interlock+Projection+Agency=perspective without collapse, Authority Service=authority separation) rather than being a missing component [S0252]. A persistent governance rationale recurs across the episode: Zero must never become a kernel article/twelfth law, because doing so would recreate exactly the collapse it exists to prevent — "Article 12: Everything must follow Zero ⇒ Zero becomes authority" is given as the self-referential danger case [S0255]. The mathematical grounding for why an external/meta-level reference is *necessary* (not optional) comes from an applied Gödel argument: a system cannot completely validate itself from inside itself, so KnowledgeOS needs an outside reference — and the Constitution's own validity is stated to rest on such external grounding (reality/observation, the human knower, constitutional ratification) [S0274, S0275, S0276]. Independent cross-tradition re-derivations are explicitly noted as corroborating evidence rather than new content: Quranic Al-Ḥaqq (a stable truth/reality reference opposed to human opinion) [S0256], and Vedantic witness-consciousness (observer remains stable while events/thoughts change) [S0262].
