## Rationale
Davidson's holism (meaning/belief interpretation draws on patterns of assent and everything known about how evidence supports belief) is used to attack an open problem referred to as 'C-11 Confidence' ('confidence has no lawful input'): a Kernel-computed Confidence=f(evidence, claim, justification, context, contradictions, source reliability, ...) drifts into Davidson's interpretive territory and is almost certainly PRODUCE not PROTECT; the safer architecture supplies confidence as an externally-produced assertion (claim, confidence assertion, method, provenance) which the Kernel governs for admissibility without reproducing the judgement -- does not resolve C-11 but supplies a falsification weapon. [S0419] Davidson argues against reference as a theoretical foundation and for the inscrutability of reference (interpretation can remain unaffected by alternative term-to-object mappings); this reinforces 'identity assigned, never derived' -- semantic-similarity->same-referent->same-KnowledgeId is suspect; 'representation equivalence does not establish identity' and 'reference resolution must not silently become KnowledgeId assignment', strongly supporting an existing constraint referenced as C-1. [S0419] Directly strengthens a prior finding referenced as 'F-CM-2'/deduplication (the Kernel cannot notice two candidates 'mean the same thing' without becoming a semantic arbiter): if reference can be inscrutable while interpretation is unaffected, semantic-equivalence(A,B) must not silently become KnowledgeId(A)=KnowledgeId(B) inside the Kernel -- deduplication by supposed semantic identity is an interpretive act, not a trivial infrastructure operation. [S0419] Davidson's requirement that a learnable language with infinitely many sentences be generated from finitely many semantic primitives resonates with the Kernel vision: the outer system can be enormously expressive/intelligent/multilingual/multimodal/domain-specific/open-ended while the authoritative core stays small/finite/stable/deterministic/governed -- 'expressive complexity can scale outward without foundational complexity scaling inward,' read as philosophical support for an existing 'inverse-scaling' ADR idea. [S0419]
