### Theme A — Core problem framing and VOI formalization (rows 1-9, all S0927)
Establishes the foundational claim that inference (what can we conclude) and information-acquisition selection (what should we learn next) are different problems requiring cost-relative optimization, not exhaustive investigation. Defines the information-gathering action set (7 worked examples), Cost(I) across 5 components, Expected Value of Perfect Information (EVPI=L0-L_PI, an upper bound), Expected Value of Sample Information (EVSI) and Net Value of Information (NVOI(I)=EVSI(I)-Cost(I)) as the step's core idea (row 6 depends on `decision-theory-value-of-information-algebra`), the first formal Next-Best-Epistemic-Action, the principle that information value ≠ uncertainty reduction, and DecisionSensitivity as the governing criterion for information value. 9 rows condensed into this theme; full text in 03-CONTRIBUTIONS.jsonl.

### Theme B — Decision-sensitivity, prioritization, and worked examples (rows 10-22, all S0927)
A sequence of worked examples and formalizations building the prioritization machinery: a low-decision-sensitivity example (RAM precision beyond safety margin) contrasted with a high-decision-sensitivity example (backup restorability); a decision-relevance partition via perturbation of the decision function; a prioritization formula combining Step 32's dependency closure with decision dependency (depends on `epistemic-algebra-type-closure-composition-algebra`); a domain-owned (not KnowledgeOS-invented) Criticality classification; expected loss and current-optimal decision with a two-decision expected-loss-reversal example; DecisionBoundaryUncertainty with a threshold-straddling risk-interval example and contrasting harmless-far/critical-boundary-straddling examples; a conceptual (not-yet-universal) epistemic-triage priority formula; a worked arithmetic example showing higher-EVSI investigations can have lower net value once cost is subtracted; the principle that human attention is itself a costed epistemic resource; a note that compute cost differences matter even for similar uncertainty reduction; and a requirement that Cost(I) include operational risk. 13 rows condensed into this theme; full text in 03-CONTRIBUTIONS.jsonl.

### Theme C — Acquisition hierarchy and decision-relative sufficiency (rows 23-26, all S0927)

### Theme D — Active learning and the critique of entropy-only measures (rows 27-30, all S0927)
Introduces active learning and generalizes it beyond machine learning to "epistemic active learning"; defines entropy-based information gain and states InformationGain ≠ DecisionValue; proposes decision-weighted information gain (explicitly not a universal law); and argues entropy-based measures fail to distinguish critical from irrelevant uncertainty reduction. 4 rows condensed into this theme; full text in 03-CONTRIBUTIONS.jsonl.
