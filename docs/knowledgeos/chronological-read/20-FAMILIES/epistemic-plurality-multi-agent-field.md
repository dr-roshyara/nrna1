## Rationale

Argues difference is a prerequisite for knowledge generation: an undifferentiated state (X=X) permits no interaction, whereas epistemic inquiry requires distinctions (H!=H', Evidence!=Hypothesis, Observer!=Observed, Question!=Answer, Proposal!=Challenge, CurrentState!=IdealState); connects this to the Zero Lens (which identifies boundaries/differences) via the chain Difference -> Interaction -> Transformation -> NewState [S2442].
