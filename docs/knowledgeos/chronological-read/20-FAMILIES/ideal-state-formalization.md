## Rationale
Argues via the Arjuna case that Knowledge != Understanding: possessing a fact does not entail grasping its decision-relevant implications, motivating the separate Ideal Understanding State I^U and the corresponding Understanding-comparison operation [S0790]. Shows via the Arjuna example that measured distance reaching zero (D_E(K_2,I^K_0)=0) does not mean the epistemic journey is complete, because the Ideal State itself evolved in step (I^K_2 != I^K_0); reframes KnowledgeOS's problem as dynamic epistemic navigation rather than static optimization against a fixed target [S0791].
