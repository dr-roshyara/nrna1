## Rationale
- [S2321] (CORRECTION/ARGUMENT) Argues the previous atomic-tuple's per-dimension scalar probability p_i is mathematically inadequate because probability theory does not generally license treating dimensions independently: for a joint random element X=(X_1,...,X_n), the fundamental object is the joint law L(X), which carries information the collection {P(X_i)} does not.
- [S2321] (ARGUMENT/EXAMPLE) Argues conditional independence must be established, not assumed: dimensions such as OS and kernel version, or CPU architecture and available package, are not generally independent, so P(d1,d2,d3,d4) can carry information the product P(d1)P(d2)P(d3)P(d4) does not; consequently the 'one probability per dimension' formulation is downgraded, and evidence items from the same measurement system cannot be treated as independent either (P(E1,E2|X) != P(E1|X)P(E2|X) unless conditional independence is established), strengthening the corpus's existing dependency-before-aggregation finding.
- [S2321] (ARGUMENT/VALIDATION) Uses Kallenberg's distinction between equality-in-distribution and equality-of-realization (two random elements can share a law without being the same realization) as an independent mathematical precedent for the corpus's existing representation-equality != state-identity discipline, explicitly paired with the corpus's own SNF(x)=SNF(y) does not imply x=y warning as two independent regimes converging on the same non-collapse principle -- proposed as a candidate cross-theory invariant, and connected to the Persistent Identity research line.
