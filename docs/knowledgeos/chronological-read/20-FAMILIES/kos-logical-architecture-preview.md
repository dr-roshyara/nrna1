## Rationale
Recommends a transactional-outbox mechanism for a modular monolith as providing reliable graph/event propagation without requiring Kafka from day one (contrasting a DB-commit-then-failed-publish stale-graph failure mode with the outbox's atomically-committed state+record then publish); states the graph becomes EventuallyConsistent, acceptable only if SourceOfTruth is clearly identified, and warns never to use a StaleGraph as proof of CurrentAuthority — for high-authority operations the platform may query the authoritative context directly.
