## Rationale

From Chapter 18's distinction between understanding that correctly distinguishes proper/improper action and understanding that fails to (per the modes): having an evaluation mechanism != having correct discrimination. Therefore B_t != truth oracle; Buddhi is an epistemic discriminator, not an omniscient truth machine -- assessed as much more compatible with KnowledgeOS than treating Buddhi as infallible [S2249]. Reformulates 'kernel can become its own enemy': if the operating mode becomes dominated by an undesirable configuration (G_t=T/Tamas), B_t(E) may systematically produce poor decisions even though the system executes correctly -- kernel malfunction need not be computational failure, it can be epistemic misclassification, reasoning under a defective epistemic mode. Connects this to why Governance/authority must remain external to the kernel (per N notin K), consistent with 'the mechanism records authority; it does not grant authority' [S2249].
