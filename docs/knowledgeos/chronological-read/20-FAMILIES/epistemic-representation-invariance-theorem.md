## Rationale
The evidence base attributes the following rationale to this object (as recorded, cited to its source):

- **[EXPLANATION]** [S0682]: In a Bayesian regime S_t=P_t(H) and new conditional evidence gives P_{t+1}(H)=P_t(H|E,C)=P(E|H,C)P(H|C)/P(E|C); Bayesian reasoning is one perfectly rigorous instantiation of U_R but does not itself define the abstract epistemic state.
- **[EXPLANATION]** [S0682]: Dempster-Shafer instantiates U_R differently from Bayesian: instead of P(H) it assigns mass m(A) over sets of possibilities, deriving Bel(A) and Pl(A), representing support for a set of hypotheses rather than commitment to one -- yet the abstract transition remains S_{t+1}=U_{DS}(S_t,E), which is exactly why the abstract layer is needed.
- **[EXPLANATION/WARNING]** [S0682]: Fuzzy logic instantiates U_R with membership degree mu_overloaded(x)=0.8, which does not automatically mean P(overloaded)=0.8 nor Knowledge(overloaded)=0.8 -- the numerical value has a completely different semantics from Bayesian probability, yet fuzzy reasoning still fits the abstract update pattern S^fuzzy_{t+1}=U_fuzzy(S_t,E).
- **[EXPLANATION/EXAMPLE]** [S0682]: Non-monotonic reasoning instantiates U_R as defeasible revision: given normally(P) and P currently derived, new evidence not-P can cause the system to retract the previous consequence (S_t={P} becomes S_{t+1}={not-P}) -- structurally still U_NMR(S_t,E)->S_{t+1}, but not Bayesian posterior movement.
- **[EXPLANATION]** [S0682]: Argumentation theory instantiates U_R by producing arguments, attacks, defenses, and accepted/rejected/undecided classifications from conflicting evidence (A1 supports P, A2 supports not-P); the epistemic state S_t^arg is the accepted/defeated/undecided argument structure, updated as S_{t+1}^arg=U_arg(S_t,E) -- a representation very different from Bayesian probability but modelling the same kind of epistemic change.
- **[EXPLANATION]** [S0682]: Epistemic logic instantiates U_R via a possible-worlds model M=(W,R_a,V): K_a p (agent a knows p) means p is true in all worlds accessible to a; S_t^EL is an epistemic possible-world structure, updated as U_EL(S_t,E)->S_{t+1} -- same abstract role as other regimes, different mathematics.
- **[EXPLANATION]** [S0682]: Temporal logic (G(P)='P always true', F(P)='P eventually true') adds time to the epistemic state without becoming probability, important for KnowledgeOS since Knows(a,p,t) and Valid(p,t) are not timeless -- the temporal regime provides the semantics of how they evolve.
- **[EXPLANATION/DISTINCTION]** [S0682]: Measurement theory (Roberts) instantiates a fundamentally different operation: not updating knowledge but asking whether a claimed numerical value for a property of the epistemic state is legitimate, via a representation f:R_emp->R preserving the relevant empirical relational structure; measurement theory therefore applies after the epistemic state is defined -- Epistemic update != Measurement, though the two interact.
