5 rows condensed into this theme (source_ids: S1013; full text in `03-CONTRIBUTIONS.jsonl`).

### Concept-by-concept evidentiary tests (Experiments 1-7): Observation, Claim, Decision-vs-Recommendation, Authority, Action, Provenance, temporal validity

States the critical Observation test is whether the system distinguishes ObservedFact from Interpretation, tested by Experiment 1 (a bare status=FAILED value without source/time/context yields Observation=Partial; PASS) [S1013]. It states a Claim must be distinguishable from raw document/observation/recommendation/decision (Experiment 2: an AI agent's unbacked assertion is not a first-class claim; PASS); states distinguishing Recommendation from Decision as one of the most important semantic boundaries (Experiment 3: an undifferentiated shared table yields DecisionSemantics=Weak; PASS); states Authority is harder to establish than role (Experiment 4: a role without decision-type restriction shows authority semantics absent; PASS); requires Action testing to reconstruct Who+What+Why+When+AgainstWhat+UnderWhichAuthority (Experiment 5: session logs recording only 'file changed' yield ActionProvenance=Partial; PASS); defines Provenance(X)=Source+Actor+Time+Transformation+Context as possibly the most important cross-cutting concept (Experiment 6: a source_url field establishes only partial attribution; PASS); and states CreatedAt≠ValidFrom (Experiment 7: an object with only created_at leaves temporal validity unproven; PASS) [S1013].

### Relationship/edge-level tests (Experiments 8-10): semantic edges, foreign keys are not semantic relationships

6 rows condensed into this theme (source_ids: S1013; full text in `03-CONTRIBUTIONS.jsonl`).

States concept-level evidence is insufficient -- relationships (Evidence-supports->Claim, Claim-informs->Decision, Decision-authorizes->Action) must also be tested (Experiment 8: independently existing Decision and Evidence records with no explicit relationship leave the semantics unestablished; PASS) [S1013]. It defines the semantic edge test requiring evidence of relationship existence, direction, meaning, and lifecycle for every important edge (Experiment 9: an evidence_ids[] field is strong evidence at S1/S2 but not automatically S3 without enforced verification), and states a foreign key does not necessarily establish a semantic relationship, requiring independently established meaning (Experiment 10: a decision_id foreign key in an audit table does not prove the record is supporting evidence; PASS) [S1013].
