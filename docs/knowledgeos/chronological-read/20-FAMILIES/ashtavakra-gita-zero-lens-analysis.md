## Rationale
Maps the Zero lens's five questions onto the Ashtavakra Gita's own claims: what is represented (universe, body, mind, knowledge, experience), what is assumed away (the universe's independence from consciousness), what is absent (independent reality of the universe, i.e. mithya), what is undefined (the true nature of the Self until realized), and what is unrepresented (Brahman/consciousness itself, which the text holds cannot be represented at all) [S0717]. Draws four textual insights from the Gita: representation is never independently real (the universe, though represented, borrows its reality, 'like a snake in a rope'); knowledge is not a thing to be stored but an appearance arising, experienced, and disappearing in consciousness; the knower is not represented in the knowledge state -- it is the witness, unattached to body/mind; and self-knowledge (Tat tvam asi) is the only real knowledge, all other knowledge being mithya [S0717]. Poses the text's central challenge to KnowledgeOS as a dilemma: is KnowledgeOS modeling reality or appearance -- if reality, Ashtavakra holds there is no reality other than consciousness; if appearance, all appearances are mithya (false). KnowledgeOS assumes there is a state to be known; Ashtavakra says there is only consciousness -- framed as a fundamental challenge to the entire KnowledgeOS enterprise, closing with the unresolved 'Mithya question for the Kernel': how should KnowledgeOS model the relationship between representation and reality [S0717].
