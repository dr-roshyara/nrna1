## Rationale
The kernel/mind 'enemy' danger is not only bad data but can arise from: (1) incomplete observation, (2) overwhelming observation, (3) incorrect interpretation, (4) defective discrimination, (5) incorrect decision, (6) state transition based on that decision -- pipeline O_t -> B_t -> D_t -> K_{t+1}. Hence Buddhi is a critical control point in the kernel architecture. Observation != Understanding and Understanding != Discrimination [S2221]. DDD consequence: a bounded context may be only a local projection of a larger reality; this does not invalidate bounded contexts but makes the boundary explicit (Bounded Context != Whole Reality), preventing the Kernel from confusing its represented world with the world itself [S2221].
