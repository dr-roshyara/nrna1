## Rationale
Analyzes institutional facts as relational rather than isolated: institutional facts form networks of dependency (e.g. money depends on an exchange system, which depends on property, which depends on contract, which depends on institutional recognition). [S0534] Argues for the primacy of process over object in the institutional domain, directly extending the earlier Merricks 'is Assertion really an object?' question: Marriage, Government, Election, Corporation, Money, Contract, and Office are argued to be maintained practices/processes rather than inert objects. [S0534] Argues KnowledgeOS needs to preserve utterance + speaker + authority + context + constitutive rule + institutional state together in order to correctly interpret institutional claims/actions, since a statement like 'Alice is President' being true and 'I declare Alice President' successfully performing an institutional act depend on different conditions (valid appointment vs. speaker authority under constitutive rules). [S0534] Analyzes Searle's discussion of iterated status functions and interlocking systems (a status can itself become the basis for another status), applying it to an election chain (Person -> Voter -> Candidate/outcome -> Winner -> President -> Power -> Appoint -> new Institutional Status) to argue the Knowledge Space is not a flat graph but has iterated institutional structure. [S0534] Argues against putting all relation kinds into one generic Relation type at the conceptual level, proposing instead a meta-level RELATIONAL SUBSTRATE with natural/semantic/epistemic/institutional branches, so the Kernel can preserve typed relations without prescribing all domain semantics -- described as a much safer architecture. [S0534] Argues a governance decision is not only a report-of-decision assertion but may be a decision event that constitutes a status-function assignment producing a new institutional status and new rights/obligations/powers; proposes KnowledgeOS distinguish these two cases as a potentially major architectural invariant. [S0534] Refines the per-agent projection model (from S0529/S0530) by arguing not all projections project the same kind of reality -- some project natural facts, some semantic structures, some institutional statuses, some epistemic states -- and that KnowledgeOS must preserve which kind of projection a given projection is, calling this a major boundary condition. [S0534] Argues against a single generic KnowledgeObject using 'President' as a worked ambiguity example (depending on context it may be a person, a status, an institutional role, a relation, a power-bearing position, a concept, a proposition, or an epistemic object), proposing instead that KnowledgeOS preserve the underlying structures (person, status function, context, institution, constitutive rule, authority, time, rights/obligations, evidence) so different projections ('X is President', 'X has presidential authority', 'X was President from T1 to T2') can be expressed without losing the underlying structure -- called exactly the kind of semantic integrity being sought. [S0534] States an architectural verdict that Searle's book should materially influence the KnowledgeOS model, identifying Status(X,Y,C)/status-assignment-under-context (not 'Institution' as a class) as the biggest new addition, applicable to roles, elections, mandates, offices, authority, rights, obligations, ownership, certification, governance, and constitutional status/boundaries, because institutional facts form interlocking systems, persist through collective recognition, and can be created by authorized/constitutive acts. [S0534]
