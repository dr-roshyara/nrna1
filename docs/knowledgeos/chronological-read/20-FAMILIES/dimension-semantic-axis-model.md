## Rationale
Argues Arjuna's Selection S was not merely adding new selected dimensions but restructuring relationships among existing ones (Enemy alone becoming Enemy-intersect-Relative-intersect-Teacher-intersect-Elder), supporting the principle NewKnowledge -> Reinterpretation(ExistingKnowledge), with the earlier 'Enemy' representation reframed as incomplete rather than false (a Zero-Lens-style move). [S0765] Argues a dimension can function as a new axis of inquiry (Person -> Relationship -> Duty -> Consequence -> Ideal -> Action) that opens new regions of an infinite knowledge space, rather than being merely a static database field. [S0766] Argues Relationship should be treated as a first-class KnowledgeOS construct distinct from Dimension/Statement/Value, rather than being collapsed into the same triple structure, since relationships carry their own type, context, evidence, and epistemic status. [S0768] Argues consequences/inferences (e.g. 'Arjuna may kill Bhishma' derived from grandfather/opponent statements) are derived statements produced by an Inference function over prior statements, not primitive dimensions -- and that this distinction is required for evidence provenance (observed vs. inferred). [S0768]
