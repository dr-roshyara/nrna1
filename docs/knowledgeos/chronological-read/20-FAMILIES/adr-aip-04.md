A principled reason is given for freezing ADR-AIP-04 (role-model ownership) during BC-7's strategic discovery: the discovery itself may surface evidence about whether Role/Assignment/Actor/Authority belong partly to BC-7, so deciding roles first would risk designing them before their ownership is understood [S0063]. Additionally, The discovery's core structural result: BC-7's invariants (I-1 single mutation owner, I-2 HANDOFF+human START, I-3 sticky STOPPED, G-1 closure is a governance act, G-2 single writer for the Authority State) are all mechanically enforced, while almost every invariant outside BC-7 (R-34 producer!=acceptor, INV-ATTR-2 separation, AIP-11 frozen-artifact supersession, AIP-14 Product Primacy) is declared only, with no enforcement mechanism [S0091]. Further, Finding F-9/F-9a: the drafting process itself, first-hand, occupied verification, architecture-review, architecture-drafting and domain roles in sequence within one process, self-recording its own STARTs each time -- evidence that 'Governance' as practised is a cross-cutting capability set with only ONE strictly-separated duty (acceptance/closure via COMPLETE, mechanically refused to non-governance/human writers), not a distinct actor [S0091]. Relatedly, The adoption decision retroactively supersedes the narrow thesis Verification #2's finding W-1 was testing ('the six-role model is not currently established as governed architecture'), because that thesis is now false by decision; the verdict-G re-scoping requires the still-pending Verification #3 lane to be redirected to the evidence-quality question rather than the adoption question itself [S0093].
