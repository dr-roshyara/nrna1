## Rationale
- [S0829] (ARGUMENT, DISTINCTION): Quine's ontological-commitment criterion: a theory is committed only to entities that must occur among the values of its bound variables for its assertions to be true — determined by quantification, not by surface nouns/names/predicates. Argument A formalizes this: names can be paraphrased away, predicates need not name entities, but bound variables do range over entities, so ontological commitment is best assessed through what must be values of bound variables — 'a formal method for detecting hidden commitments instead of inferring them from surface vocabulary'.
- [S0829] (ARGUMENT, PRINCIPLE): Rejects the analytic/synthetic dogma (every attempted definition of analyticity — logical truth, synonymy, definition, interchangeability, semantic rules, verification — eventually depends on the concept it was meant to explain) and radical reductionism (Carnap's sense-data construction of physical objects leaves 'is at' undefined rather than eliminating it, and Carnap abandoned the program). States epistemic holism: 'the unit of empirical significance is the whole of science' — the scientific system is a network whose boundary conditions are experience; experience forces change somewhere but does not uniquely determine where. Argument B: since statements form an interconnected system and experience constrains the whole, a given conflict can be accommodated by revising different parts, so 'evidence constrains a system ≠ evidence uniquely determines which proposition changes'.
- [S0829] (ARGUMENT, DISTINCTION): No statement is absolutely immune to revision (even logic can become a candidate for revision under sufficiently radical circumstances) but statements are not equally likely to be revised — peripheral statements (directly tied to experience) vs central statements (deep theoretical principles, logic, ontology) — giving 'revisability ≠ equal revisability'.
- [S0829] (ARGUMENT, EXAMPLE): Argument D (referential opacity): Giorgione=Barbarelli, yet some statements containing 'Giorgione' become false under substitution of 'Barbarelli', so not every occurrence of a name is purely referential — identity of reference does not guarantee substitutability inside every context (the basis of Quine's 'referential opacity'). Argument C: dictionary definitions report antecedent usage rather than explaining why a synonymy exists, so definition normally does not explain synonymy. Argument E: quantifying into modal contexts treats necessity as a property of the object itself, requiring privileging some ways of specifying the object over others — 'something resembling Aristotelian essentialism', which Quine rejects.
- [S0829] (ARGUMENT, OPEN-QUESTION): Six explicit challenges to assumptions a KnowledgeOS architecture program might take for granted, each with a falsification target: (1) every claim has identifiable evidence — can a claim have a well-defined evidence boundary independent of surrounding theory?; (2) conflicting evidence identifies the wrong claim — can multiple internally coherent revision paths exist for one contradiction?; (3) canonical terminology establishes shared meaning — can two actors share a term while differing materially in inferential/referential commitment?; (4) a representation of X is effectively X — does promoting a representation to a first-class object silently change the model's ontology?; (5) identity is independent of modelling context — can two objects be indistinguishable under one model but distinguishable under another?; (6) the semantic layer can freely reason about itself — what happens when a system treats its own assertions/truth-conditions/validation-rules as ordinary objects at the same semantic level?
