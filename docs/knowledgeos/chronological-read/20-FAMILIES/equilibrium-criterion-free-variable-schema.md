## Rationale
S1-F009's 'equilibrium criterion' for Kernel membership contains a free variable: law carries eleven invariants (INV-KOS-IDENTITY-001 through HISTORY), and the criterion's output is entirely determined by which is substituted -- ranging from a near-minimal rule-evaluator to 'everything in' (the god-object F007 warns against). The criterion is therefore a schema, not a decision procedure, and its apparent power to reconcile the small-Kernel/large-Kernel dispute (S1-F007 vs S1-F008) is an artifact of underspecification, not resolution: 'compatibility with two opposed positions is not resolution of them; it is silence wearing a decision's clothing.' [S1243] S1-F009 asserts the Kernel is 'a domain boundary, not a component' but then elaborates in component language ('the part of the aggregate...'), an unflagged type error: a set of rules is not a part of an aggregate, it is a constraint the aggregate satisfies. This means related findings (S1-F011's 'not a thing', S1-F012's 'domain space') may agree with F009's assertion while disagreeing with its elaboration, so any convergence claim must specify which half it converges on. [S1243] Implementation verdicts for S1-F009: identity uniqueness/immutability -- DO NOT IMPLEMENT (already protected by INV-KOS-IDENTITY-001); admission event-completeness -- NEEDS FURTHER EVIDENCE (open question, not adjudicated); the equilibrium criterion itself -- PRESERVE AS KNOWLEDGE ONLY, useful as a review prompt but not implementable in any form until its invariant is bound; no new Kernel membership is supported by this artifact. [S1243] Kernel-test verdict: DO NOT IMPLEMENT -- a member-list is a proposal, not a capability; implementing from a member list would repeat the exact failure S1-F007 diagnoses (membership by capability enumeration with no invariant named). The two lists survive fully as data; only the 'instability' interpretation and the intersection's informativeness are challenged; zero implementation consequence, the appropriate outcome for a finding about competing proposals rather than a required capability. [S1245] S1-F012's conjunctive co-consistency-and-recoverability invariant (across six components) is shown to be the maximal substitution into S1-F009's unbound equilibrium-criterion schema: substituting the conjunctive invariant for 'the aggregate invariant' yields the six-component God Aggregate S1-F007 diagnoses and S1-F011's Q4 asks how to prevent -- so F009 and F012 are not two independent formulations but one completing the other in the god-object direction; the document half-concedes this itself, flagging 'Accountability' as non-standard DDD vocabulary that might translate to 'invariant protection.' [S1251] S1-F015's twelve-question discovery sequence (with the boundary question ordered twelfth, project-endorsed as 'the correct discovery sequence') is confirmed as the sharpest methodological result reviewed: every earlier Kernel formulation answered the boundary question first and worked backwards, deriving different boundaries from differing assumptions about commitment/identity/evidence/change; this sequence inverts that, and S2-F024.1's free-variable finding is a direct instance -- S1-F009's criterion could not bind its invariant because it never asked questions 1-9 first.
