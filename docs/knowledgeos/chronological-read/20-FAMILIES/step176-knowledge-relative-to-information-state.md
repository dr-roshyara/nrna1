## Sources (how this label entered the ledger)
- **OBJECT-INDEX**, batch B0033, scope THEORY-LEVEL: Step 176 formalizes Knowledge_t = Knowledge(Evidence_<=t, Methods_t, Context_t) -- knowledge is associated with an information state, not a static object -- while explicitly rejecting relativism ('not every historical belief is equally true'): a historical determination can be simultaneously ReasonableAt(t1) and InvalidAt(t2). Applies this to governance: a Decision_1 properly authorized under Policy_1 is not automatically invalidated when Policy_2 is later introduced -- instead the system records ValidUnder(Decision_1,Policy_1,t_1) and Governance separately decides ReassessmentRequired(Decision_1,Policy_2), preserving historical truth while supporting current governance.
