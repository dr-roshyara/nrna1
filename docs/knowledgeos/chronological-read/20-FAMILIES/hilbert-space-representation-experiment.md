Mandates distinguishing eight pairs of mathematically-named-alike but conceptually distinct constructs; specifies the formal starting model (separate embedding maps into a generic inner-product space, identity to be investigated not assumed); mandates Experiment B (E_t vs K_t collapse test), an anti-circularity rule, Experiment D (equivalence-relation and invariance testing for an epsilon-ball definition), Experiment M (respecting the frozen FR-001 boundary while testing richer constructions), and Experiment N (treating Linga/Yoni strictly as interpretive lenses, forbidding an unearned identity claim). Fixes a six-criterion kernel-inclusion test, an ablation requirement (remove each structural component to test genuine dependence), sixteen adversarial test cases designed to break the mapping, a strict separation of Mathematical/Empirical/Conceptual result types, an outcome-independent success criterion, the standing versioning discipline (no v1.2/v1.3 edits, no promotion from simulation success), and frames the uploaded Hilbert-space assessment as a hypothesis to be attacked, not an established result.
