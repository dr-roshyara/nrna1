## Rationale
Specifies the priority-ordered artifact list for auditing the old KR-ZERO corpus: cases.jsonl (1,395 level-test records, the correct unit for validating the published aggregates), subsets.jsonl (14,194 individual subset-level records, needed to inspect actual S-level Zero behaviour and higher-order elimination witnesses), property-results.json (the ~4.7KB published ground-truth aggregate: 1,395 cases, k=1:1252, k=2:25, k=3:3, irreducible:115), emit_corpus.py (the deterministic seeded generator proving the corpus is not a hand-produced reconstruction), and CORPUS-AUDIT.md (prior audit context) -- explicitly excluding the 481 irreducible-witness tail sample as a primary dataset and warning against constructing a KR-REP-DATASET from the old R1-R4 labels, which would be a category error. [S2628] Adds a transformation-registry schema (transformation_id, input_level, output_level, transformation_definition, source_provenance, reconstruction_status) so that any measured information loss between representation levels can be attributed to a specific operation, and restates the R1-R4-vs-reduction-hierarchy warning in dataset-construction terms: the next operation must be to inspect the actual KR-ZERO corpus schema empirically, never to write a mapping parser from specification alone. [S2632] Specifies Phase 4's independent-Q audit, accepting only an inquiry answer Q(D_i) that is explicitly evaluated from or deterministically reproducible from the raw source D, rejecting any Q derived from a reduced representation, from Zero-status, or from the desired outcome, with unverifiable independence recorded as Q=NULL / Q_independence_status=UNVERIFIED rather than manufacturing ground truth. [S2633]
