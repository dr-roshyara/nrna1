- [S0206] (ANALYSIS) Invariant-ownership table finding: all 11 workflow-record invariants (Inv A-J, G-2/G-3, R8) have a single identifiable code owner and an executable test (mostly class A); by contrast grant-identity uniqueness, temporal ordering of authority, and process/actor authenticity have NO owner at all (class E), while corpus reference integrity, identifier uniqueness, document schema conformance, and placement correctness have only advisory-only owners (class C) -- 'every invariant outside the workflow record either has no owner or has an advisory-only owner.'
