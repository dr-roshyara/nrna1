## Sources (how this label entered the ledger)
- OBJECT-INDEX · batch B0033 · scope THEORY-LEVEL: Step 177's core distinction chain for a proposition like 'the Nexus migration is safe': ClaimExists(C) does not imply Truth(C); an evidence-support relation E |- C means E supports C by the accepted method, not that C=True (drawing the P(H|X)>P(H) does not imply P(H|X)=1 statistical parallel, giving Evidence->DegreeOfSupport rather than Evidence->AbsoluteTruth). Distinguishes Evidence from Document (a document can contain evidence, but evidence's epistemic meaning -- Source/Time/Method/Provenance/Reliability/Scope/Validity -- is richer than its container). Builds the semantic (not persistence) knowledge tuple K=<Claim,Evidence,Method,Context,Validity,Confidence,Provenance,Time>, later condensed to K=<C,E,M,S,T,V,P>, explicitly a semantic model, not a database schema.
