## Rationale
Reads GoF Chain of Responsibility (multiple potential handlers, sender unaware which handles it) as a model for multiple evidence/cognitive routes (Network/Repository/CI-CD/Backup/Security), but notes the key difference that a KnowledgeOS chain must permit 'no route determines' (result Underdetermined) rather than assuming some handler eventually takes responsibility -- observing this is nonetheless compatible with GoF since the pattern itself allows a request to remain unhandled [S2864]. Concludes with a reframing of kernel-minimality research: rather than asking only whether operator X is irreducible, ask whether X's semantic capability can be reproduced by composing already-admitted capabilities behind the same contract, said to be directly testable with the existing capability-simulation framework and to give GoF 'a precise place in the KnowledgeOS research programme without contaminating Theory v1.2.' [S2864].
