## Rationale

Normality (the requirement cr(T)=1 for every logical truth T) is challenged because no finite agent can verify all logical truths. Two responses are given: the Extendability Criterion (a partial credence distribution is rational iff it can be extended to a complete probabilistic distribution), and Truth-Functional Bayesianism (restricting Normality and Finite Additivity to truth-functional truths/exclusivity only), the latter explicitly flagged with the drawback that it 'draws the line at an artificial place.' Mapped: 'the Zero Lens can detect logical inconsistencies in the Knowledge State without requiring full logical omniscience.' [S2305].
