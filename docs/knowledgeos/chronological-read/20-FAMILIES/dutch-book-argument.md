## Rationale
[S2305] (ARGUMENT/FORMALIZATION/EXAMPLE): The Dutch Book Theorem: violating the probability axioms (or violating Conditionalization diachronically) entails susceptibility to a set of bets guaranteed to produce a net loss in every possible state; worked with two concrete bet tables (a finite-additivity violation with cr(P)=cr(Q)=0.5, cr(P v Q)=0.8 producing a guaranteed -0.2 loss, and a non-Conditionalization update producing a guaranteed -0.05 loss). The Package Principle objection holds that a rational agent's value for a bundle of bets equals the sum of the individual bet values, underwriting the Dutch Book argument's force. Mapped as 'a formal argument for probabilism -- the Probability Axioms are rational requirements.'
