## Rationale
Before assigning a probability to a fact, one must first examine the logical/reasoning structure R:(O_1,O_2,F_1,F_2)->p that supports it and determine how strongly/weakly that reasoning establishes p; only if the relevant regime is probabilistic does one then assign P(p|O_1,O_2,O_3,F_1,F_2,R). The correct sequence is Facts+Evidence -> Reasoning/Logic -> Epistemic Assessment -> Probabilistic Value, not a direct Facts -> Probability jump. [S0673] Logic determines the relationship (A=>B); the probabilistic regime must separately determine how uncertainty propagates through that relationship (P(B|A,...)), which is not automatically equal to P(A). Additional assumptions are required, which is precisely why a logic lens must be applied before a probabilistic lens. [S0673] Probability must not be equated with uncertainty in general; probability is one mathematical representation of uncertainty under specified assumptions. If the assumptions/model change, P1(p|E,C) != P2(p|E,C); consequently two rational observers with the same evidence E and context C but different models can legitimately hold P_A(p|E,C) != P_B(p|E,C) -- same information + different model -> different epistemic state. [S0674]
