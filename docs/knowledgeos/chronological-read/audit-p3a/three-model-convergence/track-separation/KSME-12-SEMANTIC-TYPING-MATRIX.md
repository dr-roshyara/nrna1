# KSME-12 — Semantic Typing Matrix

**Central resolved question**: is `Observation` (the K_t primitive) the same mathematical object as an
observation function `o:E→Y`? **No — confirmed, source-established, not invented here.**

The corpus contains its own formalization: the **"Sañjaya layer,"** `W --Ω--> O`, where `W` = domain
reality, `Ω` = the observation *capability* (a function/operation, typed but bodyless), and `O` = state
*knowledge* — the output-kind the corpus explicitly identifies with the ratified `Observation` primitive.

Reality→StateKnowledge") → `20260826-160322` (table form) → `H-K16` (`R5-RESEARCH-TO-ARCHITECTURE-REPORT`,

`W--Ω-->O`"). `Ω` itself has **no executable semantics anywhere in the corpus** — the category confusion
is resolved; the missing function is not supplied by resolving it.

## The two senses of "observation" this matrix forces apart

1. **Trivial structural projection** — a getter on a hypothetical `E_B` carrier (e.g. `π_Entity:E→
   Entity-value`). Once `E_B` has a concrete carrier (which KSME-11 already found doesn't exist), such
   projections are definable for *all 8* primitives, Entity/Observation/Action included. No invention
   wall in this sense.
2. **Semantically-loaded, epistemically distinguishing observation** — the actual `step-291/02` catalog
   (`TraceOrigin`, `ExplainRevision`, etc.), the kind `∼_B` actually needs. **This is where Entity,
   Observation, and Action remain at zero.** Trivial projections are already known-inadequate for this
   role (bare structural equality/projection proven NOT a congruence, `step-288/06`).

**Corrected restatement of KSME-11's finding**: *"0 of 8 primitives have a semantically-loaded
distinguishing observation for Entity/Observation/Action"* — not "observations are categorically
impossible to construct." The gap survives, correctly scoped; it does not dissolve.
