## What this crosswalk explicitly does not do

- Does not force a Model-C column value where none was checked — cells read `UNRESOLVED` rather
  than an inferred guess, including for CC-04's Model-C cell.
- Does not treat "same correspondence-matrix row exists" as proof the row's adjudication is
  correct — CC-01 and CC-02 were the only rows independently cross-checked against this session's
  own primary-evidence work; CC-05–CC-10 are carried forward as unaudited claims from the prior
  program, explicitly marked as such.
- Does not merge CC-01 (cross-model Kernel non-identity) with this session's own intra-label
  9-formulation Kernel finding into a single number or a single verdict — they measure different
  things (which models a formulation belongs to, vs. how many formulations exist within one
  already-identified label) and are kept as two distinct, non-competing facts.
