## The extended model

For a cross-model concept pair (M_i-concept, M_j-concept), define `Dep()` exactly as in the
intra-corpus model, plus one new category specific to cross-model work:

4. **`INDEPENDENT-RECONSTRUCTION`** — the two concepts were produced under an explicit
   authorization boundary designed to prevent cross-contamination (e.g. `03_model-b_mathematical`'s
   own stated "does not import or reference any Model-A material, per the authorization's
   independence requirement"). This is the *strongest* form of dependency-independence available in
   this corpus — stronger than "no citation found," because it is a **designed, disclosed
   methodological control**, not merely an absence.

material:

  not hidden, and is the reason B's four cardinality-8 kernels are not mutually reducible either.

  (not proof of) the designed independence-authorization finding above.
