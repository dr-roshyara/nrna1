## 2a. Supplementary finding — Step 273 as a common cited ancestor of `K_min⁴` and canonical-construction `K` (added after this pass's own initial synthesis, by a parallel review pass)

While this document was being produced, a parallel review pass independently re-read `S1792` more
closely (lines ~1970–2015, `S1792` Pass 2's own §276.3, "What Steps 273–275 Actually Achieved") and
then directly inspected Step 273's own primary source file —
`docs/knowledgeos/brainstorming/phase_measure_theory/20260830-214401_step_273_knowledge-state-sufficiency-and-minimality.md`
— to check a hypothesis raised independently during that pass: that `K_min⁴` and the
canonical-construction package might not be fully independent sources.

**Finding, confirmed by direct primary-source reading of both citing documents and the cited
ancestor itself:**

- `S1792` Pass 2 states verbatim (§276.3): *"Step 273 established the correct research question:
  K_canonical = minimal state representation sufficient to preserve mandatory distinctions and
  operations. It also explicitly treated K_c=(A,R,Σ,E_L) as a starting hypothesis."*
- The canonical-construction package's own `03-CANONICAL-K.md` separately cites "Step 273 §273.31"
  (already established in BC-02.13).
- Step 273's own file confirms both citations independently: line 18/68 states
  `K=(A,R,Σ,E_L)`/`K_c=(A,R,Σ,E_L)` as *"the minimal state representation sufficient to preserve
  every mandatory distinction and operation of KnowledgeOS"* (there attributed to **Step 272**, one
  step earlier, not originated by Step 273 itself), and §273.36 states a **non-negotiable four-part
  test** before any canonicality claim is permitted: *"every primitive component is necessary"* AND
  *"every non-primitive component is derivable or externally accessible"* AND *"every mandatory core
  operation is computable"* AND *"no required semantic distinction is lost."* §273.37 lays out the
  exact pipeline both later documents are, in different ways, attempting to execute:
  `O_core → Requirements(K) → Candidate K → Deletion/Replacement/Counterexample Tests → K_minimal →
  State Algebra → ...`.

**Corrected classification** (this supersedes BC-02.12's framing of `S1792` and the
canonical-construction package as two independent, `I1`-basis primary sources that merely happen to
disagree on minimality): **the two are not independent — they are two same-day-or-later applications
of one common, explicitly-named primary source's (Step 273's) own stated criterion**, diverging in
which candidate object each actually tested (`K_min⁴`'s hypothesis, left untested per `S1792`'s own
words, vs. canonical-construction's actually-executed removal test on a differently-scoped,
larger object). This is structurally the same correction already applied elsewhere in this
investigation to the `Qualify`/`D285-6` chain (BC-02.13-Q): **downstream witnesses of one shared
primary source are not independent confirmation or independent contradiction events.**

**What this does NOT change**: the minimality *contradiction* itself (§8, §15 below) stands — the two
objects still disagree on which candidate satisfies Step 273's own four-part test, and `K_min⁴`
specifically was never subjected to that test at all, per `S1792`'s own admission ("`K_minimal` is a
hypothesis, not a theorem"). What changes is only the **provenance character** of the disagreement:
from "two unrelated sources independently disagree" to "two sources citing the same named ancestor
diverge in execution rigor." Status: `SOURCE-CLAIMED` common ancestry (both citing documents name
Step 273 explicitly), independently corroborated by direct reading of Step 273's own file.

### 12.2 `Γ`: `E_t → K_t` (`knowledgeos-sim`) — **new this pass, the only fully computable mapping found in this entire investigation**

`knowledge_attribution(E, Q, C, EC)` (`kos/state.py`, read directly):

- **Well-definedness**: **yes** — every valid `(E,Q,C,EC)` input produces a uniquely determined
  `dict`.
- **Totality**: **yes over its stated domain** — the function always returns (possibly empty for
  propositions outside `Q.target` or absent from `E.determinations`); no undefined case in the code
  read.
- **Determinism**: **yes** — purely functional over its inputs, no randomness in the mapping itself
  (randomness is introduced only upstream, in scenario generation for the 10,000-trial suite).
- **Computability**: **yes** — this is the one mapping in the whole BC-02 arc that is not blocked
  on a missing function body.
- **Information preservation**: **explicitly partial by design** — `K_{a,c,t}=KnowledgeAttribution(E)
  ⊆E` (the package's own stated "v1.1 CORRECTION"); per-proposition fields not in `Q.target` are
  dropped, and only `status/A/independent_sources/weight/causal_status/provenance/assumptions/
  attributed/value` survive per attributed proposition — raw observations, interpretations,
  rejections, models, and history are not carried into `K_t`.
- **Semantic preservation**: **proven to fail**, rigorously, for one specific property.
  `factivity.py`'s witness construction shows two worlds with different ground truth for `os`
  produce a **bit-identical** `E` (verified by an explicit fingerprint over every field `Γ` could
  possibly read), so `Γ` returns an identical `K` in both — meaning `Knows(a,p,c,t)→True(p,c,t)`
  and `K_t=Γ(E_t,…)` are **jointly unsatisfiable for any total `Γ` that attributes anything**.
  Confirmed empirically over 10,000 randomized trials: 420 factivity violations, conditional
  failure rate `0.1237` given an attribution was made.
- **Task sufficiency, computation-dependent — independently reconfirming BC-02.7's own method**:
  19 of the package's own 20 tested properties (`P1`–`P20`) **hold** under `Γ` as defined; property
  `P11` (factivity) **fails, necessarily**. This is a second, wholly independent instance
  (different corpus thread, different projection, different author) of exactly the pattern BC-02.7
  established for S0881's `π₁`: **a single projection can be sufficient for the great majority of a
  theory's own required properties while being provably insufficient for one specific, named one.**

**No mapping test is performed for `KO-005`↔`KO-006`, `KO-005`↔`KO-008`, or `KO-005`↔`KO-009b`**,
