pair, but the reviewer never sees the evidence that would justify a positive

## PROTOCOL-AMBIGUITY-001

A11's text ("a lineage_claim links them... target string matches label Y's own
working_label") does not specify whether "matches" means exact string equality
or permits a paraphrase/substring form. V1 resolved this ambiguity silently, by
implementation, toward the narrowest reading (exact equality only). **This
repair does not resolve the ambiguity by picking one interpretation and hiding
it — it makes the distinction explicit**: mechanism D (exact match) and
mechanism E (substring match, separately confidence-graded) are recorded as
**separate, independently-labeled mechanisms**, so an adjudicator (or a future
protocol revision) can see exactly which kind of match justified a candidate,
rather than the ambiguity being silently collapsed into one code path as V1 did.
**This is flagged as PROTOCOL-AMBIGUITY-001, not resolved in the protocol text
itself.**

## Repair summary (see the four companion specs for full detail)

1. **Candidate generation** (`derive_reconciliation_v2.py`): 8 mechanisms (A-H,
   see CANDIDATE-GENERATION-SPEC.md), all provenance-aware, all deterministic,
   zero relationship/basis decisions made.
2. **Evidence bundle** (`evidence_bundle_v2.py`): full-field bundle per row
   (see EVIDENCE-BUNDLE-SPEC.md), excluding only `version_ref`/`experiment{}`/
   `review_flag` (no protocol rule ties these to a relationship decision).
3. **Negative-evidence / provenance-firewall handling**: **NOT modified in this
   repair.** The `NEGATIVE-BOUNDED` enforcement gap and R16 discipline are
   adjudication-schema matters (`verify_reconciliation_pairs_batch.py`, the P3a
   dispatch prompt template), not candidate-generation matters. Fixing them is
   explicitly out of scope for this "surgical P3a evidence-flow repair" (§19) —
   documented here as a known, deferred item, not silently absorbed.
4. **One disclosed mid-repair correction**: an initial version of mechanism F
   (prose-trigger) produced 538 candidate pairs, 74.1% of which were driven by
   just 2 of 2,497 labels (`KnowledgeOS`, `provenance`) being generic vocabulary
   that coincidentally co-occurs with relationship verbs in unrelated text. Fixed
   by excluding the 8 single-word (no-hyphen) labels from serving as mechanism
   F's matched target — reduced the mechanism's output from 538 to 102 pairs
   (81% reduction) with zero effect on the 4 structured mechanisms (B-E).
