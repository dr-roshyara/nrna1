## 2 · The recorded boundary (the answer is grounded, never invented)

The architecture already establishes the entire classification envelope the question needs. Every clause below is existing law:

| Surface | The rule (existing) |
|---|---|
| **Article 1 · expression** (Port Contract §1, lines 21 · 58) | an expression is a **surface form · any language · any order — carries no epistemic weight**; a candidate is a proposal, not an assertion |
| **INV-KOS-IDENTITY-001** (v1.1 §7) | Identity is **assigned, never derived**; similarity never becomes identity; **⟨C-1⟩ canonical-form equality is a similarity claim, not an identity determination** |
| **P-4** (v1.1 §1) | Identity is assigned, never derived — KnowledgeId is assigned at creation; **no similarity, coextension, observable match or canonical-form equality produces it** |
| **⟨C-1⟩ non-admission note** (v1.1 §12.1) | A canonical form is still a representation; canonical-form equality is therefore a similarity claim in formal dress. `SNF(E1)=SNF(E2)` ⇒ ⛔ *"therefore the same knowledge object"* (**FORBIDDEN**) · ✅ *"therefore a CANDIDATE for the same admitted meaning, offered to an authorized identity-assignment act, which may accept or refuse it"* — the ✅-route holds **without regard to the surface languages of E1 and E2** |
| **Port Contract §7 · prohibited inference 6** (lines 128 · 130) | *"SNF equality → knowledge identity"* is **forbidden** — equality of canonical forms is a similarity claim, never an identity determination; SNF equality therefore means **a candidate for the same admitted meaning**, offered to an authorized identity-assignment act (⟨C-1⟩); the SNF family may support identity **reasoning** (as evidence, §8), it never performs identity **assignment** |
| **Port Contract §Q8** (lines 132–138) | collisions = **candidate-equality observations**; evidence **never** admission; **never read as identity, truth, equivalence, or certainty**; non-collapse measured **both directions** (semantic invariance without non-collapse = lossy canonicalization); **no state change** · **not a domain event** |
| **OQ-2 ruling** (HPA, 2026-08-23 · recorded 56e1bd8a) | SNF-equivalence may be recorded as an EvidenceLink supporting an identity-assignment act, **as a candidate-side evidence observation, never as the assignment itself**; reference-only (⟨C-3⟩) · no state change (⟨A-3⟩) · no identity derivation (INV-KOS-IDENTITY-001) · no Verification-Port bypass (INV-KOS-VERIFICATION-001) |
| **Negative boundary — translation collapse** (Sanskrit Word-Order review 20260822-1415 · §9) | **REFUSED failure**: *"English word = Sanskrit word; meaning structure may differ"* → similarity ≠ truth — a translated surface is **not** thereby the same meaning |
| **Negative boundary — token ≠ meaning** (Sanskrit Grammar review 20260822-1345 · §8) | **REFUSED failure**: *"translation/dictionary fails; LLM word-statistics → meaning assumption"* — word-level translation is not meaning identity |
| **No translation authority** (Port Contract §1–§4) | the port publishes **candidates**, never translation-equivalence; translation is not a verb in the port's published language |

**What this envelope already decides:** the observation that two expressions in different languages (e.g. EN/DE) normalize to the same candidate is **already classified** by the architecture. It is a **candidate-equality observation (a collision)** — a **candidate for the same admitted meaning**, offered to an authorized identity-assignment act (⟨C-1⟩ ✅-route · §Q8 · contract §4), **never an identity determination** (INV-KOS-IDENTITY-001 · P-4 · prohibited inference 6), and **never a claim of translation-equivalence** — the translation reading is a **refused failure** (translation collapse · token ≠ meaning) and the port has no translation authority. The only genuinely open remainder is the **empirical** one the Second Review flags — whether a real normalizer's cross-language collisions reflect shared meaning or translation-collapse (mechanism reliability) — which v1.1 §20 and both reviews route to **experiment design** (OQ-4 territory).
