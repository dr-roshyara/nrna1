## OBSERVATION

The hypothesis: the two divergent Kernel member lists in `S1-F003` are not competing answers to *"what is in the Kernel?"* but answers to **different questions about the same Kernel** —

| Question | What an answer enumerates | Which Session-1 list |
|---|---|---|
| **WHY** does the Kernel exist? | purpose | — |
| **WHAT** must it protect? | protected concerns | **list A** |
| **HOW** does it operate? | mechanism / pipeline stages | **list B** |

Under this reading `S1-F003`'s "divergence after 36 minutes" is not instability at all. It is a single author moving from the protected-concern question to the mechanism question and writing down each answer — which is what a modeller *should* do.

## EVIDENCE

Only what is already in the register: the type mismatch recorded in `S2-F007`, and the systematic conflation of question-types recorded in `S2-F010`. **No new evidence.** In particular:

- ⚠ I have **not** read the corpus, so I cannot confirm that either list was actually written in answer to the question this model assigns it. The assignment is inferred from the *shape* of each list, not from any stated intent.
- ⚠ The WHY column is **empty**. A three-part model whose first part has no instance in the evidence is, at best, two-thirds observed. Under the second lens that emptiness is *unmentioned* — not *absent*, and certainly not *excluded*.

## ANALYSIS

What the model would explain if true — and this is its real attraction — is not one finding but the cluster:

| Register finding | What the model would say about it |
|---|---|
| `S2-F007` ill-typed intersection | expected; the lists answer different questions, so no intersection was ever meant |
| `S2-F009` F1 undercuts F2 | softened; a mechanism list is not a category claim |
| `S2-F010` four question-types conflated | this *is* the model, stated as a defect rather than as a structure |
| `S2-F011` A/B same-altitude | ⛔ **contradicted** — see below |
| `S2-F012` count is 1–2, not 3 | untouched |

**`S2-F011` is the load-bearing objection.** I ran the altitude test on A/B directly and **declined** the reconciliation: both lists speak about *mechanism*, so the altitude test gives no relief there. This model asserts the opposite — that A is about protected concerns and B about mechanism. Both cannot stand.

I do not resolve that. Two candidate explanations, neither tested:

1. `S2-F011` is right and this model reads list A too generously — its items may name mechanisms in concern-flavoured language.
2. This model is right and `S2-F011` classified list A by its vocabulary rather than by the question it answers.

Distinguishing them requires knowing what question each list was written to answer — which is corpus evidence, and therefore **out of this session's reach.** Recorded as the discriminating test for whoever holds that evidence.

## WHY IT MATTERS

Because the model is *good*, and that is exactly the hazard the standing rule was written for. It is parsimonious, it dissolves four register findings at once, and it flatters everyone: Session 1 made no error, Session 2 found a structure, no contradiction survives. **A reconciliation that comfortable should raise the burden of proof, not lower it.**

The standing rule is explicit: finding a plausible reconciliation does not license resolving the issue. So:

- `S1-F003`'s status remains **as Session 1 recorded it.** Unchanged.
- `S2-F007` and `S2-F011` remain **as delivered.** Not withdrawn, not annotated as superseded.
- This model is a **third reading beside them**, holding no rank over either.

If it were adopted now, its first act would be to retire `S2-F011` — the one finding that contradicts it — on no evidence beyond its own elegance.
