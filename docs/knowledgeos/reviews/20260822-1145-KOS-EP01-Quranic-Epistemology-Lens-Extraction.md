## 1 · The nine lenses (HPA, in substance)

| Lens | Quranic pattern | Architectural abstraction | KnowledgeOS mapping | Classification |
|---|---|---|---|---|
| **1 Ontology** | Reality (al-ḥaqq) exists independently of human opinion; humans know partially, misunderstand, distort; knowledge is not created by belief | Reality → human perception → knowledge claim — **the claim is not the reality** | Observation ≠ Reality · Expression ≠ Meaning · Belief ≠ Knowledge | ✅ Existing Identity/Evidence principle — not new |
| **2 Epistemology** | Āyah (sign): the world contains indicators from which knowledge is discovered; knowledge is not only transmitted, it is interpreted | Phenomenon → Observation → Reflection → Understanding | Evidence lifecycle: Event → Evidence → Interpretation → Knowledge state · **Evidence ≠ Interpretation** (a sign is not the conclusion; it points toward understanding) — aligns with Observation ≠ Inference | ✅ Reasoning/Evidence support |
| **3 Human limitation** | *"You have been given only a little knowledge"* — the knower is bounded | Current knowledge state ≠ absolute complete knowledge | Unknown state · Uncertainty · Revisability · preserve Known/Unknown/Conflicted/Unvalidated | ✅ Existing Uncertainty principle |
| **4 Verification before acceptance** | Do not accept information without checking; verify information brought by a source | Claim → who says it? + what evidence? → Verification → knowledge status | **Authority ≠ Evidence** — a source contributes provenance/context/confidence, but verification decides admission | ✅ Existing Verification Gate |
| **5 Intention / Knower (Niyyah)** | Intention, honesty, motive, sincerity | Knowledge is not only Object → Claim but Agent → Intent → Claim | Agent dimension: who observed / who interpreted / who asserted / under what role (≈ Tripuṭī Knower-Knowing-Known) | ✅ Existing Agent dimension |
| **6 Truth–falsehood criterion (Al-Furqān)** | The ability to distinguish | Information → evaluation criteria → Knowledge | Evidence evaluation · Reasoning · Contradiction handling | ✅ Verification/reasoning support |
| **7 Testimony / transmission (Isnād)** | A statement is *X reported by A from B from C with reliability assessment* | Knowledge → Origin + Transmission path + Reliability + Context | Provenance graph · Evidence lineage · Transformation history — **the HPA's own necessity test: "KnowledgeOS can exist without religious transmission chains, but cannot exist without provenance."** | 🟡 **Mechanism / representation — NOT kernel** |
| **8 Reflection (Tadabbur/Tafakkur)** | Knowledge is not passive storage; reflection/contemplation/reasoning | Input → Reflection → Understanding → Action | Evidence → Reasoning Engine → Knowledge state → Decision — **but the lens does not define the reasoning algorithm** | 🟡 Reasoning mechanism |
| **9 Certainty–humility balance** | Seek knowledge but avoid claiming absolute certainty where it cannot be known | Strong evidence → high confidence · weak evidence → open uncertainty — **the system should not pretend** | Unknown ≠ Failure · Uncertainty ≠ Error | ✅ Existing Unknown dimension |
