| # | Lens | False identification | KnowledgeOS boundary |
|---|---|---|---|
| 1 | Vedic/Vedānta | Information = Knowledge = Realization (memorization ≠ understanding) | **Stored representation ≠ semantic understanding** (document = *representation of possible knowledge*) |
| 2 | Gita (Jñāna/Vijñāna) | Information volume = Knowledge maturity | A bigger store ≠ more knowledge — it may be **more unprocessed claims** |
| 3 | Tripuṭī | Knowledge independent of the knower | **Claim without knower = incomplete epistemic object** — who assessed it? when? using which evidence? under which assumptions? |
| 4 | Nyāya/Tarka | Belief = Valid cognition (Pramā) | Authority produces a **claim**, not **truth** |
| 5 | Hetvābhāsa | A convincing argument = Knowledge (false cause · weak evidence) | Premise + inference rule + conclusion must be preserved — **a conclusion without reasoning provenance is not knowledge** |
| 6 | Abhāva | Absence = nothing | **Absence = structured knowledge** — absent object + locus + time + relation (no security patch installed = a structured fact, not emptiness) |
| 7 | Zero | Current position = Truth (Engineer A vs Engineer B) | Knowledge = **best justified state relative to evidence**, not strongest opinion — return to Zero, collect evidence, evaluate |
| 8 | Quranic | Someone reported X = X is known | Verification precedes acceptance — **transmission creates provenance, not automatically truth** |
| 9 | Isnād/Provenance | The final statement alone = Knowledge | **A knowledge object includes its journey** (observation → generated-by → processed-by → confirmed-by → at-time) |
| 10 | LLM | Most likely continuation = Knowledge | **Plausible expression ≠ accountable knowledge state** (Prompt→continuation vs Observation→Evidence→Reasoning→Validated state) |
| 11 | Similarity/Vector | Semantic proximity = Semantic identity | **Similarity ≠ Identity** (coextension: same examples, similar descriptions, still different concepts) |
| 12 | Transformation | Latest version = Knowledge (v2 replaces v1) | **Update ≠ deletion** — the old state remains part of identity |
