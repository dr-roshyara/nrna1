Completely different traditions reached the same structural problems:

| Source | Core extraction | Architectural consequence | Supports |

| **Epistemic Control Systems** | system governs belief, not reality | never "reality = stored state"; always "current justified belief = stored state" | Temporal · Evidence · Authority · Revision |
