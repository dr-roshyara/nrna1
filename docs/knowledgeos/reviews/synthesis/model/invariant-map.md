both documents sit in one generative lineage (PQ-02), so cross-regime support is R2's Q17 + R3's
authority correction rather than document count.

**3 · "extraction ≠ determination" — INVARIANT-CANDIDATE, exact evidence:**
⟦C⟧ `20260825-234405`: *"**Extraction retrieves material. Determination establishes what that material
warrants asserting.**"* Single locus, R1, never contradicted, never formally re-hosted (OQ-03).
Classification: **candidate INVARIANT, single-source** — strong wording, weak corroboration.
