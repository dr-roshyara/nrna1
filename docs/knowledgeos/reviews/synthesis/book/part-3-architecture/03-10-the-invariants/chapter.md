# III.10 · The Invariants

[FA] Twelve invariants, each carried with the grade it earned — because an invariant list where
everything looks equally certain is itself an epistemic collapse of the kind this architecture
forbids.

| # | Invariant | Grade, as ratified |
|---|---|---|
| I-1 | The Knower owns problem, purpose, IdealState, and final authority | READ — the three-regime chain, the model's strongest lineage |
| I-2 | Proposal ≠ decision; the selector holds no authority | READ |
| I-3 | SufficientKnowledge ≠ ValidDecision ≠ AuthorizedAction | READ |
| I-4 | Authority determines commitment, not evidential truth (A6) | READ |
| I-5 | Duplicates must not raise confidence; independent corroboration must | **TESTED** (EXP-01) |
| I-6 | Dependency resolution precedes aggregation | **TESTED** (EXP-01) |
| I-7 | `X_t ≠ Observed(X_t)` — model ≠ reality, structurally | READ |
| I-8 | No architectural assertion without evidence (method invariant) | READ (109), partially executed |
| I-9 | Zero's four-way non-satisfaction typology never collapses to Boolean | READ |
| I-10 | Constitution changes require approval (governance) | READ (042) — **violated in the real repo per Step 121**: live finding |
| I-11 | No in-force policy changes without a governed, versioned decision | REQUIRED-BY-COHERENCE, corpus-adjacent |
| I-12 | Status transitions follow the covering relation; no skipping | REQUIRED-BY-COHERENCE |

Three readings the table rewards. **First**, only two rows are TESTED — both about evidence
combination, both from one experiment; everything else is read-verified from the corpus or
required by coherence under ruling. The architecture's honesty about its own grades is not a
disclaimer; it is I-8 applied to itself. **Second**, I-11 and I-12 are the two invariants the
falsification pass *forced* — the model as first synthesized violated the first and lacked the
second; they entered by ruled repair, and the ledger says so. **Third**, the conformance pass
tested how the running world honors these: the boundary invariants (I-2/3/4) are enacted in
governance practice and running bootstrap code; the ordering invariant I-6 has *no repository
statement at all* (OQ-12) — an asymmetry worth keeping visible, because it marks exactly where the
formal model is ahead of its own ecosystem.
