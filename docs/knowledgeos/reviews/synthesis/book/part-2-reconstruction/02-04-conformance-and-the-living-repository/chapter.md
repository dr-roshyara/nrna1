# II.4 · Conformance and the Living Repository

[M] With an authorized model in hand, the programme asked the opposite question: does the *actual*
repository — constitution, governance records, running code — conform to it? The conformance pass
(3C) ran under strict rules that are themselves worth study: a scope plan approved before any
testing; five verdicts only (CONFORMANT, PARTIALLY CONFORMANT, NON-CONFORMANT, NOT ESTABLISHED,
OUT OF SCOPE); *no silent upgrade* of NOT ESTABLISHED; evidence ⟦E⟧ separated from interpretation
⟦INT⟧ with verdicts resting on evidence alone; and the cardinal rule — 3C tests the model, never
repairs it. Difference is a finding, not a defect.

[M] The results reshaped the programme's self-understanding. The repository corresponds to the
model **at the boundaries** — authority assigned by human act, adoption and authorization as
separate acts, no-skip enforced in practice, fail-closed authorization in running code — and
**not at the formal layer**: no executable counterpart exists for any formal object, a fact
recorded at exactly that strength (the ruled conclusion: substantial evidence for the boundaries
and governance principles; implementation-level correspondence for several formal objects not
established — *not* "therefore the model is wrong").

[M] The pass also surfaced the seams later gates had to govern: a diverged parallel branch
carrying a Reference Architecture v1.1 (resolved: a lane, not a rival — intake deferred to an
explicit future act); the constitution's stale status banner (resolved: the ratification act was
real; the banner sync is held); a three-cell contradiction between an experiment's CSV export and
its own prose record (adjudicated: the prose prevails; the CSV is unreliable standalone); and the
vocabulary discovery — the repository's rich epistemic states versus the model's lean ladder —
that became, through a ruled disposition and the archaeology's dating, the inheritance Part III.6
describes.

[M] Every one of those seams was dispositioned by explicit ruling — resolve-before, feed-into,
adjudicate — before the final synthesis was allowed to begin. The chapter's lesson generalizes:
a conformance pass whose findings can be repaired in-line will find what is convenient; one whose
findings must survive to a ruling finds what is there.
