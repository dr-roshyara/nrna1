⟦INT⟧ Reading across the rows — **corrected at the review gate (2026-08-28):** the **declared evidence
standard increases in stringency** across the regimes: argument → enumeration → guarded analogy →
property test → audit/evidence. ⚠ Two cautions fixed by the gate: (1) *evidence sophistication ↑ does
not imply truth/correctness ↑* — the later regimes have **stronger mechanisms for detecting error**,
which is a different property; an R2 assertion is not thereby less intellectually valuable than an R4
property test. (2) Two trajectories must be kept separate: **how we came to know** (method/evidence)
and **what we came to believe the architecture is** (object). The regimes are not a maturity ladder:
R(i+1) changes the question and/or the evidence available to R(i) — it may invalidate, preserve,
rename, or split earlier conclusions. The three-dimensional model (object / method / evidence) in
`../model/regime-transition-analysis.md` supersedes any ladder reading of this matrix.
