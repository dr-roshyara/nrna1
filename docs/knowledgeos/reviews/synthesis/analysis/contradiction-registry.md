## CON-01 · Zero Lens → Zero Algebra — **the formalization changed the concept**

| # | Question | Answer ⟦READ⟧ |
|---|---|---|
| 1 | Original lens? | ⟦C⟧ *"Zero asks: What is absent, undefined, unrepresented, or assumed away?"* — protecting `UNKNOWN ≠ ABSENT`, `NOT_ASSESSED ≠ LOW_CONFIDENCE`, `NO_EVIDENCE ≠ INVALID_EVIDENCE` (`20260826-105126`). An **absence-detection instrument**. |
| 2 | What was formalized? | ⟦C⟧ `step-025d`: *"we have used Zero intuitively as **'the gap between where we are and where we need to be'**"* → `Zero(K, G, EC)` comparing **requirements against epistemic state**, with the correction *"Zero ≠ simple subtraction"* and a four-way non-satisfaction typology (unknown / conflicting / missing / invalid). |

| 6 | Computationally tested? | Indirectly — the kernel containing it survives Step 50's 50-attack audit ⟦READ⟧; a Zero-specific test is NOT ESTABLISHED. |
| 7 | Repository validated? | NOT ESTABLISHED. |

⟦INT⟧ **Verdict: this is bridge-type D of the instruction's taxonomy (creative modeling move via

goal-free, the second is goal-indexed. The corpus never records that the meaning changed.
⟦OBS⟧ Aggravating context from outside this corpus (recorded, not imported as authority): the kernel
corpus already carried **two other incompatible Zero definitions** (subtractive-structural at
`kernel/…152415`; statistical-residual at `kernel/…154254`). `025d` is therefore at least the **third
distinct meaning** of the corpus's most-used instrument.
**Status: EPISTEMIC GAP CONFIRMED · semantic shift UNACKNOWLEDGED in source.**
