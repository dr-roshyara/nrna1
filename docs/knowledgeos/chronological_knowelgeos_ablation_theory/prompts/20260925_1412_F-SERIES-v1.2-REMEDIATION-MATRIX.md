# F-SERIES v1.2 — REMEDIATION MATRIX (decided before coding)

**Status: DRAFT → implemented in v1.2 (F-LOG-0008).** Input: the independent audit
`audits/20260925_1500_F-SERIES-v1.1-INDEPENDENT-AUDIT.md` (F-LOG-0007), architect review notes RN-01…RN-10
(F-LOG-0005, F-LOG-0006), and the human remediation commission of 2026-09-25 ("F-SERIES — v1.2 REMEDIATION AND
RE-AUDIT BEFORE F3082"). **Guiding principle:** first make L1 evidence trustworthy and immutable, then permit L2, then L3.
**Proportionality test for every control:** does it materially protect source integrity, epistemic separation,
statistical validity, reproducibility, or mathematical/DDD correctness? If not, DEFER.

Decisions: **ACCEPT** (as the auditor stated) · **MODIFY** (a revised control) · **REJECT** (with a reason) ·
**DEFER** (safe to wait, with a reason). **HDR** = HUMAN DECISION REQUIRED (a commission stop condition). The item is
mechanically blocked, not improvised.
