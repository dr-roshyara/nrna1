## 5. Mathematical closure opportunities

### 5.1 `[E]-02'` — the CAP minimum independence definition is too weak (a deductive counterexample)

- **CAP definition:** `indep(o₁, o₂) ⟺ Src(o₁) ∉ Chain(o₂) ∧ Src(o₂) ∉ Chain(o₁)`.
- **Counterexample (abstract; no corpus claim).** Let o₁ and o₂ have distinct sources a₁ ≠ a₂, where a₁ and a₂ both cite a common artifact c, and neither cites the other.
  - The CAP definition returns **independent**.
  - But both rest on c, which is ARCH RA-15 D's third defeating test (*"shared underlying evidence"*, L418–424; GI-1 caveat).
  - So the definition admits **common-cause dependence**.
- **Closure `[E]`:**
  - `indep(o₁, o₂) ⟺ Anc(o₁) ∩ Anc(o₂) = ∅`, where Anc(o) is the reflexive-transitive closure of recorded provenance links.
  - "n independent occurrences" is **the size of the largest pairwise-independent set**: the clique number of the independence graph, equivalently the independence number of the dependence graph. The bar `n ≥ 2` then requires **one** ancestry-disjoint pair.
- **Consequence:** an evidential count that feeds H-F2-1 must be computed by this rule, never by raw occurrence counts (`[E]-02` survives, sharpened).
- **Limit:** recorded ancestry is a **lower bound**. A pair found disjoint in the records is `UNWITNESSED`-dependent, **not** proven independent (MP §25 discipline).

## 10. Minimum F2 closure path — H-F2-1, the "governed-change structure" `[E]`

**Status:** `HYPOTHESIS`, proposed in this analysis. The statements it formalizes are `[C]`/`[S]` (T-0013, T-0014, T-0056). The formalization is `[E]`.

**Signature:**
- a governed item k has state **x = (p, s, e)** and an act log g;
- **P = {generated, derived}** and **S = {authoritative, provisional, historical}** (T-0014 statement);
- **(E, ≤)** is a finite poset of evidential standings; one instance is the P-10 chain n0 < n1 < n≥2;
- **g** is an append-only log of grants;
- **𝒯** is the set of recorded mechanisms. Each μ ∈ 𝒯 is a step relation on (x, g) with a **kind κ(μ) ∈ {GOV, EVID, WORK, COMPOSITE}** (T-0056 definitions).

**Axioms** (each is the corpus's own claim, made precise):

| # | Axiom | Source |
|---|---|---|
| **A0** | every candidate bar is monotone, i.e. an **up-set** U ⊆ E | [E] assumption. It holds for the recorded ES-006.1 bar `n ≥ 2`. **If some bar in the corpus is not an up-set, A0 fails and H-F2-1 does not apply to it** |
| **A1 (provenance invariance)** | for every step (p, s, e, g) → (p′, s′, e′, g′): **p′ = p** | T-0014 *"Nothing is a transition in P"*; T-0056 *"PROVENANCE … does not progress at all"* |
| **A2 (governance locality)** | κ = GOV ⇒ **e′ = e**; only GOV steps append to g | T-0013 *"no ruling makes an observation Replicated"*; T-0056 GOVERNANCE-ACT def |
| **A3 (evidential locality + monotonicity)** | κ = EVID ⇒ **s′ = s, g′ = g, and (e ≤ e′ or the step is tagged refutation)** | T-0013 *"no evidence makes a document frozen"*; T-0056 *"reversible only by refutation"* |
| **A5 (work locality)** | κ = WORK ⇒ **s′ = s, g′ = g, e′ = e**. | **A4 (composite factorization)** | every COMPOSITE mechanism is a finite sequence of GOV, EVID and WORK steps; **no single step changes both (s or g) and e** | T-0056 COMPOSITE = *"crossing the above"*; F0018 conclusion *"four kinds of change and one immutable fact, wearing ten mechanisms"* |

| # | Proposition |

| **D2** | if ¬granted, no sequence of EVID or WORK steps makes promote_U true (A3 keeps g fixed) |
