# Independent review (frozen)

Researcher A answered `TASK.md` from `SOURCES.md` (in `ANSWER.json` / `ANSWER.md`). Use only these files.

Check each of the following:
1. Only permitted evidence was used.
2. Every quote is verbatim, and supports the claim it is attached to.
3. Nothing was silently inferred. Separate:
   - what the text **states** about order;
   - what follows **logically**, e.g. "a checklist defined by the rule cannot run before the rule text exists";
   - what is **assumed**.
4. No category confusion. Keep these apart:
   - the PA's instruction;
   - the hosting or writing of the rule;
   - the commit;
   - the register row;
   - the first checklist run.

   Which of these is the *decision act*?
5. Any missed quote bearing on the order.
6. Whether the ordering and the decision-time evidence follow. Recompute them under your own corrected reading.
7. The strongest alternative, e.g. "the PA's instruction already cited both instances", and whether the text rules it out.

Classify each disagreement as: wording · source interpretation · coding · evidence scope · independence · formal reasoning · substantive. Do not average.

Write **REVIEW.md** (summary · findings · recomputed ordering · alternatives · disagreement register · what can and cannot be established) and **REVIEW.json** ({ordering_A, ordering_reviewer, evidence_A, evidence_reviewer, disagreements: [...]}).
