- **[INT] What this batch contributes to the theory** (interpretation, ≤ 8):
  1. The probabilistic branch is reframed as a Kernel-minimality test, K_min^det ≅? K_min^prob. There are two different hypotheses. F1796 L822 records an unconditional one, "H: Probability is not Kernel-primitive [PROP][OPEN]". F1800 L407–L409 gives a conditional H_0, "…unless a Kernel-owned invariant requires persistent probabilistic state", labelled "My recommended" (candidate). F1800's H_0 and H_1 are not logical complements; the source calls H_1 "the alternative" (L415).
  2. A "derive structure from observability" programme replaces importing topology or vector spaces. The chain is required distinctions → admissible observables → separation → equivalence → quotient → congruence → minimal representation (F1808, F1811).
  3. D4.5 gives the first proved core in this batch: faithfulness as kernel inclusion, and S/~_req as the coarsest faithful identification. The proofs are near-definitional. Minimality is left explicitly open (F1811 L1345), despite the source calling T2 "the important minimality result" (L762).
  4. Dimension is redefined as an independent or separating requirement-relevant observable distinction, not a field or sentence. Its count varies across files (see bullet 8).
  5. A split stabilises across several voices (F1813, F1814, F1825, F1826): a structural representation layer (R_t^{min} / \mathfrak R) and an epistemic valuation layer (K_t over it). K_t is not to be identified with the quotient.
  6. Probability is relocated from a marginal vector to a consistent family of finite-dimensional measures (F1825). It is also denied vector-space status (F1826).
  7. Evaluation is formalised as Sat/Adeq, with Δ_t as the set of unsatisfied requirements and Zero ⟺ Δ_t=∅ (F1816). Sat semantics remains "the most important remaining problem" (F1816 L2714).
