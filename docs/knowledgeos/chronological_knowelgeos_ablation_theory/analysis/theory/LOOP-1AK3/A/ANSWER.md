## Classification
- **FORMAL CONSEQUENCE:** `kind` is known and differs (reusable doc vs protocol that is explicitly not a document). That alone makes the pair NOT A WITNESS.
- **FORMAL CONSEQUENCE:** `target` is known and differs. P1's target is extraction into a reusable doc. P2's target is an operating standard, with the standards doc explicitly *not* created.
- **FORMAL CONSEQUENCE:** `state_before` is known and differs (candidate vs parked candidate). P2 is the disposition of a parked candidate; P1 is the parking itself.
- **UNKNOWN:** Whether actors are equal. P1 names the "chair"; P2 says "the PA parked" it. No passage says the chair is the PA.
- **UNKNOWN:** Whether the evidence values differ. P1 states no count.
- **INFERENCE:** The outcomes differ only because the targets differ. For the target P1 actually refused (promotion into a governed document), P2 also does not raise it. P2 leaves that decision to the DA and recommends (b), holding to the parked criterion. So P2 is better read as the P1 rule being *followed* than as the rule being overcome by more evidence.

## Ambiguities
1. **Object identity.** It rests on one "in substance" claim by the implementer, not by an authority.
2. **Actor.** It is unclear whether the chair and the PA are the same authority. P2 attributes the parking to the PA.
3. **P1 evidence.** No number is given. Reading 0 from "vs. starting WP-1" is an inference.
4. **P1 ground.** It is RULE if "evidence-before-promotion" counts as a cited principle. It is CHOICE if the chair's proportionality judgment ("would not produce proportionate value") is what drove the parking.
5. **What P2 "adopts".** It is adopted as the operating standard, but not promoted to a standards document. So the RAISED outcome depends on which target is meant.
6. **Who adopted in P2.** "ADOPTED" is passive. The PA sent the protocol, and the DA's decision on promotion is still open.
7. **Exception in P2.** It is coded NO because option (a) is only offered, not carried out. If the DA later picks (a), it becomes YES.
