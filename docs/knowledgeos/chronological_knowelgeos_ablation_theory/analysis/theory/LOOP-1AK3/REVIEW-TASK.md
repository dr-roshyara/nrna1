# Independent review (frozen)

Researcher A answered `TASK.md` from `SOURCES.md` (in `ANSWER.json` / `ANSWER.md`). Use only these files.

Check each of the following:
1. Only permitted evidence was used.
2. Every quote is verbatim, and supports the value it is attached to.
3. Nothing was silently inferred, and nothing that the text establishes was left UNK.
4. No category confusion. In particular:
   - an operating standard vs a reusable document;
   - a chair vs the PA vs the DA;
   - parking vs refusal;
   - adopting a protocol vs promoting it into a document.
5. Whether the two dispositions concern the same object.
6. Whether the classification follows the frozen rule in §3. Recompute it under your own corrected coding.
7. The strongest alternative reading that would change the classification, and whether the text rules it out.

Classify each disagreement as: wording · source interpretation · coding · evidence scope · independence · formal reasoning · substantive. Do not average.

Write **REVIEW.md** (summary · per-field findings · recomputed classification · alternatives · disagreement register · what the text can and cannot establish) and **REVIEW.json** ({classification_A, classification_reviewer, decisive_fields_reviewer, disagreements: [...]}).
