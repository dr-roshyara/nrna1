# Independent review (frozen)

Researcher A answered `TASK.md` from `SOURCES.md` and `START-EVENTS.json` (in `ANSWER.json` / `ANSWER.md`). Use only these files.

Check each of the following:
1. Only permitted evidence was used; the quotes are verbatim and come from the stated rows.
2. For each event: is the class right?
   - **INDEPENDENT** requires a separate statement that would survive deletion of the START / outcome sentence.
   - A statement in the *same ruling* can still be INDEPENDENT if it is a separate provision; judge by content, not by row.
   - A **later** statement that retroactively describes the earlier state is not "prior". Flag it.
3. **ACT-NOT-ATTESTED:** are refusals real attempted acts, or permission statements that were read as refused acts?
4. Coded `s` vs the source: note every mismatch, including post hoc recodes.
5. Independence across clusters: do INDEPENDENT events from "different clusters" rest on one decision episode?
6. Recompute the counts and the non-circular-contrast verdict under your corrected classification.
7. The strongest alternative reading that would change the verdict.

Classify each disagreement as: wording · source interpretation · coding · evidence scope · independence · formal reasoning · substantive. Do not average.

Write **REVIEW.md** and **REVIEW.json** ({classes_A, classes_reviewer, counts_reviewer, non_circular_contrast_reviewer, disagreements: [...]}).
