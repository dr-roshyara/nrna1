# Independent review (frozen)

Researcher A answered `TASK.md` from `SOURCES.md`, in `ANSWER.json` / `ANSWER.md`. Use only these files.

Check each of the following:
1. Only permitted evidence was used.
2. Each quote is verbatim, and supports the claim it is attached to.
3. Nothing was silently inferred. In particular, did A infer the actor from voice, headings or context without saying so?
4. Actor vs act type is not confused: recommend vs decide vs report vs self-restraint.
5. Whether A missed any quote, either for or against.
6. The strongest alternative reading, and whether the text rules it out.

Classify each disagreement as: wording · source interpretation · coding · evidence scope · independence · formal reasoning · substantive.

Write **REVIEW.md** (summary · findings · alternatives · disagreement register · what the text can and cannot establish) and **REVIEW.json** ({actor_reviewer, act_type_reviewer, agree_with_A: bool, disagreements: [...]}).
