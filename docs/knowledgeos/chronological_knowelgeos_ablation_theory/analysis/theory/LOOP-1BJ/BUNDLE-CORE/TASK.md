# Coding task: three binary fields per source span

Use ONLY:
- SCHEMA-CORE.md: the coding schema; read it completely;
- RECORDS.json: 36 records, each an opaque id, a section heading and a verbatim span;
- SOURCES.md: the full sources the spans come from; read the surrounding section when a span alone does not decide.

No other path, no web, no commands.

For **each** of the 36 records, code ACT_REPORTED, ACT_SELF_PERFORMED and NORM_STATED (YES / NO / UNKNOWN) exactly as SCHEMA-CORE.md defines them, with the status layer and notes. Code the three fields independently.

Write **CODING.json** in the format given in SCHEMA-CORE.md: one entry per record, all 36 record ids.
Write **NOTES.md**: one line per hard or ambiguous record.

There are no expected answers. Do not consult any other coding of these records.
