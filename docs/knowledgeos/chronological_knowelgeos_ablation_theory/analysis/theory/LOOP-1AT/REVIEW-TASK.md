# Independent review (frozen)

Researcher A answered `TASK.md` from `SOURCES.md` and `CODED.json` (ANSWER.json / ANSWER.md). Use only these files.

Check each of the following:
1. The item mapping and the verbatim quotes.
2. Is each coded `e` value **stated**, **derived** or **not supported**? Pay attention to the units: slices vs tickets vs contexts.
3. Is each outcome decided by R-36 (the adoption) or by the matrix (a recommendation)? Is that distinction respected?
4. Is each non-promotion reason genuinely evidential? Or is it scope / domain-specific, which would make evidence a confound?
5. Recompute the evidence-only contrast pairs. Are they within one cluster?
6. The strongest alternative reading.

Classify each disagreement as: wording · source interpretation · coding · evidence scope · independence · formal reasoning · substantive.

Write **REVIEW.md** and **REVIEW.json** ({basis_reviewer: {...}, evidence_pairs_reviewer, confounded_pairs: [...], verdict: e_SUPPORTED_WITHIN_CLUSTER | e_CONFOUNDED | e_NOT_SUPPORTED, disagreements: [...]}).
