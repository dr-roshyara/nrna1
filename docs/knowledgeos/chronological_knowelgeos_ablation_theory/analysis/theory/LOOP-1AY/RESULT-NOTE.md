# 1ay r1 result: all NOT-DEMONSTRATED with zero possible pairs. **An instrument defect plus a substantive finding** (post hoc diagnostic, disclosed)

1. **Defect (mine, formal reasoning / coding).** 1ay pairs records by **exact string equality** of `operation` (and compares actor and target by exact string). A′ uses an **open vocabulary** there. The coded strings are heterogeneous: ACT has 20 distinct operation strings, NORM 19; **0** opposite-polarity pairs share an exact operation string. Semantically equal operations are split ("execute" ×3; "begin implementation (RED)" / "start (implementation work)" / "RED (first authorized activity)"). **The r1 zero-pairs result is therefore largely an artifact**, not evidence. The r1 output stands unamended (RESULT.json).
2. **Substantive (SOURCE FACT over the reviewed coding).** The ACT dataset has **24 ACT_OCCURRED vs 2 ACT_REFUSED / ACT_WITHDRAWN** (R06, R29). Most operations have **no negative instance at all**, so no act-level contrast exists for them **regardless of matching**. The corpus attests *performed* norm-making acts, almost never refusals. The NORM dataset has 12 positive / 9 negative.
3. **Record-construction defect (mine):** R06 / R07 carry an identical span; schema §1 requires one record. They share a cluster, so they cannot add disjoint support. They are to be merged in the next build.
4. **Fix:** controlled-vocabulary normalization of the operation, actor and target fields (1ay-n: blind worker + reviewer), then 1ay r2 on the normalized fields. The instrument logic is unchanged; it only reads the normalized fields.
