## 4. The pair

**INFERENCE:** The closest candidate is **Q = A2** (R-89 refused) and **P = A3** (R-90 issued), both for the same ruling (Discovery Boundary Confirmation, WP-4C-2). The variable that separates them is **occupancy**: whether the number is already held by another filed ruling.

**Strict verdict: NOT established (`exists: false`).** Three things fail the "differs only in prior state" test:
- **UNKNOWN:** P's prior state is never quoted. That R-90 was unused is inferred.
- **UNKNOWN:** the text never names who put forward "R-89". "Same actor" is inferred.
- **INFERENCE:** P and Q are two halves of one correction, not two separate acts that could be compared.

Under a lenient reading that accepts these inferences, the pair exists and occupancy separates it.

**Is it the same variable as "retired, not recycled"?** No.
- **SOURCE FACT:** Both rules rest on the same defect: "one number two decisions".
- **INFERENCE:** The state variables differ. Q concerns a number held by a *live* ruling. Retirement concerns a number held by a *withdrawn* ruling whose row is kept. Retirement can be read as occupancy that outlasts withdrawal, which makes the two related, but they are not the same variable.
- **SOURCE FACT:** No refusal on retirement grounds appears in these rows. The retirement rule is only a norm (A4).

## 5. Independence

**INFERENCE: 1 cluster.** P and Q both come from the single "NUMBERING CORRECTION RECORDED AT ISSUE" passage in R-90: one author, one date, one event. The R-89 row backs up Q's prior state (the number was really taken), but it is not a second decision about the contrast. The retirement norm is a separate, later cluster (the withdrawal annotation) and is not part of the pair.

## Ambiguities

1. **Who proposed "R-89".** The text says only "was put forward" (passive).
2. **Who refused it.** The refusal is "recorded at issue" without naming a person. The ARB Chief is inferred from the row's issuer.
3. **R-90's prior state.** It is never stated.
4. **R-89's prior state before A1.** It is never stated.
5. **Who retired R-90.** The Decision Authority ruled the withdrawal, but whether it also authored the retirement and the "next is R-91" line is not stated.
6. **Whether "issued" is final.** Both rows are PREPARED, not ADOPTED.
7. **How to class A4 and A5.** Each names one specific identifier yet works as a rule. A5 could be read as UNCLEAR, a reservation rather than an issuance.
8. **Whether a retained, withdrawn row still "holds" its number.** This decides whether retirement is just a kind of occupancy.
