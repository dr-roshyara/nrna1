## 6. What the key does NOT say

The key states what each convention's authors computed. It says nothing about which convention is correct, which purpose the counts should serve (hosting relevance or constraint coupling), or which arm "should" win. A REPRODUCED label means the text determined its convention's verdicts for these encoders; nothing more (PROTOCOL.md §2, §10).
