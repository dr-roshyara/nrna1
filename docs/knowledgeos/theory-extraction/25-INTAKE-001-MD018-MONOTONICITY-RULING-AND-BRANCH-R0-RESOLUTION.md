may skip a stage"* constrains **step size**, not **direction**. That measurement is unchanged by the
ruling.

$$\boxed{\begin{array}{c}\textbf{The ruling does not make monotonicity EVIDENCED. It makes it STIPULATED.}\\[6pt] \boxed{\textbf{Everything derived from it inherits that provenance: } \mathbf{[DER\text{-}S]} = \textit{derived from a stipulated premise.}}\end{array}}$$

## ⭐ A consequence that strengthens `K2` rather than weakening it

`[DER-S]` If the chain is monotone, the **current status entails the whole status history**. So the
current status is **necessary and sufficient** for status history — which is precisely `K2`'s content.

$$\boxed{K2 \textbf{ is not merely retained under } R0 \textbf{ — it is the SOLE bearer of status history, and prior statuses need not persist at all.}}$$

# 4. ⭐⭐ What the ruling does NOT settle — one new question, deliberately raised

`P-09` §3.3 kept **six** notions apart, of which **five are not regression**. The ruling forbids
**regression (1)**. It does **not** touch **correction (5)**.

$$\boxed{\begin{array}{c}\textbf{A status recorded IN ERROR and later fixed is NOT a regression — it is a CORRECTION,}\\ \textbf{and correcting it is a NON-MONOTONE change to the RECORD while the chain itself stays forward-only.}\\[6pt] \boxed{\textbf{So correction remains available, is } K3\textbf{-bearing, and must be DISTINGUISHABLE from a forbidden regression.}}\end{array}}$$

⭐ **This is a good outcome, not a loophole:** the ruling does **not** accidentally forbid error
correction. ⚠️ **But it creates an obligation Lane T had not recorded:** the estate must be able to
tell *"this status was corrected"* from *"this status regressed"*, because one is permitted and the
other is now prohibited.

|---|---|
| **`O-INT001-1`** | ⭐⭐ **Is a status CORRECTION distinguishable from a prohibited REGRESSION in the record?** If not, the prohibition is unenforceable and `K3`'s non-monotone scope silently re-widens toward the whole chain. `[OPEN]` |
