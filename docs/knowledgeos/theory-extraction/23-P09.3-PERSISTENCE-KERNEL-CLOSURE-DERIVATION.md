# 2. What a capability is — derived, not inherited

$$\boxed{K = (\Delta,\ \mathcal{T}_K) \qquad \begin{array}{l}\Delta = \textbf{a semantic distinction the estate is REQUIRED to make}\\ \mathcal{T}_K \subseteq \mathcal{T}_{KOS} = \textbf{the transition classes under which } \Delta \textbf{ could be lost}\end{array}}$$

⭐⭐ **A capability is INDEXED BY A TRANSITION SET.** That is the load-bearing part: *"X must be
preserved"* is not a capability until the transition under which X could be lost is named.

| kept strictly apart | |
|---|---|
| **semantic distinction** | *"was this adjudicated, or never in doubt?"* — a difference the estate must be able to make |
| **preservation obligation** | that distinction **must survive** a named transition |
| **capability** | ⭐ the pair `(Δ, 𝒯_K)` |
| **mechanism · representation · field · entity · record · relation · implementation construct** | ⛔ **`[ARCH]`. None may enter the kernel ontology** |

⭐ `[DERIVED]` **Consequence used throughout:** a proposed sub-part whose variation is **not produced by
any transition in the current universe** yields **no admissible counterexample** — it is `[OPEN]`, not
a capability. §5 turns on exactly this.

# 3. The decomposition criterion

$$\boxed{\begin{array}{c}K = (\Delta,\mathcal{T}) \textbf{ DECOMPOSES into } (\Delta',\mathcal{T}')\textbf{, } (\Delta'',\mathcal{T}'') \textbf{ iff there exist TWO admissible history-pairs:}\\[4pt] \textbf{one varying } \Delta' \textbf{ with } \Delta'' \textbf{ and all else held fixed, and one varying } \Delta'' \textbf{ with } \Delta' \textbf{ held fixed,}\\ \textbf{AND both distinctions are independently REQUIRED.}\end{array}}$$

⛔ **Insufficient as evidence:** different objects · different DDD categories · different
implementations · different tables or fields · different names · ⭐ **the mere ability to describe
sub-parts.**

**Admissible** = the varying transition lies in the **current** `𝒯_KOS`, and the requirement is `[EMP]`
or `[DERIVED]` in Lane T.

# 4. The decomposition-stability criterion

| verdict | condition |
|---|---|
| ⭐ **DECOMPOSITION-STABLE** | **no admissible counterexample** exhibits two independently variable required distinctions **under the present evidence boundary and transition universe** |
| **DECOMPOSABLE** | at least one admissible counterexample does |
| ⭐ **UNDERDETERMINED** | the distinction depends on `W6`, `P2`/`O-P08-1`, `Q3`/`Q4`, a Lane M question, or the `[OPEN]` part of `𝒯_KOS` |

$$\boxed{\textbf{"No counterexample found" NEVER means "atomic". It means STABLE UNDER THIS BOUNDARY. And no-evidence } \neq \textbf{ false.}}$$
