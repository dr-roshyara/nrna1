## 2 · Why this is not merely "not found"

⭐ The corpus contains **positive controls** and a **negative control**, so the boundary is testable rather than merely absent:

* **Positive** — PO/ARB is competent over `AST-019` because it is a **KnowledgeOS asset on a named work item and component**. The R persistence kernel has **no work item, no component, no asset identity**, so the same competence argument cannot be constructed.
* **Negative** — `ES-006` excludes Project Knowledge *"to prevent `ES-006` from slowly absorbing project concepts"*. ⭐ **Scope boundaries here are real, stated, and operative.**
