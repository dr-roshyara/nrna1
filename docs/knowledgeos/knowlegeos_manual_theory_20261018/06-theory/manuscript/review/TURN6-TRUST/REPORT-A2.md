## 3. Answers to the brief's six questions

1. **Lemma step 8 (KK ≤ WF from "WF is a Fitting fixed point"): valid.** At a fixed point (T, F = GUS) of W_P: true atoms = atoms with a true body (T_P step); every rule of an atom of F has a literal false in I or a positive body atom in F, hence false (unfounded definition), so Φ gives F; an atom neither true nor in F must have some rule with no false literal, otherwise F ∪ {a} would be unfounded, contradicting maximality of the GUS, and since no body is true, Φ gives U. So WF is a Fitting fixed point and KK ≤ WF. This is the standard fact that the well-founded model is a three-valued model of the completion, derived here. The text compresses the "neither true nor unfounded" clause ("has a U body") without the maximality argument; add it (low, not a defect of the result). Empirical: WF was a Φ-fixed point on 4,000 further D records (n 5-12).
2. **R2's derivation of U's causes: valid.** (a) U atom: no body T, some body U, so a literal U, so an atom U; (b) finite graph, every U node has a U successor, so a cycle; (c) positive edges point to earlier positions (or to u atoms, which point only to themselves negatively), so a cycle has a negative edge. **The model's walk finds every cyclic SCC reachable among the U atoms it starts from (so at least one cycle always); it does not name every cycle** (A2-06). Its starting set matches what `current` reads (adoptions with t_y ≤ t, later revocations, endings of cited grants), except the queried-scope clause (A2-05).
3. **Coherence of the general definition.** "Self-cancelling: an annulment whose target is among the grants its own authority rests on" matches the code (target in the SCC and reachable by positive edges) and matches the decision's "any link of its own chain" for grants; it differs for roots and for unneeded cited bases (A2-07). U cases without a named reason: none by the placeholder test (3,000 records; my 6,000-record qscope run, 0). U cases with a wrong reason: a self-annulling act (A2-04); a spurious additional reason (A2-05).
4. **"Authorization after the fact"; "checkable at each new entry".** Consistent with C1 as to recording order. Not consistent with the rest of §9.13.2 in two places: the dangling-citation tolerance and the id-collision (A2-01), and backdated grants and forward targets (A2-03). The reason is a decision rationale, so it is evaluated by its words and consequences; its consequences contradict its own second clause.
5. **Θ_f rows.** Operator and code agree on: root annulment (root fixed T), conjunctive P (`intact` over all cited grants, check 16), revocation scope (never read), endings by key, annulments retroactive, C6, ι, π, σ. Only the decision-3 interaction in A2-07.
6. **Dependants.** §9.07 result 2: consistent (restricted, "refused is not not-a-function"). §9.08 Lemma D: consistent. §9.09 T1: missing the merge condition (A2-08). §9.10 Q1/Q3 and vacuity table: consistent ("on D", R5). §9.12 C1 lines: consistent. CON-0191: consistent with v4 (it names "annulment rings", "direct or indirect"); it omits that D is not closed under appending and A2-01.
