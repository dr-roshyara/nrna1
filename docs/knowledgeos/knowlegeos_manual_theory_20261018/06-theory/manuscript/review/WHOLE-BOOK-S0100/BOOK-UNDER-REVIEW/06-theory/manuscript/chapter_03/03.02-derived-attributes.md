# 3.2 What is not a dimension: the admission test and derived attributes

## In plain language

It is tempting to add a new label whenever a new distinction appears. The corpus guards against this with a test: a new dimension must be genuinely independent of the existing ones, genuinely needed, and enough for its job. If a proposed label can be computed from existing ones, it is **not** a new dimension. It is a derived attribute.

## The admission test `[CON-0009 · invalid as stated]` (Src)

*Consolidation review: "sufficient" is a property of a set of dimensions, not of one; "necessary" is argued from error history, not tested; only orthogonality is applied. Restated form (PROVISIONAL): (i) not derivable from existing dimensions on the cases in scope; (ii) at least one required distinction is inexpressible without it. Sufficiency moves to the set.*

A proposed dimension is admitted only if it is **orthogonal · necessary · sufficient** [S0016 L37]. Otherwise it is "an overloaded existing dimension" or "merely another value" [S0016 L16].

The corpus applies it consistently, including to its own proposals:

| Proposal | Result | Why |
|---|---|---|
| **INTENDED** as a fourth evidence grade (the author's own) | **withdrawn** | "Intent is not evidence": it overloaded evidence status [S0016 L16] |
| **INTENT-STATUS** (proposed · sponsor-intended · ratified · operational [S0016 L47]; a reviewer's) | **rejected** | not orthogonal: "Ratified" and "approved" are the same axis; "proposed" is draft; "operational" is baseline [S0016 L54] |
| the flat category list A–G (§3.3) | **rejected** as a meta-model | categories that change with encoding or scope are not kinds [S0009 L46, L55–58] |

**Int:** the test is applied **symmetrically**, to one's own proposals and to a reviewer's. The corpus names this: applying it "to my error and not to the proposal would be selective" [S0016 L56].

## Derived attributes (Src)

The model lists three attributes that are **functions** of dimensions, "never axes" [S0016 L65–68]:

| Attribute | = | Source of the rule |
|---|---|---|
| lifecycle regime | f(nature) | RQ-002 |
| validation method | f(representation, nature) | RQ-002 |
| **intent** `[CON-0007 · invalid]` | f(governance status, **owner**) | S0016 |

"Sponsor intent" is "simply governance-status draft/approved with owner: sponsor" [S0016 L55].

## Why intent is marked invalid here `[CON-0007 · invalid]`

**Ded.** The intent function depends on **owner**, which is **not** one of the six dimensions (§3.1). The model is therefore not closed under its own derived attributes. Either owner is an attribute outside the dimensional space (like provenance, Ch. 1 §1.2), or the six dimensions are not sufficient. The source does not say which. Partly valid (TODO T3-02).

**Consequence for this book.** A derived attribute may be **reported** (e.g. "intended by the sponsor") but never **stored as an independent value**. If it were, it could disagree with the dimensions it is computed from, which is the drift the admission test exists to prevent.
