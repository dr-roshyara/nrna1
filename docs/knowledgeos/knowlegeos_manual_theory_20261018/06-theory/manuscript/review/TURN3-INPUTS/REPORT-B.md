## 4. Rival formulations

- Make the act-object granularity (documents vs claims vs instances) its own parameter, independent of F37; then CE has one input set, parametrized by object type.
- Treat all four A1 readings as settings of θ (C1, κ, υ plus a refutation policy) on one CE rather than as meanings; the §9.12.5 table becomes a θ table.
- Rival to "refutation is an input": refutation as a domain exclusion (like as-form), with a separate "record validity" function.
