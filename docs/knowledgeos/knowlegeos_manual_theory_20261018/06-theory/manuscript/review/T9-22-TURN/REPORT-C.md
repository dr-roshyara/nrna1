## Summary
1. §9.21 gets the core shape right: Q2's form is derived; Q1's and Q3's forms are narrowed, not derived; the turn reduces to one question for the Principal.
2. **The minimality table (§9.21.4) has a false row.** It says no core output conveys the authentication status of a grant or root under identity outputs. Q1's marks do: the support follows citations to grants and roots, and the marks read their status (§9.13 L137–138). I confirmed this with the T9-02 model (probe below). §9.20.5 L106 carries the same claim and needs an R3 note.
3. **Q2's scope is labelled "derived" but rests on a reading.** §9.21 equates "about k" with "has k in its item field". That treats which k you may ask about as if it were which entries come back. Under that reading, Q2(k) would omit annulments of k's adoptions, removal acts and withdrawals of reliance (`ewdr`, read by g1). DC-1 is met: the scope is narrowed, not derived.
4. **"The forms differ exactly in recorder, status and content" ignores B-07.** B-07 is the R3 note at §9.16 L93. The literal identity rule also puts recording time and store in the identity, which contradicts K2. The M6 row ("separated under identity outputs") depends on how B-07 is resolved.
5. **G is not fixed by derivation.** A single appender defined case by case over all kinds is not a composite, behaves exactly like G-act, and §9.19.4's list does not name it. So "the grain the book can derive" (§9.21.1) overstates; U3 (b) still stands for it.
6. **Batching.** It is excluded for **act** entries (the same point §9.19.4 L164 already makes). Batches of non-act entries are not excluded. The unobservability argument assumes the guards are evaluated entry by entry; an all-or-nothing batch changes guard verdicts and replies, so DC-4 is met for that case.
7. No critical finding. Five high, the rest normal.
