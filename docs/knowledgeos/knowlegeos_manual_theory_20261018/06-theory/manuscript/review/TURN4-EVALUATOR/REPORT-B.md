## 4. R3 by type (practice 5)

- Boundary cases: (a) one-step self-grant Grant(A,A): WF F; fine. (b) Loop plus a legitimate root path to one member: least model grounds it; fine. (c) mixed loop through negation (holder annulling own grant, F6): WF U, so WF does not make "all self-dependence" F, only positive. R3 should say so: "self-supporting through citation = F; self-referential through annulment = U" is a consequence the text states only for mutual annulment of two separate acts. - Coherence: WF, KK both consistent; the C1 link is coherent.
- Consequences: WF F is not forced by Φ (F2).
- Rival: KK for both with loops reported (the author's rival); a third, stable-model semantics (which would also make positive loops false and may leave odd cycles without a model, so total answers would not exist). WF is a defensible middle.
- Falsifier stated by the author: an organisation recognising a self-supporting chain. Adequate.
