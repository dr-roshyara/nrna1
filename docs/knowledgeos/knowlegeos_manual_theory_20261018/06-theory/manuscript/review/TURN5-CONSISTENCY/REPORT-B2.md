## 3. Answers to the brief's questions

1. **R1.** Step 1 is right: minimality is a property of the effect family at the point, and effective applicability only decides which rules enter ℛ(c,t). Duplicate effect sets cannot lie in a minimal set, so rules and sets correspond. "Applicability plays no part" is true. The UNKNOWN extension is sound for unknown applicability (B2-08). The converse needs realisability and that X is the space the effect sets are taken in (B2-02).
2. **R2.** Correct if X is the full product. No non-emptiness (a product with an empty factor is itself empty and is a one-member conflict). No independence in the probabilistic sense, but yes the cross-attribute freedom of B2-02.
3. **R3.** All h-values re-derived: required value 2; forbidden value k (infinite: B2-09); both max(2,k); allowed set k; interval 2 (proof valid, B2-10); forbidden range n (single-value complement is a forbidden range, R4 gives ≤ n); linear d+1 reals (tight, check 5 correct: witnesses (0,0), (0,-1), (-1,0), the three rows sum to 0 ≤ -1), 2^d integers (Doignon); disjunctions ≤ |X|. Placement: B2-04, B2-05, B2-06. §2.3 (a)'s "linear arithmetic over thresholds": a decidability example there (applicability or effects), not a statement that rule effects are cross-attribute; the placement is an Int. Trace links: §2.0 (the file `02.00a`) cites SD L103–108 for per-kind traceability obligations; that it is Boolean is Int, correctly marked.
4. **R4.** Valid; tightness right (complements of points; clauses on n Booleans give 2^n).
5. **R5.** (a) B2-07. (b) correct. (c) B2-03, and the precedence example is correct (§2.8.4a: alternatives within one decision versus independent obligations; criterion quoted correctly). (d) B2-01, B2-03.
