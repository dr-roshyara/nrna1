## Answers to the brief's questions
1. **Marks.** Defined over `support`, not over what the answer rests on; the superset claim is false for F (A2-01). Well-defined as a function for U and F. For F by C1 the support is empty and no mark appears (A2-08).
2. **Tombstone.** "Every field D requires" is more than "the fields citations rely on" (A2-04) and omits position (A2-03). The integrity check is undefined on a tombstone in §9.13 (A2-02). A tombstone cannot change an answer by construction in the model; in the theory only if position is kept and the check is defined.
3. **I15.** signed-as-other with recorder = actor is incoherent against §9.15 and D accepts it (A2-05). The defaults hide no value dependence (0 changes in 3,000 random records), but the randomized checks never see the new fields (A2-10).
4. **Decision 3.** Met: the walk starts from U alternatives and follows U literals of U bodies, so an unneeded basis is never reached (a second T basis gives T and no reason; an F basis supports nothing). If an act is U for two independent reasons, both cycles are named, which the text states.
5. **Ties.** Nothing in §9.13 reads position beyond the key (t,s) and D's citation rule (grep: `pos` used only at lines 99, 116–118). Holds provided the tombstone keeps its position (A2-03).
