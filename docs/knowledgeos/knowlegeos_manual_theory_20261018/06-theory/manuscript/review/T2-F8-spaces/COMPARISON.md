## Did the strength scan and the coverage pass help?

- **Strength scan: yes, for overstatement.** It found 16 strong words before review and 5 were weakened. Overstatement findings fell from 6 per T1 report to 3. **What it does not catch:** a circular definition. The critical T2 finding was a definition that quoted its own answer, and no strong word marked it.
- **Coverage pass: no measurable effect on omissions.** There were 4 omission findings, as in T1, and 11 items missing. The largest omissions came from **the book's own earlier results** (§1.11's three authority systems, §6.3's type/instance split, I-7), not from the five sources. The pass checks the sources against the map. It does not check the new section against the earlier chapters, so it could not catch these.
- **The fixed source rule** removed selection by judgment, but I applied it wrongly once: S0113 was counted as read, so the fourth pick should have been S2041. The rule itself works only as well as the read set it is given.
- **Commissioning once** halved review time compared with T1 and gave one clean report.

## Recommendation: a mix, and topic first for open forks

- **Chronological reading for coverage of the corpus**, five sources per turn, as before.
- **Topic-first turns for open forks**, run with T2's conditions:
  - a fixed source rule;
  - already-read sources included;
  - the strength scan;
  - one commission.
- **One new step:** before review, check the new section against the chapters it depends on, not only against the theory map. T2's largest omissions would have been caught there.

**Reasons:** across two trials, topic first moved two forks, mapping F11 and narrowing F8, while C6 moved one. With the T2 conditions it cost less review time and produced half the overstatement findings. It did not reduce omissions, and it leaves most of the corpus unread, so it cannot replace chronological reading.
