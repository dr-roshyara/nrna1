## 8.72.1 In plain language

1. **The correction changed the canonical rule document, and its header still names the producer.** The correction's own file list includes the boundary proposal (S0324), with the field name and pointers changed in §5, §9 and §11. The matching text is in S0324 as the book read it. The header still says the producer registered it, and the status still says "self-verified", which now also covers code the correction changed. The question the book left undecided at §8.71 can be answered from an allowed source: S0324, as read, is the producer's text with the correction's lines in it.
2. **The V-1 fix is a reporting fix.** The field "recorded human start act" used to say yes for any lane that had left CREATED; it now says yes only while the lane is ACTIVE. No permission changes anywhere: the gate always required ACTIVE. The fix aligned the code with the producer's own definition, which already read the field as "ACTIVE". So the field's name and its meaning had parted in the producer's design; the fix carried that into the code. A lane that started and then completed now reports "no human start act". Whether that meets the commission's requirement to tell an actual recorded START from merely leaving CREATED depends on how that requirement is read, which is for the PO/ARB or a verifier, and no verification took place.
3. **The only identity check reported comes after START, by the actor's own run.** It reports MATCH, which holds by construction under the premises the book stated at §8.71. The record names who appended REGISTER only as a role, "governance". The process named to append it was the appointee, which had acted as Governance before.
4. **The author's work ended, but nothing in the record says so.** The commission's "STOP" ends the author's work. The record still shows the lane ACTIVE, which the mechanism reads as authorized. Which transition, if any, should record the end, and who owns it, is not in the window; the author is barred from appending one. The stop exists only in the commission and in the author's report.
5. **The would-be verifier refused, correctly.** Its prompt described the author's lane; the record had no lane for the verifier. It read the record over the prompt, and it refused to act without a lane. The commission's own sequence ends with "fresh independent verifier" and has no REGISTER, HANDOFF or START for that lane, unlike the author's. The verifier also noticed, independently of the book, that two records disagree about who verified the resolver before.
