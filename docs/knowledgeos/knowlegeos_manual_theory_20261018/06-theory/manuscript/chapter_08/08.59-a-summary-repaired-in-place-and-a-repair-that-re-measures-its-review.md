## 8.59.1 In plain language

1. **The correction summary in the corpus is not the text its reviewer read.** The review read 403 lines; the file now has 405 and carries the repair's notes. The repair kept the old wording beside the new and labelled it "superseded". The header still names only the first author; which act wrote which line is shown only by the repair's own disposition record. The book has no form for this: in the book a revision is a new entry, and the only change in place is a tombstone, which drops content under a recorded removal act. Read in the book's terms the file is either two entries or one item over versions, which the book leaves open.
2. **The repair re-measured a count instead of copying it.** The review said the scripts folder held "11 shell scripts" in 13 entries; the repair counted 10 and said so. The review's own figures do not add up to its total. A reviewer's measurement is evidence, and the repair treated it as evidence. But a second site the finding named was left unrepaired, and the summary's own self-check had passed while the wrong figures were still in it.
3. **One record will carry three pieces of evidence: the closed comparison object, the receipt of the comparison, and the record of the copy write.** The receipt says the comparison was made and passed, not that the copy is right, and not that the write happened; so the write needs its own record. The summary asked whether adding a placement row applies the rule or extends it; the line's independent reviewer judged that it applies it. That is the reviewer's judgment, not an acceptance, and for the book the question stays open.
4. **A closed comparison object belongs to one attempt.** If the final check fails, the run stops; a later attempt measures again and closes a fresh object. The book's own rule that a reference must be taken again at the operation it protects already gives the same answer, if each attempt counts as a new operation; and on a failure the source changes after the object closed, so the old object is stale anyway.
5. **Several points agree with the book:** the repair closes nothing and accepts nothing; it reads its grant as limited to the findings; a test that passes because it matches nothing is not evidence. The routing that seemed to differ between the summary and the repair is consistent within the line: the summary's required fresh review was the independent review, which itself routed the repairs to Architecture, then Governance, then the product owner.
