## 8.82.1 In plain language

1. **The new capability reads the session's identity from the runtime, never from an argument, but it reads the human's act from an argument the session itself passes.** The START it writes is recorded as the human's, with the words it was given.
2. **The capability was built by a session that held no lane on the work item and whose label no record names.** The producer bar cannot be applied to a process nobody can identify.
3. **The capability's success criterion is that "Start the Governance adoption review" no longer ends in "no lane therefore refuse".** On the work item as it stands, the capability refuses anyway, because the item is stopped and it never records a continuation.
4. **As specified, a candidate is not eligible only if it already holds a lane on this work item.** The process the second refusal barred as the correction author held no lane there, so this check would admit it.
5. **The amended model's adoption review is to be staffed through the capability whose own verification and adoption are still pending.**
