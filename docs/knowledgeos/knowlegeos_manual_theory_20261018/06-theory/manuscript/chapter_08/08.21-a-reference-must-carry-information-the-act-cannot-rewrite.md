## 8.21.1 In plain language

This window closes the stretch before the S0150 consolidation. Four points come out.
1. A check is only as good as what it compares against. To show that a result differs from what it should be, the reference must carry information that comes from somewhere independent of the result and that the act cannot rewrite. Where it is stored does not matter. A reference whose information comes only from the result can catch internal inconsistency, but not that divergence (C1).
2. A tool that is implemented and verified is not thereby adopted, which is the other half of "adopted is not verified". And an aggregate of three-valued checks must not depend on the order in which they run (C8, C9).
3. A disputed figure from one source reappears in the next as "Observed", with a target anchored to it. A report's own instruction says "PASS" where its own table shows "INCONCLUSIVE" (C10, C11).
4. A ledger kept by its own author proves authorship and priority only inside the estate. To an outsider it needs a commitment held elsewhere and trusted time (C14).

Two sources were skimmed: a role diagram and an architecture proposal. Review found that the second skim lost theory (C13).

A principle that a careful reading usually satisfies is still a principle.

Unless the derivation adds information from elsewhere, that is impossible by construction. So the falsifier is a derivation that turns out to read an independent input.
