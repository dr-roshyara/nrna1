## 8.87.1 In plain language

1. **S0362 is the same text as the last part of S0361, word for word.** It is counted once.
2. **The first adviser of S0363 makes the kernel "the Admission Boundary", with the invariant that no knowledge claim exists without identity, evidence, justification, epistemic state, confidence and history.** For promotion along an evidence ladder the book agrees: two keys, evidence and an act. For standing in general it does not: a claim's standing comes from a recorded act, and a claim with no recorded evidence is shown as "not attested". There the invariant would forbid what the book displays.
3. **The same adviser mentions "justified true belief" only while describing formulations it then sets aside.** Its chosen model, governed admission, does not make truth a condition. *(Restated at review: W-02)*
4. **The reply asks whether the kernel governs a whole lifecycle rather than only admission, and finds confidence's place unproven.** In the book a claim's displayed class is worked out from the record at a cut; later changes are new entries, not transitions of the claim. The book has no concept called "confidence". *(Restated at review: W-03, W-04)*
5. **The reply proposes a test: remove a responsibility; if no invariant breaks, it is not the kernel's.** That is the book's removal test with only its invariant half. A kernel that refuses everything breaks no invariant, so on its own the test can only show that something is not needed, never that it is. *(Restated at review: W-01)*
