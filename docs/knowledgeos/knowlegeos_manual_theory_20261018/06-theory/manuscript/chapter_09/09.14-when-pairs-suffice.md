## 9.14.1 The research question

§2.3 (d) defines conflict on **sets** of rules, point by point, and shows by a counterexample that checking pairs is not enough. **For which classes of rules does checking pairs (and single rules) find every conflict that the set-wise test finds, with the same regions? And which of the book's rule classes are such classes?**

**What would disprove the answer:**
- a rule base whose effects all lie in a class said to need only pairs, on which the set-wise test finds a minimal conflicting set of three or more rules;
- or a class said to need more than pairs whose every conflict is caught by pairs (the realisability premise of R1's converse would then be false for it).

## 9.14.2 Definitions and assumptions

- **Context, outcome, effect set** (§2.3 (d)). At a context c, rule r's mandatory effect φᵣ(c, x) constrains the outcome x. Its **effect set** is Eᵣ(c) = {x : φᵣ(c, x)}. A set S of rules is **minimal in conflict at (c, t)** iff all of S apply at (c, t), the intersection of the Eᵣ(c) over S is empty, and every proper subset of S has a common point (§2.3 (d)).
- **The class of a rule base.** 𝓔 is the set of all effect sets Eᵣ(c) that the rule base's effects can take, over all rules and contexts. Several rules may share an effect set.
- **Helly number** (*Ext:* Helly 1923; Danzer, Grünbaum and Klee 1963): h(𝓔) is the largest size of a **minimal** subfamily of 𝓔 with empty intersection. Equivalently, every finite subfamily with empty intersection contains at most h(𝓔) members that already have empty intersection. "Pairs suffice" means h ≤ 2.
- **Scope.** Mandatory effects only (MUST, MUST_NOT). Permissions against rules and SHOULD tensions keep their own finding classes (§2.3 (b), (d)).
  - Exceptions narrow **applicability** (§2.3 (b), effective applicability A′). Allow-lists are such exceptions (§2.9, §2.11). They do not change effect sets, so they do not change h.
  - Placement rules that **compete for one output** are resolved by precedence and are not checked for conflict (§2.8.4a). They are outside this section.
- **Assumption for the converse of R1 (realisability):** any finite family of effect sets from 𝓔 can be carried by rules that all apply at one point. Applicability "true" is in the language (§2.2), and effects may be the same at every context.

## 9.14.3 Results

**R1. Pairs suffice exactly when the effect class has Helly number at most 2 (Ded).** `[CON-0192 · provisional]` Let 𝓔 be the effect class of a rule base, with h = h(𝓔).
- **(a) Bound.** At every point, every set minimal in conflict has at most h members.
- **(b) Reduction.** The set-wise report (§2.3 (d): each minimal conflicting set with its region) is obtained by testing, point by point, every subset of at most h rules. In particular, if h ≤ 2, testing single rules and pairs point by point gives exactly the set-wise report, regions included.
- **(c) Converse.** If h > 2 and 𝓔 is realisable, some rule base in the class has a conflict that no pair and no single rule shows.

| Step | Claim | Justification |
|---|---|---|
| 1 | S is minimal in conflict at (c, t) iff all of S apply at (c, t) and {Eᵣ(c) : r ∈ S} is a minimal family with empty intersection | §2.3 (d), definitions |
| 2 | a minimal family with empty intersection has at most h members | definition of h |
| 3 | so \|S\| ≤ h: (a) | 1, 2 |
| 4 | the minimal conflicting sets at (c, t) are exactly the subsets of at most h applying rules that are minimal in conflict there; each set's region is the set of points where it is minimal | 3; the region is computed per set (§2.3 (d)) |
| 5 | so testing all subsets of at most h rules, point by point, reproduces the report: (b) | 4 |
| 6 | if h > 2, there is a minimal family F ⊆ 𝓔 with empty intersection and \|F\| ≥ 3. Realise it by rules applying at one point: their set is in conflict there, and every proper subset, every pair included, is satisfiable there: (c) | definition of h; the realisability assumption |

Applicability plays no part in the bound. A pairwise test run **point by point** ("is there a point where both apply and their effects clash?") is all that h ≤ 2 needs. The same holds for the UNKNOWN report under three-valued applicability (§2.8): a set possibly in conflict at a point has an effect family with empty intersection, and step 2 bounds its minimal subsets.

**R2. The product lemma (Ded).** Suppose every effect set of the class is a **product** of per-attribute sets: each rule constrains each outcome attribute separately, as a conjunction of single-attribute constraints. Then h(𝓔) ≤ max over attributes a of h(𝓔ₐ), where 𝓔ₐ is the class of the attribute-a factors.
- *Proof.* An intersection of products is the product of the per-attribute intersections. So it is empty iff, for some attribute a, the intersection of the a-factors is empty.
- That intersection already empties for at most h(𝓔ₐ) of the members (definition of h).
- Those members' products then have empty intersection. ∎
- *Model:* on 60 random pairs of factor classes, h(products) ≤ max h(factors) in every case (`helly_check.py` check 2).

**R3. The book's rule classes (Ded for each h; Src or Int for each class's place in the book).**

| Class (where the book has it) | Effect set on one attribute | h | Pairs suffice? |
|---|---|---|---|
| **required value**: "production APIs must use OAuth2" (§2.3, RM L154–162); "use TLS 1.3" vs "use TLS 1.2 only" (§2.3 (b)) | a single value {a} | **2** | **yes** |
| **Boolean obligation or prohibition**: MUST p / MUST_NOT p, e.g. a required trace link per document kind (§2.0, SD L103–108; that it is Boolean is Int) | {true} or {false} | **2** | **yes** |
| **threshold** on one ordered attribute: the design checks' "final target 0" and phase targets on a violation count (§2.9) | an interval | **2** (Helly in dimension 1; proof below) | **yes** |
| **forbidden value**: "internal production APIs must not [use OAuth2]" (§2.3, RM L154–162) | the complement of one value, on a k-valued attribute | **k** (all k complements form a minimal family); **2** if the attribute is Boolean or its domain is infinite | **only if k ≤ 2 or the domain is infinite** |
| **required or forbidden value** together (the OAuth2 pair is one of each) | {a} or its complement | **max(2, k)** | only if k ≤ 2 |
| **allowed set**: MUST x ∈ L | any subset of a k-valued attribute | **k** | only if k ≤ 2 |
| **forbidden range**: MUST_NOT a ≤ x ≤ b on n ordered values | the complement of an interval | **n**: it includes forbidding a single value | no (n ≥ 3) |
| **conjunctions of the "yes" rows**, one or more per attribute: boxes; partial assignments | products of the above | **2** (R2) | **yes** |
| **linear inequalities across d numeric attributes**: "linear arithmetic over thresholds" (§2.3 (a)) | a convex polyhedron | **d + 1** over the reals (Helly; tight); **2^d** over the integers (Doignon 1973) | no, for d ≥ 2 |
| **disjunctions; general propositional effects**: §2.3 (d)'s MUST (p ∨ q) | any set of assignments | up to **\|X\| = 2ⁿ** on n Boolean attributes (R4) | no |

*Proofs of the entries.*
- **Required value:** two different single values are disjoint. Any family containing one value a and otherwise only supersets of {a} has the common point a. So an empty family contains two different singletons: h = 2.
- **Forbidden value:** a family of complements of values is empty iff it forbids every value of the domain. That needs all k members, and drops no member: h = k. On an infinite domain it never empties.
- **Required or forbidden:** an empty family contains two different singletons, {a} together with its complement, or all k complements.
- **Interval** (finite families in a total order): if every two intervals Iᵢ, Iⱼ meet, choose pᵢⱼ ∈ Iᵢ ∩ Iⱼ. Let lᵢ = minⱼ pᵢⱼ and uᵢ = maxⱼ pᵢⱼ; both lie in Iᵢ, so [lᵢ, uᵢ] ⊆ Iᵢ by convexity. Let x = maxᵢ lᵢ = l_k. Then lᵢ ≤ x ≤ p_kᵢ ≤ uᵢ for every i, so x is a common point: h = 2.
- **Allowed set:** contains every complement of a value: h = k by R4.
- **Linear, over the reals:** Helly's theorem gives d + 1. Tightness for d = 2: x ≥ 0, y ≥ 0, x + y ≤ −1 are satisfiable two at a time, with witnesses (0, 0), (0, −1) and (−1, 0); the three sum to 0 ≤ −1, a contradiction (check 5).

*Model (check 1, exhaustive on small domains):*
- required value h = 2 for k = 2, 3, 4; forbidden value h = k; both together h = max(2, k); allowed set h = k;
- interval h = 2 on 0..5; forbidden range h = 6 on 0..5;
- boxes h = 2 on a 4 × 4 grid; partial assignments h = 2 on 3 Boolean attributes;
- clauses h = 4 = |X| on 2 Boolean attributes; lattice half-planes h = 4 = 2² on a 4 × 4 grid.

*End to end (check 3), on 300 random rule sets with context-dependent applicability per class:*
- for required value and threshold intervals (h = 2), pairs give exactly the set-wise report;
- for forbidden value on 3 values (h = 3) and for clauses (h = 4), pairs miss a conflict on 136 and 52 rule sets respectively;
- no minimal conflicting set exceeded h.

**R4. A finite outcome space bounds h by its size, and the bound is tight (Ded).** If the outcome space X is finite, h(𝓔) ≤ |X|.
- *Proof.* Let F be minimal with empty intersection. For each A ∈ F, the other members have a common point x_A, and x_A ∉ A. For A ≠ B, x_A ∈ B but x_B ∉ B, so x_A ≠ x_B. Hence |F| ≤ |X|.
- *Tight:* the complements of the single points of X form a minimal family of size |X|. They are expressible as clauses, so general propositional effects on n Boolean attributes reach h = 2ⁿ.
- *Model:* check 4 (random classes; tightness for |X| = 2..5).

**R5. What follows for the book (Ded).**
- **(a) Cost (§2.3 (d)).** For a class with Helly number h, the set-wise report needs at most C(n, 1) + … + C(n, h) point-wise tests, polynomial in n for fixed h; the exponential 2ⁿ is the cost only when h is unbounded. For h = 2 classes the cost is that of pairs.
- **(b) Partitioning (§2.6).** "Comparing every pair whose keys intersect is not enough" (§2.6) holds in general. **For h = 2 classes it is enough**, provided each pair is tested point by point (R1 (b)).
- **(c) The class belongs to the rule base, attribute by attribute.** One forbidden-value rule on a k-valued attribute, with k ≥ 3, raises that attribute's h to k for the whole base. Example: three placement roots, and three obligations "must not be placed under root i". Pairwise satisfiable, jointly not. That is only if they are independent obligations; placement by precedence is a different mechanism (§2.8.4a). Whether pairs suffice is therefore a property of the **rule language actually admitted** (§2.3 (a)), not of single rules.
- **(d) A test the analyser can run.** Pairs-only checking is sound for a rule base iff the base's admitted effect forms lie in an h = 2 class. For per-attribute forms this can be read off R3's table with R2: required values and thresholds, Boolean literals, conjunctions of these, and forbidden values on Boolean or infinite domains. Otherwise the analyser must test subsets up to the class's h, or the whole set (§2.3 (d)).

## 9.14.4 The strongest counterexample, and why it does not refute R1

R1's converse needs realisability. If a rule base never lets two forbidden-value rules on the same attribute apply at one point (for example, every such rule's scope is a different region), its conflicts on that attribute are caught by pairs although the effect class has h = k. The **class** then over-states what the **base** needs. R1 (c) is a statement about classes, under realisability; for a given base the exact quantity is the largest size of a pointwise-minimal conflicting set, which R1 (a) bounds above.

## 9.14.5 Rival formulations

- **Local consistency in constraint networks** (k-consistency: every consistent assignment to k − 1 variables extends to any k-th; *Ext:* Freuder 1978, 1982; Mackworth 1977). It concerns extending partial assignments of **variables**. R1 concerns **subsets of constraints** over all variables. They are different questions; §2.3 (d) cites the gap between local and global consistency as the established fact behind its counterexample. The two properties are defined on different objects; neither is claimed here to imply the other.
- **Algebraic characterisation.** Jeavons, Cohen and Cooper 1998 characterise, by an algebraic property, the constraint types for which strong k-consistency ensures global consistency (abstract, as verified). It is a benchmark for the *kind* of result, about local consistency, not about R1's Helly bound. Its exact property is not cited here because it was not verified.
- **Minimal unsatisfiable subsets** (*Ext:* Liffiton and Sakallah 2008). These enumerate the minimal conflicting sets of a given base. R1 bounds their size in advance from the class alone.

## 9.14.6 Internal guarantees and assumptions about the world

**Internally:**
- R1–R4 are mathematics about effect sets.
- R1 (b) guarantees that a pairs-only analyser misses nothing **if** every admitted effect form lies in an h = 2 class.

**About the world, or the implementation:**
- that each rule's effect is correctly formalised into its class: a forbidden value written as "allowed set minus one value" is the same set, but a free-text effect is not in any class (§2.3 (a); E6);
- that an attribute's domain is what the analyser assumes. Whether a forbidden-value class has h = 2 or h = k depends on whether the domain is finite, and on its size: a new value **added later** (§2.8, "adding a value") can change h for forbidden values. With k values, h = k; adding a value raises it to k + 1;
- that an UNKNOWN effect (undecidable, time-out) is reported, not dropped (§2.3 (e)).
