## The theory found

1. **Four orders, not one hierarchy.** A reviewer's single stack (Purpose → Knowledge → Domain → Capability → Process → Runtime → Artifact) is tested edge by edge: one edge supported, one refuted, four unevidenced (L66–77). Instead there are four evidenced orders (L81–86):
   - **authority:** purpose → strategy → principle → DP-n → capability;
   - **production:** process → knowledge, artifacts and evidence; capability → evidence; container → projection (n=1);
   - **realization:** knowledge → artifact; capability → runtime asset;
   - **containment:** container ⊃ artifacts (⊃ spaces? open).

   "Which is above" is answerable only per relation (L90).
2. **Domain is the classification archetype.** It owns nothing, produces nothing and constrains nothing; it scopes meaning. Ownership is done by DP-n (L48–51), described as "orthodox Evans, found empirically".
3. **Executability.** Execution is the essence of exactly one archetype, the capability. An executable artifact (a script) is still an artifact; its executability is a value of the representation dimension (L59).
4. **Nature of the archetypes:**
   - conceptual: purpose, domain, knowledge;
   - temporal: process (it "has a clock") and projection (rebuildable);
   - persistent: knowledge outlives its artifacts (L60–62).
5. **Container is demoted to a candidate archetype** by the n=1 rule. Only one space generates projections. A settling test is stated: a second generating space confirms; reducing the generator to a capability plus a scope refutes (L29, U-ONT-1).
6. **The decision test for relations.** "A relation that enables no decision is not admitted" (L10). §5 gives each relation its decision and an operational "scar" (L96–103).
7. **The parsimony rule already exists** at concept level. Extending it to archetypes is a governance act, routed to D-8 (L110–119).
8. **Empty cells:** "absence-of-evidence, not evidence-of-absence" (L128).
