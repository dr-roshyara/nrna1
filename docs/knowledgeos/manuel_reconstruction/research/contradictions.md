# Contradictions — pilot F0001–F0005

Contradictions are kept, not smoothed away. Each one is marked **Genuine?** and **Resolves by**.

## C1 — Has the evidence loop ever closed?

- **Statement A:** "L-6 … EMPTY … never traversed" (F0001 L182). "Operational Learning: 0 traversals" (F0001 L57; F0005 L57, L180). *Dated 2026-08-02.*
- **Statement B:** "'0 traversals' … (as a generalization)" is REJECTED on the basis of a Phase B blind review that found n≈3 (R-36, R-41, R-63) (F0003 L101). F0004 L23 reports a formal n=1 at instrumentation level, while "canon-level … still n=0". *Dated 2026-08-03.*
- **Genuine?** Partly.
  - It is largely a **measurement-definition** conflict. The count depends on what counts as a traversal (informal / formal / canon-level).
  - F0001's quoted qualifier "ZERO-INDEPENDENT" suggests it counted only *independent* traversals.
- **Resolves by:**
  - an explicit, shared operational definition of "traversal";
  - reading the Phase B review and the Operational Evidence Register.
- **Significance:** this is the programme's central loop, and its measured value flips depending on the instrument. That is evidence for P5 (levels) and a warning for any quantitative theory.

## C2 — Is anything enforcing?

- **Statement A:** "0 of 11 responsibilities are enforcing" (F0005 L68, traceability L208).
- **Statement B:** "'0 of 11 enforcing' is too strong … deny×19, ask×22" (F0005 L70–78; F0003 R-8; F0004 L39).
- **Genuine?** It was, and it has been **resolved** by distinguishing scopes: no *capability* enforces; the *runtime* does.
- **Residue:** F0005's traceability line still states the uncorrected claim. A correction and the claim it corrects coexist in one file (P6).

## C3 — "Nothing is in two states" vs concepts that carry two standings

- **Statement A:** "every row has exactly one bucket … Nothing is in two states" (F0003 L118).
- **Statement B:** In F0002, PKS is both TRIPLE-SUPPORTED (the need) and a UNIQUE HYPOTHESIS (the governed form). "Kernel set-sufficiency" is a hypothesis *and* "falsified at n=1". The standings total 11+3+5 = 19 items across 17 rows (F0002 L55–57, L64).
- **Genuine?** **Yes, for a model at concept level.** A total status function is possible only if the bearer of status is a *proposition*, not a concept.
- **Resolves by:** whether later sources make status bearers explicit propositions (claims), so that one concept can have several claims.
- **Significance:** high. The answer determines what the *atoms* of any KnowledgeOS theory are.

## C5 — "Method demonstrated portable" at n=1 vs the programme's own n≥2 rule

- **Statement A:** "whose method has been demonstrated portable" (F0001 L257). "proven in a foreign domain" (F0005 L50, n=1).
- **Statement B:** "n=1 admits a CANDIDATE, never a rule" (F0001 L91). There is no second adopting product (F0001 G-3; F0004 L43).
- **Genuine?** **Yes, as a tension with P1.** "Demonstrated" and "proven" are stronger than n=1 allows under the corpus's own ceiling.
- **Statistical note:** one success in a foreign domain is an existence proof of *possibility*. It is not an estimate of *reliability*.
- **Resolves by:** a second independent foreign-domain run. This is F0001's own Stage 2.

## C6 — Two framings of PKS

- **Statement A:** PKS is "one product's knowledge … never reusable — an instance" (F0001 L25).
- **Statement B:** PKS is "governed, machine-readable context for AI", which "EXTENDS" context engineering (F0002 L11, L23).
- **Genuine?** **Probably not.** A describes *scope* (per product, instance) and B describes *function* (consumed by AI, governed). They could be two dimensions of one concept.
- **Resolves by:** a later definition that states both, or one that clearly separates two PKS notions.

## C7 — Is reasoning an admissible trigger for a change of state?

- **Statement A:** "rows change only when EVIDENCE lands or an AUTHORITY rules — never … by re-reasoning" (F0004 L7).
- **Statement B:**
  - F0005 L20: architectural gaps are "resolved by **modelling**".
  - F0003 R-12: "'One owner ⇒ one context' rejected by **this synthesis, on review challenge**".
  - F0003 L24: "'space map is the real ownership map' **downgraded** finding → HYPOTHESIS" after review.
- **Genuine?** **Yes.** In practice, argument and review do change standing (especially downwards).
- **Possible explanation:** the rule may govern *upward* moves and derived views only. Demotion by argument may be allowed because it lowers claim strength, which keeps P1 safe. That is an asymmetric rule: **evidence is needed to go up; argument is enough to go down.**
- **Resolves by:** finding the canonical transition rules (ES-006.1).
