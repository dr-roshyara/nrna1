# scripts/

**Empty by decision, not by delay.**

A script in this root may **derive**: count · order · group · roll up · check.

A script may **never interpret, decide, or resolve identity.** Interpretation is a recorded act by a
person or a reasoning agent. **A derived number is not a finding** — it measures a scope and a
pattern, never a theory.

| a script may | a script may not |
|---|---|
| count records | decide that two forms are the same |
| order records | decide that a form is canonical |
| group labels by string similarity | conclude that a grouped pair is related |
| roll up a status vector | set a status |
| check that the register and the tree agree | repair a record (§C8 — corrections are appended) |

**Nothing is added here in advance.** A script is added when a stage actually needs a derivation that
cannot be done reliably by hand — the Markdown-first decision. Until then this directory declares the
home rather than filling it.

When the first script is added, it is registered in [`../00-INDEX.md`](../00-INDEX.md) §E like any
other artefact.
