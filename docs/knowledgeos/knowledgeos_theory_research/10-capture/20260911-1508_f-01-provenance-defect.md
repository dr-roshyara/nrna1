## 1. The finding

As first committed, `C6` defined `PRIMARY` as source material **not produced in this root**, and
`DERIVED` as *"our own synthesis — the default for everything in this root"*. A statement made by a
participant in this root is produced in this root. It therefore fell to `DERIVED`.

So the corpus's **evidence layer would have been typed as agent material on contact** — and the
whole purpose of this station is to preserve source material so theory can be built from it.

## 2. What says this

- `C6` as committed: `PRIMARY` = *"an external source document — **not produced here**"*; `DERIVED` =
  *"**our own synthesis — the default for everything in this root**"*.
- `TEMPLATE-finding.md` as committed hard-coded `Provenance: DERIVED` in its header — the mis-typing
  was not merely permitted, it was the template's default.
- `C10` as committed made resolving three out-of-root pointers a **prerequisite** for the first
  document that needed them — so the corpus could not have started under its own rules.

## 3. What would make this wrong

A capture record written under the committed `C6` that carries a participant's statement as
`PRIMARY` **without breaking `C6`**.

Under the committed text this is not possible: nothing produced in this root could be `PRIMARY`. If a
record of that kind can be produced, this finding fails. *(It cannot — the class did not exist.)*

## 4. What it does NOT claim

- It does **not** claim anything downstream was corrupted. No capture record existed at the time, so
  nothing was mistyped in practice. **The defect is in the model, not in any record.**
- It does **not** claim the choice was careless. The classes were inherited from a protocol whose
  root was a *reconstruction* of an external corpus; in that setting "not produced here" was correct.
  The defect appeared only when the root changed purpose to *producing* the corpus.

## 5. Consequence

Amendments **A1** (pointer register withdrawn) and **A2** (`C6` redefined) were adopted; **A3**
(`claim_layer`) was adopted to carry the epistemic-role question the provenance classes were being
asked to answer alone.

**Verified by the bootstrap capture** `S-01`: in that file a participant's words are recorded
`PRIMARY · UTTERANCE` and the agent's reading of them `DERIVED · OBSERVATION`, in the same document.
The two layers are separable *in one file* — which is the case that would have been impossible under
the committed text.
