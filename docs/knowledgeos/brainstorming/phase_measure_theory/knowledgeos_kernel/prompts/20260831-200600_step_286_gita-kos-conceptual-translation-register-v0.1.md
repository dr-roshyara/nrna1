## 3. Critical Corrections

### 3.1 Arjuna ≠ Knower (Simple)

**Previous Mapping:**

```
Arjuna = Knower
```

**Corrected Mapping:**

```
Arjuna ⟷ Human Knower + Actor
```

**Rationale:**

- Arjuna is observer + experiencer + decision-maker + actor + person experiencing uncertainty
- `kṣetra-jña` is the more precise Gītā concept for "knower of the field"
- Gītā explicitly distinguishes `kṣetra` (field) from `kṣetra-jña` (knower of field)

**Implication:**

Do not use `Arjuna = Knower` as a definition. Use `Arjuna = Human Knower + Actor` as a **strong analogy**.

***

### 3.2 Ātman ≠ Knowledge Ātma (Literal)

**Previous Mapping:**

```
Ātman = Knowledge Ātma
```

**Corrected Mapping:**

```
Ātman → enduring Self → persistent identity principle → Knowledge Ātma
```

**Rationale:**

- `𝒦_ātma` is a KnowledgeOS research construct **inspired by** the analogy
- It is **not** a literal theological definition of Ātman
- Gītā research connected Ātman to enduring Self while bodily states change
- KnowledgeOS reflection: persistent identity/substrate not identical to any particular transient knowledge state

**Implication:**

Explicitly record in research canon: `𝒦_ātma ≠ literal theological definition of Ātman`

***

### 3.3 Krishna → Ω (Not God)

**Previous Mapping:**

```
Krishna = God
```

**Corrected Mapping:**

```
Krishna → Ω = Infinite Knowledge Space / Knowledge Horizon
```

**Rationale:**

- `Ω ≠ God` within formal KnowledgeOS theory
- `Ω` is the mathematical/philosophical abstraction produced by using Gītā's conception of Krishna as a **lens** on the problem of an unbounded knowledge horizon
- Properties of `Ω`:
  - `|Ω| → unbounded/non-exhaustible`
  - `K_t ⊊ Ω` (any particular knowledge state is partial projection)
  - Contains both represented and unrepresented possibilities

**Implication:**

Do not use `Krishna = God` in KnowledgeOS. Use `Krishna → Ω` as a **philosophical lens**.

***

### 3.4 Kṣetra → Knowledge Field (Strong Structural Analogy)

**Mapping:**

```
Kṣetra = field → Knowledge Field → K_t
```

**Rationale:**

- Gītā describes body as field, knower of field as `kṣetra-jña`
- KnowledgeOS reflection: `K_t = current Knowledge Field / Knowledge State`
- Earlier research explicitly states: "State = the field of knowledge at a given time"

**Status:** **Strong structural analogy** — one of the strongest conceptual translations

***

### 3.5 Kṣetra-jña → Knower (Canonical)

**Mapping:**

```
Kṣetra-jña ⟷ Knower
```

**Rationale:**

- This should be the **canonical Gītā term** behind our Knower concept
- Important property: `Knower ≠ K_t`
- Field changes while knower is distinguished from that changing field
- Gītā source explicitly develops this distinction

**Implication:**

Highly relevant to Blocker 1 — what exactly is `K`? The knower is **not** the knowledge state.

***

### 3.6 Karma → Operation (Structural Analogy)

**Mapping:**

```
Karma ⟷ o ∈ 𝒪
```

**Rationale:**

- Gītā's treatment of action is extensive (Chapter 5: "Karma-yoga – Action")
- KnowledgeOS reflection:
  ```
  Karma → Action → Operation → δ(K, o) → K'
  ```
- Should be labelled **structural analogy**, not theorem

**Implication:**

Do not claim `Karma = Operation` as a definition. Use as **analogy** for thinking about action/transformation.

***

### 3.7 Karma-phala → Result (Action ≠ Result)

**Mapping:**

```
Karma ≠ Karma-phala → o ≠ K'
```

**Rationale:**

- This is the source of our **Action ≠ Result hypothesis**
- `o` = operation/action
- `K'` = resulting state
- Gītā extensively discusses action, renunciation, and relation between action and result

**Implication:**

One of the strongest places where Gītā provides a useful conceptual lens for the transformation problem.

***

### 3.8 Sañjaya → Observer/Reporter (Architectural Metaphor)

**Mapping:**

```
Sañjaya → Observation / Reporting
```

**Rationale:**

- Earlier research describes Sañjaya as observer/reporter
- Arjuna as direct observer
- Krishna observes Arjuna's observation and understanding, acts as guide
- Architecture:
  ```
  Reality / Domain → Sañjaya-like observation → KnowledgeOS observation → Human Knower → Krishna/Sārathi-like guidance → Decision
  ```

**Status:** **Architectural metaphor**, not literal implementation

***

### 3.9 Buddhi → Discrimination/Evaluation (Strong Heuristic)

**Mapping:**

```
Buddhi → discrimination / evaluation / decision reasoning
```

**Rationale:**

- Earlier research explicitly associated intelligence with discrimination and knowledge processing
- KnowledgeOS terms (potentially):
  ```
  Evidence → Evaluation → Qualification → Assessment → Determination
  ```
- Whether these belong in kernel remains separate architectural question

**Status:** **Strong heuristic** — useful for thinking about evaluation/discrimination

***

### 3.10 Zero → Boundary of Knowledge (Research Construct)

**Mapping:**

```
Zero = boundary between known and unknown → KnowledgeOS epistemic boundary
```

**Rationale:**

- Zero Lens is **not** a Gītā term — it is our research construct
- Used to represent boundary between known and unknown
- Earlier research explicitly defined ignorance as boundary of knowledge

**Implication:**

Do not write "The Gītā defines Zero." It does not. Zero is a **KnowledgeOS research construct** inspired by thinking about knowledge limitations.
