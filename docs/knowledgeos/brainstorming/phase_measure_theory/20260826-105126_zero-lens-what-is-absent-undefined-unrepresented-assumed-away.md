# 2. Zero is not simply "unknown"

This is the key insight.

In an infinite knowledge space, **Zero represents the boundary of what has not been represented in the current knowledge state**.

```text
              INFINITE KNOWLEDGE SPACE Ω

 d1  d2  d3  d4  d5  d6  d7  d8  d9  d10 ...
 │   │   │   │   │   │   │   │   │   │
```

Our current knowledge state is a projection:

$$
K_t \subseteq \Omega
$$

Zero asks:

> **What lies outside the currently represented projection, and what exactly does that absence mean?**

That is much stronger than simply saying:

> "We don't know."
