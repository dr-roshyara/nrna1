$$
\boxed{

$$

### 1.3 The Key Question

The mathematical question is:

$$
\boxed{
\text{What information about the joint dependence structure determines } P(M_n \leq x)?
}
$$

Not:

$$
\boxed{
N_{\text{eff}} = f(\lambda_1, \ldots, \lambda_n)?
}
$$

**The distinction matters enormously.** If two covariance structures have the same spectrum but different extreme-value behaviour, then:

$$
\boxed{
\text{Spectrum alone cannot determine the multiplicity burden.}
}
$$

## Part 4: The Factivity Decision

### 4.1 What Factivity Means

In KnowledgeOS, factivity is the relationship between:

$$
\boxed{
\text{Knowledge Attribution}
\rightarrow
\text{Truth}
}
$$

Specifically:

$$
\boxed{
\text{Knows}(a, p, c, t) \rightarrow \text{True}(p, c, t)
}
$$

### 4.2 The Two Options

| Option | Description | Consequence |
|:---|:---|:---|
| **Rename** | Do not call attributed states "knowledge" | Honest but semantically weaker |
| **Externalize** | Factivity is verified outside the kernel | Kernel remains clean; verification external |

### 4.3 The Decision Criteria

The factivity decision should be based on:

1. **Architectural clarity:** Which option produces cleaner boundaries?
2. **Kernel minimality:** Which option keeps the kernel minimal?
3. **Empirical adequacy:** Which option matches the observed system?
4. **Philosophical coherence:** Which option is epistemologically defensible?
