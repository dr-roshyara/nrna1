\[

### III.5 The non-collapse principle

**Claim (Yoni Lens, Part 3.3).** \(P_t + N_t = 0 \not\Rightarrow \text{Knowledge}\).

**Derivation attempt from L0–L11.**

By D44–D45, Determine is a *Heyting-valued thresholded meet*:
\[
\text{Determine}(h) = [\min(s_h, e_h) \ge \tau].
\]
The *polarity* \(P_t\) corresponds to \(s_h\), \(N_t\) to \(1 - e_h\). A *zero-balanced argument* \(P_t + N_t = 0\) could arise from *different* \((s_h, e_h)\) pairs:
- \(s_h = 0\), \(e_h = 1\): fully excluded.
- \(s_h = 1\), \(e_h = 1\): fully supported and competitor-free (determined).
- \(s_h = 0.5\), \(e_h = 0.5\): Heyting intermediate.

**Consequence.** The *non-collapse* of the Yoni Lens *is already derived* by L3.6's Heyting-valued typing (D44). **The principle is a *consequence*, not a *new axiom*.**

**Verdict.** Non-collapse principle is *derivable*.

**Verdict.** The recursion structure is *derivable conditionally on \(\mathcal{Y}_t\) being derivable*.
