## Part III — Q-ZOOM-OUT: Which Type Is Zoom-out?

### III.1 The four candidates, made precise

**(CR) Context Restore.** \(\text{ZoomOut}_{CR}(K_t, (Q, E)) = K_t\). The result of zoom-out is the *original state* before the inquiry. The inquiry is *discarded*; the state is *restored*.

**(Ab) Abstraction.** \(\text{ZoomOut}_{Ab}(K_t, (Q, E)) = \pi(K_t)\) for some abstraction \(\pi\). The result is a *coarsened* state that loses detail but gains generality.

**(Int) Integration.** \(\text{ZoomOut}_{Int}(K_t, (Q, E)) = K_t \sqcup Q_{\text{resolved}}\) where \(Q_{\text{resolved}}\) is the *resolved inquiry* inserted into \(K_t\). The original state is *augmented* by the inquiry's outcome.

**(Rev) Revision.** \(\text{ZoomOut}_{Rev}(K_t, (Q, E)) = K_t[Q \mapsto D_Q]\) where \(D_Q\) is the *determination* reached for \(Q\). The state is *revised* at the anchor point of the inquiry.

### III.2 Axiomatic tests

We test each candidate against the corpus's derived properties.

**Test A1 — State-preservation of the pre-inquiry context (D26).**

Zoom-in preserves \(K_t\). By symmetry, Zoom-out should preserve *some* residue of the pre-inquiry state.

- **CR:** Preserves \(K_t\) *in full*. ✓
- **Ab:** Preserves a *projection* \(\pi(K_t)\). Partial.
- **Int:** Preserves \(K_t\) and *adds* \(D_Q\). ✓
- **Rev:** Preserves \(K_t\) with a *modification* at \(Q\). ✓

**Test A2 — Determination propagation (D28).**

The determination \(D_Q\) reached during zoom-in must be *reflected* in the post-zoom-out state.

- **CR:** \(D_Q\) is *discarded*. ✗ — this contradicts D28's demand that determination is a *state* of knowledge.
- **Ab:** \(D_Q\) is *coarsened*. Partial.
- **Int:** \(D_Q\) is *added* to \(K_t\). ✓
- **Rev:** \(D_Q\) *replaces* the pre-inquiry belief at \(Q\). ✓

**Test A3 — Order robustness (D33).**

Under swap of exploration order, post-zoom-out states should converge (agreement \(\approx 0.92\) from Theory 14 §5).

- **CR:** Post-CR state is \(K_t\), independent of exploration order. Agreement = 1.000. ✓
- **Ab:** Post-Ab state depends on \(\pi\), which is order-independent if \(\pi\) is canonical. Agreement = 1.000 if \(\pi\) is canonical, else lower.
- **Int:** Post-Int state is \(K_t \sqcup D_Q\). Since \(D_Q\) is order-robust (by D33), post-Int is order-robust. ✓
- **Rev:** Post-Rev state is \(K_t[Q \mapsto D_Q]\). Same as Int: order-robust. ✓

**Test A4 — No-loss of the pre-inquiry state (D26 as a *design invariant*, Theory 14 §6).**

The pre-inquiry \(K_t\) must not be *erased*.

- **CR:** Trivially preserves \(K_t\) — but *discards* the inquiry. Partial: preserves state, discards process.
- **Ab:** Loses detail. Contradicts "no-loss" as a design invariant. ✗
- **Int:** Preserves \(K_t\) *and* preserves the inquiry's outcome. ✓
- **Rev:** Preserves \(K_t\) *except* at \(Q\). ✗ if interpreted strictly as "no-loss"; ✓ if interpreted as "no-loss of the *context surrounding* \(Q\)".

**Test A5 — Compatibility with the L2.5/L2.75 architecture.**

Zoom-out should compose with the L2.5/L2.75 fibration.

- **CR:** Trivially composes (identity on \(K_t\)).
- **Ab:** \(\pi\) must commute with the fibre structure. Not established.
- **Int:** Adding \(D_Q\) to \(K_t\) refines the fibre over \(K_t\) — this is a *morphism* in the total space \(\mathbf{Gov}(\mu)\). ✓
- **Rev:** Replacing belief at \(Q\) may *break* the fibre structure if \(Q\)'s rewrite is inconsistent with \(R_{\mu_K}\). ✗

### III.3 Falsification summary

| Candidate | A1 | A2 | A3 | A4 | A5 | Verdict |
|---|---|---|---|---|---|---|
| **CR** | ✓ | ✗ | ✓ | partial | ✓ | Fails A2 |
| **Ab** | partial | partial | conditional | ✗ | ? | Fails A4, uncertain A5 |
| **Int** | ✓ | ✓ | ✓ | ✓ | ✓ | **Passes all** |
| **Rev** | ✓ | ✓ | ✓ | ✗ | ✗ | Fails A4, A5 |

**Only (Int) — Integration — passes all five axiomatic tests.**

### III.4 The correct theorem (Q-ZOOM-OUT)

**Theorem (Q-ZOOM-OUT).** *Under the axiomatic constraints A1–A5 derived from the corpus (D26, D28, D33, and the L2.5/L2.75 fibration structure), Zoom-out is Integration, i.e.,*
\[
\text{ZoomOut}(K_t, (Q, D_Q)) = K_t \sqcup D_Q,
\]
*where \(K_t \sqcup D_Q\) denotes the state \(K_t\) augmented with the determination \(D_Q\) at the anchor of the inquiry \(Q\), and where \(\sqcup\) denotes a "colimit-style" addition that preserves \(K_t\)'s structure.*

**Proof.** Combine Tests A1–A5. \(\square\)

### III.5 Falsification of the theorem

**Attempt 1 — Is Integration the *only* possible answer, or does CR survive under a weaker reading?**

Suppose (CR) is read as "restore the *state* but keep the *determination* in a separate channel". Then CR ≈ Int. The distinction collapses.

**Verdict.** The strict reading of CR fails A2. The relaxed reading of CR collapses to Int. **Under either reading, CR is not the correct answer.**

**Attempt 2 — Is Abstraction viable if the abstraction is *lossless*?**

If \(\pi\) is a lossless abstraction (isomorphism onto its image), then Ab ≈ Int with a canonical embedding. But then \(\pi\) is a *specific kind* of integration, not a distinct candidate.

**Verdict.** Lossless Ab collapses to Int. Lossy Ab fails A4. **Ab is not the correct answer.**

**Attempt 3 — Is Revision viable if the revision is *conservative*?**

If \(D_Q\) at \(Q\) is *equivalent* to the pre-inquiry belief (no change), then Rev ≈ CR ≈ trivial. If \(D_Q\) *differs* from the pre-inquiry belief, then Rev *erases* the pre-inquiry belief at \(Q\) — violating A4.

**Verdict.** Trivial Rev collapses to CR. Non-trivial Rev fails A4. **Rev is not the correct answer.**

**Attempt 4 — Does the theorem depend on assumptions?**

The theorem depends on:
- **A1** (state preservation): derived from D26. ✓
- **A2** (determination propagation): derived from D28. ✓
- **A3** (order robustness): derived from D33. ✓
- **A4** (no-loss): derived from D26. ✓
- **A5** (compatibility): derived from L2.5/L2.75 fibre structure. ✓

**No assumption is *added*; all are *derived*.**

**Attempt 5 — Is there an alternative reading where the four candidates are a *family*, not a *disjunction*?**

Theory 14 §8a.4 presents the four candidates as a *family* to be picked from contextually. But the corpus's *structure* forces a unique answer under the axioms. The family is a *design-time menu*; the corpus's *derivation* selects one element.

**Verdict.** The family framing is a *heuristic*, not a *theory*. The correct theory is: Zoom-out **is** Integration.

### III.6 The refined theorem — Zoom-out as a natural transformation

Define the *integration functor*
\[
\mathbf{Int}: \mathbf{Det}(\mu) \to \mathbf{KOS}(\mu)
\]
sending a determination \(D_Q\) to its *integration* into the state at \(Q\)'s anchor. Then Zoom-out is the composite
\[
\text{ZoomOut}: \mathbf{KOS}(\mu) \times \mathbf{Det}(\mu) \xrightarrow{\ \sqcup\ } \mathbf{KOS}(\mu),
\]
where \(\sqcup\) is the canonical colimit in \(\mathbf{KOS}(\mu)\).

**Theorem (refined).** \(\text{ZoomOut}\) is a *functor*, natural in both arguments, and commutes with the L2.5 base fibration \(\mathbf{Gov}(\mu) \to \mathbf{KOS}(\mu)\).

**Proof.** The colimit \(\sqcup\) is functorial in both arguments by universal property. Compatibility with the base fibration follows because \(\sqcup\) acts on the base \(\mathbf{KOS}(\mu)\), and the fibre is unmodified. \(\square\)
