### III.2 Testing invariant derivability

**(ZI-01) UNKNOWN ≠ ABSENT.**

Derivation attempt from L0–L13.

By D11, \(K_t = (\mathcal{D}_t, \mathbf{V}_t, \mathbf{A}_t, Q, \Gamma)\). Unknown dimensions \(d \notin \mathcal{D}_t\) and unknown values \(v_d = \bot\) are *distinct structures*. By D15, \(K_{\min}^{Q,\Gamma}\) is the *quotient* by the congruence closure of \(\sim_{\mathrm{req}}\). The *unknown* state at a dimension is *not* the *absent* dimension, since the quotient identifies *states*, not *existence*.

**Verdict.** ZI-01 is *derivable*. ✓

**(ZI-02) NOT\_ASSESSED ≠ LOW\_CONFIDENCE.**

Derivation attempt. \(\mathbf{A}_t\) (assurance structure) at D11 *distinguishes* the *type* of assurance. A "not-assessed" state has *no assurance*; a "low-confidence" state has *weak* assurance. These are *distinct* assurance values in \(\mathbf{A}_t\).

**Verdict.** ZI-02 is *derivable*. ✓

**(ZI-03) NOT\_APPLICABLE ≠ UNKNOWN.**

Derivation attempt. Applicability is determined by the *contract* \(Q\). A dimension *outside the contract* has *no value* because *the contract excludes it*. This is *distinct* from a dimension *within the contract* whose value is *unknown*.

**Verdict.** ZI-03 is *derivable*. ✓

**(ZI-04) NO\_EVIDENCE ≠ INVALID\_EVIDENCE.**

Derivation attempt. Evidence is external (D13). *Absent* evidence (\(E = \emptyset\)) is distinct from *invalid* evidence (\(E \neq \emptyset\) with *invalid* content). By D27 (exploration), evidence *accumulates*; validity is a *separate property*.

**Verdict.** ZI-04 is *derivable*. ✓

**(ZI-05) UNRESOLVED ≠ FALSE.**

Derivation attempt. Determine is a *Heyting-valued thresholded meet* (D44–D45). The values *below threshold* \(\tau\) are *not* the *false* value; they are *below-cutoff* values. In Heyting semantics, \(\neg\neg u \ne u\) for *intermediate* \(u\).

**Verdict.** ZI-05 is *derivable*. ✓

**(ZI-06) UNKNOWN\_DIMENSION ≠ UNKNOWN\_VALUE.**

Derivation attempt. \(d \in \mathcal{D}_t\) with \(v_d = \bot\) is *derivable* from D11. \(d \notin \mathcal{D}_t\) requires *dimension discovery*, which is outside \(K_t\)'s scope. The two are *structurally distinct*.

**Verdict.** ZI-06 is *derivable*. ✓

**(ZI-07) MODEL ≠ REALITY.**

Derivation attempt. This is a *philosophical* principle, not obviously derivable from L0–L13. But: L1's \(s \to \rho_t(s) \to K_t\) decomposition (D12) explicitly *distinguishes* the *semantic state* \(s\) from its *representation* \(\rho_t(s)\) from the *epistemic state* \(K_t\). **The three-level separation is precisely this non-collapse.**

**Verdict.** ZI-07 is *derivable* from D12. ✓

**(ZI-08) PREVIOUSLY\_UNKNOWN ≠ PREVIOUSLY\_ABSENT.**

Derivation attempt. History is external (D13). A state at time \(t_1\) is *recorded*; a state at time \(t_2\) *revises* it. The *historical fact* of "unknown at \(t_1\)" is *preserved*; it is *not* rewritten as "absent at \(t_1\)". This is a *consequence* of D13's externalization.

**Verdict.** ZI-08 is *derivable*. ✓

**(ZI-09) CONFLICT ≠ INVALIDITY.**

Derivation attempt. By D40 and D44, hypotheses are *Heyting-valued*. Two conflicting hypotheses \(h_1, h_2\) can *both* be above threshold. The conflict is *information*, not *invalidity*.

**Verdict.** ZI-09 is *derivable*. ✓

**(ZI-10) NO\_KNOWN\_GAP ≠ COMPLETE.**

Derivation attempt. This is the *deepest* invariant. By D11, \(\mathcal{D}_t\) is the *recognized* dimension set at time \(t\). Completeness requires \(\mathcal{D}_t = \mathcal{D}^*\), but \(\mathcal{D}^*\) is *not known*. **Derivation requires the *infinite knowledge space* structure** — which is *not explicitly in L0–L13*.

**Verdict.** ZI-10 is *not derivable from L0–L13 as currently formulated*. **A gap.**

### III.3 The gap for ZI-10

**Falsification attempt.** The *union* is the *discovered* dimensions, not the *ideal* dimensions. There is *no canonical upper bound* on the dimension set derivable from the corpus.

**Verdict.** \(\mathcal{D}^*\) is *not derivable* from L0–L13. **ZI-10's derivation requires *new structure*.**
