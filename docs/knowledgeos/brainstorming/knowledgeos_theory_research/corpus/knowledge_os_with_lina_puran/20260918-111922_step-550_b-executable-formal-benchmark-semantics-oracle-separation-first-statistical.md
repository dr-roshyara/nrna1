Step 550-A §34 rejects "metamorphic duplication as universal rule." This is correct as stated for **duplicate**: `Det(E) = Det(E ∪ {E})` is not universally true, because duplication may change the support count in a counting rule. The correct metamorphic relations are:

# PART II — Term Definitions (One by One, Real-World Grounded)

## 550B.3 Ground Truth

**Definition.** `K*` is the complete synthetic reality generated by the benchmark:
```
K* = (V*, E*, I*, P*, Det*, M*, Z, seed)
```
where `V*` is the full node set, `E*` the full edge set, `I*` the independence oracle, `P*` the perturbation family, `Det*` the determination function, `M*` the materiality relation, `Z` the hidden state, `seed` the generator seed.

**Real-world example:** the actual organisational reality of which documents truly derive from which sources.

## 550B.4 Observation

**Definition.** `O = Obs(K*)` where `Obs : K* → Ω` is the observation operator. `O` is what a real-world KnowledgeOS system could legitimately perceive.

**Real-world example:** the document text, metadata, timestamps, and citations visible to an analyst.

## 550B.5 Observation Contract

**Definition.**
```
OC = (Ω, Obs, F_O)
```
- `Ω` — the observation space.
- `Obs` — the observation function.
- `F_O` — the allowed observable features.

**Real-world example:** `F_O = {text, metadata, timestamps, citations}`; forbidden = `{dataset_id, model_id, generator_seed, G*, I*, Z}`.

## 550B.6 Ground Truth Oracle

**Definition.** `𝒪*` is an oracle with access to `K*` that answers `Truth(p, K*)` for benchmark evaluation. It is invoked **only after** the system under test has completed inference.

**Real-world example:** the benchmark author's own scoring function.

## 550B.7 Leakage

**Definition.**
```
Leakage ⟺ I(K*; S | O) > 0
```
where `S` is the system's effective input. Ideal: `S = O`.

**Real-world example:** a validator that reads `G*` to check an edge is leaking.

## 550B.8 Observational Equivalence

**Definition.**
```
K₁ ~_O K₂ ⟺ Obs(K₁) = Obs(K₂)
```

**Theorem (Observation Determinism).** If `S : Ω → Y` is deterministic and `Obs(K₁) = Obs(K₂)`, then `S(Obs(K₁)) = S(Obs(K₂))`.

**Proof.** Equal inputs to a function produce equal outputs. ∎

**Theorem (Randomized Determinism).** If `S(O, R)` is stochastic with randomness `R`, and `Obs(K₁) = Obs(K₂)`, then `P(S(O, R) = y)` is the same for both.

**Proof.** The distribution of `S(O, R)` depends only on `O` and the distribution of `R`. ∎

## 550B.9 Equivalence Class

**Definition.**
```
[H]_O = { H' ∈ ℋ : Obs(H') = Obs(H) }
```

**Definition (Identifiability).**
```
H is observationally identifiable ⟺ |[H]_O| = 1
```

**Real-world example:** if two different hidden datasets produce identical observations, `|[H]_O| > 1`, and no system can distinguish them.

## 550B.10 Three Identifiability Notions

| Notion | Definition | Real-world meaning |
|---|---|---|
| **SIA** | `I(O; 1{Z ≠ 0}) / H(1{Z ≠ 0})` | Can we tell "something is hidden"? |
| **SI** | `I(O; Z) / H(Z)` | Can we tell "which thing is hidden"? |
| **Exact Recovery** | `|[H]_O| = 1` | Can we identify the hidden structure uniquely? |

**Theorem (Hierarchy).**
```
Exact Recovery ⟹ SI ≤ SIA
```
but not vice versa.

## 550B.11 Information Availability Ratio (Corrected)

**Definition.**
```
IAR = I(O; Z) / H(Z)
```

**Estimator (Corrected).** Do **not** use classifier accuracy. Use conditional entropy:
```
Ĥ(Z | O) = −(1/N) Σᵢ [ zᵢ log p̂ᵢ + (1−zᵢ) log(1−p̂ᵢ) ]
Î(Z; O) = H(Z) − Ĥ(Z | O)
ÎAR = Î(Z; O) / H(Z)
```

**Requirements:**
- held-out data,
- repeated seeds,
- confidence intervals,
- calibration,
- permutation controls.

## 550B.12 Total Variation Distinguishability

**Definition.**
```
TV(P₀, P₁) = ½ ∫ |P₀(o) − P₁(o)| do
```

**Interpretation:** `TV = 0` means indistinguishable; larger `TV` means more distinguishable.

## 550B.13 Recoverability

**Definition.** The ability of a **specified system class** to recover a target structure from permitted observations with a specified error criterion.

**Theorem (Recoverability Chain).**
```
Information → Distinguishability → Identifiability → Learnability → Recoverability
```
Each arrow requires separate justification.

## 550B.14 Tri-State Validation

**Definition.**
```
Validate(C, E_v, Γ) → V ∈ {Supported, Rejected, Inconclusive}
```

**Real-world example:** a citation extractor returns `Supported` if a citation is found, `Rejected` if the source is cited but the claim contradicts, `Inconclusive` otherwise.

## 550B.15 Epistemic Acceptance

**Definition.**
```
Accept_Γ(V, K) → {Established, NotEstablished}
```

**Pipeline.**
```
Candidate → Validation → {Rejected, Inconclusive, Supported}
                       → Epistemic Acceptance → Established
```

## 550B.16 Materiality

**Definition.**
```
M_S(z, K) = 1 ⟺ ∃ π_z ∈ P : Det_S(K) ≠ Det_S(π_z(K))
M*(z, K) = 1 ⟺ ∃ π_z ∈ P : Det*(K) ≠ Det*(π_z(K))
```

**Theorem.** `M_S ≠ M*` in general. Materiality precision/recall are measurable.

## 550B.17 Five Uncertainty Levels

```
U_s = structural     (does the dependency exist?)
U_i = identifiability (can it be inferred from O?)
U_p = statistical    (is the signal significant?)
U_e = epistemic      (does it materially affect the determination?)
U_d = decision       (does the determination affect the decision?)
```

**Theorem (Non-Collapse).** The five are distinct and cannot be reduced to a scalar without loss.

## 550B.20 Observation Operator

```python
def observe(K, oc):
    """Obs(K) → O. Only F_O features are exposed."""
    O = {"nodes": {}, "edges": set(), "features": {}}
    for v, attrs in K["V"].items():
        for k in oc["F_O"]["node_features"]:
            if k in attrs:
                O["nodes"][v] = O["nodes"].get(v, {})
                O["nodes"][v][k] = attrs[k]
    for (x, rho, y) in K["E"]:
        if (rho in oc["F_O"]["edge_types"]) and (x, y) in oc["F_O"]["visible_edges"]:
            O["edges"].add((x, rho, y))
    return O
```

**Critical:** `Obs` reads only `F_O`-allowed fields. Hidden structure (`D, M, A`) is excluded by construction.

## 550B.21 Ground Truth Oracle (Isolated)

```python
class Oracle:
    def __init__(self, K_star):
        self._K = K_star           # private
    def truth(self, query):
        # invoked ONLY after system inference
        if query == "Det_star":    return self._K["Det_star"]
        if query == "I_star":      return self._K["I_star"]
        if query == "G_star":      return self._K["E"]
        if query == "Z":           return self._K["Z"]
        raise ValueError
```

**Invariant:** `Oracle` is never passed to a system. The benchmark orchestrator instantiates `Oracle` **after** `S(O)` completes.

## 550B.22 Observation Determinism Test

```python
def determinism_test(S, K1, K2, oc):
    O1 = observe(K1, oc); O2 = observe(K2, oc)
    assert O1 == O2, "K1, K2 must be observationally equivalent"
    y1 = S(O1); y2 = S(O2)
    return y1 == y2
```

**Theorem (Observation Determinism).** For a deterministic system `S` with fixed random seed, `determinism_test` returns `True` always. If `False`, there is leakage, hidden state, or uncontrolled randomness.

## 550B.23 IAR / MI Estimator

```python
def estimate_IAR(worlds_0, worlds_1, feature_fn, n_splits=5):
    """worlds_0: Z=0; worlds_1: Z=1."""
    X = [feature_fn(observe(K, oc)) for K in worlds_0 + worlds_1]
    y = [0]*len(worlds_0) + [1]*len(worlds_1)
    # held-out probabilistic classifier
    p_hat = cross_val_predict(LogisticRegression(), X, y, cv=n_splits, method="predict_proba")[:,1]
    # conditional entropy
    H_Z = entropy_bernoulli(np.mean(y))
    H_Z_given_O = -np.mean(y * np.log(p_hat + 1e-9) + (1-y) * np.log(1-p_hat + 1e-9))
    I_hat = H_Z - H_Z_given_O
    return I_hat / H_Z if H_Z > 0 else 0.0
```

**Requirements:** use held-out folds, repeat with multiple seeds, report bootstrap 95% CI, verify calibration with Brier score.

def materiality(S, K, oc, Γ, z):
    """M_S(z, K) = 1 iff some admissible π_z flips Det_S."""
    Det = S(observe(K, oc))["Det"]
    for π in admissible_perturbations(K, z):

# PART IV — First Statistical Execution

## 550B.27 Experiment A — Observation Determinism

**Procedure:**
1. For each world family, generate `K*`.
2. Generate `K'` by permuting hidden-node identities such that `Obs(K') = Obs(K*)`.
3. Run each system `S_i` on `O = Obs(K*) = Obs(K')`.
4. Check `S_i(O) = S_i(O)` for all `i`.

**Predicted outcome:** all deterministic systems pass; any failure indicates leakage.

**Falsification criterion:** if any deterministic system fails, its implementation violates the Observation Determinism Theorem.

## 550B.28 Experiment B — Equivalence-Class Test

**Procedure:**
1. Generate pairs `(K₁, K₂)` with `Obs(K₁) = Obs(K₂)` but `K₁ ≠ K₂` (differ in hidden structure only).
2. For each system `S_i`, verify `S_i(Obs(K₁)) = S_i(Obs(K₂))`.
3. If equal: **consistent** with observational determinism.
4. If unequal: **leakage**.

**Predicted outcome:** all systems pass.

## 550B.29 Experiment C — IAR Estimation

**Procedure:**
1. For `W7-N`: generate 200 worlds with `Z = 0` and 200 with `Z = 1`. Extract observable features. Fit classifier. Estimate `ÎAR`.
2. Repeat for `W7-W` and `W7-D`.
3. Report `ÎAR ± 95% CI`.

**Falsification criterion:**
- If `ÎAR(W7-N) > 0.05`, the world is mis-generated.
- If `ÎAR(W7-D) < 0.95`, the world is mis-generated.

## 550B.30 Experiment D — Total Variation

**Procedure:**
1. For each world family, estimate `TV(P₀, P₁)` using kernel density or histogram-based methods on observable features.
2. Report `TV ± 95% CI`.

**Predicted outcome:** `TV(W7-N) ≈ 0`, `TV(W7-D) ≈ 1`, `TV(W7-W) ∈ (0, 1)`.

## 550B.31 Experiment E — Tri-State Validation

**Procedure:**
1. Generate candidate edges.
2. Apply tri-state validator.
3. Report counts: `Supported / Rejected / Inconclusive`.

**Falsification criterion:** if `Rejected = 0`, the validator is not discriminating.

## 550B.32 Experiment F — Leakage Detection

**Procedure:**
1. For each system, run an information-flow test: compare `S(O)` when `O` is generated from `K₁` vs `K₂` with `Obs(K₁) = Obs(K₂)`.
2. Compute mutual information `Î(K*; S(O))`.
3. Ideally `Î(K*; S(O) | O) = 0`.

**Falsification criterion:** `Î(K*; S(O) | O) > 0` for any system indicates leakage.

## 550B.33 Experiment G — Negative Controls (W9)

**Procedure:**
1. Generate `W9` with `Z = 0` but observable features distributed identically to `W7-W`.
2. Run `S5`.
3. Report `NegativeControlFPR`.

**Falsification criterion:** `NegativeControlFPR > 0.1`.

## 550B.34 Experiment H — Metamorphic Relations

**Procedure:**
1. **Rename:** `S(rename(O)) = S(O)`.
2. **Permute:** `S(permute(O)) = S(O)`.

**Falsification criterion:** any failure indicates a bug or leakage.

## 550B.35 Experiment I — Materiality Precision/Recall

**Procedure:**
1. For each dependency `z`, compute `M_S(z, K)` and `M*(z, K)`.
2. Report `Precision_M`, `Recall_M ± 95% CI`.

**Predicted outcome:** `Precision_M` and `Recall_M` vary by system and world.
