# 13. Correct computational measurement of information

For a discrete \(Z\), estimate:

\[
I(Z;O)
=
H(Z)-H(Z\mid O).
\]

A practical estimator can use a held-out probabilistic classifier:

\[
\hat p_i=P(Z=1\mid O_i).
\]

Then estimate conditional entropy:

\[
\widehat{H}(Z\mid O)
=
-\frac1N
\sum_i
\left[
z_i\log\hat p_i+
(1-z_i)\log(1-\hat p_i)
\right].
\]

Then:

\[
\boxed{
\widehat{I}(Z;O)
=
H(Z)-\widehat H(Z\mid O)
}
\]

and:

\[
\boxed{
\widehat{IAR}
=
\frac{\widehat I(Z;O)}{H(Z)}.
}
\]

This is statistically much better aligned with the definition.

# 31. This gives us a new theorem

## Observation Determinism Theorem

If a system \(S\) is a function solely of its permitted observation \(O\), then:

\[
O_1=O_2
\Rightarrow
S(O_1)=S(O_2).
\]

### Proof

Since:

\[
S:\Omega\rightarrow Y
\]

is a function, equal inputs have equal outputs.

Therefore:

\[
O_1=O_2
\Rightarrow
S(O_1)=S(O_2).
\]

QED.

### Why it matters

If our implementation violates this, then either:

1. the system has hidden state;
2. randomization is uncontrolled;
3. additional information entered the system;
4. the observation contract is incomplete.

This is a **computer-logic invariant**, not merely a testing suggestion.
