## Part 8: The Simulation Code

### 8.1 The Simulation Variables

```python
# 1 Linga, 2 Yoni — Simulation

class Linga:
    def __init__(self, proposal, strength, confidence):
        self.proposal = proposal
        self.strength = strength
        self.confidence = confidence

class Yoni:
    def __init__(self, name, context, receptivity):
        self.name = name
        self.context = context
        self.receptivity = receptivity
        self.interpretation = None

    def receive(self, linga):
        if self.receptivity > 0.5:
            self.interpretation = linga.proposal
            return self.interpretation
        else:
            self.interpretation = f"Rejected: {linga.proposal}"
            return self.interpretation
```

