# 1. The Sanskrit Principle

Consider a simplified example:

English:

> Rama sees Krishna.

If we reorder:

> Krishna sees Rama.

The meaning changes completely.

Why?

Because English relies heavily on:

```
Subject position → Actor
Object position → Receiver
```

Sanskrit encodes this through grammatical markers.

Example:

```
Rāmaḥ Kṛṣṇaṃ paśyati

Rāmaḥ = Rama + nominative
Kṛṣṇaṃ = Krishna + accusative
paśyati = sees
```

The endings tell us:

```
Actor:
Rama

Action:
seeing

Object:
Krishna
```

So the sentence can be rearranged:

```
Kṛṣṇaṃ Rāmaḥ paśyati

or

Paśyati Rāmaḥ Kṛṣṇaṃ
```

The grammatical relationships remain.

The structure survives.
