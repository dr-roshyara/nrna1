## Part 8: The Simulation Code

### 8.1 The Simulation Variables

```python
# 3 Linga, 2 Yoni — Simulation

class Linga:
    def __init__(self, name, proposal, strength, confidence):
        self.name = name
        self.proposal = proposal
        self.strength = strength
        self.confidence = confidence

class Yoni:
    def __init__(self, name, context):
        self.name = name
        self.context = context
        self.proposals = []
        self.evaluations = []

    def receive(self, linga):
        self.proposals.append(linga)
        evaluation = linga.strength * self.context_factor()
        self.evaluations.append(evaluation)
        return evaluation

    def context_factor(self):
        # Different contexts have different factors
        if self.name == "Yoni1":
            return 1.0
        else:
            return 0.8
```
