### 3. Investigation Path & Graph Traversal Protocol

$$T\_i = \left( v\_0 \xrightarrow{e\_1} v\_1 \xrightarrow{e\_2} v\_2 \xrightarrow{e\_3} \dots \xrightarrow{e\_k} v\_k \right)$$

We define $R \subset V$ as the set of **Root-Cause Nodes** in $G\_t$. A node $r \in V$ is a root-cause if and only if:

1. $r$ is an origin of the observed anomaly $v\_0$ (i.e., there exists a directed path $r \rightsquigarrow v\_0$ in $G\_t$).



2. $r$ possesses an actionable boundary condition or invalid state configuration: $\text{IsRoot}(r) = \text{True}$.




### 4. Guarantees for Root-Cause Determination

To guarantee that $T\_i$ terminates at a valid root-cause node $r \in R$, $G\_t$ and the traversal mechanism must satisfy four formal conditions:

#### Condition 1: Direct Reachability (Weak Causality)

For the selected observation $v\_0$, the set of root causes $R(v\_0) \subseteq V$ must be reachable via directed path reversal:

$$\forall r \in R(v\_0), \quad \exists \text{ path } P = (v\_0, v\_1, \dots, r) \quad \text{in } G\_t^T$$

#### Condition 2: Causal Path Monotonicity (Acyclicity)

$$\text{Cycles}(G\_{t,\text{causal}}) = \emptyset$$
