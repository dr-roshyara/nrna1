# synthesis/ — NOT the working location

**Synthesis is happening on the Kernel question, so it belongs in `kernel/synthesis/`.**

This directory is reserved for synthesis that spans the **whole** brainstorming corpus — work that
is genuinely not kernel-scoped. No such work exists yet. **Currently empty by design, not by delay.**

```
SOURCE  ->  CLASSIFIED  ->  SYNTHESIZED  ->  ADVERSARIAL  ->  ARCHITECTURAL AUTHORITY
```

**A document never acquires a later status because of the directory it sits in.** Status advances
only by a recorded act. Directory names express **artifact function** — never subject, never authority.
Source classification is **metadata** (recorded in a census), never a path or a filename code.
