# classification/ — corpus-wide (coordination level)

**This level covers the WHOLE brainstorming corpus:** the 99 documents in
`docs/knowledgeos/brainstorming/` root, plus `kernel/`, plus `_misc/`.

**Kernel-specific classification does NOT belong here** — it lives in `kernel/classification/`.

## Known gap

The **99 root-level documents have never been censused.** Only the kernel corpus has
(`kernel/00_CENSUS.md`, 141 documents). A corpus-wide census would need to span all three
locations and reconcile the parent/kernel duplicate pairs already found
(e.g. `../20260824-145631` vs `kernel/…151311`).

Expected member when done: `corpus-index.md`.

```
SOURCE  ->  CLASSIFIED  ->  SYNTHESIZED  ->  ADVERSARIAL  ->  ARCHITECTURAL AUTHORITY
```

**A document never acquires a later status because of the directory it sits in.** Status advances
only by a recorded act. Directory names express **artifact function** — never subject, never authority.
Source classification is **metadata** (recorded in a census), never a path or a filename code.
