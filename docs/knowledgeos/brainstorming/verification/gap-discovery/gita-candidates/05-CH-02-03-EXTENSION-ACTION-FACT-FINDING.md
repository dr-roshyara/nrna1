### ⭐ Why `A9` is the substantive new object

**`Warrant` is not `Det`, not `EU`, and not `Authorization`:**

```
Det        : evaluation → a discrete epistemic stance
EU         : a utility model over a feasible action set
```

*being permitted to do it*, there is *being justified in doing it*. **And the source explicitly
refuses the cheap definition**, `W_t = EU(a) > 0`, *"that would make warrant entirely dependent on
one utility model."*
