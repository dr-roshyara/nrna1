# 5. USE A FOUR-WAY EVOLUTION TEST

For every significant earlier proposition/question determine whether a later document:

### RESOLVED

The later document provides a precise answer and the answer survives verification.

### PARTIALLY_RESOLVED

Some aspects are answered but important conditions remain missing.

### REFRAMED

The later document changes the question/model rather than solving the original problem.

### UNRESOLVED

The original problem remains open.

Also allow:

### CONTRADICTED

A later authoritative-looking document explicitly conflicts with the earlier claim.

### SUPERSEDED

The earlier formulation is explicitly replaced and the replacement is actually justified.

Do NOT infer supersession from chronology alone.
