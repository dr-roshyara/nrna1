A4  Is OR-merge compatible with RETRACT?
============================================================================
  merge(Supported, Refuted) = Conflict  (union: monotone, idempotent, commutative)
  RETRACT test: withdraw the refuting item from Conflict.
    Conflict -\ Refute = Supported  -- requires SUBTRACTION
  => union is a JOIN-semilattice op (monotone); retract is NON-monotone.
     They are compatible ONLY IF Sigma is DERIVED from the evidence set each
     time. If Sigma were STORED as a lattice element, retract could not undo a
     join without extra information.  *** THIS IS A PROOF ABOUT D-4: ***
     OR-merge + retract TOGETHER FORCE Sigma to be DERIVED, not stored.
