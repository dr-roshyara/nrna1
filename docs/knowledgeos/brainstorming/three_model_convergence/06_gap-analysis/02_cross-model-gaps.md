# Cross-Model Gaps (GA-001–GA-006), Full Treatment

## GA-001 — Kernel identity is unresolved across all four model families

Five distinct, named Kernel-candidate families now exist in this reconstruction's own history: Model
A's four-way `unresolved_equivalence` family; Model B's tested, representation-dependent cardinality-8
family; Model C1's eight-way family (the largest, `04_model-c_kernel-ddd/02` §L); Model C2's single
untested candidate; and the frozen Phase 5A–5N K-1/K-2 8-primitive-tuple family (external, not
compared here — see GA-006). **No pair among the four in-scope families is shown structure-preserving-
equivalent.** Phase 3 and Phase 6 both independently found the same categorical split: A/C1/C2 propose
*aggregate/tuple* objects (nouns — what domain entities exist); B proposes a tested *operator set*
(verbs — what actions are performed). This categorical difference, confirmed a fourth time by C1 and a
fifth by C2, is now the best-evidenced finding in this whole gap-analysis: **"Kernel" does not
currently name one comparable object across this corpus's independent reconstructions — it names at
least two different kinds of formal object, wearing one shared word.**

**Blocking status**: BLOCKING for any *unified* four-model formalization of "the Kernel." NOT blocking
for a formalization that stays within one model's own evidence (e.g. Model B could proceed to formalize
its own already-tested, representation-dependent kernel family without needing this question resolved).

**What would close it**: a demonstrated, structure-preserving map between a specific aggregate-style
candidate and a specific operator-set candidate, under a stated representation — not attempted by any
model's own evidence, and this stage does not attempt it either.

## GA-002 — The C1↔B `K_t`/`Δ_t` notation convergence has no structural mapping

Phase 6 found C1's own `phase_measure_theory/` `K_t`/`Δ_t` thread (main corpus, seq 0446–0492) and
Model B's own math-lane `K_t`/`Δ_t` thread (M0001–M0132) share identical variable names, similar
instability signatures, and — verified directly — **zero citation link in either direction**. This is
recorded at PARTIAL CORRESPONDENCE, notation/process level only. No component-level comparison between
any specific C1 `K_t` formulation and any specific B `K_t` formulation has been attempted by any prior
phase — both registers summarize their own families rather than fully enumerating every field.

**Blocking status**: RESEARCH OPPORTUNITY, not blocking — no formalization stage currently depends on
this mapping existing.

**What would close it**: a dedicated, separately-scoped formalization pass enumerating each thread's
full component list and testing for a structure-preserving map — explicitly not performed here.

## GA-003 — The proliferation-without-convergence pattern remains a hypothesis, not a tested claim

Three independent instances now exist of the same phenomenon: an under-constrained attempt to
formalize "epistemic state" producing a non-convergent, self-superseding tuple family (A's Knowledge
Vector, 9+ variants; B's K_t, 9+ variants; C1's own K_t, 6 variants). Phase 3 first proposed this as a
**PROPOSED CROSS-MODEL HYPOTHESIS**; Phase 6 strengthened it with a third, notation-matching instance,
but explicitly declined to promote it past hypothesis status.

**Blocking status**: RESEARCH OPPORTUNITY — a genuinely interesting research question about *why* this
recurs, not required for any specific formalization target.

**What would close it, or falsify it**: testing whether a sufficiently-constrained, early-committed
representation avoids the pattern (as Model B's own representation-dependence result, §P-2, already
demonstrates for kernels specifically) — not attempted for state formalizations by any model's evidence.

## GA-004 — No shared "knowledge" definition exists across all four models

A and B's own registers contain no dedicated definitional treatment of "knowledge" as a term (A works
with pramāṇa — means of *acquiring* knowledge; B works with `K_t` — a formal state structure, not a
prose definition of the word). C1 and C2 both define "knowledge" repeatedly and explicitly (`04_model-
c_kernel-ddd/03`, the MD-007 falsifier discussion). This is a genuine content asymmetry, not a
term-collision or a tested contradiction.

**Blocking status**: BLOCKING only if a future formalization stage requires one cross-model-uniform
definition of "knowledge" as its starting point. NOT blocking for model-specific formalization work
(each model can proceed on its own terms — A/B never needed a prose "knowledge" definition to do their
own formal work).

## GA-005 — Representation-theoretic apparatus is a model-specific construct, not a universal one

Only Model B (tested: induced equivalence, Representation Adequacy Principle, Hilbert-space rejection)
and Model C2 (proposed, untested: regime-functors, Shani's invariant) have a formal apparatus for
reasoning about representations. Neither A nor C1's own registers show an equivalent construct.

**Blocking status**: NON-BLOCKING. There is no evidence any model *needs* this apparatus to complete
its own internal work — A's and C1's own kernel/state proliferation problems (GA-001–003) are not shown
to require a representation theory to resolve; Model B's own already-tested apparatus already resolved
its own kernel-minimality question (P-2, ESTABLISHED) without needing A or C1 to have an analogous
construct.

## GA-006 — A corpus-wide "K-1" naming collision, deliberately left unresolved

The label "K-1" is confirmed, by Phase 6's own raw-source check, to denote at least two unrelated
structures: Model C1's `KnowledgeAggregate+ConflictRecord+VerificationPort` (seq 0165/0167,
`kernel/`, `engineering_knowledgeos`-primary) and the frozen Phase 5A–5N sub-sequence's own
`𝒦=(E,S,T,O,P,R,Π,A)` 8-primitive tuple (seq 0630, `phase_measure_theory/`). Model A's own per-file
synthesis for seq 0219 appears to conflate these two without a raw-source citation supporting the link
(also confirmed by Phase 6's own check).

**Blocking status**: GOVERNANCE-BLOCKED. Resolving which "K-1" a future reader means, or whether the
two are genuinely unrelated coincidental namings, would require inspecting the frozen Phase 5A–5N
sub-sequence's own artifacts as comparison material — explicitly out of scope for this gap-analysis
stage and for Stage 07 formalization alike, per this reconstruction's own standing boundary against
reopening a governance-frozen track. **Recorded here as the single clearest instance of why the K-1/K-2
governance boundary must stay closed during ordinary research work** — even a purely descriptive
gap-analysis stage runs directly into it.
