# Internal Model Gaps (GA-007–GA-050)

Each model's own gaps, sourced directly from that model's own frozen contradictions/open-questions
document — see `01_gap-register.md` for the full compact table. This document adds only the reasoning
the register table's own columns cannot carry, and highlights the highest-priority items per model.

## §A — Model A (GA-007–GA-021)

Model A's own `03_contradictions-and-open-questions.md` records 4 contradictions, 5 unresolved
equivalences, and 6 open questions — none resolved here, none imported from B/C1/C2 (Model A's own
authorization forbade that at reconstruction time, and this stage does not retroactively violate it).

**Highest priority**: **GA-010** (10 kernel-candidate files never cross-tested against the KR-SIM
falsification apparatus) and **GA-016** (the Mithyā/reality-appearance challenge). GA-010 matters
because it means Model A's own "zero kernel candidates" framing — cited informally elsewhere in this
reconstruction's history — applies only to a narrow sub-test, not to A's full evidence; any future
formalization drawing on A's kernel material needs to know this precisely, not assume a clean null
result. GA-016 matters because it is A's own evidence base's explicit, self-identified deepest
unresolved question, and no formalization that models "what KnowledgeOS represents" can silently
sidestep it without at least acknowledging the corpus itself never settled it.

**Everything else (GA-007–009, 011–015, 017–021)** is narrow, non-blocking, and already precisely
scoped in the register table — repeating each here would not add information beyond what
`01_gap-register.md` and Model A's own `03_contradictions-and-open-questions.md` already state.

## §B — Model B (GA-022–GA-038)

Model B's own document records 5 contradictions, 3 unresolved equivalences, and 10 open questions —
the richest internal gap inventory of any model, consistent with B's own evidence base being the most
formally mature (multiple executed experiments, a frozen negative result, a ratified governance
rejection).

**Highest priority**: **GA-038** (no corpus-internal way to select a canonical `K_t`) is the single
most consequential item in Model B's own register — it is literally the corpus's own explicit
statement of the exact question GA-002/GA-003 ask from the cross-model side. **GA-026** (7
non-equivalent "closure" meanings, none selected) is the second — "closure" is used across multiple
constructs in Model B's own evidence (Zero Closure, Epistemic Closure Event, the Structure-First
framework's own rejected `Zero=closure(B_π)`), and a formalization stage cannot safely use the word
without first picking one of the seven meanings, or explicitly parameterizing over them.

**GA-022, GA-031, GA-032, GA-033, GA-034** are genuine but narrower research opportunities — each names
a specific missing execution record or untested extension, each independently traceable and closeable
by locating or running the named experiment, not by new theoretical work.

## §C — Model C1/C2 (GA-039–GA-050)

C1's own document records 4 contradictions, 3 unresolved equivalences, 8 open questions, plus the
dedicated C1↔C2 relationship section (MD-007's three-way framework, found UNRESOLVED for a more
specific reason than insufficient evidence — the framework's own operative distinction does not
cleanly partition the evidence).

**Highest priority**: **GA-050** (the C1/C2 classification boundary itself may not track a clean
content split) is the single most structurally important finding in C1's own evidence, because it
means every other C1/C2 gap in this register is conditioned on a classification act whose own validity
is not yet confirmed. **GA-039** (the 8-way kernel family, largest in the whole reconstruction) and
**GA-047** (the `kernel/` vs. `phase_measure_theory/` chronology, corpus-acknowledged and unresolved)
are the second tier — GA-047 in particular bears directly on GA-002's own cross-model finding, since
knowing which of the two K_t threads (if either) came first would materially change how the notation
convergence should be read.

**GA-044** (ADR-KOS-KERNEL-001 never formally accepted) and **GA-048** (seq 2330's own reconciliation
question, unanswerable from C1/C2 evidence alone since the cited material is `meta_research`/
`cross_model`-tagged) are both explicitly GOVERNANCE-BLOCKED or EVIDENCE-BLOCKED by classification —
neither is closeable by further reading within the current C1/C2 population.
