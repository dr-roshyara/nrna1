## H. FR-001 — a frozen, ratified negative research result

**Source:** M0101, M0103, M0104, M0106 (exact parameters) · **Terminology:** `H_i ∼_Λ H_j`
(hypothesis indistinguishability under regime Λ), `N_eff = |H/∼_Λ|` · **Evidence status:** `[RF]`
(refuted, via an explicit constructive proof) · **Maturity:** ESTABLISHED (frozen by an explicit
governance act, the strongest maturity level this evidence base's own vocabulary provides for a
negative result).

M0101 executes KR-NEFF, an effective-hypothesis-complexity experiment (N_eff ≈ 9.0/51.1/201.9/940.6
for |H|=1000 under increasingly dependent hypothesis-space structures) and proposes `N_eff =
|H/∼_Λ|` as a candidate formalization. **M0103 proves this construction fails**: `∼_Λ` is reflexive
and symmetric but **not transitive**, via an explicit 12-link counterexample chain (`H_1 ∼_Λ H_2
∼_Λ ... ∼_Λ H_12` while `H_1 ≁_Λ H_12`) — a genuine mathematical proof, not an experimental
observation. **M0104 ratifies this as FR-001**, an explicit "freeze-as-constraint, not conclusion"
governance act, with exact quantified parameters (`Λ=(40,1.0,0.05)`, `δ=0.3099`; M0106). **A δ-packing
repair is also shown to fail categorically under strong correlation** (M0103), later shown to fail
"as much as 222×" (M0104's own quantification). **Relationship:** `genuine_contradiction` — M0103
directly and formally refutes M0101's own proposed construction; `refinement` in that M0101's raw
executed N_eff numbers remain valid data, only the proposed quotient-based *formalization* of them
is refuted.
