# 3. SOURCE VS INTERPRETATION VS HYPOTHESIS
============================================================

Maintain a strict epistemic distinction.

Every important statement must be classified as one of:

[SR] SOURCE-DERIVED
Directly stated or clearly established in the source material.

[DR] DERIVED
Derived by combining multiple source statements without introducing
a fundamentally new assumption.

[DF] FORMAL DEFINITION
A definition explicitly established by the research.

[HP] HYPOTHESIS
A proposed interpretation or model that has not yet been established.

[CG] CONJECTURE
A stronger mathematical proposition requiring proof.

[PR] PROPOSITION
A formal statement that can potentially be demonstrated.

[TH] THEOREM
A mathematically established result with proof.

[EX] EXPERIMENTAL
Supported by an experiment or computational test.

[AN] ANALOGICAL
A metaphorical or philosophical analogy that has not been formalized.

[UN] UNDEFINED
The concept is used but has no sufficiently precise definition.

[OP] OPEN PROBLEM
An explicitly unresolved research question.

[RF] REFUTED
The hypothesis or claim has been shown to be invalid.

[CT] CONTRADICTORY
Conflicts with another established source/model.

Never silently convert:

    analogy → mathematics
