## Summary

Corrects a proposed four-orthogonal-axes model of epistemic points: 'orthogonal' is withdrawn as unproven (history/causality/context/consequence may overlap), replaced with 'four typed traversal directions' whose relationships remain an open experimental question. Reframes a 'directional vector' as a typed traversal relation tau in R_trav rather than an object with vector-space structure. Formally promotes 'junction' as the strongest new concept: J(x) = {R_1(x),...,R_m(x)}, the set of relations exposable around a given point x, with the four traversal directions read as different ways of exposing relational structure around the same object rather than four distinct objects.
