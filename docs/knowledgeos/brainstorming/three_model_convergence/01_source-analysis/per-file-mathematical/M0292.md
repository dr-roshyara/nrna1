## Summary

Elevates the temporal/recursive character of knowledge-state transitions: K_{t+1} is not just the output of reasoning on K_t, it becomes the substrate from which the NEXT reasoning cycle starts. Proposes retaining an explicit transition record TR_t=(K_t,I_t,K~_t,R_t,K_{t+1},Delta_t,Gamma_t) (ingestion event, reasoning/reinterpretation, state difference/residue, justification/provenance) rather than only the before/after states, since two systems can reach the same K_{t+1} via different histories. Downgrades five proposed 'fundamental' trajectory classes to 'candidate trajectory classes for experimental analysis.' Proposes an empirical delayed-activation hypothesis: exists k>0 such that Z_t(x)=0 and Z_{t+k}(x)=1 after a legitimate transition, and a comparative retain-vs-delete experiment design (K^retain_{t+k} vs K^delete_{t+k}) to test whether retaining currently-neutral information changes future determination.
