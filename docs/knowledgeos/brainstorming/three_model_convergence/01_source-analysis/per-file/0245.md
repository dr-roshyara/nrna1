## Tier 2
**TRIGGERED (critical).** Adds Fraser's *Hidden Markov Models and Dynamical Systems* as a fourth book.
State-space framing: hidden state x(t), observation y(t)=G(x(t)); if G non-invertible, several states can
generate the same observation — a formal analogue of "language is a projection of meaning." Strongest
direct empirical precedent yet: Fraser's own HMM, trained on raw text with **no dictionary or manual
categories**, discovers hidden states corresponding to recognizable grammatical categories via Baum-Welch/
Viterbi. Explicit warning: `latent state != knowledge` — a discovered state may encode grammar, style,
author, topic, or pure accident. Most significant conceptual shift: **reframes Dhātu as a
TRANSITION/OPERATOR** (`Z_i --D--> Z_j`) rather than a semantic-primitive noun, directly compatible with
the Pāṇinian lens. Adds a Baum-Welch local-optima stability requirement (a candidate state must survive
different random initializations — a new Shani invariant), an entropy-gap model-fidelity measure, a formal
Zero criterion (`Z*=argmin[Complexity(Z)+λ·InformationLoss(Z)]`), and an identifiability test (does
`P(Z_t|Y_1..Y_T)` concentrate as evidence grows?). Reinforces `estimation != classification`. Proposes a
five-experiment (A–E) research design spanning linguistic/semantic/operational state discovery, Zero
(state-count sweep), and Dhātu (transition, not label, discovery).
