## Tier 2
**TRIGGERED (high).** Initial assessment of Åström's *Introduction to Stochastic Control Theory* (scanned
150-page source). Central hypothesis: not "stochastic control → AI agent control" but a general epistemic
loop inserting an explicit **State Estimation** stage between evidence and decision (`Observation → Evidence
→ State Estimation → State/Belief → Prediction → Decision → Control/Action → Observation`), grounded in
Åström's own state-as-sufficient-statistic definition (minimum information to predict the *future
probability distribution*). Adds information-timeliness (delayed measurements degrade performance),
uncertainty as intrinsic to the state model (not after-the-fact metadata), a Markov/sufficient-history
principle, a convergence taxonomy for the assurance vocabulary (probability-one/in-probability/mean-square,
must not collapse), model-precondition regularity as a Zero Lens candidate, and `Stability != finite
result`. Explicit disciplined caution: this particular volume does not appear to develop Kalman filtering
or dynamic programming, so those must not be attributed to it.
