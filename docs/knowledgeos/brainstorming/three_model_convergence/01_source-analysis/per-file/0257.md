likely beforehand — directly supplying philosophical precedent for the corpus's inverse-problem
knowledge-definition thread (0244). Proposes an epistemic vector P(C)=(p1..p6) per pramāṇa pathway with a
leave-one-out robustness test and a Convergence(C) metric: knowledge is strongest when independently
convergent across multiple acquisition routes. Adds Pramāṇa as a tenth lens ("by what legitimate epistemic
route did we arrive at this claim?"), and gives a dynamic epistemic-status ladder (Unknown → Evidence →
Hypothesis → Justified Claim → Stable Knowledge → Robust Knowledge) with explicit defeater-driven
degradation. Closes with an exemplary, explicitly self-applied source-discipline triage — PRIMARY/STRONG
(pramāṇa concepts) vs. SECONDARY (author interpretation) vs. NOT-IMPORT (civilizational/religious
superiority claims, "ancient texts contain modern physics") — the file's own stated "most important
methodological lesson of all." Remains classified as correspondence-reinforcing per the registry's existing
