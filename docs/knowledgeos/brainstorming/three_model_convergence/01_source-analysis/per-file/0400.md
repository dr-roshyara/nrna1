## Tier 2
**TRIGGERED — landmark, highly concrete architectural extension** of 0399's dimension-extraction
experiment. Refines "do not make the token the dimension" into a full **semantic parser** architecture
(Sentence → Lexical tokens → Syntactic structure → Semantic structure → Knowledge dimensions → Dimension
values → Relationships → Evidence/provenance/time/uncertainty), citing a research tradition consonant with
the corpus's Pāṇinian lens (0370). Refines Sentence→dimension into an explicit **one-to-many**
`Sentence→{d1,...,dn}`. Distinguishes "what does the sentence say" from "what state information does it
contribute": "Nexus is outdated" is a **derived** value (`Version=2.69`, `Required=3.85`, `2.69<3.85` ⟹
`Outdated`), formalizing **three kinds of sentence information** (observed value / relationship / derived
determination), operationalizing "reason has logic" (0372/0396) into a concrete pipeline stage.

Introduces the **Semantic Token** `T=(Entity,Dimension,Value,Relation,Context,Time,Source,EpistemicStatus)`
and a **bidirectional meaning↔expression** architecture (Sentence→Semantic Tokens→State Fragment, and the
reverse). Confronts sentence **ambiguity** ("Nexus is secure" underdetermines which sub-dimension is meant)
— the parser must represent `Resolution:insufficient`/`Status:ambiguous` rather than inventing dimensions,
reconfirming 0389-0393. Precisely scopes probability to **extraction-hypothesis** uncertainty
(`P(D_i|Sentence)`), explicitly distinct from `Knowledge(D_i=V)` — "I would not call those probabilities
'knowledge.'" Draws a profound constraint: **semantic parsing itself cannot establish completeness**, since
`D_observed` can only grow but `D_observed=D*` can never be proven.

**Explicitly rejects** the standard `Document→Chunk→Embedding→Vector→Knowledge` RAG-style extraction
pipeline, replacing it with a **thirteen-stage** alternative integrating 0397's Epistemic Qualification
layer for the first time. Introduces the **Dimension Resolver** component (surface-expression → candidate
dimension → context → canonical dimension, e.g. disambiguating which "version") — "context becomes part of
semantic identity." **Directly resolves the corpus's long-tracked "smallest unit of Knowledge" question**
(0361): the sentence is *not* the smallest unit — it's an expression container. The new candidate: **a
semantically resolved assertion about a dimension of a state, together with the minimum context required to
preserve what that assertion means** — "a much stronger candidate" than prior formulations. Closes with a
worked reasoning-chain example (three sentences reducing to one derivation) and a final reformulation of
KnowledgeOS's central question around asserted dimensions/values/relations/observed-vs-derived/reasoning.
