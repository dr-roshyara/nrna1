## Tier 2
**TRIGGERED (critical).** Major, rigorously-cited synthesis (Stanford Encyclopedia of Philosophy: Gettier,
reliabilism, coherentism, understanding-as-distinct-good; Pollock & Cruz's defeater theory; a Sri Vidya
tantric source) rejecting "knowledge = true information" as far too weak. Establishes eleven things
knowledge is NOT (data/information/belief/truth-alone/justified-belief-alone/confidence/memorization/
language/coherence-alone/authority/prediction-alone/understanding). Central formalization: the **Knowledge
Vector** `K=(T,J,R,A,S,C,U)` — Truth/Justification/Reliability/Anti-luck/defeater-Stability/Competence/
Uncertainty — knowledge is a **vector, not a scalar**. Quantifies each dimension (reliabilist `R(f)=P(true
output|f)`; counterfactual robustness `CR(p)`; Pollock's rebutting vs. undercutting defeaters; competence
tested by held-out application, not recitation; explicit warning that entropy/mutual-information is NOT
automatically epistemic uncertainty). Introduces **Knowledge Invariance** (do independent representations —
sensors, languages, agents — converge on the same underlying state?, grounded in Sri Vidya's "one reality ≠
one representation"), five distinct knowledge-amount metrics (Coverage/Reliability/Depth/Robustness/
Transfer) reported as a **Knowledge Profile** rather than one percentage, and knowledge as **time-indexed**
(decay). Reframes knowledge acquisition as a transformation chain (reinforcing 0245's Dhātu-as-operator).
**Bridge note:** the Sri Vidya-derived Data→Information→Knowledge→Understanding→Wisdom hierarchy further
reinforces the corpus's Knowledge-is-not-yet-Wisdom convergence cluster (0110-0117, 0209).
