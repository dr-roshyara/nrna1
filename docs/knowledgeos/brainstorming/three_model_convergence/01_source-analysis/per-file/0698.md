## Tier 2
**TRIGGERED — delivers the reconstruction's richest semantic-core falsification exercise, naming its
implicit Popperian methodology explicitly for the first time**: a ten-question checklist systematically
applied to ten candidate concepts (Evidence, Observation, Claim, Decision, Authority, Action, Verification,
Finding, Rule, Architecture).

**Delivers `Artifact≠Evidence` as a semantic transformation** (a Git commit becomes evidence only when a
verification process establishes its evidentiary role, PASS×2), with a genuinely valuable three-model
architectural-identity taxonomy: `EvidenceAuthority`/`EvidenceAggregator`/`EvidenceProcessingPlatform` — "the
implementation must tell us which one is real," extending 0697's who-owns-the-meaning discipline.

Delivers Observation≠Claim (extends 0688) and Decision≠Recommendation reconfirmed (extends the corpus's
central family). **Delivers `Authority=(Actor,Role,Scope,Rule,Validity)` with the precise caution that
administrative identity ≠ semantic authority** (`admin`≠`ArchitectureAuthority`, PASS), extending 0687's
authority-naming caution. Delivers Action=(Actor,Intent,Target,Change,Time,Authorization) with `PARTIAL`
attribution when agent identity is missing (extends 0690). Delivers Verification≠Evidence≠mere-Test.
**Delivers `TestFailure≠Finding without interpretation`** (infrastructure failure/flakiness/developer
error/actual violation all possible, PASS), extending 0682's/0684's finding discipline. Delivers the
circularity caution: KnowledgeOS may manage architectural knowledge without architecture being the semantic
root of all knowledge.

Delivers cross-cutting Provenance with **identical content from different sources ≠ semantically
equivalent** (Architecture Board vs LLM, PASS), reinforcing 0697's True≠Authoritative. Delivers cross-
cutting TemporalValidity: a superseded rule should not be treated as current — "this is why semantic
retrieval needs more than vector similarity" (PASS), extending 0673's/0680's embeddings-never-authoritative
discipline.

**Delivers a formally stated Semantic-core-minimality principle, a genuinely novel Occam's-razor
formalization**: `Core_minimal=argmin(Model)` subject to `Model⊢ObservedBehavior` — "a powerful anti-
overengineering principle" (if Artifact+Observation+Decision+Evidence already explain behavior, adding a
separate `Claim` entity "provides no explanatory value," PASS). **Delivers systematic, rigorous multi-
experiment validation of 0697's semantic-core-test heuristic**: removing vector search leaves the core
intact (PASS); removing provenance/authority/temporal-validity each independently causes semantic
degradation or collapse (PASS×3) — the first place in this reconstruction where a prior heuristic is tested
across multiple concepts rather than asserted once.

Delivers six candidate invariants under a **new `S`-prefixed notation** (S1-S6, e.g.
`EveryAuthoritativeDecision→Authority`, `Projection→AuthoritativeSource`) — each restating an already-
tracked `I_{Name}` invariant rather than introducing new substance; flagged as a notation-scheme variance,
not a name collision. **Delivers the graph-not-pipeline refinement**: `RawData→Observation→Evidence→Claim→
Decision` is explicitly NOT linear — a Decision can become Evidence for a later decision, an Observation can
trigger a Finding directly — "the correct model is a graph, not a pipeline," refining the corpus's
epistemic-firewall family. Delivers the most complete consolidated semantic graph in this reconstruction,
explicitly "a target semantic model, not yet a claim about the actual code."

Delivers the decisive per-edge test (SemanticGap when no relationship exists at all; DocumentedRelationship,
not MachineReadableSemanticRelationship, when it exists only in prose, PASS×2), extending 0693's/0694's
naming/documentation-proves-nothing family.

**Delivers the reconstruction's most precise formulation of its central tension yet — `CurrentAuthoritative
Knowledge` vs. `TopKSimilarDocuments`**: "find authoritative decisions concerning X, their supporting
evidence, current validity, and unresolved findings" rather than "find documents mentioning X" — "the
latter is useful retrieval infrastructure. The former is a knowledge operating model."

Verdict continues the calibrated pattern with unusually precise phrasing: "`TargetSemanticCore=Defined`,
`ActualSemanticCore=To Be Reconstructed`."

time: **"Every non-unknown cell must have evidence"** — framing the outcome as "a true semantic knowledge
