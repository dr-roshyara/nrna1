failed-evaluation). **Correction 6**: rejects the linear lifecycle for a branching
supported/open/contested model — "**epistemic evolution is not necessarily linear**." **Correction 7**:
History should be a **causal/provenance graph** (Temporal+Provenance+Causal Evolution), not a version list.

knowledge was wrong."** Closes confirming **Question 6 — What is a Knowledge State?** as next.
