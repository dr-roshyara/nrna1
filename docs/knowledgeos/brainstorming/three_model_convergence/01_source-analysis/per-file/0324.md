## Tier 2
**TRIGGERED — the corpus's most mathematically dense synthesis to date.** Directly builds on Williamson
(0320), Brandom (0321) and Gelfond & Kahl (0322). Headline: stop searching for a universal knowledge
scalar; define a knowledge **element** mathematically and quantify its properties under an explicitly
declared regime. Formally separates knowledge **element** `e=(p,a,c,τ,r,E,D,σ)`, knowledge **state**
`K_t^{a,R,C}`, a multidimensional **measurement vector** `K(e)=(L,P,U,T,I,X,S,M,C,G)`, and the
**Kernel**. Defines **fifteen candidate measurement dimensions** with explicit formulas — logical support
`L(p)` (ASP-grounded true/false/unresolved), degree-of-model-support, probabilistic support `P_R(p|KB)`
(explicitly distinguished from logical support), a five-category unknownness classification, evidence/
provenance coverage, inferential strength (graph centrality, explicitly not epistemic importance),
conflict, revision stability, an **epistemic margin** formula `Margin(p)=|{K'∈N(K):p supported}|/|N(K)|`
(the corpus's first explicit formula connecting the topological lens to Williamson's Knowledge Margin,
0320), explanatory value via information gain, scope coverage (explicitly *not* computable against the
infinite Knowledge Space, only a declared finite scope), knowledge-space depth, a "Knowledge Flux" rate,
cross-participant agreement (Jensen-Shannon divergence), and three proxies for orientation toward the
infinite Knowledge Space (external adequacy, predictive adequacy, refinement stability). Distinguishes
Representation/Epistemic/Task measurement families, prefers **Pareto-frontier analysis** over a single
weighted scalar, and states the core rule **"store the substrate; compute the measure."** Produces a
formal `KS=(V,E,τ,Γ,Π)` KnowledgeOS model with a typed-entity vocabulary (Entity/Event/Observation/
Proposition/Assertion/Commitment/Rule/Assumption/Evidence/Question/Explanation/InstitutionalStatus/
KnowledgeAttribution) and a sixteen-item relation vocabulary, a refined element tuple
`e_K=(p,α,β,τ,E,D,C,R,σ)` with `σ` explicitly a **tuple, not a scalar**, a transition formula
`K_t+1=Transition_R(K_t,I_t+1)`, a `Snapshot_t=(History≤t, Boundary, Participant, Context, Regime,
Projection)` formula, and five research-method families (formal logic / probability-Bayesian /
information theory / graph-topology / statistical-causal — all explicitly outside the Kernel). A
distance-between-knowledge-states framework (Jaccard, Jensen-Shannon) enables a proposed **Knowledge
Flux** theory and a measurable **Knowledge Depth**. Narrows 0322's twelve-item Kernel to **eleven**.
Explicitly warns against re-collapsing the vector back into a single `KnowledgeScore` — "that would undo
the progress made by Williamson." Closes with four boxed working definitions (knowledge element / state /
Knowledge Space / Kernel) and a proposed next research program: Knowledge Measurement Vector + Knowledge
State Distance + Projection Refinement test. A strong candidate consolidation point for the corpus's
long-tracked Knowledge-Vector-family (16+ prior variants), though not itself declared canonical.
