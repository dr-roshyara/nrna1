epistemic layer — hidden states with non-geometric durations, producing observable evidence, transitioning
on evidence/events (`Z_t^epistemic -> O_t^evidence`). Formalizes `HESMM=(S,A,D,B,Pi)` and the three core
temporal operations: filtering, smoothing (named a formal **Historical Reconstruction Engine** for
architecture/audit), and Viterbi best-state-sequence reconstruction. Introduces a **three-layer state
architecture** — Authoritative / Observational / Inferred — that must never collapse (an inferred signal
triggers review, never automatically overrides authoritative state). Adds identifiability warnings,
epistemic entropy/volatility/**momentum** (trajectory direction, not just a static score), and the explicit
invariant `MissingEvidence != ContradictoryEvidence`. Covers context-dependent, switching (regime-change),
adaptive, and multichannel HSMM variants, and a governed `LatentStateDiscovery -> Proposal -> DomainReview
-> CanonicalState` pattern combining unsupervised ML with DDD governance. Explicit anti-overfitting
warning: HSMM is one model family inside KnowledgeOS, not KnowledgeOS itself. Closes with the final
invariant: **Observed != Inferred != Authoritative != True**.
