formulation we have reached so far." Reframes "knowledge returning to the space" as new representations
becoming objects of *future* inquiry, not a literal universal-database mutation, and demonstrates knowledge
recursively about knowledge (a four-level worked example) as one reason the space is effectively unbounded.
