**TRIGGERED — LANDMARK: substantially deepens 0531's Epistemic Admission Boundary closure with new formal
machinery.** Reaffirms `A=(P,E,Σ,Π,τ,C,ID)`, `A≢Truth(P)`, and demonstrates that the SAME proposition can
be held by two epistemically non-equivalent assertions — `Assertion⇏StrongEvidence`,
`Assertion⇏Certainty`, `Assertion⇏Truth`.

**Delivers a four-outcome admission function** (not merely admit/reject):
`Admit(P_c,E,C,Π_adm)→{Assertion,Reject,Defer,RequestMoreEvidence}`. **Delivers purpose-dependent
admission**: `Admit(P,Π_1)≠Admit(P,Π_2)` — exploration policies tolerate weak support, migration policies
require strong support — explicitly connected to Ideal State theory: a shortfall between an admitted
assertion's epistemic state and the Ideal State's requirement is a **Discrepancy**, not an invalid
assertion.

**Delivers `Admission≠Validation`**: admission decides whether a proposition may exist as governed
knowledge at all; validation checks whether an admitted assertion meets a specific downstream requirement
— an assertion can be admitted yet fail validation without being deleted, "remains useful historical
knowledge." **Delivers `Evidence≠Support`** (`Support=f(E,Π,C,ℛ)`, not `|E|`) and generalizes 0528/0530's
independent-evidence finding into a concrete **evidence dependency graph** mechanism (e.g.
`Document→LLM` means the LLM's output is not independent evidence).

**Delivers `Conflict⇏Reject`**: conflicting assertions may both be admitted, coexisting alongside an
explicit Conflict record — "preserves reality rather than destroying evidence." Delivers history-preserving
resolution: a superseded assertion is marked `Status:Superseded`, never deleted, connecting to
`H_{t+1}=H_t‖e_t`. Formalizes a genuine epistemic state-transition system
(`P_c --AdmissionPolicy--> A`, `A_t --Evidence--> A_{t+1}`, `A_t,A'_t --ConflictRule--> C_t`,
`C_t --Resolution--> C_{t+1}`).
