classification, and worked YAML dependency declarations. **Delivers "prefer allowlists,"** a genuinely
valuable security-engineering principle applied to architecture governance for the first time: allowlists
are safer than forbidden-lists because unknown dependencies fail by default (`Unknown→FAIL`) rather than
silently succeeding — the classical default-deny principle.

classification. Delivers Port/Adapter/Contract/Event/Persistence Registries and a Projection declaration
with an explicit `rebuildable` attribute, operationalizing 0727's/0734's/0737's/0740's graph-rebuildability
discipline into a concrete field. Delivers a Checker Registry with an explicit `deterministic:true|false`
declaration — a checker marked `false` "cannot silently serve as an authoritative deterministic verifier."

**Delivers the Architecture Graph vs. Knowledge Graph distinction**, a genuinely important new bifurcation:
the Architecture Graph (derived from the Registry) describes how KnowledgeOS itself is structured; the
Knowledge/Assurance Graph (0716) describes the engineering world it governs — "they can eventually coexist.
They should not be conflated."

Delivers Registry validation (five integrity checks), Implementation discovery
(`ObservedArchitecture`), and the central `Compare(Declared,Observed)` conformance operation, worked through
a concrete "six months later" drift-detection maintenance scenario and a full Architecture Finding schema.
**Delivers Remediation discipline preserving the anti-hallucination boundary precisely at the remediation-

generated deterministically" — `Deterministic checker→Architecture Finding→AI→Remediation proposal`, never
