not merely incomplete because we lack values. It is incomplete because we may not yet know which dimensions
of the state matter" — sharpening the research question toward how an epistemic system discovers, maintains,
and revises its dimension model over time, with probability's role explicitly deferred until dimension/
value/relationship uncertainty are each precisely determined.
