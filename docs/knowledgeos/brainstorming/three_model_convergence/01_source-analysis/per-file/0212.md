## Tier 2
**TRIGGERED (critical).** Tom Chivers' *Everything Is Predictable*, seven lenses (Zero/DDD/Chinese/
Evidence-epistemology/Causal/Wisdom/AI-Engineering). Central thesis: KnowledgeOS needs explicit
uncertainty/prior/belief-revision/prediction/surprise/model-change machinery — **not** because it should
"be Bayesian," but because it must be a **belief-revision system, not a document-accumulation system**.
Introduces `BeliefState` (traceable to information+assumptions), a Prediction/Outcome/Assessment triad,
`ReferenceClass`/outside-view base-rate reasoning, `PriorAssessment` as non-arbitrary first-class object,
**hyperpriors**/two-level uncertainty (parameter vs. model), `ModelValidity` states (active/degrading/
contradicted/superseded), `HypothesisSet` (evidence updates a hypothesis space, not one favored
explanation), Evidence Discriminative Power ≠ Credibility, `ForecastCalibration`/epistemic observability
(`PredictionLedger`), an extended provenance model driven by the replication crisis (Analysis/Selection/
Publication provenance, `AnalyticalLineage`, `EvidenceEpisode`), epistemic temporal versioning, Value of
Information, and a five-state epistemic status model (UNKNOWN/UNCERTAIN/SUPPORTED/CONTRADICTED/
ESTABLISHED — "established" ≠ metaphysical certainty). Reconfirms the Epistemic/Decision-model separation
with a worked EUR10-vs-EUR10M utility example. Produces a candidate `EpistemicCore` and a disciplined
14-step agent behavior chain. Closes with an explicit anti-pattern warning: **not** "everything should be
Bayesian" — Bayesian updating complements deduction/causal-inference/statistical-estimation/governance/
human-judgment, it does not replace them.
