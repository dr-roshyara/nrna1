## Tier 2
**TRIGGERED.** The most substantial pure DDD/engineering-architecture contribution across the entire
0247-0267 stretch. An initial PlantUML "Knowledge Space" model (Semantic/Representation/Epistemic/
Question/Evaluation layers, a `TruthValue{TRUE,FALSE,UNKNOWN,BOTH,NEITHER}` enum, and a proposed evaluation
vector `E=(S,T,C,R,A,K,U)`) is followed by a rigorous DDD critique that **rejects the single-aggregate
framing** in favor of a six-bounded-context federation (Semantic Modeling / Representation-Interpretation /
Assertion-Evidence / Inquiry / Assessment / Projection). Reframes `KnowledgeState` as a projection
(`KS=Project(A,E,C,τ,P)`), disambiguates `Fact` into four distinct meanings, formalizes Evidence as a
directional typed relation toward an Assertion (not a bare property of Proposition), grounds Observation
as a `W3C PROV`-style event, and redesigns the enum/vector into separately-typed `AssessmentResult`
categories (`TruthStatus` split from `KnowledgeStatus` split from `ConflictStatus`) — explicitly flagging
the original `TruthValue` enum as "potentially dangerous" for conflating model-theoretic truth, knowledge
availability, and paraconsistent logic into one scale. An explicit "facts versus hypotheses" section
**rejects the file's own proposed "universal numerical knowledge assessment vector" by name** as an
unproven hypothesis — a concrete, corpus-internal instance of 0266's freshly-established discipline. Closes
with a full **Published Language / context-map design**: worked JSON message contracts that publish facts
about domain *activity* and never universal interpretations (`AssertionPublished` ≠ "the proposition is
true"), an Anti-Corruption-Layer worked example, a five-dimension versioning strategy, a governed
`PublishedTerm` artifact schema, and the decisive principle: **shared communication language ≠ shared
domain model**.
