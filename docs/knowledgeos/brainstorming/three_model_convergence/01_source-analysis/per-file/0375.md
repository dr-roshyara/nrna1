## Tier 2
**TRIGGERED — landmark critique of an external "uploaded synthesis."** Confirms the synthesis correctly
identified the "conditional evidence problem" and surveyed Bayesian/Dempster-Shafer/fuzzy/non-monotonic/
argumentation/epistemic/temporal/measurement approaches, correctly keeping KST as one regime. Corrects its
conclusion by pushing one level deeper: the synthesis skips the **missing middle** (conditional
determination) the corpus established across 0371-0374. Connects Evidence's conditionality to KST's
`r(R,K)=P(R|K)` — already probabilistic, yet "doesn't tell us what evidence *is* at the Kernel level."

**Rejects "raw evidence" as dangerous terminology**: an observation (e.g. "server returned HTTP 200") is
not intrinsically evidence ("server is healthy") until interpreted relative to a hypothesis. Proposes
**Evidence as a relation**, `Supports(O,p,C,t)`, not an object — "a very important DDD consequence,"
deepening 0370's relational lens. Challenges the synthesis's proposed invariant ("possible worlds/states
consistent with the evidence") as an untested **hypothesis**, since five regimes disagree about what
"consistent" means.

Proposes a deeper candidate invariant: **Epistemic Provenance** — the determination lineage `p←R←E←O`
(with `C,t,M` attached) — explicitly distinguished from mere uncertainty: when new evidence challenges `p`,
the system must reconstruct *why* it was ever accepted; "more fundamental to the Kernel than any particular
probability distribution." Splits the research question into two **non-identical dimensions**: Question A
(Mathematical: invariant structure across evidence-combination regimes) vs. Question B (Kernel: substrate
enabling regime-independent reconstruction) — protecting against conflating mathematics with ontology.
Produces a nine-stage research-object pipeline diagram.

Proposes a **concrete six-regime comparison experiment** — more operationalized than 0358's seven-regime
Intersection Method: one real proposition, a nine-item preserved substrate, six regimes (Classical logic,
Bayesian, Dempster-Shafer, Non-monotonic, Argumentation, Fuzzy), and an explicit **eight-question**
comparison protocol (same proposition? same observations? same provenance? same conflicts? same possible
states? same dependencies? can *why* be reconstructed? is it revisable?) — claimed to "tell us far more
about the Kernel than another month of abstract architecture discussion." Closes with the sharpest Kernel
question to date: **"What is the minimum substrate required to reconstruct a conditional determination?"**
