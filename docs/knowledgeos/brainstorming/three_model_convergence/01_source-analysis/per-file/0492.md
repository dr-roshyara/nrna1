Reliability,Time,Provenance); EvidenceRelation(A,E)∈{support,weaken,contradict,qualify,contextualize};

Discrepancy≠MetricDistance into a four-way **Severity≠Priority≠Distance≠Risk** separation.

DerivedAssertion→Conflict→Resolution→Decision, enabling "why is this in the decision?" **Introduces a
Question/Intent State**: Q=(Intent,Entities,Constraints,Context,Purpose,Completeness,Ambiguity). **Introduces

investigation system." Expands the "complete state" catalog with seven new first-class states (QuestionState,
ObservationState, EvidenceState, InvestigationState, DecisionCriteria, EpistemicLineage, Policy).
