## Tier 2
**TRIGGERED (high).** Adds Paul & Elder's critical-thinking framework as a qualitative epistemic
state-extraction method extending 0247/0249. Eight **Elements of Thought** (Purpose/Question/Information/
Interpretation-Inference/Concepts/Assumptions/Point-of-view/Implications) crossed with nine **Universal
Intellectual Standards** (Clarity/Accuracy/Precision/Relevance/Depth/Breadth/Logic/Significance/Fairness)
into an evaluation matrix. Formalizes `KnowledgeState(t)` as a set/vector, with state transition
`K_{t+1}=Update(K_t,E_new)` — old claims re-evaluated (historically-valid but current-invalid), never
deleted. Central discipline: critical thinking as an **adversarial knowledge filter** — actively search for
opposing, not merely supporting, evidence. Combines lenses into a three-stage pipeline (Text→
SemanticStructure→EpistemicStructure→InvariantStructure). Introduces a multi-component `State(K,t)` vector
with delta-state tracking enabling qualitative statements ("more complete but less certain") instead of a
bare score change, and a three-way **QuestionType** distinction (Definitive/Subjective/MultiPerspective)
affecting how a claim should be epistemically evaluated.
