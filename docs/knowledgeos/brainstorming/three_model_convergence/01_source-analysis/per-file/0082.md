**Part 1 — seven candidates ranked.**
- **State machines** (strongest, ⭐⭐⭐⭐⭐): `S_{t+1}=T(S_t,E_t)`; `KnowledgeState=(State,
  EvidenceHistory,Authority)` — explicitly said to already match observed EKS/PKS/AIP behavior.
- **Lattice theory** (⭐⭐⭐⭐⭐): knowledge is multi-dimensional and only partially ordered
  (high-evidence-but-obsolete vs low-confidence-but-approved cannot collapse to one scalar).
- **Category theory** (⭐⭐⭐): Observation→Evidence→Assessment→Decision as morphisms that must
  preserve identity/provenance/authority — "kept as a research lens, not implementation."
- **Temporal logic** (⭐⭐⭐⭐): `Knowledge=(Content,ValidTime,TransactionTime)` — implementation need
  not require a bitemporal database.
- **Graph theory** (⭐⭐⭐⭐): useful for dependency/impact/provenance paths, but explicitly reaffirms
  "Knowledge System ≠ Knowledge Graph" (citing the earlier research — 0080/0081).
- **Information theory** (⭐⭐⭐): entropy `H(X)` as an uncertainty measure, explicitly *not* a
  truth-probability calculator — "AI confidence score = truth" is explicitly warned against, since the
  architecture separates confidence from authority (direct link to 0081's Claim/Confidence-absent
  finding).
- **Complex numbers** (⭐⭐, demoted): 0079's `K=S+iA` reinterpreted away from "knowledge = complex
  number" toward "knowledge has orthogonal dimensions," generalized to **`K=(S,A,E,T)`**
  [Semantic, Authority, Evidence, Temporal state].

**Deeper insight (closes part 1).** The kernel is probably not a mathematical engine but a "formal
semantic operating system," with primitives Identity/Evidence/Authority/State/Transition/Provenance/
Time/Invariant; mathematics helps prove properties of them, not replace them. Recommends posing a
research question ("which mathematical structures naturally preserve the discovered invariants?")
rather than choosing a model yet.

**Part 2 — topology, added as an equal third-strongest candidate.** Same discipline restated: ask
whether an invariant's *natural* structure is topological, not how to force topology onto the kernel.
- **Knowledge state as topological space**: nearness/continuity as a normative constraint — a small
  evidence update should not cause an unexplained large semantic jump.
- **Bounded contexts as topological spaces**: DDD boundary ≈ topological boundary (open/closed
  sets, neighborhoods; anti-corruption layer ≈ boundary map) — explicitly "not identical, but useful."
- **Knowledge evolution as continuous deformation** — claimed the *strongest* topology connection;
  kernel candidate: "state evolution must preserve lineage" / "preserve continuity of knowledge
  identity," tied directly to EKS's transition-history + state-reconstruction (0081's C-2).
- **Topological invariants**: candidate list — Identity, Authority, Evidence origin, Ownership,
  Decision history, Temporal validity — directly overlapping 0081's C-1..C-10 and 0080's nine
  dimensions.
- **Persistent homology / TDA**: explicitly demoted to a higher layer (domain/bounded-context
  discovery), "not kernel."
- **Sheaf theory** ("probably the most intellectually aligned"): local-to-global consistency of
  knowledge — two teams' differing local meanings of the same term — framed as "almost exactly a
  KnowledgeOS problem"; kernel need: "preserve local meaning while enabling controlled composition,"
  explicitly DDD-compatible.
- **Topological reading of 0081's semantic non-collapse principle**: Observation/Evidence/Assessment/
  Authority read as distinct dimensions of a multidimensional space, not points on one scalar line —
  a direct, same-region cross-reference to 0081's Ledger Entry 22 finding.
- **A second, differently-shaped formal proposal**: **`K=(X,T,I)`** where X=knowledge states,
  T=allowed transformations, I=preserved invariants. **Symbol collision, internal to this single
  document**: `T` meant "temporal state" in part 1's `K=(S,A,E,T)`, and means "transformations" here —
  the corpus's most concentrated single-document instance of the standing K/T term-collision risk
  (MD-006). No identity between the two `K` tuples may be assumed.
- **Explicit boundary**: "KnowledgeOS Kernel ≠ Topology Engine" — topology is a reasoning framework
  like category/graph/lattice theory, not the kernel itself.
- **Final ranking**: state transition / lattice / topology-invariants = 5 stars; temporal logic /
  sheaf theory / graph theory = 4; category theory = 3; complex numbers = 2.
- **Closing research question**: which mathematical invariants best describe trustworthy knowledge
  evolution (state-machine, lattice, topological-continuity, or categorical-composition) — explicitly
  deferred until after the EKS/PKS/AIP evidence phase, matching 0081's own explicit restraint.
