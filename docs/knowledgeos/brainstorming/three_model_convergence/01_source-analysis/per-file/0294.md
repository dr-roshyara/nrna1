## Tier 2
**TRIGGERED.** A tight closing synthesis for this reading stretch — the last genuinely new file in this
`kernel/` directory segment before a manifest boundary marker at 0295. Rejects "knowledge = capacity to
write information" as too narrow, separating **Information / Knowledge Capacity / Knowledge Projection**
(`Ω→Information→Knowledge Capacity→Knowledge Projection`, with capacity sitting between the infinite space
and any particular projection). Formalizes a Knowledge Capacity tuple `K=(B,L,R,C,P)` and a **three-type
capacity typology** — Information capacity (storage/bandwidth), Epistemic capacity (reasoning/inference/
uncertainty-handling), Expressive capacity (language/symbols/documents) — with worked contrasting profiles
(a person can have high epistemic but low expressive capacity; an LLM high expressive but uncertain
epistemic capacity; a database high preservation but almost no intrinsic epistemic capacity). Explicitly
unifies Floridi/Gärdenfors/Dretske/Searle into this single concept, refines the KnowledgeOS mission
statement toward preserving "the conditions and history of knowledge projection" rather than knowledge
itself, and closes with an open question: is capacity itself a Kernel primitive, or fully derived from
participant/boundary/representation/regime/resources?
