**Delivers the central architectural insight — the real input to inference is an Evidence Graph, not a
flat set**: three distinct dependency cases (duplicate/dependent/independent) each with distinct

Support/Challenge/Conflict state simultaneously — **`EpistemicAssessment+StatisticalInference`** must
coexist, "much richer than storing" a bare confidence number.

Delivers `Reliability belongs in the model, not as an arbitrary score` and **`EvidenceCount≠
EvidenceStrength`**. **Delivers the file's most concrete common-cause-dependence worked example** (three

EvidenceHistory is cumulative`** — explicitly stated to "perfectly match the result from 25A.3."

projection of KnowledgeState, not the KnowledgeState itself`** — inference results can never be first-class

Delivers a formal four-mode reasoning taxonomy (Deductive/normative, Statistical, Causal, Semantic/fuzzy)

**Delivers the file's central formal deliverable — ten named formal properties (A1-A10)**: Duplicate
idempotency; Independent evidence can accumulate under suitable conditions; Dependent evidence must not
be double-counted; Contradiction must remain visible; Inference depends on a model/assumptions/knowledge

Delivers a refined three-tier evidence algebra `ℰ_H→Assessment_H=A(ℰ_H,C)→Inference_H=M(Assessment_H,

does not care which inference mathematics is used."

Delivers **`EvidenceAggregation≠WorldEventComposition`** (aggregation is legitimately commutative;
sequential real-world events generally are not). Delivers a worked conflicting-priors scenario yielding
**`ModelPlurality`**: preserve multiple valid inference results from different models side by side, "rather
than pretending one is universally 'the truth.'" Delivers a new concept — **`ModelSelection`** — "when
