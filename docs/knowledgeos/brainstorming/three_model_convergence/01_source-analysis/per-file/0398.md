or what makes a determination *socially legitimate*, worked via a six-stage Nexus pipeline.

Extends dimensions to the explicitly non-physical: an owner's decision itself is a dimension. Introduces a
new **three-type dimension taxonomy**: State dimensions (object properties), Epistemic dimensions
(properties of our knowledge of the state), Social/Governance dimensions (institutional acceptance) —
`D*=D^state∪D^epistemic∪D^social`, a research hypothesis. Introduces the **reification** warning: treating
human products (organizational determinations) as things — worked cautionary example of a bare status flag

and-reasoning discipline (0395/0396) as a defense against a documented sociological failure mode. Revises
the KnowledgeOS working hypothesis: not "stores knowledge" but "preserves the evolving evidence,
determinations, relationships, institutional meanings and decisions from which organizational knowledge is
continuously reconstructed." Produces an eleven-stage unified pipeline integrating all three layers as a
feedback system — the corpus's most complete single-diagram integration to date.

Closes by reformulating the central research question: **what exactly is the object that KnowledgeOS is
supposed to preserve?** — five explicit candidates (the state itself / observations / determinations /
socially-accepted-knowledge / all-of-the-above-with-explicit-separation), current hypothesis (E) explicitly
offered for challenge: "this is exactly where we should not allow the KnowledgeOS architecture we already
have in our heads to dictate the answer."
