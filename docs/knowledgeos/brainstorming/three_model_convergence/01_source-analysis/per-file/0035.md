Three review challenges are resolved first, one by the document's own admission rule rather than by

§2 builds an archetype relationship matrix (own/reference/realize/constrain/generate) and produces the
section's central finding: **DOMAIN is a confirmed archetype with almost no outgoing edges** — it
owns nothing, generates nothing, constrains nothing. The document reads this not as a gap but as
**orthodox Evans, rediscovered empirically**: a domain in DDD never owns artifacts either — it
delimits where a language holds, while ownership work is done elsewhere (here, by `DP-n`). *"DOMAIN
is the archetype of classification, not of ownership."*

claim: **exactly one archetype has execution as its essence — CAPABILITY** (I-11, from 0027: "Knowledge

archetype property — explicitly cited as RQ-002's smoking gun passing its third test.

§4 is the file's structural core. A reviewer's proposed single-stack hierarchy (`Purpose → Knowledge →
Domain → Capability → Process → Runtime → Artifact`) is tested **edge by edge against evidence**: one
edge supported, one already refuted (Domain→Capability, refuted at 0027), four entirely unevidenced.
**Verdict: the single stack does not exist.** In its place, **four distinct partial orders**, each
with its own evidenced chain: **Authority** (Purpose→Strategy→Principle→DP-n→Capability, the same
chain discovered at 0027), **Production** (Process→Knowledge/Artifacts/Evidence; Capability→Evidence;

per R-7, with the undeclared CAP↔AST link flagged), and **Containment** (Container⊃Artifacts, nesting
open). Collapsing the four into one stack is diagnosed as **the fourth instance of the corpus's
level-mixing error** — and pointedly, this time the draft came from the reviewer, not from the
document's own author, extending the self-correction discipline to catching *others'* instances of a
named recurring error, not only one's own.

§5 states and applies an unusually rigorous DDD-purpose test: every admitted relation must name **the
engineering decision it enables**, evidenced by an **"operational scar"** — a real incident that
proves the decision was consequential. The sharpest instance: the `contains` relation enables *"what
moves together when a boundary moves — the extraction question,"* and its scar is precise: *"the MVK
FAIL was a containment failure in disguise: the 15-file set was drawn before 'what does the platform
CONTAIN?' was ever modeled."* This retroactively re-diagnoses 0008/0011's MVK failure as, specifically,
an unmodeled `contains` edge — a sharper causal account than either 0008 or 0011 itself supplied.

## TIER 2 — DEEP ANALYSIS
**Trigger status: TRIGGERED** — supplies the first content for a previously flagged undefined
construct ("four partial orders"), performs a genuine edge-by-edge hierarchy refutation, and states
the corpus's most rigorous relation-admission discipline to date. Three independent triggers.

### Mathematical derivation
None with proof. But this is the moment to assess the "four partial orders" claim precisely, because
it is finally testable:
```
For each order O ∈ {Authority, Production, Realization, Containment}:
  - a CARRIER SET is implied (archetypes, or instances of archetypes?) but never stated explicitly
  - a RELATION is given as a CHAIN (e.g. Purpose → Strategy → Principle → DP-n → Capability for
    Authority) — a chain establishes a TOTAL order on the elements actually listed, not a partial
    order on a general carrier set
  - NONE of reflexivity, antisymmetry, or transitivity is checked for any of the four
  - it is UNSTATED whether the four orders are meant to compose, whether an archetype can appear in
    more than one order (several clearly do — CAPABILITY appears in Authority AND Production AND
    Realization), and if so what relation (if any) holds between an archetype's position in one order
    and its position in another
```
**Precise verdict:** the document supplies **four evidenced directed chains**, not four verified
partial orders. Calling them "partial orders" is a plausible informal label — a chain is trivially a
partial (indeed total) order on its own elements — but the label implies more structure (a full
carrier set, a general relation, checked axioms) than has been established. **This is not a
contradiction with 0003's `[AN]` flag; it is the flag's resolution downgraded from "content-free
vocabulary" to "content present, formal status still short of an actual order."** Recorded precisely
because §29 (convergence core) will eventually ask whether a genuine mathematical structure exists
here, and the honest answer at seq 35 is: **evidenced chains, not yet verified partial orders.**

### Formal definitions
The decision-plus-scar admission rule (§5) is a genuine, checkable methodological definition:
`admit(relation) ⟺ ∃ decision : enables(relation, decision) ∧ ∃ incident : evidences(incident, decision)`.
This is the sharpest relation-admission criterion in the corpus, stronger than the plain
orthogonal/necessary/sufficient test (0013) because it requires *operational* evidence, not merely
conceptual non-redundancy.
