`Conflict(A_1,A_2)=f(A_1,A_2,Context,Time,Scope)` — "a major result"; (5) stale evidence and purpose-
dependent assessment, refining to `Q(E,A,P,C,t)`; (6) unsupported LLM output (`Support(A_3)={LLMOutput}`,
`Assessment=Unsupported`); (7) LLM-as-interpretation-mechanism, requiring provenance `A_4→LLMExtraction→
Document`; (8) summary traceability (`Summary→SourceArtifact`); (9) `Authenticity≠Truth`; (10)
`Authenticity≠Authority`; (11) statistical aggregation caution (`{98,101,99}` vs. outlier `140`, naive
`Mean=109.5` explicitly wrong); (12) evidence-dependence lineage (`NumberOfSources≠
AmountOfIndependentEvidence`); (13) negative-evidence precision (`BackupExists=True` but
`Restorability=False`, not automatically `BackupExists=False`).

**Delivers the file's central architectural principle**: "evidence does not directly modify truth. It
modifies the epistemic state associated with propositions" — `E→Assessment(A)→K`, never `E→Reality`.
Delivers a provisional richer knowledge state `K={A,Assessment(A),Support(A),Conflict(A),Validity(A),
Provenance(A)}` and three formally distinguished relations (Support `E⊢A`, Conflict `E⊢¬A`, Derivation

potentially mapped to a scalar.
