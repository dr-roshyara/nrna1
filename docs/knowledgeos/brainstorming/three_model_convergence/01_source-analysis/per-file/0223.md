## Tier 2
**TRIGGERED (critical).** Rescorla's *Bayesian Models of the Mind* (2024), direct continuation of
0216→0221→0222. Central verdict: **Bayesian inference should be a supporting mechanism, not the Kernel
itself** — "semantic epistemic kernel + pluggable reasoning mechanisms." Strongest finding: a probability
number is not itself epistemic meaning — the same PDF can represent speed, size, or distance; probability
requires mandatory **SemanticReference** (`NoProbabilityWithoutSemanticReference`). Introduces `EpistemicState`
and `EpistemicTransition` as new *stateful* core Kernel elements (Bayes's theorem = synchronic;
Conditionalization = diachronic), an **Inference Port** pattern (Kernel → EpistemicState → Port →
{Bayesian/Deductive/Other engines}), and `PriorBelief` with mandatory origin/provenance — motivated by
Rescorla's own acknowledgment that priors are often postulated without explaining their etiology. Produces
**twelve numbered ZERO-01..12 gap findings** (prior origin unexplained; probability without semantic
grounding; incomplete hypothesis space silently excluding a true H3; posterior ≠ complete world knowledge;
untraced likelihood-model origin; inference without recorded environment; utility-function
justification outside probability theory; ModelPrediction/Explanation/RealityClaim conflated;
no model-failure representation; exact vs. approximate inference undistinguished; EpistemicValidity vs.
ComputationalFeasibility confused; InferenceCorrectness coexisting with RepresentationError). Produces a
ten-dimension `InferenceAssessment` model and a formal research-outcome record **KOS-RESEARCH-BAYES-001**
("accepted as research input, not yet constitutionalized," with explicit non-promotion of "KnowledgeOS =
Bayesian system"). Closes with three deepest principles: epistemic quantities meaningless without semantic
identity; epistemic state is stateful, not scalar; an epistemic transition must be distinguishable from
its calculating mechanism.
