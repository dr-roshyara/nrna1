## Tier 2
**TRIGGERED (critical).** Stigler's *Seven Pillars of Statistical Wisdom*, applied as a **falsification-
question generator** against a minimal Knowledge Kernel — structurally distinct from prior extraction
files (no ASCII domain diagrams; Parts 1-8: strongest observations / falsification questions / surprising
findings / Kernel-relevant findings / explicitly-excluded findings / anti-reasoner table / DDD-blind-spot
questions / final statement). Central finding: the seven pillars are tools for **managing uncertainty**,
not eliminating it. Key content: Aggregation paradox (discarding information can be information gain),
root-n diminishing returns, Likelihood-as-calibration-not-truth (P-value = surprise, not truth), regression
directionality (asking backwards gives a different answer), Design/randomization as creating a basis for
inference, residual-as-signal, and the Rule-of-Three extrapolation trap. Produces an **Anti-Reasoner
table** mapping each pillar to a specific architectural failure mode it guards against, and **ten DDD-
blind-spot questions** showing where conventional DDD analysis alone would miss these issues (aggregates-
as-identity-holders vs. aggregation-as-identity-discarding; data-as-generation-independent; residuals-as-
error; symmetric relationships; more-data-is-always-better). No new positive domain objects proposed —
this is a question-generation, not a modeling, exercise.
