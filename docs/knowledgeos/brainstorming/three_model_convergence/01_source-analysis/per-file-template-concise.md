# Concise Per-File Record Template (MD-008 — routine files)

Used when a file has no new theoretical/mathematical/epistemic/Kernel/DDD/Gītā content beyond
possibly one small addition. Coverage is never optional — every required section still appears,
just briefly. Tier 2 is still evaluated and stated (usually NOT TRIGGERED for these files).

**Note:** `## Concepts Introduced`, `## Definitions Introduced`, `## Hypotheses Introduced`,
`## Mathematical/Statistical/Gītā/Kernel Content`, `## Operators`, `## State Model`,
`## Invariants`, `## Evidence/Provenance`, `## Open Questions` are folded into "What Is This
Document About?" and "New Contribution" for concise records — omit as separate headers. If a file
genuinely has content for one of these that isn't captured elsewhere, state it inline rather than
promoting the whole record to full depth.
