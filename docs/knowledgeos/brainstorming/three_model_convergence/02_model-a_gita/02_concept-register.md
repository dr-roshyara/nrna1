# Model A — Concept Register

Named concepts/formalisms Model A's evidence base (`01_evidence-base.md`) produces. Each entry
gives: **source** (seq references), **terminology** (as the corpus itself names it — not
paraphrased into cleaner vocabulary), **evidence status** (protocol.md §3's tag set:
`[SR]/[DR]/[DF]/[HP]/[CG]/[PR]/[TH]/[EX]/[AN]/[UN]/[OP]/[RF]/[CT]`), **maturity**
(`ESTABLISHED/DEVELOPING/HYPOTHETICAL/SPECULATIVE/UNDEFINED/CONTRADICTORY`), and **relationships**
to other Model-A concepts, typed per **MD-017's six-way taxonomy** (`new_concept /
new_representation / new_decomposition / refinement / genuine_contradiction /
unresolved_equivalence`). No concept below is asserted without its source `seq`.

Given the density of the evidence base (84 files, most `critical` importance, extremely
cross-referenced), this register is organized around the **major recurring formalisms**, not every
individual named ID (H-KOS-*, INV-KOS-*, ADR-KOS-EPI-*, etc. — dozens of these exist; see the
per-file records at `01_source-analysis/per-file/NNNN.yaml` for the exhaustive list). Concepts that
never advanced past a single file's proposal are folded into the cluster they belong to rather than
given a standalone entry, to keep this register navigable.

## A. Pramāṇa and reasoning-provenance apparatus

**Source:** 0092–0100, 0127–0131, 0257–0259 · **Terminology:** Pramāṇa (valid means of knowledge

catuṣkoṭi mapped onto `EpistemicState(P) ∈ {T,F,B,N}` with time/context/scope parameters (0259).
**Relationship:** `refinement` chain across 0092→0096→0097→0100→0101 (each source adds precision to
the same taxonomy, none contradicts a prior one). Avacchedaka's relation to "Context" is an
`unresolved_equivalence` — see §C below.

**SCOPE CORRECTION (added at Phase-1 audit, 2026-09-07 — evidence-preserving, not a rewrite):** the
claim "the Gītā supplies zero kernel candidates" is **narrower than it first appears** and must not
be read as a verdict over the whole Model-A evidence base. Every per-file record in this evidence
base carries an `anchor_test.alternative_minimal_kernel` field. Across the KR-SIM companion series
(2329–2376) this field is **`false` on all six files without exception** — confirming the series'
own "no kernel candidate" verdict is genuinely well-supported **for what it actually tests**: whether
a given Gītā chapter, read against one specific KR-SIM mathematical experiment (its own Zero-algebra/
contradiction/reduction/audit/bridge apparatus), yields a new formal primitive within *that*
apparatus.

That is **not** the same question as whether Model A's evidence base as a whole proposes kernel
candidates. It does: **ten files carry `alternative_minimal_kernel: true`** — 0219 (§F) and the
*entire* Sañjaya/Arjuna architecture cluster (0430, 0435, 0436, 0441, 0443, 0451 — §I/§J/§K/§L) and
the Chapter-4 capstone trio (0800, 0801, 0808 — §M). Nine of these ten also carry
`supplies_operator_or_transition: true` (0219 is the exception). **These are not the same proposals
the KR-SIM series tested and rejected — they were never tested against it at all**: a direct search
of all six KR-SIM companion records for any reference to 0219/0430/0436/0441/0808 or to
"Sañjaya"/"Sārathi" returns zero hits in either direction. The two threads are **independent and
non-overlapping**, not convergent-by-cross-check.

Nor are these ten proposals shown to be *withdrawn*: 0808 retracts three specific named mathematical
formulas (§M) while its own `alternative_minimal_kernel` field remains `true` — its new
contribution (the three-layer separation model, the I1–I14 invariant consolidation) is a *further*
kernel-structure proposal, explicitly flagged by its own record as unreconciled against the arc's
prior parallel notation series, not rejected. The correct summary is therefore: **Model A's evidence
contains at least ten self-flagged candidate contributions to kernel structure, none shown
withdrawn, sitting entirely unreconciled — not merely undecided, but literally never
cross-examined — against a separate, narrower, and genuinely well-supported six-cycle finding that
one specific mathematical test-apparatus finds no new primitive when driven by Gītā chapter content.**
Treating the second as a verdict on the first would overstate what either thread's evidence actually
shows. This correction is reflected in `03_contradictions-and-open-questions.md` (item CT-4).
