# Model A — Boundary Observations

**This is a boundary register, not a reclassification exercise.** Nothing here changes any file's
`initial_primary`, `initial_secondary`, `final_primary`, or `final_secondary` in
`00_control/classification-register.tsv`. Everything below is material that touches Model A from
*outside* its primary evidence population (`01_evidence-base.md`'s 84 files), recorded so a later,
separately-authorized phase can consume it without this phase having silently absorbed it into
Model A's own evidence.

## 1. The 511 secondary-tagged files (Design decision, per `00_index.md`)

something else — **498 `engineering_knowledgeos`, 10 `cross_model`, 3 `meta_research`**. These are
**Model-A-adjacent material, not Model-A evidence**: their primary classification places current
ownership elsewhere, and a secondary tag is a provisional multi-lineage flag, not proof of Model-A
membership (per the authorization's Boundary 4).

## 3. Schema/data-quality carryforward (per the authorization's Boundary 6)

Consistent with Phase 0's own findings (`14_decision-log/model-boundary-decisions.md`, MD-021):

- **The `importance` field is not a controlled vocabulary** across this evidence base either — this
  84-file set alone uses `critical/high/medium/low/important/standard/none` (7 distinct values; see
  `01_evidence-base.md`'s totals line), not protocol.md's own defined 4-value
  `CRITICAL/HIGH/MEDIUM/LOW` scale. Reported verbatim, not collapsed.
- **No `maturity` field exists** in any of the 84 records (all fall in the "new schema" range, seq
  ≥ ~60, which Phase 0 already established lacks this field entirely) — the "Maturity" values used
  in `02_concept-register.md` are this document set's own judgment calls (`ESTABLISHED/DEVELOPING/
  HYPOTHETICAL/SPECULATIVE/UNDEFINED/CONTRADICTORY`, reusing protocol.md §4's defined scale), applied
  per concept from the evidence, not transcribed from a source field that does not exist.
- **No `bytes:0` or malformed-YAML anomalies** were found among the 84 records (unlike the
  math-lane's seq 0002/0009/0056 reconciliation) — all 84 parsed and read cleanly.
