# Model A — Contradictions and Open Questions

Every item below is evidence-traced to specific `seq` numbers. None is resolved here — per the
authorization's Boundary 4, importing Model B/C1/C2 evidence to settle a Model-A-internal tension is
explicitly out of scope for this phase. Where the corpus's own later files partially address an
earlier tension, that is noted as such, not treated as full resolution unless the corpus itself
states resolution.

## Genuine contradictions (`[CT]`, MD-017 `genuine_contradiction`)

### CT-1 — The Context dispute (four non-identical treatments, never reconciled)

**Files:** 0094 (Avacchedaka/delimiter), 0095 (`INV-KOS-SemanticBoundary-001`, over-/under-extension
boundary), 0098 ("Context-Bounded Meaning"), plus the flat-dimension treatment referenced from
outside this evidence base (0088–0091). 0094's own record explicitly contradicts 0091's
Context-merged-into-Identity treatment by keeping Context as a separate item. No file in this
evidence base declares one treatment canonical or shows two of the four are the same construct.
**Status:** open, `unresolved_equivalence` per §C of `02_concept-register.md`.

### CT-2 — EKI-08 identifier collision

**Files:** 0260 (`EKI-08 = Modal Integrity`) vs. 0261 (`EKI-08 = Epistemic Type Preservation`).
0261's own record explicitly names this "an ID collision, not a content merge" — the two underlying
invariants are independently coherent; only the shared numeral conflicts. **Status:** open,
unresolved within this evidence base; a future phase would need to renumber one or the other before
either could be merged into a consolidated invariant catalog.

### CT-3 — 0808's explicit retraction of three earlier Gītā-derived formulas

**Files:** 0808 retracts a knowledge-decay exponential (`K_t^decayed = K_0 e^{-λt}`), a
divine-intervention threshold function, and a binary epistemic-reward function, none of which
originate inside this evidence base's own 84 files. **Status:** the retraction itself is
Model-A-internal evidence (recorded in §M of the concept register) and is treated as authoritative
for how this reconstruction reads any Gītā-derived formula — but the *originating* files are outside
Model A's evidence population as defined for this phase (`initial_primary == gita`), so their exact
location and content could not be independently verified here. Flagged for a future phase, not
chased down in this one.

### CT-4 — Ten `alternative_minimal_kernel: true` records vs. the KR-SIM series' `false` verdict, never cross-checked (found at Phase-1 audit, 2026-09-07)

**Files:** 0219, 0430, 0435, 0436, 0441, 0443, 0451, 0800, 0801, 0808 all carry
`anchor_test.alternative_minimal_kernel: true` in their own per-file record (nine of the ten also
carry `supplies_operator_or_transition: true`) — i.e. each self-flags as proposing an alternative
kernel-structure candidate. The KR-SIM companion series (2329, 2370, 2372, 2373, 2375, 2376) carries
`alternative_minimal_kernel: false` on all six files, and none of the six references any of the ten
`true`-flagged files or the Sañjaya/Sārathi architecture by name (verified by direct search).
**These are not the same claim tested twice with different results — they are two disjoint research
threads that were never cross-examined against each other.** Recorded as a genuine contradiction in
*scope*, not in content: nothing here shows either thread is wrong, but the corpus's own "zero
kernel candidates" framing (echoed uncorrected in this reconstruction's own first-draft principal
finding, session log, and CONTEXT.md entries of 2026-09-07) applies only to the KR-SIM series' own
narrow mathematical-primitive test, not to the ten architecturally-flagged proposals. **Status:**
recorded, not resolved — resolving which (if any) of the ten survive would require running them
against the KR-SIM series' own apparatus or an equivalent test, which is out of this phase's scope.

## Unresolved equivalences (`unresolved_equivalence`, MD-017 default)

(0216 itself outside this evidence base's 84, referenced by 0219) vs. "K-1"'s KnowledgeAggregate vs.

### UE-2 — The Knowledge Vector family (nine+ variants)

0247/0253/0254/0255/0259/0260/0261/0262, each proposing a differently-componented tuple for a
"Knowledge Vector" or "Knowledge State." See §G of the concept register. 0261's own record explicitly

### UE-3 — Gyāna/Vigyāna vs. Object-Knowledge/Meta-Knowledge

0414 introduces Gyāna (knowledge of underlying principle) / Vigyāna (knowledge of the manifested
world) as a candidate parallel to 0410's Object-Knowledge `K_t(O)` / Meta-Knowledge `M(K)`
two-level framework (0410 itself outside this evidence base's 84, referenced by 0414). 0414's own
record leaves this an explicit open question: "whether Gyana/Vigyana is ever formally adjudicated
as identical to, or distinct from" the Object/Meta-Knowledge framework. **Status:** open.

### UE-4 — The Trustee/governance lens vs. the corpus's existing evidence/provenance/governance work

0409 introduces a new Trustee lens (knowledge as entrusted, not owned) and its own record flags this
as a candidate convergence with "the corpus's existing Evidence/Provenance/governance
formalization" (outside this evidence base's 84, referenced as 0367/0375/0380) — explicitly recorded
with `status: candidate`, not confirmed. **Status:** open; see also `04_boundary-observations.md`
for this as an outward-pointing bridge candidate.

### UE-5 — Mode-of-knowing (Para/Apara Vidyā) as a candidate third orthogonal axis

0409 proposes that the Upaniṣadic Para Vidyā/Apara Vidyā (higher/lower knowledge) distinction may be
a genuine third orthogonal axis alongside dimension-count and value/dimension-uncertainty — recorded
by its own source with `status: candidate`, explicitly not adjudicated. **Status:** open.

**File:** 0407. Stated in its starkest, least-hedged form anywhere in the Model-A evidence base:

84-file population does not contain a file that resolves it** — 0407's own record notes a possible,

deepest unresolved philosophical question this evidence base carries.**

### OQ-2 — 0421's methodological lapse

**File:** 0421. Applies the Bhagavad Gītā directly to the corpus's own named research questions
*without* the explicit non-collapse/rejection discipline used by every other file in this evidence
base's external-source-engagement clusters (Clusters 1, 4, 6) — and does so immediately after a
prior file (0419, outside this evidence base) had explicitly warned against exactly this failure
mode. Produces two claims in evident tension with the rest of the evidence base: "Ideal State
redefined as self-knowledge" (diverging from 0419's `S*_t` formalization) and "determination
legitimacy redefined as non-attachment to outcomes" (in tension with the evidentialist,
evidence-grounded Kernel-design work found throughout Clusters 3 and 5). **Status:** open — no later
file within this evidence base's 84 explicitly revisits or corrects 0421's specific claims (0808's
much later capstone rule, §M of the concept register, addresses the *general* failure mode 0421
instantiates, but does not name or retract 0421 specifically).
