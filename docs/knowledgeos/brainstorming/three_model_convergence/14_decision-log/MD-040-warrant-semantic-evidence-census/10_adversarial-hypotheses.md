# Adversarial Hypotheses

## H1 — `Warrant` is already formally defined somewhere

**Fails.** Confirmed across both threads (`03`/`04`): every occurrence names or lightly constrains
`Warrant`; none computes it.

## H2 — `Warrant` is computable but its computation is distributed across several source rules

**Fails, on close examination.** The candidate pieces (the atom assignment, `04`; the input typing,
`06`; the two-valued "kind" typology, `11`; the operation/standard DDD split, `13`/`FINAL`) genuinely
exist and are genuinely distinct — but combining them still does not yield a procedure that, given
`(Claim/Hypothesis, Evidence)`, would output a `Warrant` value. They constrain the *shape* of the
question, not its *answer*. This is a meaningfully closer call than H1, and is recorded as such
rather than dismissed quickly.

## H3 — `Warrant` is only represented/named, not semantically defined

**Succeeds.** This is the precise, source-faithful summary of `03`/`04`'s own findings.

## H4 — `Warrant` can be derived from existing `Defeater`/`Evidence`/`Verdict` rules without new
semantic assumptions

**Fails.** `06` confirms: `15`'s own F-10 (the closest candidate derivation) is explicitly an open,
untested falsifier, not an established rule.

## H5 — `Warrant` is equivalent to "surviving a defeater"

**Fails.** No admitted or characterized source equates them; they occupy different grammatical roles
in the same derivation system — `Warrant` is atom-adjacent (the power/process name), "surviving a
defeater" is an input-carrier requirement specific to `V6`. Treating them as the same concept would
be an unwarranted inference this study does not make.

## H6 — the Semantic Kernel framework itself supplies enough information to derive `Warrant`

**Fails**, re-confirmed rather than newly established (MD-039): the framework's own `Warrant`
dimension is a named slot in `P`, with no computation rule.

## H7 — absence of a definition merely reflects search incompleteness

**Fails.** This study's own search was materially broader than MD-037's or MD-039's (finding and
incorporating an entire second thread, `M0036`, from a genuinely different part of the corpus) and
still found no definition — if anything, the broader search *strengthens* the negative finding, and
additionally surfaces a plausible architectural reason for the gap (the standard-is-policy boundary,
`04`) that a narrower search would not have found. The absence is not attributable to this study's
own search having stopped too soon.
