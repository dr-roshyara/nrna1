## Central, unanticipated finding

register.md` §C** (this reconstruction's own already-established Model-B concept register, written
during Phase 2, fully in scope — not a new admission) cites three math-lane primary-evidence files
(**M0032, M0033, M0036**) proposing a formal tuple `A_t = ⟨attitude, strength, warrant, status⟩` and
a broader model `𝔈_t = (E_t,S_t,A_t,K_t,Q_t,C_t,H_t)`. Read directly (M0036 in full, M0032/M0033
grep-confirmed), this is a **separate, independent research thread within Model B's own math lane**
(Titelbaum-epistemology-derived, not the kernel-reduction/C0-operator thread) that **also introduces
`Warrant`/`W_t` repeatedly, as a named tuple component and pipeline stage, without ever supplying a
computation rule for it** — the identical gap shape found in the kernel-reduction series, arrived at
independently in vocabulary and derivation, though **explicitly in conversation with the same
kernel experiment** (M0036 directly names and discusses "KR-2026-09-01").

## Headline finding

`Warrant` is **named and represented, but not semantically defined**, in every source examined —
both the kernel-reduction thread (already established, MD-037/039) and this newly-found Titelbaum
thread (new to this study). No computation rule, predicate, or derivation exists in either. The two
threads' agreement on this gap is **corroboration within a common corpus/programme context, not
independent statistical confirmation** — M0036 explicitly engages with the same kernel experiment,
so this is not two unrelated research efforts converging by chance.
