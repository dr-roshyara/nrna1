# The Critical Question — Can the Framework Generate or Identify the Missing Predicate?

## The three possible outcomes, tested

1. *The framework contains enough structure to derive a testable predicate.* **Ruled out.** Nothing
   in `B` or `P`'s own specification generates content — every one of the sixteen named components
   (six in `B`, ten in `P`) is a bare slot with no computation rule attached anywhere in `19`. A
   framework that only names variables cannot derive their values.
2. *The framework provides a test apparatus but requires an externally supplied predicate.*
   **This is the finding.** The equivalence condition (`B(𝒦₁,·)=B(𝒦₂,·)`) and the preservation
   condition (`P(𝒦₁)=P(𝒦₂)` on declared-essential dimensions) are themselves well-formed comparison
   *schemas* — structurally coherent, reusing the already-established `Reach(S)` machinery for the
   one genuinely computable piece (capability-closure). What is missing is not the shape of the test,
   but the content that would go into `Warrant` (and, by extension, "survival") before the test could
   be run.
3. *The framework itself is insufficiently specified to determine what would count as survival at
   all.* **Not quite this either** — the framework does not fail to specify *what kind of thing*
   would count (a value on the `Warrant` dimension, compared for equality/preservation across two
   kernels); it fails to specify *what that value is or how it is computed*. This is a narrower,
   more precise gap than "insufficiently specified to determine what would count."

## Verdict for this section

**Outcome 2**, precisely: the framework is a genuine test apparatus, structurally sound in its own
comparison logic, that presupposes an externally-supplied semantic definition for its own `Warrant`
dimension (and, less directly, several of its other nine `P`-dimensions) — it cannot generate that
definition from anything stated within itself or within any of the eight currently admissible files.

## Why this is not the same finding as MD-037's own "no definition found"

MD-037 established the definition does not exist anywhere in the searched narrative text. This study
establishes something additional and more specific: even the one candidate *instrument* the corpus
itself proposes for eventually testing such a definition is built in a way that presupposes the
definition as an input, rather than as something the instrument's own operation would produce. The
gap is not merely "no one wrote the definition down yet" — it is "the proposed next experiment's own
design requires the definition to already exist before that experiment can even be run."
