# Adversarial Hypotheses

## H1 — The framework is sufficient to formalize "survival"

**Fails.** `03` rules out outcome 1 directly: nothing in `B` or `P`'s own specification generates
content — every component is a named slot, not a computation rule.

## H2 — The framework can test survival but cannot define it

**Succeeds.** This is the precise finding of `03` (outcome 2): a structurally coherent comparison
schema exists, applicable once a definition is supplied, but it does not supply one itself.

## H3 — The missing definition must be supplied independently before the framework can operate

**Succeeds**, and follows directly from H2 — `02`'s own census shows `Warrant` (and most of `P`'s
other nine dimensions) has no computation rule anywhere in the admissible evidence; the framework
cannot be run without an externally-supplied one.

## H4 — `I9: Verdict ⇒ Defeater consideration` can substitute for survival

**Fails**, re-confirmed rather than newly established (MD-037 `04`, MD-038 `02`): `I9`'s own stated
condition (mere consideration) is explicitly weaker than survival, and no admitted source equates
them.

## H5 — V6's additional carrier requirement alone establishes an epistemic safeguard

**Fails.** `05` explicitly declines to treat "requires more input" as evidence of epistemic
superiority — the reachability difference is a structural fact, not an epistemic-quality claim,
exactly the distinction MD-036 already drew and this study preserves.

## H6 — The statistical confounding example formally proves the V6 safeguard

**Fails.** `06` confirms: statistical motivation exists, no formal implication for `Validate` has
been established.
