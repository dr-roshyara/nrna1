# Scope Options — Presented, Not Selected

## Option A — Do not admit

**Scope**: no change to the corpus boundary. **Benefits**: preserves the exact boundary MD-010/MD-011
established; zero risk of contaminating the reconstruction's own evidentiary discipline. **Risks**:
the MD-024 specification gap remains genuinely unresolved indefinitely, absent a different evidence
route. **Provenance consequences**: none — nothing changes. **Scientific consequences**: composition
testing (GA-001) stays exactly where MD-024 left it. **Governance consequences**: none created.
**Permissible afterward**: pursuing the specification gap through a different, still-admissible route
(e.g. further search within `docs/knowledgeos/brainstorming/` itself). **Remains prohibited**: any use
of `kernel-reduction/` content as evidence for anything in this reconstruction.

## Option B — Admit only the operator-contract artifacts, for specification-sufficiency analysis only

**Scope**: `04-operator-contracts.md` (and, if needed, its own directly-referenced dependencies, e.g.
`03-capability-model.md` for the atom vocabulary's own derivation) — not the whole 22-file lane.
**Benefits**: narrowly closes exactly the gap MD-024/025 named, without importing the directory's own
broader (and partly superseded) minimality claims. **Risks**: a narrow admission could still be read,
informally, as endorsing the surrounding lane; requires active discipline to keep the boundary narrow
in practice. **Provenance consequences**: admitted material carries `RECONSTRUCTED PROVENANCE`,
explicitly, permanently. **Scientific consequences**: a future, separately-authorized composition
retest (MD-024's own Pairs 1/2) becomes possible. **Governance consequences**: establishes a precedent
for partial, purpose-bound admission — itself worth naming as a new kind of governance act, distinct
from MD-010/011's own all-or-nothing directory exclusion. **Remains prohibited**: use of the directory's
own superseded minimality conclusions (`19`'s own restructuring) as if ratified.

## Option C — Admit the entire `kernel-reduction/` lane, preserving non-canonical status and
reconstructed provenance

**Scope**: all 22 files. **Benefits**: preserves the lane's own internal context (its own
falsification/negative-results/supersession discipline), avoiding the risk of cherry-picking only the
convenient parts. **Risks**: broadest scope, broadest chance of importing conclusions (e.g. the
originally-superseded `|K_min|=13` headline) that were never meant to be read in isolation.
**Provenance consequences**: same as B, at larger scale. **Scientific consequences**: same as B, plus
potential future relevance to other gaps this package does not anticipate. **Governance consequences**:
the broadest precedent-setting act among the four options. **Remains prohibited**: treating any single
file's own claim as validated merely by admission.

## Option D — Defer, pending additional organizational provenance evidence

**Scope**: no change now. **Benefits**: buys time to locate stronger provenance evidence (e.g. asking
the human collaborator directly whether `kernel-reduction/` was produced as part of the same research
effort as M0030) before deciding. **Risks**: indefinite deferral has the same practical effect as
Option A while appearing less final. **Provenance consequences**: none, yet. **Scientific
consequences**: same as A, for now. **Governance consequences**: names a specific, answerable
organizational question (§`07`) rather than closing the matter. **Remains prohibited**: everything A
prohibits, until the deferral resolves.

## Not offered as an option

**Retroactive reclassification as Model B** (treating `kernel-reduction/` as if it always was part of
the 151-file admissible population) — explicitly excluded from this option set, since no evidence
supports that stronger claim and every phase of this reconstruction has declined to manufacture
membership from resemblance or convenience.
