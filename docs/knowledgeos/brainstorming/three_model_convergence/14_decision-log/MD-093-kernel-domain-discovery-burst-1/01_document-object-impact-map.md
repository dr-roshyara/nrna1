# MD-093 §01 — Document→Object Impact Map (39 files, `kernel/` genesis burst)

## Headline finding

This 39-file burst (2026-08-22 16:19 – 08-24 01:05) is **entirely pre-formal**. Exhaustive search
across all five batches confirms **zero occurrences** of every symbol this reconstruction has tracked
since MD-067 — `Sat`, `Det_r`, `EvalReq`, `EC`/`EC_t`, `Γ`, standalone `r`-as-requirement, `Δ_t`,
`≡_sem`, `⪯_cap`, `MinKer`, `K-1`/`K_1`. This is the corpus's own DDD/philosophical-brainstorming
origin of "Kernel" as a research object — nine days before the F4-lineage birth point (M0001,
2026-09-01) this reconstruction previously treated as its own earliest evidence.

## The dominant structural pattern: "propose → immediately re-open"

Every single file in this burst that proposes a Kernel definition, boundary, or enumeration is
followed — usually within the same file, always within the burst — by an explicit re-opening of that
proposal as unproven hypothesis. At least ten distinct, never-unified "senses of Kernel" are proposed
across the 39 files (god object [rejected]; pure function; Constitutional Validator; authoritative
admission boundary; Admission Boundary; constitutional evaluator for the epistemic lifecycle;
Transformation Boundary; Epistemic Accountability Core; five further competing hypotheses in File 14
of the burst; the "boring Kernel" responsibility-tree shape from Files 42–43; ADR-KOS-KERNEL-001's own
`KnowledgeCore` proposal). **One genuine falsification event occurred**: the six-part
`KnowledgeAggregate` invariant (Identity+Evidence+Justification+EpistemicState+Confidence+History) was
explicitly falsified via pairwise atomicity testing early in the burst (file 11 of the burst) and
never resurrected in its original form.

document its filename suggests — it contains **three** full AI-authored architecture reports (DeepSeek,
Perplexity, and a previously-unflagged third, attributed to "Kimi"), each using a **materially
different domain vocabulary** for the same subject: DeepSeek/Perplexity use `KnowledgeId`/

`AdmissionContract`/`ADMITTED→RETRACTED→RE-ADMITTED`. Neither vocabulary is reconciled with the other
within the file, and this third report is distinct from the Kimi report separately reviewed in file 18
of the burst. This is a genuine, previously-uncharacterized corpus feature — flagged for the registries,
not resolved here.
