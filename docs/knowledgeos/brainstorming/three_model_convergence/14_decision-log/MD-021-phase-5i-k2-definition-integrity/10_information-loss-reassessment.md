# Phase 5I — Information-Loss Reassessment (D1–D7, only where new evidence bears on it)

Per the authorization's §11: re-evaluate only where the new executable evidence materially changes
the classification. Most of Phase 5H's `09` (D1–D7 table) stands; three changes are made, each
justified.

| Primitive | Phase-5H classification | Phase-5I reassessment | Reason for change |
|---|---|---|---|
| Event, Policy, Action | D1 (deliberate abstraction) | **Unchanged for $\pi_1$; for $\pi_2$, `Policy`'s own status is now `D7 — UNRESOLVED`** | The `Π`-as-Policy-vs-provenance discrepancy (`06`, discrepancy 5) means it is no longer clear `Policy` is cleanly "dropped" under $\pi_2$ — it may instead be present, relabeled as `Π`, with its meaning ambiguous. Not a field disappearing merely because one implementation lacks it (the authorization's own caution, §11) — this is a positive, disclosed ambiguity about what `Π` denotes |
| Observation | D4 (computational limitation) | **Split by projection**: D4 for $\pi_2$ (unchanged — present, blocked on `Qualify`); **D5 (undefined mapping) for $\pi_1$** (`Observation` is not merely computationally blocked under $\pi_1$ — it has no target field at all, `09`) | The new two-projection distinction (`09`) requires this split; it was not previously possible to state |
| State | D7 (unresolved) | **Unchanged** — still D7 under both $\pi_1$ and $\pi_2$, since "the carrier" remains undefined regardless of which Assertion characterization is used | No new evidence found this phase bearing on `State` specifically |

## What is explicitly NOT changed

Entity, Proposition, Relation remain **not lost** (preserved) under both projections — the new
evidence does not disturb this. No field is reclassified as D6 (genuine information loss) merely
because it "disappears from one implementation," per the authorization's own explicit caution — every
change above is justified by a positive finding (the `Π` ambiguity; the two-projection distinction),
not by a bare absence.
