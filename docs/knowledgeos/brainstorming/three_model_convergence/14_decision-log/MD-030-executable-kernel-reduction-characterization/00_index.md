## Headline finding (stated here for reader orientation; justified in the artifacts below)

`nrna1/research/kernel-reduction/kr/carriers.py` contains an explicit, machine-encoded derivation
rule — `({Claim, Evidence}, {A_WARRANT}) -> Verdict` and `({Hypothesis, Evidence}, {A_WARRANT}) ->
Verdict` — that supplies a concrete candidate answer to exactly the input-carrier question MD-029
left open for B `Validate`. This is genuinely new, on-point information. It is also: (a) completely
untracked in git (zero commit history — a *weaker* provenance status than the narrative lane's own
2026-09-06 commit), (b) self-labeled by its own README as `[EXP]` "a research instrument, not
KnowledgeOS architecture," and (c) explicitly treated, by the code's own `variants.py` module (V6),
as one of at least two tested alternative rules for the same step — not a single fixed fact even
within this lane's own internal design. All three qualifications are load-bearing for the
admissibility question in `08`.
