## `baseline.json` — full content already quoted in `03`/`00`; restated precisely here

`C0` (13 operators, no `Qualify`): `score: 21, total: 25, lost: ["C10","C16","C17","C25"]`.
`C0_plus` (14 operators, with `Qualify`): `score: 25, total: 25, lost: []`. `C10` is exactly the
Validate-capability defined in `capabilities.py`. This is a **computed, deterministic result** (per
the README's own "deterministic given the seeds" note, and this particular computation — reachability
closure — does not depend on the randomized trials at all; it is a pure fixpoint over declared rules)
showing that, *within this model*, `Validate`'s own capability is unreachable without `Qualify`
present, because `Verdict` requires `Evidence` as an input carrier, and `Evidence` is only derivable
via `Qualify`'s atom (`A_QUALIFICATION`).

## `minimal_kernels.json` — full content already quoted in `00`

`n_covering_subsets: 3` in the `_meta`-adjacent field name but the actual array `minimal_kernels`
contains 2 entries (both include `Validate` and `Qualify`; noted as a minor internal field/array-length
inconsistency in the file itself, not investigated further — out of scope for a Validate-specific
census). Both listed minimal kernels are 13-operator sets (12 of `C0`'s named operators minus
`Represent` or minus `DetectGap`, plus `Qualify` in both) — i.e., under this experiment's own capability
model, no minimal covering set excludes `Validate`.

## Reproducibility

README states `python3 run_all.py` "regenerates `results/*.json` (~30 s, no dependencies)" and that
results are "deterministic given the seeds `[1, 7, 13, 101, 2718]`." **This study did not execute
the script** — reproducibility is stated as a source claim (direct evidence of what the README says),
not independently verified by re-running it, per this study's own non-goal of executing code.
