external semantic ordering?** Answered directly from the source's own structure: minimality is
explicitly defined via an EXTERNAL ordering (`⪯_sem`/`⪯_cap`) applied to candidates drawn from

property, not an intrinsic property of any single candidate object considered alone.** This also

**H1 (MinKer is merely another notation for an existing candidate) is therefore not well-posed as
stated** — MinKer and F1–F8 are different TYPES of thing, not competing instances of the same type.

governance choice would still have to occur**, exactly matching the `Δ_t` precedent's own shape. This
answers Phase F's central question directly and without qualification: **the latter**, not the
former.
