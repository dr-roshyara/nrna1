## The one upgraded verdict, justified

The K-1 (seq 1006) ↔ K-1-B (seq 1008) pair is the only one in this phase reaching **structural
correspondence** — justified because: (a) both sources name the identical 8-primitive list
(`Entity, State, Event, Observation, Proposition, Relation, Policy, Action`), (b) both carry the same
`RATIFIED`/authoritative status marker, (c) both sit inside the same D285 research package (seq 1006
is D285-1, seq 1008 is D285-7 — sequential parts of one documented package, not independently-arrived-
at candidates). This satisfies the authorization's own evidence bar (§8, "distinct state space" would
argue against identity — here the state space is explicitly the *same*, named identically, in the
same package) more strongly than any prior pairing in this reconstruction's history. **It is still not
promoted to formal equivalence or demonstrated identity**, since no explicit isomorphism/mapping proof
was found or sought this phase.
