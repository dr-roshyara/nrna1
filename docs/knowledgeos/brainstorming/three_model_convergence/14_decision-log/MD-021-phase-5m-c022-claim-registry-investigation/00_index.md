## Central finding, stated up front (full evidence in `12`)

**M-B — CITATION PARTIALLY SUBSTANTIATED.** Genuinely relevant, corroborating material was found for
**several components** of D285-1's citation, but **no single artifact matches the citation as a
whole**, and the literal identifier "`C-022`," when it does appear elsewhere in the corpus, denotes an
unrelated concept. Three separate, real documents each substantiate a *fragment* of the citation:

1. **seq 0630 (step-049)** — substantiates "`step-049`" directly: the 8-primitive tuple's own origin,
   confirmed (already established, Phase 5F–5L).
2. **seq 0764 (HPA RULING — GN-31)** — substantiates "FA-4 D-FA-6" **partially**: contains a genuine
   "D-FA-6 — K_t naming register... RULING: ACCEPT" and explicitly expands **HPA = "Highest Project
   Authority"** (a new finding — the abbreviation itself is defined, though its own organizational
   legitimacy remains self-declared, not externally verified). Does **not** contain "C-022," "50
   attack classes," or an item literally named "FA-4."
3. **seq 0757 (Phase 1 Status Report, "how_to_combine/combine-prompt-2")** — substantiates "50 attack
   classes, no counterexample" **with an important, dropped hedge**: the primary wording is *"the
   8-primitive M₄₉ kernel survived 50 attack classes... no counterexample found in tested scenarios,
   explicitly NOT a proof"* — D285-1's own citation drops "explicitly not a proof." This same document
   also **reports** producing a `claim-registry.md` (1C, 26 claims) deliverable — **which cannot be
   found anywhere in the checked-in corpus.**
4. **"`C-022`" itself, wherever it literally appears** (step-152, seq 0740, §152.26) — denotes "Trace
   identity" (`TraceID`/`RequestID`/`CausationID`), an unrelated topic. **No document anywhere assigns
   the identifier "C-022" to the K-1 ratification claim.**
5. **The file literally named "claim-registry"** (step 239, seq 0865) concerns a completely different
   Kernel object (the five-element `𝔎=(G,σ,θ,λ,π)` lineage) — not K-1 at all.
