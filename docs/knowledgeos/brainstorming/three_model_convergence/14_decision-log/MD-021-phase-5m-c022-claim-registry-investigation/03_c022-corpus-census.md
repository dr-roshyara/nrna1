`grep -rn` (case-sensitive and case-insensitive variants) across the entire corpus (not limited to
`phase_measure_theory/`) for: `C-022`, `C022`, `C 022`, `claim-registry`, `claim registry`, `50 attack
classes`, `FA-4`, `D-FA-6`. Also `find` for filename variants of "claim-registry."

## The single most important negative result

**No file anywhere in the corpus (main corpus, `phase_measure_theory/`, or `kernel/`) contains BOTH
"C-022" AND "50 attack classes" AND K-1's own 8-primitive list together.** The three elements D285-1's
own citation bundles together **never co-occur** in any single source document.

## The "claim-registry.md" deliverable question

Multiple `how_to_combine/` planning documents (seq range 0755–0761, same 2026-08-28 date cluster as
seq 0757) describe an intended directory structure containing `analysis/claim-registry.md` as a
planned deliverable (1C, 26 claims). **No `analysis/` directory, and no file literally named
`claim-registry.md`, exists anywhere in the checked-in corpus.** The only file with "claim-registry" in
its own filename is Step 239's differently-scoped document (`...kernel-genealogy-and-claim-registry`),
about the 5-element `𝔎` kernel, not the 8-primitive K-1.

## Verdict

**Census complete for the search method used.** The identifier "C-022" and the phrase "claim-registry"
each independently exist somewhere in the corpus, but never together, and never both attached to K-1's
own 8-primitive ratification content in one place.
