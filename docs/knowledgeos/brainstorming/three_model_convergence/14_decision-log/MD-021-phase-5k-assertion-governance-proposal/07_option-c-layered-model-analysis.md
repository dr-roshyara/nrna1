# Phase 5K — Option C: Explicit Two-Layer Model

$$Observation \xrightarrow{Qualify} Evidence$$

with the `Assertion` representation explicitly distinguishing an observation-layer field from an
evidence-layer field, rather than treating them as alternative, competing names for one slot.

## What is directly evidenced vs. what would be new construction

**Directly evidenced**: the *sequence* $Observation \rightarrow Evidence$ via `Qualify` (seq 0630
§49.76, seq 0795 §170.4, Step 272A §272A.6 — 3 independent sources, the best-evidenced single
relationship in this entire investigation). **Not evidenced**: any document proposing that
`Assertion`'s own *field structure* should be redesigned to carry both an `Observation` slot and a
separate `Evidence` slot simultaneously, connected by an explicit qualification step **inside the
Assertion record itself**. **This specific structural proposal is therefore new — labeled precisely as
such, per the authorization's own instruction.**

## Mathematical evaluation

- **Primitive set (proposed)**: $\{Proposition, Entity, Observation, Evidence, Context, Time,
  Provenance\}$ — a **union**, not a selection, of D1/D3's and D2/D4's own vocabularies, plus an
  explicit qualification relation between two of its own fields.
- **Domain/codomain**: `Qualify: Observation → Evidence` (the 1-argument form, seq 0795 — chosen here
  because it is the simplest of the 4 known variants; **this is a proposal choice, not a discovered
  fact** — Phase 5J `11`'s own 4-arity conflict is not resolved by this option, merely worked around by
  picking one variant for illustration).
- **Operators**: `Qualify` becomes an *internal* transition of the Assertion record itself, rather than
  an external, undefined dependency — a genuine structural simplification, **if** `Qualify`'s own
  algorithm is ever supplied (it still is not, under this option).
- **Consistency**: internally consistent as *proposed*; **not tested against either executable script**,
  since neither implements this specific two-field structure.
- **Completeness**: still incomplete — `State`'s own target remains undefined, `Qualify`'s own
  algorithm remains absent, and the `Π`/Policy-vs-Provenance question is untouched.
- **Closure**: not established.
- **Information preservation**: the **best of any option for preserving both source vocabularies
  simultaneously** — nothing from D1/D3 or D2/D4 is dropped, since both `Observation` and `Evidence`
  coexist as distinct fields.
- **Computability**: unchanged — still blocked on `Qualify`'s own missing algorithm.

## Verdict

**A structurally elegant proposal, directly motivated by 3 independent, well-evidenced sources — but
explicitly a NEW governance-level structural choice, not a reconstruction of something the corpus
already states.** It resolves the Observation-vs-Evidence naming tension by refusing to choose, at the
cost of being untested against any existing executable artifact.
