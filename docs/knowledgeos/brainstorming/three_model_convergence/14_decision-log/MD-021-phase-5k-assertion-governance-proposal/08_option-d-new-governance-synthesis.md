# Phase 5K — Option D: New Governance Synthesis

**PROPOSED GOVERNANCE SYNTHESIS — every element below is a new proposal, not a reconstructed corpus
fact, and is labeled as such throughout.**

$$Assertion_{proposed} = \{Proposition, Entity, Observation, Evidence, Context, Time, Provenance,
id\}$$

where:

- `Proposition`, `Entity`: retained from all three source records (universal agreement).
- `Observation`: retained from D2/D4 (Option B), justified by the strength of its own K-1-primitive
  correspondence and the 3-source `Qualify` evidence (Option C's own justification, `07`).
- `Evidence`: retained from D1/D3 (Option A), justified by `Qualify`'s own well-evidenced output type
  (seq 0630 §49.76).
- `Context`, `Time`, `Provenance`: retained from D1/D3, using their own directly-legible English names
  in preference to D2/D4's own unresolved `c`/`t`/`Π` abbreviations (a **proposed resolution of the
  `Π` ambiguity by avoidance**: since this phase cannot determine whether `Π` denotes Policy or
  Provenance, `Π` is dropped from the proposed schema and `Provenance` is named directly, with `Policy`
  left as a *separate*, explicitly out-of-`Assertion` concern, consistent with `Policy`'s own
  `VERIF_EXTERNAL` classification in `t285_reconcile.py`).
- `id`: retained from `e_equality.py`, as a **derived** field (not independent), per Phase 5J `10`'s
  own "compatible" finding.

## What this proposal explicitly does NOT resolve

- `State`'s own projection target remains undefined — **this proposal does not invent one**, since no
  evidence supports any specific choice.
- `Qualify`'s own algorithm remains unspecified — **this proposal does not invent one**.
- `Qualify`'s own arity is **not** picked by this proposal either — the proposed schema is agnostic to
  which of the 4 known variants eventually supplies `Evidence`'s own value.

## Mathematical evaluation

- **Consistency**: the schema itself is internally non-contradictory (no field appears with two
  different meanings) — but this is **a designed property of the proposal, not evidence that it is
  correct**.
- **Completeness**: still incomplete, by design (the two items above are explicitly left open).
- **Information preservation**: preserves every field named as significant by any of the 3 source
  records, at the cost of introducing one genuinely new resolution (dropping `Π` in favor of explicit
  `Provenance`, and separately-tracked `Policy`) that **no source document proposes**.
- **Novelty disclosure**: the `Π`-avoidance move above is the single most consequential new element —
  flagged explicitly, not buried in the schema's own field list.

## Verdict

**A genuine synthesis, honestly labeled as new.** It is the only option that does not require choosing
which source record to discard, but it purchases this by introducing one explicit, disclosed piece of
new governance judgment (the `Π`-avoidance resolution) that goes beyond what any existing evidence
directly supports.
