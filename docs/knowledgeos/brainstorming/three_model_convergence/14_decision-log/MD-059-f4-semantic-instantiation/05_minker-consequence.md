# MD-059 §05 — MinKer Consequences (§9 of the authorizing prompt)

1. **Does F4 now have a semantic representative?** **PARTIAL** — `Obs_F4`/`Sat_F4` exist as
   definitions (MATHEMATICALLY DERIVED IN FORM, `02`), but are not computable pending a
   decomposition-independent body for `Sat` — the same status F3 would have had before MD-050's own
   work fixed its atom table. F4 is closer to representable than F1/F5/K0, but not yet a usable
   representative.

2. **Does F3/F4 quotienting become meaningful?** **NO**, for two independent, both precisely-named
   reasons: (a) `Sat` has no decomposition-independent body yet, so `Obs_F4` itself is not computable
   (source-stated, M0132 — see `01a`); (b) even if it were, `04` shows no bridge exists between F3's
   atom-space and F4's requirement-space, so a shared `Q,𝒪` for quotienting both together cannot
   currently be posed.

3. **Can any preorder `⪯sem` be derived from existing corpus requirements?** **NO — not derived.**
   The most natural candidate — ordering `K_t` states by requirement-satisfaction (`K_t ⪯ K_t'` iff
   `Sat(K_t,r) ≤ Sat(K_t',r)` for all `r∈Req(EC_t)`) — is expressible in the same non-invented shape
   as `Obs_F4`/`Sat_F4`, and would plausibly BE a preorder (pointwise ordering of a function into
   `{0,1}` is always reflexive/transitive) — but it inherits the exact same blocking dependency
   (`Sat`'s missing body), and additionally would need the composition-rule question (§N) resolved
   before any *transition-respecting* ordering (one that behaves sensibly under `δ`/`Orgasm_t`/merges)
   could be claimed rather than a purely static snapshot ordering. **Not derived here — named as a
   plausible candidate, explicitly not adopted, per the authorizing prompt's own §9.5 instruction not
   to invent a preorder.**

4. **If not derived, identify exactly why.** Two independent blockers, both already-named corpus
   gaps, not new inventions of this phase: `Sat`'s missing decomposition-independent body (source-
   stated, M0132; structurally analogous to but distinct from `𝒪_K`/R10 from MD-058) and the
   composition-rule choice (`P-12`/`P-13`/UE-3).

5. **No preorder invented.** Confirmed — none proposed as adopted.

6. **No existence/uniqueness of a minimal element claimed.** Confirmed — with only one candidate
   (F3) fully computable and F4 only partially, `MinKer` over the real population remains exactly as
   ill-posed as MD-058 found it, now with a second, independently-diagnosed reason (registry closure
   AND a cross-candidate type bridge, rather than only "primitives missing").
