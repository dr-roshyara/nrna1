REPRESENTATION, SAME CONCEPT/DIFFERENT GRANULARITY, SAME CONCEPT/DIFFERENT DDD CONTEXT, FUNCTIONAL
ANALOGY, PARTIAL CORRESPONDENCE, GENUINELY DIFFERENT CONCEPT, UNRESOLVED.

**None of these apply, because the breakthrough documents never assert an identity claim between two
capability/concept descriptions in the first place** — the C1–C13/G-C1–G-C9 items are each a single
