# MD-050 §4 — Scope Limits, GA-001/GA-038 Impact, Backlog

## What this construction does NOT establish

**No cross-family comparison was performed or is possible with this construction alone.** `Beh_𝔠`
was only constructed using F3's own already-existing vocabulary (atoms, carriers, derivation rules) —
it says nothing about F1 (the frozen 8-primitive tuple) or F5 (C1's DDD-aggregate), because neither
has ever been described in ANY vocabulary this construction could operate on (MD-049's own finding is
unchanged by this phase — F1 and F5 remain entirely unrepresented). **This is a within-F3 result
only**: it compares different operator subsets of the same candidate family against each other, not
different candidate families against one another.

**This construction is not adopted as "the" `Beh_𝔠`.** It is one disclosed, well-motivated modelling
choice (`Beh_𝔠(K):=Reach(Ops(K))`), not a corpus-established fact — a different, equally legitimate
choice of what "observable behavior" means could yield different results. It is reported, and its
derivation is fully disclosed, precisely so it can be checked, challenged, or superseded.

## GA-001 / GA-038 impact

**Both UNCHANGED.** GA-001 (Kernel identity across model families A/B/C1/C2) requires a cross-family
comparison this construction does not perform. GA-038 (`K_t` canonicalization) is untouched — this
construction concerns operator/capability reachability, not `K_t`'s own tuple structure, and F3's own
`K_STATE` carrier plays only a passive role in the derivation rules used here (rule 20, a no-op
self-loop).

1. A working, non-circular, source-grounded instantiation of MinKer's own `⪯_cap`/`≡_sem` formulas —
   the first anywhere in this MD-044–050 arc.

   redundant) are now formally proven, for F3's own vocabulary, from first principles (atom-set
   inclusion), not merely cited from the corpus's own prose.

   pattern MD-048's breakthrough documents narrate but never demonstrate.
4. The name-correspondence between MinKer's 13 names and F3's own operator set is upgraded from
   "candidate" to "strongly indicated" (§1) — still short of confirmed identity, since no document
   anywhere cites the other by name.
