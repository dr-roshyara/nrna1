## Revised classification

**This is materially stronger than "structural correspondence candidate."** A name-for-name match of
12/13 items, including exact agreement on which single name is treated as a late, separately-added
"repair" rather than a base member, is not plausibly coincidental vocabulary convergence. **Revised
classification: STRUCTURAL CORRESPONDENCE, STRONGLY INDICATED** — still short of FORMAL EQUIVALENCE
or IDENTITY, because: (1) no document anywhere explicitly cites the other by name or ID (the citation
gap MD-044 already found remains a real gap); (2) the MinKer chain's own capability list has no
citation trail explaining where it came from; (3) `Infer` has no counterpart, so the two vocabularies
are not identical, only nearly so. **Document identity/authorship connection remains UNRESOLVED**; the
vocabulary-level correspondence is now STRONGLY INDICATED, not merely a candidate.
