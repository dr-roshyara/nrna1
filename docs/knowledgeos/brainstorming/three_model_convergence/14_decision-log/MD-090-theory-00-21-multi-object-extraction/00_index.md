## Method

Given the corpus's own density (23 files, ~840 KB, an estimated 50,000+ lines of dense mathematical
prose), extraction is split across 8 parallel batches, grouped to keep each batch's own internal
mathematical domain coherent (never splitting a part's own definitions across two agents) and roughly
balanced by size (~95–140 KB per batch):

| Batch | Parts | Domain |
|---|---|---|
| A | 01–03 | Foundational distinctions, formal ontology/type system, epistemic semantics/logic |
| B | 04–06 | Knowledge-state transitions; gap-algebra/completeness/closure/**Zero**; evidence-evaluation/**Determination calculus** (`Det_r`/`EvalReq` birth) |
| C | 07–09 | Revision/retraction/non-monotonic knowledge; identity/equivalence/provenance/representation-independence; relations/dependencies/graph-semantics/causality |
| D | 10–12 | Inference rules/models/uncertainty; measurement/quantities/scales/statistics; time/temporal semantics/versioning |
| E | 13–15 | Uncertainty/probability/risk/confidence/decision; causality/counterfactuals/explanation; models/simulation/prediction |
| F | 16–18 | Risk-decision-theory/utility; learning/adaptation/concept-drift; architecture/bounded-contexts/aggregates/invariants |
| G | 19–20 | Persistence as semantic preservation; query/retrieval/search/graph-traversal/RAG boundary |
| H | 21, 21a, 21a-rev2 | Reasoning engine/rule execution/proof objects/verification; two worked examples (evidence→verified determination, worked example→final decision) |

Each agent instructed identically to MD-089's own agents: extract every formal object (not filtered
to the tracked family), classify each per the evidence-object-change-relationship taxonomy in the
master mission's §4/§5/§6, and run the explicit cross-check against the full tracked family. Main
process adjudicates the combined output: Document→Object Impact Map, `TheoryState` updates/openings,
Definition Evolution Registry, Transformation Ledger, Negative-History Register, Cross-Lane Transfer
Register, recomputed unresolved landscape.
