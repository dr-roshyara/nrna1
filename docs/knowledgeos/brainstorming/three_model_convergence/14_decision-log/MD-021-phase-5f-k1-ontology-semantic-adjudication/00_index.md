## A terminology collision, disclosed before anything else

**The authorization's own description of "K-1-B"** ("the verification-lane ontology, including its
explicit two-component formulation and the Assertion expansion") **does not match how this
reconstruction's own Phase 5C used the label "K-1-B."** Phase 5C reconstructed "K-1-B" *from seq
1008* as **the ratified `K_t` over 8 primitives** (the same object D285-1/seq 1006 calls "K-1")
— not the two-component `(𝒜,ℛ)` "verification lane" construction, which this reconstruction has
consistently called **K-2**. This phase investigates **both** readings explicitly rather than
silently picking one:

- **Reading 1 (this reconstruction's own prior usage): "K-1" vs. "K-1-B" = K-1 (seq 1006) vs.
  Phase-5C's K-1-B (seq 1008) — both describe the ratified `K_t`, 8 primitives.** See `01`/`02`/`09`.
- **Reading 2 (the authorization's own description, matching this reconstruction's "K-2"): "K-1" vs.
  the verification-lane ontology `(𝒜,ℛ)` with its Assertion expansion.** This is the substantive,
  evidence-rich question — the corpus's own D285-6 artifact (seq 1007) already executes a rigorous,
  three-level formal equality test between exactly these two objects. See `03`/`05`/`09`.

Both readings are carried through this phase's full artifact set; neither is silently discarded.

## Central research question, answered up front (full evidence in `09`)

*Does ratified K-1 (`K_t` over eight primitives) have the same semantic object, a context-specific
representation, a partial mapping, or a distinct object relative to K-1-B and the verification-lane
ontology?*

**Answer**:
- **K-1 (seq 1006) ↔ Phase-5C's K-1-B (seq 1008)**: **the same object, cited identically within one
  authored document package (D285-1 through D285-8)** — promoted from Phase 5E's "structural
  correspondence" to **FORMAL EQUIVALENCE** (not full demonstrated identity, since no independent
  isomorphism proof beyond shared-package citation was constructed). See `09` for the exact
  justification and its limits.
- **K-1 ↔ the verification-lane ontology (K-2, `(𝒜,ℛ)`)**: **PARTIAL CORRESPONDENCE, precisely typed by
  the corpus's own D285-6 artifact** — semantic equality holds (after unpacking `Assertion`), structural
  equality does not hold, observational equality is refuted (lossy), and the projection map `π_K:
  K_t → (𝒜,ℛ)` is definable but not computable (blocked on an unimplemented `Qualify` function). This
  is **not** a homonym and **not** a simple subset relationship — it is a **lossy semantic projection**,
  precisely as the corpus's own D285-6 concludes. See `05`/`09`.
