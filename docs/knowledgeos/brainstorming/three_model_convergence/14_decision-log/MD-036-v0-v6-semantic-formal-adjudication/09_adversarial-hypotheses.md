# Adversarial Hypotheses

## H1 — V6 is only a representational variant of V0

**Fails.** A representational/notational variant would restate the same mapping in different
language, with no change in which inputs produce which outputs. `V6` genuinely changes the domain
(adds `Defeater`) and produces a directly demonstrated difference in reachability (`04`, `06`). This
is more than notation.

## H2 — V6 changes the semantics of Validate

**Succeeds, with the precise qualification `05`/`06` already established.** The change is in the
*domain of applicability* and the resulting *reachability* of a `Verdict` — a genuine semantic
difference by this study's own definition (matching the standard this sequence has used since
MD-031's own mathematical audits: a change in a partial function's domain and extension counts as
semantic, not merely presentational). It is **not** a change to what a `Verdict`, once produced,
*means* — that remains unaddressed by either rule.

## H3 — V6 adds a genuine invariant/precondition

**Partially succeeds.** It adds a genuine, source-stated additional *required input* that functions
precondition-like in ordinary language (`07`) — but the source itself does not use, or declare, a
separate "invariant" or "precondition" category (`07`'s own finding: `04`'s "Common to all" contract
names only Input/Output/State effects/Information effects/Dependencies). So: **yes** as an informal,
input-requirement-shaped constraint; **not established** as a formally-declared invariant in the
source's own vocabulary.

## H4 — V6 addresses a real methodological failure mode, but its formal semantic effect cannot yet
be established

**Succeeds, precisely.** The *reachability* consequence of `V6` (Claim 1 in `04`) is fully
established — this is not what remains unresolved. What remains genuinely open is whether
"surviving a defeater" provides any *stronger* epistemic guarantee than merely requiring one more
carrier's presence — "survive" is left undefined (`03`), so the deeper methodological content behind
the `fit ⇒ validation` critique (Claim 2 in `04`) is illustrated by analogy, not formally derived
from `Validate`'s own definitions. This hypothesis captures the split finding most precisely of the
five.

## H5 — the evidence is insufficient to adjudicate V0/V6

**Fails.** Substantial, precise adjudication was possible: the domain difference, the reachability
consequence, the classification on the seven-level ladder (`STRUCTURAL CORRESPONDENCE`), and the
DDD/mathematical characterization were all establishable from the four admissible sources. The
evidence is not insufficient — it is bounded and unevenly detailed (rich on the "what changes,"
sparse on the "why it's an improvement, formally"), which is a different, more precise finding than
"insufficient to adjudicate."

## Summary

| Hypothesis | Result |
|---|---|
| H1 (representational variant only) | Fails |
| H2 (changes semantics) | Succeeds, qualified to domain/reachability, not meaning-of-Verdict |
| H3 (adds a genuine invariant/precondition) | Partially succeeds — informal precondition-shaped requirement, not a formally declared invariant |
| H4 (real methodological point, formal effect unresolved) | Succeeds, and is the most precise single characterization |
| H5 (evidence insufficient) | Fails |
