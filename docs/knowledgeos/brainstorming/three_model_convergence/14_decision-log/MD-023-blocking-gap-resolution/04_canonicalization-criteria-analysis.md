# Canonicalization Criteria Analysis (GA-038)

Ten candidate criteria, each tested against the same six questions (§1) before being applied — per the
authorization's requirement not to choose a criterion because it "sounds desirable."

## §1. The six-question test, applied to each criterion

1. Is it already evidenced by the corpus? 2. Is it formally defined? 3. Is it independently testable?
4. Does it distinguish the competing variants? 5. Does it produce a unique selection? 6. Would applying
it introduce an external value judgment?

## §2. Result

**`NO CORPUS-JUSTIFIED CANONICALIZATION CRITERION FOUND` for the `K_t` tuple as a whole**, with one
precise, evidence-grounded qualification: **one criterion — preservation-via-explicit-ratification —
is both evidenced and was successfully applied, but only to `Δ_t` (the gap component), never to `K_t`
itself (the full state tuple).**

## §3. The `Δ_t` precedent, examined in detail

M0104's own framing of the `Δ_t` freeze is explicit: *"freeze-as-constraint, not conclusion"* — this is
not a claim that `Δ_t={r∈R_t:Sat(K_t,r)=0}` was *proven* to be the uniquely correct formalization by any
mathematical necessity. It is a **governance act**: the corpus's own research programme ratified one
already-derived candidate (from M0043/M0047's own axiomatic work) as the going-forward baseline,
explicitly to stop further re-derivation, not because a selection theorem picked it out. **This is the
single most important finding of this whole canonicalization investigation**: the one time this
corpus's own research programme actually closed a proliferating-variant problem, it did so by an
**explicit ratification act**, not by a scientific/mathematical selection criterion. None of the other
9 tested criteria (§1) achieved anything comparable for `Δ_t`, `K_t`, or the Kernel-candidate family.

## §4. Consequence for GA-038

**GA-038 is not resolvable by further mathematical analysis of the existing `K_t` variants.** The
`Δ_t` precedent shows the corpus's own successful path to closure runs through **an explicit governance
act**, structurally the same kind of thing this reconstruction has, since Phase 5K, called "ratification"
— **not** a discovery this study, or any purely scientific investigation, can make on the corpus's
behalf. This is consistent with, and now gives concrete precedent-based support to, the general
principle already governing the K-1/K-2 track (MD-021 handover, MD-022): **research can establish what
the corpus supports and what remains open; it cannot manufacture the ratifying act that would close it.**

**This finding does not reopen or reference the K-1/K-2 governance track itself** — it is an
independent observation about how *this* corpus's *own* research programme (the `phase_measure_theory/`
and math-lane threads specifically) has historically achieved closure, arrived at entirely from `K_t`/
`Δ_t`-specific evidence.
