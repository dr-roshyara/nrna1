# Phase 5H — Source-Research Gaps (explicit list, per the authorization's §2 and §17)

These are gaps in the **corpus's own research**, not gaps in this reconstruction's search effort.
Each is stated with the evidence that it is genuinely absent, not merely unfound.

## Gap 1 — No complete, governed operator register for K-1's 8 primitives

**Evidence of genuine absence**: D285-7's own explicit statement ("`𝒪` never enumerated against the
ratified 8 primitives"); independently confirmed by this phase's full re-read of seq 0630 (exactly one
passing use of "operator" in 2,232 lines). Two independent documents, from different points in the
research programme, agree the enumeration was never done.

## Gap 2 — `Qualify`'s computable algorithm

**Evidence of genuine absence**: D285-6's own explicit statement ("has no body in the corpus, one
undefined hit, Step 170"); independently confirmed by this phase's reading of seq 0795 itself (the
cited "Step 170"), which supplies only a named checklist, not a procedure.

## Gap 3 — `State`'s projection target ("the carrier")

**Evidence of genuine absence**: a corpus-wide search for "carrier" found ten occurrences, all
referring to unrelated concepts (`06`); no document defines what "the carrier" means as `State`'s own
projection target.

## Gap 4 — The Assertion-unpacking conflict (the phase's central finding)

**Evidence this is a source gap, not a reconstruction gap**: the conflict recurs identically in the
corpus's own executable code (`07`) — two scripts, both presumably authored to test the same claim,
use different field sets. No further reading resolves this; the corpus itself has not settled it.

## Gap 5 — `Qualify`'s own arity (1-argument vs. 2-argument)

**Evidence**: seq 0795 gives `CaptureAndQualify(O)` (1 argument); D285-6 gives `Qualify: Observation ×
Policy → Evidence` (2 arguments). Neither document acknowledges the other's signature.

## What these five gaps mean together

**The K-1 → K-2 projection cannot be fully mathematically closed using only evidence already present
in the corpus** — not because this reconstruction failed to find the evidence, but because the
evidence does not exist yet in a closed form. This is exactly the kind of finding the authorization's
own §22 anticipates as valid and valuable: *"The corpus does not contain the mathematical information
required to close this projection."*

## What new research would close each gap

1. **Gap 1**: a governed operator register, following the same discipline used for K-1's own primitive
   list (a frozen, ratified, single-document enumeration with input/output/precondition/postcondition/
   invariant fields).
2. **Gap 2**: a formal predicate or procedure for `Qualify`, replacing the checklist with an evaluable
   condition.
3. **Gap 3**: an explicit definition of `State`'s own carrier — what set, what structure, what
   relationship to the other 7 primitives.
4. **Gap 4**: a single, reconciled `Assertion` schema, with the two existing scripts either unified or
   one explicitly marked superseded.
5. **Gap 5**: a single, reconciled `Qualify` signature.
