## New objects discovered, opened as TheoryState trajectories

1. **`K_t^*` (ideal Knowledge state)** — born position 20. Distinct from `κ(K_t)` (MD-101) and from
   `K_t^A=Extract(...)` (MD-100). Status: DEFINED (`Cn_{R_t}(S_t∪F_{≤t})`), not yet COMPUTABLE/EXECUTED/
   VALIDATED. The segment's own gap statement (`K̂_t≠K_t^*` in general, because `F_{≤t}` is never
   perfectly accessible) is recorded, not resolved.
2. **`Φ` (qualification/recognition function)** — `TheoryState(t=225609, MD-101)`: named as an unknown
   recognition predicate `𝒫(𝒦)→{0,1}` → `TheoryState(t=233107a)`: reintroduced via an external
   ("Perplexity") synthesis as `K̂_t→{Knowledge, Not-Knowledge}`, explicitly labeled by that synthesis as
   "Strong Mathematical Evidence" → `TheoryState(t=233107b)`: **challenged within the same file** — the
   binary codomain rejected, a richer `Status(k,t,C)` proposed instead, and the "Strong Mathematical
   Evidence" label itself downgraded to "candidate mathematical representation requiring investigation."
   Three genuine evidence events for one object, none overwriting the others.
3. **`Fact`** — the segment's own newly-named central open problem. No definition given anywhere in this
   segment; explicitly named as more fundamental, at this point in the corpus's own trajectory, than the
   Kernel question itself.
4. **The multi-lens methodology and its governing rule** ("no lens is allowed to define the object it is
   examining") — a corpus-native methodological instrument, recorded as such (an instrument, per the
   established discipline for lens systems/taxonomies), not as a domain object.
