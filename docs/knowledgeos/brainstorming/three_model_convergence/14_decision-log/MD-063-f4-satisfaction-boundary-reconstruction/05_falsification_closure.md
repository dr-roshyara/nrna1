# MD-063 §05 — Q5: Re-Testing the Four MD-062 Failure Modes — Minimum Required Distinction

For each, the minimum semantic distinction the corpus requires, and its evidence — no repair
designed, only the distinction and its source identified.

| MD-062 failure | Minimum distinction required | Evidence |
|---|---|---|
| **E1 — context sensitivity** (same `K_t`, same field value, different `EC_t`) | A way to record **why**/**for what purpose** a value was judged acceptable, so the same value can be judged differently under a different purpose | `EC_t=EC(S_t,G_t,Q_t,C_t)`'s own stated purpose-relativity (M0043 `[DEF-19]`) — the requirement is corpus-evidenced in principle; **no corpus rule computes it** |
| **E2 — requirement semantics** (same field/values, different requirement meaning) | A **Reason**-shaped channel distinguishing *why* a value is required, not merely *which* value | M0125's own native `Sat`-collapse diagnosis (`04`) plus M0127's own executed Collapse C2 (five distinct contradiction types, all `(1,1)`, distinguished only by Reason/Provenance) — **evidenced for `Standing(p)`, not confirmed for `Sat(K_t,r)`** (`01`'s unresolved homonym question) |
| **E3 — missing-state information** (identical `Σ_t`, differing elsewhere) | A **temporal/history**-shaped channel (M0127's own Countermodel 5, superseded vs. current evidence) | Corpus-evidenced for `Standing(p)`'s own `Context` field, via the commissioned/executed M0127 (`04`); `H_t`/`T_t` exist as *named* V7 components (MD-060) but are never typed — **the corpus names the right kind of component, without ever connecting it to `Sat`** |
| **E5 — partial information** (no-evidence vs. not-yet-assessed) | A **Reason**-shaped channel distinguishing absence-of-evidence from absence-of-assessment | The identical distinction M0127's own executed Collapse C1 names and fixes — **the strongest, most precisely-matched piece of evidence in this whole phase**, still bound by the same `Standing(p)`-vs-`Sat(K_t,r)` caveat |

## Summary

**Every one of the four failure modes has a real, named, corpus-evidenced candidate fix — but every
one of those fixes is evidenced for a *sibling* evaluation object (`Standing(p)`, a proposition's
support status), not demonstrated, by any formula, for `Sat(K_t,r)` itself.** This is the single most
precise statement this phase can make, and it is the basis for `06`'s own Gate-B determination.
