## The word-vs-claim distinction (restated from `01_kernel-population-and-method.md`)

"Minimal" appears in all 116 documents of the Kernel-marker population (a mechanical census fact).
**Of the 13 registered objects, exactly one uses "minimal"-type language that this phase, on
inspection, distinguishes from a formal minimality claim**: KERNEL-OBJ-13 (seq 0080, "minimal trusted
core... explicitly NOT a literal spec" — a design-philosophy statement, self-disclaimed by its own
source as non-literal). **Zero of the 13 registered objects make a formally structured minimality
proposition** (a stated criterion + representation + admissible-transformation set + test result) of
the kind Model B's own kernel-reduction experiment produced. The closest approach is KERNEL-OBJ-12's
own definition using the word "smallest" ("the smallest domain-independent bounded context...") —
recorded as an **untested minimality assertion**, not a formally established minimality claim, since no
stated criterion or admissible-transformation set accompanies it.
