**Status: IN PROGRESS.** Executed under the user's explicit authorization of Phase 5C only

## Purpose

Reconstruct the distinct Kernel **research objects** actually evidenced in the corpus — their
definitions, representations, invariants, operators, provenance lineages, and relationships — and
adjudicate apparent Kernel identity/equivalence **without assuming** that differently- or similarly-
named Kernel candidates are the same object. This is an object-level reconstruction and equivalence
investigation, **not** global model convergence.

## Central methodological correction carried forward from Phase 5B

**A keyword match is not evidence of a conceptual occurrence.** Phase 5B found that 4 of 5 apparent
early C2-vocabulary occurrences were keyword-census false positives (a classifier's own forward-
looking "bridge candidate" note, and one explicit absence statement). This phase treats every
consequential Kernel claim with the same discipline: no object, lineage, or equivalence is inferred
from shared terminology, directory membership, classification label, `kernel_content: true`, bridge
candidates, filename similarity, chronological proximity, repeated summaries, or prior analytical
records alone.

## Five-level evidence typing (unchanged from Phase 5B, applied throughout)

Level 1 (direct source evidence) · Level 2 (machine-observable corpus fact) · Level 3 (reconstructed
provenance) · Level 4 (research interpretation) · Level 5 (hypothesis). Where an object-register
attribute cannot be evidenced at any level, it is recorded **`NOT EVIDENCED`** — never filled from
plausibility.

## Two units of analysis, never converted into one another

**Document unit** (a source file, `seq`/`M####`) and **research-object unit** (a named/formally
distinguishable Kernel construct). One document may contain multiple objects; multiple documents may
describe one object. An explicit document→object mapping is maintained in
`03_kernel-provenance-graph.md`.
