# Phase 5G — Observation/State Adversarial Audit (H1–H4 test)

## Observation

Testing the four required hypotheses against the evidence (D285-6 §4b; seq 0979):

- **H1 — intentionally represented in another layer**: The Sañjaya construction (`W --Ω--> O`) is
  independently corpus-formalized (2026-08-26), predating the D285 package (2026-08-31) by five days
  — it was **not invented to answer this question**, which strengthens H1 (a pre-existing construction
  was found and cited, not manufactured post hoc).
- **H2 — omitted primitive**: **Not supported** — D285-6 §4b explicitly revises an earlier, stronger
  claim ("REVISED 2026-08-31: the observation layer is NOT missing") specifically to rule this out.
- **H3 — semantically reducible to another K-2 construct**: **Not directly supported** — Sañjaya is not
  itself a construct *of* $K_2$; it is an external layer $K_2$ can, in principle, map into via
  `Qualify`.
- **H4 — unresolved**: **Partially applies** — the *structural* question (does a recovery path exist)
  is resolved (H1); the *computational* question (can the mapping actually execute) is not
  (`Qualify` undefined).

**Verdict: H1, qualified** — Observation is intentionally represented in another layer (Sañjaya), and
this is the strongest-evidenced of the four hypotheses, but the connecting function making that
representation *usable* by $K_2$ remains unimplemented. **This confirms Phase 5F's own conclusion**,
restated with the required hypothesis-test discipline rather than accepted by default.
