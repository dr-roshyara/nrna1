# MD-088 §03 — Statistical Independence Assessment (Correcting MD-087's Own Overstatement)

## The error, stated precisely

MD-087's own closing language — "ten increasingly targeted evidentiary tests... all converge" —
invited a reading of ten *independent* confirmations. This is incorrect. Per the mission's own §5, and
consistent with this reconstruction's own standing discipline (already applied to the "five independent
rediscoveries" correction, MD-084), the ten sweeps must be classified by their true dependence
structure, not credited as independent replications merely because they targeted different pairs.

## Classification of the ten MD-087 sweeps

| Sweep | Dependence class |
|---|---|
| `EC` bridging-language (425-file window) | **distinct evidence class** (class 1–4, textual bridging) applied to a distinct object family |
| `r` bridging-language (same window) | **repeated observation** of the *same* evidence class (1–4) and the *same* underlying corpus window as the `EC` sweep — not an independent test, a re-application of one method to a second target within the identical population |
| `Γ` bridging-language (21 T21 parts) | **repeated observation** of the same evidence class 1–4, different (narrower, wholly-contained-within-T21) population |
| `Sat` reversion sweep (T22/Part 21) | **repeated observation** of the same evidence class (17/18, abstraction/notation-change), applied to a sub-population already covered by the `Γ` sweep's own 21-part scope |
| `r_I`'s `causal` origin (`kos/inquiry.py` source) | **distinct evidence class** (13, operational/executable — genuinely different population and method from the textual sweeps) |
| `Sat_c`/executable `Sat` ↔ T21 citation (`research/knowledgeos-sim/` tree) | **distinct evidence class** (13 and 15 combined), same population as the previous row |

**Corrected structure**: of the ten original MD-087 sweeps, only **three genuinely distinct evidence-
class/population combinations** exist — (a) textual bridging-language search (classes 1–4), applied
across three overlapping-to-nested corpus windows (`EC`/`r`'s 425-file window fully contains `Γ`'s
21-part window as a sub-population, which in turn contains the `Sat`-reversion check); (b) executable-
source inspection (`r_I`'s own origin); (c) the `research/knowledgeos-sim/` citation check. **The
textual-bridging results for `EC`, `r`, `Γ`, and the `Sat` reversion are not four independent negative
findings — they are one method, applied four times to nested/overlapping populations, and should be
weighted accordingly**: a single failure of the bridging-language method to find anything, observed
consistently across nested applications, not four separate pieces of corroborating evidence.

## What this changes and does not change

**Does not change**: the ordinal conclusion (zero bridging-language hits found) is unaffected — the
correction concerns how much evidentiary *weight* that single finding should carry, not whether it
occurred. **Does change**: MD-087's own implicit framing (repeated confirmation across independent
tests strengthening confidence) is corrected to the honest structure (one method, one population
family, applied at different granularities — a single evidence class exhausted, not four). This
directly motivates §01/§02's own finding that *other* evidence classes (7, 10, 11, 14) remained
genuinely under-tested — the ten MD-087 sweeps concentrated evidentiary effort on one class (textual
bridging) rather than sampling the full evidence-class space, exactly the risk the mission's own §5
warns against.

## Provenance of the two genuinely independent findings

The two executable-source checks (`r_I`'s own origin; `Sat_c`/executable `Sat` citation) are genuinely
independent of the textual-bridging sweeps and of each other — different populations
(`research/knowledgeos-sim/`'s own `kos/` vs. `kos12/` subdirectories), different authorship contexts
(confirmed no shared session with the T21 rewrite or with each other, per MD-078's own dating), and
different evidence classes (operational/executable vs. textual). These two findings retain full
evidentiary weight as independent negative results.
