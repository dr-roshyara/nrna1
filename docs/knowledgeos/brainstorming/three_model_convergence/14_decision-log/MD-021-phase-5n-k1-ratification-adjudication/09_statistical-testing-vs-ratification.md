# Phase 5N — Statistical Discipline: Testing vs. Ratification (per the authorization's §9)

## Re-quoting the primary source precisely

seq 0757: *"EXP-02's scoped result: the 8-primitive M₄₉ kernel survived 50 attack classes, with the
corpus's own precise wording — no counterexample found in tested scenarios, explicitly NOT a
proof."*

## Testing each required question

- **What population of attacks was actually tested?** **NOT EVIDENCED** in this phase's own accessible
  sources — "EXP-02" itself, as a standalone experiment record, was never located (Phase 5L's own
  finding, confirmed again this phase); only its *summary* survives, in seq 0757.
- **Does "50" mean 50 classes, 50 test cases, or another unit?** The text itself says "50 attack
  classes" — a *class* count, not necessarily a case count; **the number of individual test cases per
  class is NOT EVIDENCED.**
- **Were the classes exhaustive?** **NOT EVIDENCED**, and explicitly contradicted by the source's own
  hedge ("not a proof") — exhaustiveness is precisely what a "not a proof" qualifier denies.
- **Are selection criteria documented?** **NOT EVIDENCED** in any source located this phase.
- **Is test coverage independently reproducible?** **NOT EVIDENCED** — no test harness, script, or
  procedure was found (distinct from the executable scripts already studied in Phase 5H/5I/5J, none of
  which implement an "attack class" test suite for K-1).
- **Is "no counterexample" empirical evidence or a governance assertion?** **Empirical**, per its own
  source (seq 0757 is a research status report, not a `D-FA` ruling).
- **What inferential claim is justified?** *"Within the (unspecified) 50 attack classes actually
  tested, no counterexample was found."* Nothing stronger.
- **Can the test result support ratification?** **Not by itself** — per D285-1's own citation practice,
  the test result is presented as if it were part of the ratification package, but no `D-FA`
  determination cites it explicitly (`06`'s own R6, `UNRESOLVED`).
- **Can ratification be inferred from testing?** **No** — testing and governance ratification are
  categorically different acts (an empirical result vs. an authority's decision); this reconstruction's
  own standing discipline (never conflate the two) is reapplied here explicitly.

## Verdict

**"Tested" and "ratified" are kept strictly separate throughout this phase.** The 50-attack-class
result is a genuine, disclosed, appropriately-hedged empirical finding — it is not, and has never been
shown to be, itself a governance act, and D285-1's own citation practice (presenting it inside the same
cell as "RATIFIED") is the precise source of the conflation this phase corrects.
