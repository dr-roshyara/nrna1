## Row 1 — Kernel

**Model-A concept/structure:** the four-way Kernel-structure `unresolved_equivalence` family (§F:
0219 Proposition/Position/Claim vs. 0216 KnowledgeClaim/Evidence/Determination/Authority vs. "K-1"
KnowledgeAggregate+ConflictRecord+VerificationPort vs. Kernel Candidate v0.2/v0.3's eight-field
structure), plus the ten `alternative_minimal_kernel: true` proposals in the Sañjaya/Arjuna cluster
(§I–§L), plus the scope-corrected KR-SIM "zero kernel candidate" finding (§N, CT-4).

**Model-B concept/structure:** the executed kernel-reduction experiment (§B/§P: C0's 13 operators,
falsified as uniquely minimal, replaced by four representation-dependent cardinality-8 minimal
kernels), plus the four-way Kernel/Knowledge-Space/Epistemic-State/History conflation diagnosis (§L).

**Source references:** Model A — `02_model-a_gita/02_concept-register.md` §F, §I–§L, §N;
`03_contradictions-and-open-questions.md` CT-4, UE-1. Model B —
`03_model-b_mathematical/02_concept-register.md` §B, §L, §P (rows P-1, P-2, P-15).

**Proposed relationship type (as offered by surface similarity):** the two models' kernel-related
material might be read as addressing "the same question" (what is KnowledgeOS's minimal structural
core?).

**Evidence for:** both models independently frame their kernel material as answering the same
architectural question (a minimal, irreducible structural core for a KnowledgeOS-style system); both
independently arrive at an internally *unresolved, multi-candidate* state rather than a single
schema.

**Evidence against:** no corpus-internal act in either model ever names, references, or compares the
other model's kernel material — the two threads were produced entirely independently and never
cross-examined against each other, exactly as CT-4 and Model B's own independence-preserving §L
discipline record. No structure-preserving map has been exhibited between any Model-A kernel schema
(e.g. 0219's Proposition/Position/Claim) and any Model-B kernel operator set (e.g. C0's thirteen
operators). Model A's candidates are *typed schemas* (what kinds of thing exist: propositions,
claims, evidence); Model B's candidates are *operator sets* (what actions are performed) — these are
different formal categories of object, not merely different-sized instances of the same category.

**Preserved differences:** Model A never subjects any of its four kernel-schema candidates to an
ablation or irreducibility test; Model B's kernel-reduction experiment is a specific, executed,
~150,000-trial statistical procedure with no analogue anywhere in Model A's evidence. Model B's
kernel question is explicitly proven **representation-dependent** (§8's hard constraint) — meaning
even a future demonstration that some Model-A schema "looks like" one of Model B's 8-operator kernels
would not, by itself, establish anything, since Model B's own evidence shows multiple non-equivalent
8-operator kernels already exist *within Model B alone*.

**Required assumptions (to advance this row past UNRESOLVED):** a demonstrated map from Model A's
typed-schema objects to Model B's operator-set objects, under a stated representation, shown to
preserve whatever invariants both sides consider essential — none of which exists in either frozen
evidence base.

**Adjudication status:** **UNRESOLVED.**

**Confidence:** Low that any stronger state is achievable without new cross-model source material
(neither corpus was written with the other in view).

**Unresolved questions:** Is "kernel" even the same *kind* of object across the two models (a typed
schema vs. an operator set), or is the shared word masking two structurally distinct research
questions that happen to share a name? This question cannot be settled by either model's own
evidence alone.

## Row 2 — State

**Model-A concept/structure:** the Knowledge Vector/Knowledge State family (§G, UE-2) — at least nine
independently-motivated tuple formalizations, e.g. `K=(R,M,I,P,E,B)`, `KS=(P,E,M,T,U,D,R,Z,τ)`,
explicitly flagged `unresolved_equivalence` by Model A's own corpus.

**Model-B concept/structure:** the K_t tuple-structure family (§G, UNRESOLVED) — at least nine
independently-motivated tuple formalizations, including an outlier 11-component structure with
twenty unreconciled "core invariants" (M0125/M0126), explicitly flagged unreconciled by Model B's own
corpus; separately, K_t/Δ_t itself (§A) is eventually frozen to one canonical definition.

**Source references:** Model A — `02_model-a_gita/02_concept-register.md` §G; `03_contradictions-
and-open-questions.md` UE-2. Model B — `03_model-b_mathematical/02_concept-register.md` §A, §G.

**Proposed relationship type (as offered by surface similarity):** both models independently exhibit
the identical *failure pattern* — a proliferating, non-converging tuple family for "state," of
comparable cardinality (9+ variants each), each explicitly self-flagged unresolved by its own corpus.
This is the single strongest surface-level structural parallel found anywhere across the two
evidence bases.

**Evidence for:** the shape of the unresolvedness is genuinely similar — not merely "both have a
state concept" (a weak, generic claim any two formal systems would satisfy) but "both independently
produced *the same number order of magnitude* of non-convergent variants, and both corpora explicitly
name this as an open problem in their own terms" (Model A's 0261: "whether the now-eight unreconciled
Knowledge-vector variants converge... remains open"; Model B's M0048: "another unreconciled variant in
the recurring K_t-structure debate").

**Evidence against:** no specific Model-A tuple variant is shown to correspond to any specific
Model-B tuple variant — the component sets do not literally overlap (Model A's variants draw on
`Region`/`Method`/`Identity`/`Provenance`/`Evidence`/`Belief`-type components; Model B's on
`Requirement`/`Assessment`/`History`/`Zero`/`τ`-type components with a distinct formal vocabulary).
The parallel is at the level of **research-process pattern** (how each corpus behaves when it tries
to formalize "state"), not at the level of **shared content**.

**Preserved differences:** Model B's K_t/Δ_t triad (§A) *does* eventually converge to one frozen
definition (`Δ_t = {r ∈ R_t : Sat(K_t,r) = 0}`) for the gap component specifically, even while the
broader K_t tuple-structure family (§G) remains unreconciled — a partial convergence Model A's
Knowledge Vector family has no counterpart to (Model A's evidence base ends, at seq 0264, with the
question still fully open, no analogous freeze recorded).

**Required assumptions:** none stated; this row does not require an assumption to remain at its
current level, since its finding is about the *pattern of unresolvedness itself*, not about a claimed
object-level identity.

**Adjudication status:** **UNRESOLVED** at the object level (no specific tuple-to-tuple mapping
demonstrated or attempted by either corpus). **PARTIAL CORRESPONDENCE** at the meta/process level (the
proliferation-without-convergence *pattern* itself is genuinely shared) — recorded as a distinct,
weaker claim from the object-level one, not conflated with it.

**Confidence:** Low for object-level correspondence; moderate for the meta-level pattern
observation, precisely because it is a low-commitment claim (about process, not content).

**Unresolved questions:** Is proliferation-without-convergence for "state" formalizations a general
feature of under-constrained epistemic-state modeling (i.e., would any sufficiently rich attempt at
this produce the same pattern, independent of Model A/B's specific domains), or a coincidence of two
research programmes sharing a project history? Carried to `04_non-convergences-and-open-questions.md`
as a labeled **PROPOSED CROSS-MODEL HYPOTHESIS**, not asserted here.

## Row 3 — Representation / examination-instrument discipline

**Model-A concept/structure:** the 26-lens system (§D) — "the lenses are instruments for discovering
and challenging architecture. They are not components of the Kernel."

**Model-B concept/structure:** the Structure-First representation apparatus (§F) — induced
equivalence `∼_π`, the Representation Adequacy Principle, the tested-and-rejected Hilbert-space
representation (§I).

**Source references:** Model A — `02_model-a_gita/02_concept-register.md` §D. Model B —
`03_model-b_mathematical/02_concept-register.md` §F, §I.

**Proposed relationship type:** both models discipline themselves against mistaking an examination
instrument/projection for the object it examines.

**Evidence for:** the meta-move is genuinely shared in spirit — Model A's "lenses are not Kernel
components" and Model B's "a representation cannot recover distinctions its projection has already
destroyed" (§F) are both, at bottom, warnings against conflating the tool with the thing.

**Evidence against:** Model A's lens discipline is a **governance instruction** with no formal
apparatus (no projection map, no equivalence relation, no adequacy principle, no tested rejection of
a specific representation); Model B's is a **formal mathematical framework** with a defined relation,
a stated principle, and an executed rejection (Hilbert space). The two operate at entirely different
levels of formality.

**Preserved differences:** Model B's framework produces falsifiable, tested claims (Hilbert-space
rejection); Model A's produces a standing governance rule applied by human judgment, never formalized
or tested as a mathematical proposition.

**Required assumptions:** treating "an instrument used to examine X is not part of X" as the relevant
shared function — a coarse-grained reading that discards nearly all of Model B's actual formal
content to make the comparison hold.

**Adjudication status:** **FUNCTIONAL ANALOGY** (level 3 of the six-level ladder — a shared role,
not a shared structure).

**Confidence:** Low-to-moderate; the analogy is real but thin.

**Unresolved questions:** none beyond what is already recorded — this row is not expected to develop
further without new evidence.

## Row 5 — Operator / role-function

**Model-B concept/structure:** the thirteen ablation-tested C0 kernel operators (§B) — Observe,

Revise, Determine, Select — plus the discovered fourteenth, Qualify (§C).

**Source references:** Model A — raw source as above; `02_model-a_gita/02_concept-register.md` §I,
§J. Model B — `03_model-b_mathematical/02_concept-register.md` §B, §C, §P (row P-3).

**Proposed relationship type:** a specific sub-correspondence, verified against raw source rather
than assumed: Sārathi Function 8 ("recognize when knowledge has become sufficient for the next
action") vs. Model B's `Determine`/`Qualify` operators and THM-9 ("Reachability ≠ Epistemic
Adequacy," §D).

**Evidence for:** both are, at bottom, about the same question — when is what is known *enough* to
warrant proceeding to action/conclusion? Function 8's language ("recognize when... sufficient")
and THM-9's distinction (reaching a state ≠ that state being epistemically adequate) address a
genuinely overlapping concern.

**Evidence against:** Function 8 is one compound, narrative-level guidance behavior (never formalized
beyond a prose description in its own source); `Determine`/`Qualify` are individually ablation-tested

Function 8's prose description and any operator's formal signature. The other eight Sārathi

multi-operator, relationship-level behaviors (e.g. Function 9, "Preserve human agency," is a
governance/authority constraint matching Model A's own §J invariant, not an epistemic operator of
Model B's kind).

**Preserved differences:** Sārathi Functions are behaviors of a *role* (Sārathi guiding a Knower, a
two-party relationship); C0's operators are primitives of a *kernel* (an isolated formal system,
ablation-tested independent of any relationship structure). This is a persistent categorical
difference, not merely a granularity difference.

**Required assumptions:** that a compound, narrative behavior can be meaningfully decomposed into
one or more of Model B's primitives without a stated decomposition procedure — not attempted here,
and not available from either frozen evidence base.

**Adjudication status:** **UNRESOLVED** overall; **FUNCTIONAL ANALOGY** for the specific
Function-8/`Determine`-`Qualify`/THM-9 sub-pairing only, and even that is not stronger, since no
formal decomposition is demonstrated.

**Confidence:** Low.

**Unresolved questions:** would a stated decomposition procedure (breaking each Sārathi Function into
a sequence of Model-B primitives) reveal a structural correspondence, or would it fail because
Sārathi Functions are irreducibly relational in a way C0's isolated-kernel operators are not? Neither
model's evidence answers this.

**Source references:** Model A — `02_model-a_gita/02_concept-register.md` §H, §J. Model B —

**Proposed relationship type:** both use "invariant" as a named technical term.

against.

## Row 8 — Equivalence (the shared-vocabulary trap)

**Model-A concept/structure:** `unresolved_equivalence` used throughout Model A's own register and
contradictions document (§F, §G, UE-1 through UE-5) as MD-017's procedural default.

**Model-B concept/structure:** the identical MD-017 procedural default (§G's K_t family, for
example), **plus** two domain-internal formal relations: `∼_π` (§F, induced equivalence) and `∼_Λ`
(§H, tested and proven **not transitive**, FR-001).

**Source references:** Model A — throughout `02_concept-register.md` and
`03_contradictions-and-open-questions.md`. Model B — `03_model-b_mathematical/02_concept-register.md`
§F, §G, §H.

**Proposed relationship type:** both models are saturated with the word/relation "equivalence."

**Evidence for:** the *procedural* usage is genuinely identical — both reconstructions were built
under the same `protocol.md`/MD-017 discipline, so both default to `unresolved_equivalence` in
exactly the same circumstances (a plausible-but-unproven correspondence between two same-model
concepts).

**Evidence against:** this identical procedural usage is evidence of a **shared reconstruction
protocol**, not a shared domain theory. Model A's source content never itself defines a formal
equivalence relation — every `unresolved_equivalence` tag in Model A's register is the
*reconstruction's own annotation* on Model-A material, not a construct the Gītā-lineage corpus itself
proposes. Model B, by contrast, has domain-internal formal relations (`∼_π`, `∼_Λ`) that its own
source content defines, tests, and in one case formally refutes (FR-001's non-transitivity proof) —
a level of formal machinery with no Model-A counterpart whatsoever.

**Preserved differences:** this difference is total, not partial — Model A has zero domain-internal
formal equivalence relations; Model B has (at least) two, one of which has been proven to fail a
basic relational property.

**Required assumptions:** mistaking the shared *reconstruction methodology* (both models built under
the same protocol) for a shared *domain finding* — precisely the error the authorization's
non-negotiable principle exists to prevent. This row is recorded specifically to make that
distinction explicit, not to advance a claim.

**Adjudication status:** **INCOMPATIBLE** at the domain level (Model A has no domain-internal
equivalence relation to be equivalent, or non-equivalent, to Model B's); **the procedural-vocabulary
overlap is real but is a fact about the reconstruction programme's own methodology, not about either
model's theory content**, and is recorded as such rather than as any form of cross-model
correspondence.

**Confidence:** High that this classification is correct.

**Unresolved questions:** none — this row exists to document a trap avoided, not a question left
open.

members, no defensible mapping).

**Confidence:** Moderate for the methodological-level claim; high that the value-set-level claim does
not hold.
