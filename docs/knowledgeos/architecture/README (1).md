# KnowledgeOS C4 / PlantUML Architecture Set

These diagrams represent the **proposed architecture developed in the KnowledgeOS / AI Engineering Platform discussions**. They should be treated as an architecture proposal until the corresponding PO/ARB decisions are accepted into the authoritative model.

Files:

- `01-system-context.puml` — C4 System Context
- `02-container-architecture.puml` — C4 Container view
- `03-component-knowledgeos.puml` — C4 Component view
- `04-contract-neutrality-fact-model.puml` — contract-neutrality fact-model view (C4-style component view)

The fourth diagram is not a classical C4 level by itself; it is an architecture-detail view for the L3→L5 contract-neutrality boundary.
