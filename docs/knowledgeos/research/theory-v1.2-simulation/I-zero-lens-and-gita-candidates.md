Zero Concept v1.2 §27 proposes:

```
ZeroLens(K, I, Γ, L) = 𝓑(K, I, Γ, L)          the BOUNDARY, richer than any truth value
π : 𝓑 → V                                      a POTENTIALLY LOSSY projection
```

> a coarse codomain was being asked to carry heterogeneous boundary conditions. **Two independent
> derivations, one conclusion.** `[EXP]` + `[CORPUS]`

## 2. Test — does the boundary formulation repair **D-0**? **Yes, 6 / 6** `[EXP]`

D-0 (Experiment G) found that all four `Zero` readings test only for `F` and `U`, so a contradictory
state — value `UNDEFINED`, `C` or `U` depending on the model — **closes under every reading**.

Implemented `ZL(K,I,Γ,L) → B` with boundary conditions typed
`{NotEstablished, Conflict, Unrepresentable, TheoryIncomplete}` and closure defined over `B`:

| model / case | `Zero_weak` | `Zero_reasoned` | **`Zero_boundary`** | repaired |
|---|---|---|---|---|
| three-valued / B2, S1 | true | true | **false** | ✔ |
| four-valued / B2, S1 | true | true | **false** | ✔ |
| delegated / B2, S1 | true | true | **false** | ✔ |

> **Repaired in 6 of 6 contradiction-bearing cases — and under all three contradiction models**,
> because the boundary records the conflict regardless of which value the model assigns to it.

### 2.1 This CORRECTS my own Experiment G conclusion `[NEG]`

Experiment G concluded that *"the codomain question and the `Zero` question are not separable"* and
recommended fixing them in one step. **That was wrong.** They separate cleanly if closure is moved to
the boundary:

> **You do not need to choose among three-valued / four-valued / delegated to stop a contradictory
> state from closing.** You need closure to consult `𝓑`, not `value`. The contradiction-model choice
> and the closure question are **independent** under the boundary formulation.

The blocking conditions the boundary sees, per case (delegated model):

| case | blocking |
|---|---|
| B1 factivity | *none* — every boundary condition is `TheoryIncomplete` |
| B2 revision | `content:Conflict` |
| B3 no-source | `content:NotEstablished`, `evidence:NotEstablished`, `provenance:NotEstablished` |
| S1 contradiction | `content:Conflict` |
| B4, S2, S3 | *none* — all `TheoryIncomplete` |

**B1 still closes** — the factivity counterexample is untouched. The boundary repairs the
contradiction blindness; it does **not** repair `Truth ⟂ Closure`, and should not be read as doing so.

## 3. Test — is `DetectGap` a projection of the boundary? **Supported, with the loss located** `[PROP]`

Zero Concept v1.2 §32 hypothesizes `DetectGap_Q(K) = π_Q(ZeroLens(K,Q,Γ,L))`.

| case | `\|B\|` | `\|Gap\|` | `Gap = π_Q(B)` |
|---|---|---|---|
| all seven | equal | equal | **✔ exactly** |

**Correction to a first measurement I took:** `B` is **not** richer in *cardinality* — one boundary
condition per unsatisfied requirement. It is richer in *attributes*. Across the seven cases only
**three** distinct boundary types occur, and the projection collapses all of them into "unsatisfied":

| `(kind, remediable_by, blocking)` | occurrences |
|---|---|
| `(TheoryIncomplete, theory, False)` | 34 |
| `(NotEstablished, agent, True)` | 3 |
| `(Conflict, normative, True)` | 2 |

> `Gap = π_Q(B)` is **attribute-lossy, not cardinality-lossy.** What the projection discards is
> exactly **kind** (*why* it is a boundary) and **remediability** (*who can act*) — the two fields the
> `Zero_reasoned` reading needs, and the two the `-E` run had to invent buckets for.

### 3.1 Cross-lane convergence `[EXP]`

The kernel-reduction lane (`2026-09-01`) independently found **`DetectGap` derivable in 12 of 12
representations** — the only operator with that property. The Zero lane now proposes it is a
projection of a richer boundary mechanism. **Two lanes, different instruments, same verdict: not a
primitive.** Neither promotes it; the convergence is corroboration, and per v1.2
`corroboration ≠ derivation`.
