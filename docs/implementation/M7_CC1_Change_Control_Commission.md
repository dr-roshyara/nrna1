| Required | Forbidden |

## 4A. The stage this commission added — an OBSERVATION, not a proposed methodology stage

**Authority observation, recorded as stated: governance acts in this programme increasingly take a four-step rather than two-step shape.**

| Early form | Current form |
|---|---|
| Decision → Implementation | **Decision → CONSTRAINT DERIVATION → Implementation design → Execution** |

**Three instances where the added stage prevented a governance mistake:**

| Act | What constraint derivation prevented |
|---|---|
| **AFV-F4** | **Re-disposing an already-discharged Authority act** |
| **M7-F1** | **Assuming the existing convention already applied to contested memberships** — *it did not; the word appears in M7 zero times* |
| **M7-CC1** | **Violating adopted MCR-1 while satisfying the disposition** |

> ### ***The Authority decided WHAT. The change-control commission determined HOW within existing governance constraints. Those are different acts.** ***These cases show how collapsing decision and implementation design CAN ALLOW a correct decision to produce a non-compliant implementation*** — **stated proportionally to three examples, which support the observation without establishing a universal causal law.***

**⚠️ NOT proposed as a formal methodology stage.** *Three instances, and the Authority's caution is adopted: "the evidence is still limited." **It is an increasingly visible pattern, and recording it as a stage would require PMR → MCA → CDR.*** *No candidate is raised.*
