|---|---|---|

> ### ⚠️ **Refinement: the load-bearing test applies at the level of the CLAIM, not the ARTIFACT.**

**The previous four cases (CCP-1 · ERV-1 · AFV-1 · KBI-1) were each classifiable as a whole. This artifact contains BOTH kinds in adjacent rows of one table** — so an artifact-level verdict would have been wrong in one direction whichever way it went.

**And the REMEDY differs from every prior case, because the class differs:**

| Class | Remedy | Why |
|---|---|---|
| Frozen artifact (AFV-1 · KBI-1) | **Annotate** | *Editing would destroy a completed statement* |
| **Continuing operational record (this artifact)** | **MAINTAIN** | ***Annotating a living ledger's header would freeze a document designed to grow*** |

> ***Updating this record's header is NOT "rewriting history" — and the reason is structural: the sealed segments preserve the chronology, so the header carries no historical content that maintenance could destroy. Segment sealing is what LICENSES header maintenance.***

**Remedy: (a) update the header Status to the current state; (b) mark each segment's state table with its as-at point.** *Both are metadata maintenance; no segment body is touched.*

## 13. The principle under test — **CONFIRMED, with two lawful variations recorded**

> ***Changing the governed subject (knowledge artifact → execution evidence) does not change the underlying governance responsibility.***

**Confirmed: this review applied the same responsibility — faithful preservation of governed knowledge — needing no new contract, no new family, no new emphasis slot and no new governance power.**

**Two things DID vary, and stating them is what keeps the principle from being either trivial or false:**

| What varied | Why it does not falsify the principle |
|---|---|
| **The FACETS examined** — stopping integrity has no analogue in the previous ten reviews | ***Recording restraint is part of recording execution. Expanding the facets of a responsibility is not expanding the responsibility*** — otherwise every new artifact type would falsify the principle by definition |
| **The REMEDY** — maintain, rather than annotate | ***The responsibility (historical integrity) is invariant; the MECHANISM varies by object kind.*** A living record and a frozen one discharge the same duty differently |

> ***A principle that survives a change of object while permitting its facets and mechanisms to vary is stronger than one that requires them to be identical — the latter would only ever have held for objects that were already alike.***

**Epistemic status, per the Authority's standing correction: a governance principle derived from this programme's evidence — GOVERNED on repeated evidence, falsifiable, with WITHDRAWN as its lawful exit. NOT a law.**

**The three stabilizers now close three distinct growth routes:**

| # | Principle | Route it closes |
|---|---|---|
| 1 | A new lifecycle **stage** does not imply a new review **emphasis** | *ERV-1* |
| 2 | A new analytical **scope** does not imply a new governance **responsibility** | *KBI-1* |
| 3 | A new governed **artifact type** does not imply a new governance **contract** | *ER-1* |
