## 2. Certification Decision

### 2.1 Per dimension (disposed separately, as the MCA recommends)

| Dimension | MCA advisory | **CDR decision** |

| **Method Design** | Provisionally Certified | **PROVISIONALLY CERTIFIED — accepted.** The design-side gating condition (MCR-1 adoption) is **discharged by §3 of this record** — but the dimension's grade is deliberately **not upgraded today**: a rule adopted this hour has zero executions; validating the *changed* design requires at least one run under it. The upgrade is assessed at the named re-assessment point |
| **Operational Evidence** | Supported by one execution lineage | **ACCEPTED as stated.** No decision available at this table can move this dimension — only new executions can (another architect, another corpus, M7-by-reference, external review). ### 2.2 Rationale

1. **The evidence record supports exactly this and no more.** End-to-end executability, seven demonstrated stress-test capabilities, fifteen components validated for their executed roles, ten confirmed observations — against n=1, one lineage, structural independence never exercised. *Certify* would overclaim; *Return for Revision* has no basis (nothing in the record failed that a bounded, adopted refinement does not repair); *Defer* would waste a decision the record fully prices.
2. **The first use of the two-dimensional model demonstrates its value at this very table:** adopting MCR-1 discharges a design-side condition while leaving the evidence dimension untouched — the dimensions move independently, exactly as designed.
3. **Proceeding is safe under the provisional grade:** M7/M8 by reference execute on a frozen, configuration-controlled baseline whose known defect class is closed by an adopted rule, with the re-assessment point binding.

## 3. Refinements Decision (MCR-1..MCR-6)

All adoptions below are **methodology changes made at the authorized decision point, each traceable to a demonstrated execution instance** — the constitutional rule (*no methodology changes without execution evidence*) is satisfied, not excepted.

| # | Refinement | **Decision** | Effect |
|---|---|---|---|
| **MCR-1** | Member-set fixation rule | **ADOPTED** | Binding SDM rule in v1: each candidate's member set is fixed at Phase C exit (changes thereafter recorded with grounds); every probe enumerates per declared member; a probe over a set ≠ the declared set is invalid by rule. Discharges the design-side certification condition (§2.1) |
| **MCR-2** | Name the demotion band | **ADOPTED** | **Candidate seam** is a formal SDM state (between not-falsified and not-recommendable), with required record-keeping: gap named · reopening triggers · lift-path · disposition semantics |
| **MCR-3** | Re-entry route for Phase-D-born partitions | **ADOPTED** | The route is defined: a bounded, separately-commissioned Phase-B-style collection scoped to the constructed partition's members. **Adoption defines the route; it commissions no run** — any specific re-entry (including CBC-3's preserved finer partition) remains a separate Authority act |
| **MCR-4** | Evidence Restatement stage | **ADOPTED** | The designed sequence includes an optional bounded Evidence Restatement act, orderable by a disposition, with the two fold classes (evidence-affecting vs editorial) defined. "Consolidation never modifies evidence" is now structural, not conventional |
| **MCR-5** | Convergence-semantics statement · lens-independence instrument | **ADOPTED IN PART** | The statement is adopted: every confidence grade must state its independence basis (shared-corpus/shared-lineage vs independent). The **instrument is DEFERRED, not rejected** — no independent lens or corpus exists to calibrate one against; recorded trigger: the first independent lens, corpus, or executor makes the instrument constructible and re-raises the question |
| **MCR-6** | Sequencing + records rules | **ADOPTED** (documentation-class) | An ordering rule for "first acts" in single-executor sessions (SDM-side); one records-management rule for session logs vs sealed records (EOP-side) |
