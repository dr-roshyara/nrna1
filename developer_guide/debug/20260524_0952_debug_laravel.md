# Debugging Tutorial: Laravel POST Routes Redirecting to Root

## The Classic "302 to /" Problem

**Symptom:** POST requests redirect to `/` (root) with no error message, no flash data, no exception. GET requests work fine.

---

## Step 1: Identify the Layer Where Execution Stops

### Add Controller Logging

```php
// In your controller method, FIRST LINE
public function suspend(Election $election): RedirectResponse
{
    \Log::info('Controller reached', [
        'election_id' => $election->id,
        'user_id' => auth()->id(),
    ]);
    // ... rest of method
}
```

**Check the log after running the test:**
```bash
tail -f storage/logs/laravel.log
```

| Log appears? | What it means |
|--------------|---------------|
| ✅ Yes | Controller reached → issue is AFTER controller entry |
| ❌ No | Request intercepted BEFORE controller (middleware or routing) |

---

## Step 2: If Controller NOT Reached - Isolate Middleware

### Bypass ALL Middleware

```php
public function test_post_route(): void
{
    $this->withoutMiddleware();  // Bypass EVERYTHING
    
    $response = $this->actingAs($user)
        ->post(route('your.route'), $data);
    
    $response->assertOk();  // Or whatever you expect
}
```

| Result | Conclusion |
|--------|------------|
| ✅ Test passes | Issue is in middleware |
| ❌ Still fails | Issue is in routing or controller (unlikely) |

---

## Step 3: Binary Search to Find the Culprit Middleware

### Disable Middleware One by One

```php
public function test_post_route(): void
{
    // Start with CSRF (most common)
    $this->withoutMiddleware(VerifyCsrfToken::class);
    
    // Then try auth
    $this->withoutMiddleware('auth');
    
    // Then try custom middleware
    $this->withoutMiddleware(TenantContext::class);
    
    // Then try verified
    $this->withoutMiddleware('verified');
}
```

**Pattern:** If disabling a specific middleware makes the test pass, that middleware is the problem.

---

## Step 4: Check Middleware Execution Order

### Dump the Middleware Stack

```php
public function test_debug_middleware(): void
{
    $route = app('router')->getRoutes()->match(
        Request::create(route('your.route'), 'POST')
    );
    dump($route->gatherMiddleware());
}
```

**Look for:** Middleware that runs BEFORE `SubstituteBindings` but needs session or context.

---

## Step 5: Force Exception to Surface

### Temporarily Disable Exception Handling

```php
public function test_post_route(): void
{
    $this->withoutExceptionHandling();  // ← FORCE EXCEPTION TO SHOW
    
    $response = $this->actingAs($user)
        ->post(route('your.route'), $data);
}
```

**This will reveal the REAL exception instead of a silent redirect.**

Common exceptions you might see:

| Exception | Problem |
|-----------|---------|
| `TokenMismatchException` | CSRF issue |
| `ModelNotFoundException` | Route binding failed |
| `AuthorizationException` | Gate/policy denied |
| `InvalidArgumentException` | Missing constitution rule |

---

## Step 6: Debug Route Binding Issues

### Check if Election is Found

```php
public function test_debug_binding(): void
{
    $election = Election::where('slug', $slug)->first();
    dump('Election found: ' . ($election ? 'YES' : 'NO'));
    dump('Election ID: ' . ($election->id ?? 'NULL'));
    
    // Check if global scope is filtering it out
    $allElections = Election::withoutGlobalScopes()->get();
    dump('Total elections without scopes: ' . $allElections->count());
}
```

---

## Step 7: Check Middleware Priority (Laravel 11)

### View Current Priority Order

```php
// In bootstrap/app.php
$middleware->priority([
    \Illuminate\Session\Middleware\StartSession::class,
    \App\Http\Middleware\YourContextMiddleware::class,  // ← Must be BEFORE SubstituteBindings
    \Illuminate\Routing\Middleware\SubstituteBindings::class,
]);
```

**Critical:** Any middleware that sets tenant/organisation context MUST run BEFORE `SubstituteBindings`.

---

## Step 8: Test Controller Directly (Isolation)

### Bypass HTTP Entirely

```php
public function test_controller_direct(): void
{
    $this->actingAs($user);
    
    $controller = app(YourController::class);
    $response = $controller->yourMethod($election);
    
    $this->assertNotNull($election->fresh()->suspended_at);
}
```

| Result | Conclusion |
|--------|------------|
| ✅ Passes | Controller works → issue is in HTTP layer (middleware/routing) |
| ❌ Fails | Issue is in controller or business logic |

---

## Common Culprits Summary

| Symptom | Most Likely Cause |
|---------|-------------------|
| GET works, POST fails | CSRF or middleware that only affects POST |
| Redirect to `/` (root) | Model binding failure + silent exception handler |
| Redirect to `/login` | Auth middleware |
| Redirect to `/email/verify` | Verified middleware |
| No log, no exception | Middleware intercepted before controller |
| TokenMismatchException | CSRF bypass not working (container refresh issue) |
| ModelNotFoundException | Tenant context not set before route binding |

---

## The Golden Rule

> **When POST requests redirect to root with no error, the problem is almost always in the MIDDLEWARE PIPELINE, not the controller.**

Add `$this->withoutExceptionHandling()` FIRST to see the real exception, then work backward from there.
